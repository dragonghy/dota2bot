# tests/frames/ -- decision frames NOT admitted to the census corpus

A file under `tests/fixtures/` is two things at once:

1. a world a test can load and drive, and
2. a **sample of the corpus** -- roughly two dozen tests glob
   `tests/fixtures/*.lua` and take readings over everything they find
   ("no fixture Axe reaches level 15", "zero Black King Bars anywhere in the
   corpus", "the archive ceiling is level 19", "the corpus carries no creeps").

Those readings are ratchets on purpose: a decision taken while a channel was
empty has to be re-taken once the channel stops being empty. So admitting a
frame is not free, and the price is not the same for every frame. A frame from
the same era as the corpus costs nothing. A frame from a **different era** can
reopen a dozen decisions at once, each belonging to a different question and
each needing its own reading rather than a quick edit to make the suite green.

This directory holds frames of the second kind: real, generated by the same
`make_fixture.py`, reviewable, and loaded by name from a specific test -- but
deliberately outside the corpus glob, so that admitting one stays a decision
somebody takes on purpose instead of a side effect of needing a world to test
in.

**A frame here is not hidden.** The price of admitting it is measured and
written down -- in the issue the frame names below, and in the hero report that
produced it -- so the reopen list is a document rather than a surprise. Moving a
frame from here into `tests/fixtures/` is a work unit: pay the list, then move
it.

## The twelve cast-instant frames (hero 2026-09-10, queue `hero-54`)

The first frames in this tree cut from the **event side** rather than the frame

**The recipe, in full, because it is cheap and nobody had run it** (~4 minutes
per game, zero EC2, S3 read-only -- so it is not batch-desk-only work):

```

awsx s3 cp s3://<bucket>/replays/<game>.dem .

        --t <that t> --hero <focus hero> --roles <that game's analysis.json> -o ...
```

`--t` is the cast timestamp **itself**, not a moment before it: at the ABILITY
