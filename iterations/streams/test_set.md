**但结论的「强度」我改一档,而且这一档决定了以后谁能引用它。** 英雄组的标题写的是
「门的域是分支既有否决的一个**子集**,门每一个想否决的帧,分支已经用一个**严格更弱**的条件否决过」

### Y.2 **改写 §V.7 的桌面预检写法(全队,凡引用过 §V.7 的组必读)**

英雄组 §6 提议把这条先验并进 §V.7:

> 上机一个「新增否决」的门之前,先看它所在的那条分支是不是已经用一个更弱的条件否决了。
> **是的话,新门的域就是一个已有否决的子集,必然是空的。**

**我采纳这条先验,但不采纳这个写法** —— 它在**催生它的那个案例上就是错的**(见 §Y.1),
而它一旦作为全队桌面预检推下去,**杀掉的是活着的 id,且是在桌面上、没有任何语料能反驳的地方杀的**。
这比它想省的那次语料拉取贵得多。**正式写法(替换 §V.7 里的对应条目)**:

> 上机一个「新增否决」的门之前,**把门自己的条件代入外层分支的谓词**,看它把那个谓词逼到哪里。
> 三种结果,**只有第一种能在桌面上判死**:
> **(甲)** 代入后外层谓词**恒假** ⇒ 域**结构性为空**,桌面即可判死。
>   (`wkreincarnmp` 属这一类——它的「外层」在「花蓝」那一侧,但形状相同。)
> **(乙)** 代入后外层谓词**被逼进一个更窄的区域** ⇒ 桌面只买到域的**形状**,**买不到它是否为空**;
>   仍需一次语料读数,**且该读数的有效期只到「造成那个区域的成因」改变为止**。
>   (`axeblink` 属这一类:被逼进「Axe 身边有队友」,而那正是**别的组正在改的量**。)
> **(丙)** 代入后无约束 ⇒ 桌面什么都没买到,老老实实拉语料。
>
> 一句话:**桌面预检能证「空」,不能证「稀」。把 (乙) 读成 (甲),就是把一次语料事实写成了结构事实。**

**§0b 第二十三例(新亚型:被作废的不是某条主张,而是一条方法本身被剥离出它的成立条件)。**
前二十二例都是「某个判据/推理被下游、被环境、被另一分支悄悄作废」;这一例是**一条方法论先验
被从它成立的条件里摘出来推广**,危害面比单个 id 大——因为它会被用在**所有**后续 id 上。
推论(与 §X.6 那条并列):**任何要进 §V.7 的桌面规则,必须自带「它在什么情况下不成立」那一句;
写不出那一句的,不是规则,是这一次的观察。**

已同步改到源码:`jmz_func.lua` 的 `J.ShouldHoldAxeBlinkForCall` 抬头(那里原本把过强的版本写成了
永久记录,是本轮唯一的 Lua 改动,**纯注释、行为逐位不变**)。

- `opp` = 门**会拒绝**一次施法的帧数(R 就绪且不可负担 + calm 代理 + 900 内有健康敌英雄);
- `dom` = **真的施法了**的域内帧 = **门没拦住的漏放**。

**两个数都在计量「门有没有听话」,没有一个在计量「门拿走了什么」。**
这是一道结构性的单向性:**一个完美听话、且有害的抑制型门,在这套指标上得满分。**
`unaff_frames` 虽然算了,但只逐局打印、**不进 totals**,而且它是「R 就绪且不可负担」的
时长,不是「被扣下的出价」。所以条件 (b) 在这份证据上**在任何方向都不成立**——
不能拿它发通行证(§A0 的老陷阱),也不能拿它判有害。

**为什么这件事这一次特别要紧**:GH #59 已经证明该门的**有效域恰好是「储备已经花掉之后」**,
它做的事就是**在 R 就绪但买不起的时候扣住所有 chip 施法等回蓝**。#59 自己的那段逐帧
(`20260820_042607_slot1`,t=463.5..491.5 连续 57 帧扣住 → t=492.2 Zeus 攥着 116 蓝、
R 就绪且仍买不起**死了**)**正是这个门按设计工作时的样子**,不是缺陷。
**扣住**才是它的主要产出,而现有证据对主要产出的观测量为零。

**(b) 可判的最小口径(交录像组,现有语料够用,不需要新花钱)**:两侧**按种子配对**、
**按局归一化**(批测台 12:08Z 第 3 节:本波 Zeus 候选侧局数 **+23.8%**,裸计数必假阳性):
1. **域内施法率**(不是次数):`dom / opp`,armed vs base —— base 侧的 `dom/opp` 就是
   **反事实基频**,armed 相对它的下降 = **被扣下的出价量**(这是唯一能观测到「扣住」的方法:
   被扣下的施法**不产生任何事件**,只能用对照臂的同域施法率反推);
2. **扣住的时长**:`unaff_frames` 进 totals,并拆出「R 就绪且不可负担 **且** 门为真」的连续段长度分布;
3. **扣住的兑现率**(这条最关键,决定 (c) 还成不成立):每个扣住段之后,Zeus **是否真的
   攒到 R 并放出来**,以及**攒到之前先死的比例** —— #59 那一帧属于后者。
