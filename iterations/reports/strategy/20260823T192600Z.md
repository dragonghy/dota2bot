## 3. 杠杆:被 zoning 必须**留下痕迹**(一个杠杆,常数由推导定)

```lua
function J.IsLaneZonedByEnemy( bot, tEnemyHeroes )
	if bot == nil or tEnemyHeroes == nil or #tEnemyHeroes < 1 then return false end
	if J.WeAreStronger( bot, 1200 ) then return false end
	if J.IsSoakCandidate( 'pullzone' )
	and not bot:WasRecentlyDamagedByAnyHero( 6.0 ) then return false end
	return true
end
```

配上调用方的 SAFE-1b(2.0s),armed 语义是「**2–6 秒前有人在打我、此刻有窗口**」——
正是人类勾线的时机(在两波骚扰之间拉,不是一边挨打一边拉)。**6.0 的两个来源都写在源码头注里**:
远程对线攻速下约 3–4 个攻击周期;而且它是**本语料能回答的最宽 lookback**
(fixture `recent_window = 6.0`,loader 对更长的**会静默 clamp**)—— 更大的常数
不是更大胆而是**不可测**,这条边界写成了断言而不是信任。

**unarmed 逐字节等价于旧表达式**(抽成 helper 是为了能在真实帧上普查:
端到端谓词在本语料**结构性不可达**,见下)。
