## 2. ⭐ 主判据:前两次普查给的是上界,这一次给的是恒等式

普查一、二都住在 `X.ConsiderItemDesire["item_tpscroll"]` 里,那里每个分支触发都只能
是**上界** —— `X` 是 file-local,`X.CanJuke` / `nAttackAllyList` / 外层
`nMode == BOT_MODE_RETREAT` 从 fixture 一律读不到。

`bots/mode_retreat_generic.lua` 的早退链不一样:

```lua
if J.ShouldStayAndRegen(bot)     then return BOT_MODE_DESIRE_NONE end  -- PROMOTED
if J.ShouldRegenNotWalkHome(bot) then return BOT_MODE_DESIRE_NONE end  -- gated 'stayfield2'
```

两条都是**顶层 `if <helper>(bot) then return`**,而且**中间没有任何 return**
(`MRG_RETURNS_BETWEEN 0`,sweep 与测试**两处独立推导**)。于是

> 第二条被求值 **⟺** 第一条答 FALSE

是**恒等式不是上界**。`srnwh_armed_true_live` 因此是**域**,不是天花板 —— 三次普查里
第一个能这么说的格子。

**⛔ 恒等式只覆盖两条之间。** pair 上游还有 **3 条 return**(死亡/免疫修饰符、WK 复活、
开局前对人类线),它们对两条**同样成立所以在 shadow 里抵消**,但 19 是「pair 被到达
的前提下」的域。这 3 条**钉成一个数**(`MRG_RETURNS_ABOVE 3`),第四条不能悄悄进来。

## 4. ⭐⭐ 交给总监的那块证据:这个 atom 的两半不对称

`stayfield` 与 `stayfield2` 是**同一个谓词**挂在两个地址上 —— 两个 wrapper 除 id 字符串
外逐字相同(结构断言),而且**逐帧核对过**(`core_disagree 0`)。它们是已注册 promote
atom **`field_hold_needs_magnitude`** 的两半,standing plan 是**同一波 arm**。

- 上一轮量出:`stayfield` 在其**唯一调用点**('撤退:3')上**至多可达 1 帧**;
- 本轮量出:`stayfield2` 在其**唯一调用点**上**恰好可达 19 帧**。

⇒ **同一波 arm 产出的不是两个可比读数,而是一个杠杆加一个近乎 no-op**,
而且事后**无法把联合裁定拆开**。

**建议(交总监,不代总监决定)**:要么两半分波,要么明确把该波记作 **`stayfield2` 单腿**
的读数、`stayfield` 另行取证。任何一种都比「读完再想怎么归因」便宜。

## 5. ⭐⭐⭐ 符号仍然一格一格量 —— 本格是三次里最强的良性

上一轮立的规矩是「**『查到 shadow』本身不是判决,符号要一格一格量**」。本格:

两条线返回的是**同一个** `BOT_MODE_DESIRE_NONE` ⇒ 被遮的 5 帧上 **bot 的决策逐字相同**。
输掉这场竞速**什么都没丢**,丢的只是**测量**(一波 arm 会把这 5 帧读成 no-op)。

这条**钉在结构上**(`MRG_SWH_RETURNS_NONE` / `MRG_SRNWH_RETURNS_NONE`),不钉在计数上——
计数说不出这句话。三次普查的符号各不相同:

1. 普查一:shadow **吃掉了一个域帧**(有代价);
2. 普查二:赢家**守得至少一样好**(良性);
3. 普查三:赢家**做同一个决定**(最强的良性)。

## 6. ⭐⭐⭐⭐ 载荷性更正:`stayfield2` 自己的注释把两个盲点排错了序

该 helper 的注释把 (1)**未归因的危险读数**放第一位并附了钉帧(lina,全局大招从 7.5k 外
读成贴脸),(2) flask/tango-only 的补给读数放第二。本语料上这个排序**一点都不接近**:

| 列 | 值 |
|---|---|
| `sf2_live_swh_noflask` | **19 / 19**(盲点 2,**每一帧**) |

**连带的波次算术(直接可用)**:`stayattr` 是专修盲点 (1) 的独立 id,它让 PROMOTED 那条
