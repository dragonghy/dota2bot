## 2. 阻塞点(本轮真正的发现):fixture 世界里**没有任何 modifier**

`tests/mock/bot_api.lua` 的 `default_for` 对任何没被 spec 覆盖的 `Is*/Has*/Can*` 返回
`false`,`NumModifiers` 返回 0。于是 **repo 里每一个 fixture、每一个英雄、每一帧**:

```
unit:HasModifier(任何名字) == false      NumModifiers() == 0
```

这不是「少个便利字段」,是**一条没人声明过的世界断言**:没人被缠绕、被晕、被沉默、被变羊、
在读 TP、身上带任何 buff。两个后果都是静默的:

1. **整段已发布分支在 fixture 里结构上不可达**:上表九处全部;
   `X.ConsiderItemDesire['item_tpscroll']` 开头那张十条 modifier 否决表;
   **`J.ShouldAbandonTpChannel`(本组 gated id `tpwatch`,在 eligible 集内)第一行就是
   `if not bot:HasModifier('modifier_teleporting') then ... return false end`**
   —— 也就是说 **`tpwatch` 的逻辑本体从来没有在任何真实帧上跑过一行**。
2. **测试可以断言错的东西还全绿**:见 §4 的负结果 —— 本轮取到的那一帧,主角其实**被缠绕**,
   旧 fixture 世界把他呈现成可以自由走动,「他这里应该撤退」是可以断言出来并通过的。

与总监 §F 记的 `GetTower` / `GetIncomingTrackingProjectiles` 两个缺口**同一类**。

## 3. 工具链修复

- **`tools/batch_test/replayscope/make_fixture.py`**:新增 `active_modifiers()`,用整局解析出的
  `MODIFIER_ADD` / `MODIFIER_REMOVE` 配对重建每个英雄在 t 时刻**仍然生效**的 modifier
  (与 `replayscope/build.py` 画 CC 倒计时用的是同一套区间匹配,只是不再只留 CC 白名单),
  每条输出 `name / remaining / elapsed / stacks`。**该英雄当帧没有时整块省略**,
  所以旧 fixture 的世界逐字节不变。
- **`tests/mock/replay_fixture.lua`**:接上 `HasModifier` / `NumModifiers` /
  `GetModifierName` / `GetModifierRemainingDuration` / `GetModifierStackCount`。
  引擎索引 0-based,而 jmz 的读者(`J.GetModifierTime` / `J.GetModifierCount`)扫的是
  `for i = 0, NumModifiers()`(**多一格**),那一格必须无害 —— 已断言。
- **`stacks` 的诚实边界**:combat log 的 stack **数值**语义没定论(观察到
  `MODIFIER_STACK_EVENT` 连续两次都是 value=1),所以这里数的是**事件条数**,不是引擎自己的
  计数器,且只在真的看到堆叠证据时才 >0(否则省略 → loader 答 0,对非堆叠 modifier 正是引擎真值)。
  **在 dumper 落下实体真实 stack count 之前,不要拿它去钉
  `J.GetModifierCount(...) >= N` 那种阈值。** 已写进两处注释。

## 4. 钉住的真实帧,和一条负结果

`tests/fixtures/f_260819_223607_sniper_rooted.lua` —— `20260819_223607_slot1` @ **t=563.5 (9:23)**,
subject sniper。同一帧上**同时真实存在**三种东西:

| | modifier | 剩余 | 录像 ground truth |
|---|---|---|---|
| 控制 | `modifier_crystal_maiden_frostbite` | 2.0s | 562.5 CM 命中,sniper 从 562 到 572 **一步没动** |
| 增益 | `modifier_item_mask_of_madness_berserk` | 5.0s | 562.5 开 MoM,568.5 到期 |
| 读条 | drow 的 `modifier_teleporting` | 1.8s | 560.3 起跳,**565.3 无干扰落地** |

**负结果(明说,本轮不写 gated 修复)**:这一局唯一两次 MoM **都不支持** `roamreach` 那种伤害:

- **窗口 1(562.5–568.5)**:buff 到期后他确实又打了 4 秒,但那 4 秒**打死了 Crystal Maiden**
  (t=572.2,+554 金 +922 经验)。而且开头 3 秒他是**被 Frostbite 缠住**的 ——
  「站着不动」不是陈旧命令的证据。**照着这帧写修复就是照着误读写修复。**
- **窗口 2(609.2–615.2)**:刚复活、TP 出泉水,整整 6 秒**1600 内一个敌人都没有**。
  这是一次**白扔的自伤 buff**,属于**物品使用**问题(英雄/物品组),不是命令边界问题。

⇒ 九处站点的形状我认为是对的,但**取到的这一份帧证据不足以支撑改动**。要动它们,
需要一帧「buff 到期 → 目标逃走 → 追出去且没有收益」的实证。现在**工具链已经能取到**了。

## 6. 顺带发现的一个 bug(已上报,**没修**)

是给第一个接线的人埋的雷。归总监的 `[bug]`,本轮**不动**(一个词的改名会在有人接线的那一刻

`attempt to call field 'GetCastPoint' (a nil value)`。
