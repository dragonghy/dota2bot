## 2. 但下面一层是坏的:**赢了竞价,动作却打了小兵**(新发现)

出价审计做完,按总监 §0b 对**动作类**缺陷的推论(「动作类 → 断言动作真的达成了 helper
假设的那个状态」)继续往下走一层,撞到这个:

### 2.1 机制(静态可证,读代码即可)

`bots/mode_team_roam_generic.lua`:

- `hTargetCreep` 是**文件局部变量**,**只有一个写者** —— `GetDesireHelper` 里的
  last-hit 分支(L267 附近);
- 那个写者**位于全部六条提前 return 的出价分支之下**:
  `X.ConsiderHelpWhenCoreIsTargeted`(**已发布**)、`ConsiderHelpAlly`(**已发布**)、
  `J.ShouldPunishDive`(`ownhalf`)、`J.ShouldPunishOverchase`(`overchase`,**此刻在
  armed 集内**)、`J.ShouldInitiateLaneKill`(`l1trade`)、
  `J.ShouldSupportComboKill`(`l5combo`);
- 它**从不在帧开头复位**(旁边的 `bDefensiveCollapse` / `bLaneKillCommit` /
  `IsAvoidingAbilityZone` 都复位了,它没有);
- `Think()` **第一件事**就是 `if J.IsValid(hTargetCreep) then Action_AttackUnit(...) return end`
  —— 排在每一条 `Action_AttackUnit(targetUnit)` **之前**。

于是:**任何一帧,只要上面六条分支之一赢下竞价,这个模式的 Think 就去打「上一帧那只
小兵」并 return,它自己刚刚算出来的集火目标一次都不会被碰到。**
出价说「扑那个孤身入侵者」,动作说「继续补刀」。

### 2.2 帧证据(真实帧,端到端)

`tests/test_roamstale_collapse_action.lua` 在真实帧上跑**两帧**真的
`GetDesire()` + `Think()`:

- **帧 N−1**(入侵者尚未压上来 —— 把 Juggernaut 挪到 (3000,3000),其余一个字节不动):
  没有分支提前返回 → 真的 last-hit 分支执行 → `hTargetCreep` 被盖上;
  动作 = `Action_AttackUnit(小兵)`。**断言出来的**,不是假设的。
- **帧 N**(Juggernaut 回到 fixture 里的真实坐标):
  `ShouldPunishDive` 返回 Juggernaut,`GetDesire()` = **0.72**(赢下竞价),
  而 `Think()` 发出的唯一动作是 —— **`Action_AttackUnit(上一帧那只小兵)`**。

这**机械地解释了 `ownhalf` 的立案观察本身**:「232228,WK 满血、晕已就绪,在一个 69%
血的落单 Juggernaut 旁边 ~1000 码悬停了 17 秒」。不需要假设 punish 分支有没有触发、
出价够不够高 —— 它触发了,出价也赢了,只是动作被上一帧的小兵吃掉了。

### 2.3 这是总监 §0b 的第八例,而且是**新的一种**

前七例都是「消费方把 helper 的推理作废」或「验收世界退化」。这一例是:
**出价完好无损、而且赢了竞价,被这个 mode 自己的 `Think()` 丢掉。**
(#37 的 `lf_rescue` 是最接近的一例 —— 那里落点让「一步」变成 8 秒;这里连动作都没发出。)

## 3. 改动(gated,一个小杠杆)

`GetDesireHelper()` 开头、紧挨着已有的两个复位:

```lua
if J.IsModeTurbo() and J.IsSoakCandidate('roamstale') then
    hTargetCreep = nil
end
```

**可分离性论证**(与 `capmono` 的「纯 min」同一形状):last-hit 分支在**每一帧到达它时
都会重新赋值**,所以 armed 的差集**恰好**是「某条提前分支返回了」的那些帧;armed
**只可能移除一次残留的小兵攻击,不可能新增一次**;并且**不改变任何一处出价**
(`hTargetCreep` 在被赋值之前没有任何读者)。未 armed / 非 turbo 时残留句柄**逐字节保留**。

**依据 (c)**:(1) 这个变量的名字、它唯一的写者、它唯一的读者三方都认为它是「**本帧**的
补刀目标」,只有那条缺失的复位不同意;(2) 标准打法:已经决定扑一个落单入侵者的英雄不会
把这个窗口花在补刀上 —— 惩罚越位的全部价值就在于它是有时限的。

**诚实边界**:armed 时,若某条提前分支触发但 `targetUnit` 被 `Think()` 的 leash 闸
(>1800 / 失效 / 对线期超攻击距离)清成 nil,则该帧 armed 不发动作、shipped 会补一刀。
这是本改动唯一的"少做一件事"的情形,已如实记进 `state.json`。
