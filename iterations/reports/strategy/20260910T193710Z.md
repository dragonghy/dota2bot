## 3. ⭐ 真正坐在那里的是它的邻居:尺子被喂了正确种类的东西,只是只喂了一个

`bots/FunLib/aba_special_units.lua`:

```lua
function X.IsHeroWithinRadius(tUnits, nRadius)
    if J.IsValidHero(tUnits[1]) and J.IsInRange(bot, tUnits[1], nRadius) then
        return true
    end
    return false
end
```

它**唯一的调用者**(`:203`,grimstroke 墨兽 / weaver 虫群 / tidehunter 锚那一支)问的是一个
**存在量化**的问题:

```lua
if not X.IsHeroWithinRadius(tEnemyHeroes, botAttackRange - 130)
then
    return 0.96
end
```

交给它的名单是 `J.GetEnemiesNearLoc(bot:GetLocation(), 1600)`,而那个 producer 按
`GetUnitList(UNIT_LIST_ENEMY_HEROES)` 的迭代序 `table.insert`,**全程没有任何 sort**
(§1b 是从出货源码里读出来的,不是记忆)。

**⇒ `[1]` 是集合里的任意一个成员,不是最近的那个。**

**后果不是抛错也不是恒假**(这是与上一轮 `tombhp` 的分界):当近处那个英雄不是 `[1]` 时,
helper 答 false,调用者读成「没人贴我」,于是 bot 用 **0.96(接近满值)**的欲望走上去打一个
**召唤物**,而一个敌方英雄就站在它的攻击距离里。

调用者相邻那行 `if #tEnemyHeroes == 0 then return 0.9 end` 已经花了一行区分
「一个英雄都没有」和「没有英雄**靠近**」—— 后者正是这个 helper 该答的问题。
