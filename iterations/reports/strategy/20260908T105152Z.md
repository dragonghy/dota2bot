## 4. ⭐⭐ 下沿的缺席是算术,不是疏忽 —— 而且只能结构钉

同一条带上的**决策侧**杠杆 `J.ShouldDeepSipNotTpRecover`(`tpdeep`,今天早些落地)
带 **0.10** 下沿,理由它自己写着:野外一口是 115(tango)/ 85(faerie fire)/
135(bottle 一充),低于 `0.18 − sip/MaxHealth` 时**一口已经抬不回家族自己的地板**。

**大药是 400。** 对那份算术所依据的 6 级以上 turbo 区间(900–1400 血)是
**0.29–0.44** ⇒ `nHP + 400/MaxHealth >= 0.18` 在这条带上**处处成立,包括零**。
抄兄弟的常数会**丢掉本臂域的一半**(6 帧里 3 帧在 0.10 以下)。

⇒ 缺席**用结构钉**(`DEEP_NO_LOW_EDGE`,两种拼法都数:`nHP <` 与
`GetHP( bot ) <`),**不用域计数钉**。理由是上一轮 M6/M7 的教训:
域计数是下一轮会 re-baseline 的东西,**缺席是下一轮会「顺手补齐」的东西**。
变异台 **M5**(把 0.10 抄进来 —— 长得像「让两条深带杠杆一致」)**被抓两次**:
结构钉一次,0.096 那帧一次。

## 5. ⭐⭐⭐ 锚唯一性差点把账记到兄弟头上(GH #550)

地板本来自然写成家族通用的两行:

```lua
local nHP = J.GetHP( bot )
if nHP >= 0.18 then return false end
```

第二行与 `J.ShouldDeepSipNotTpRecover` 的**带上沿逐字节相同**,而
`tools/agent/mutstand_tpdeep.sh` 的 **M5 正锚在它上面**,且那台子把
**歧义锚当作整台失败**。⇒ 那样落地,**一个与 `tpdeep` 毫无关系的改动会让
`tpdeep` 的台子整台中止**,而失败会显示在 `tpdeep` 名下。

改写成 inline 的 `if J.GetHP( bot ) >= 0.18 then return false end`(全文件出现 1 次),
并把这件事**在本文件里钉住**(`DEEP_FLOOR_INLINE` + `TPDEEP_BAND_LINE_COUNT == 1`),
让「有人把它 tidy 回 local」在**做这件事的地方**变红,而不是在会被误归因的兄弟台子
里变红。变异台 **M6** 就是这条,**被抓**。
