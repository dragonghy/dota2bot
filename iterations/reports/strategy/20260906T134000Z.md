## 4. ⭐⭐ 立法级:**一个恒零的计数器必须先证明它数得动**(本轮最值钱的一条)

`flip_false_to_true`(「这是个否决,不可能把 FALSE 变成 TRUE」)在本语料上**永远不会被 bump**——
方向由构造固定 —— 所以**把那条 bump 删掉,读数逐字节不变**。

变异台 **M14 首跑 SURVIVED**。按证据纪律第 2 条,嫌疑人是**断言不是变异体**:
**那个 0 从来没有被测量过。** 它是 GH #171 的形状,但这次丢的不是一个桶,是**一条方向断言** ——
而方向断言恰恰是这一族每一条杠杆的安全论证的**地基**。

修法(可复制):两个方向合进**同一个 `tally(a, b, sDown, sUp)`**,**再调用一次、把两条腿对调**:

```lua
tally(shipped, arm,     'flips_g200',         'flip_false_to_true')
tally(arm,     shipped, 'dirprobe_down_g200', 'dirprobe_up_g200')   -- 读数 0 / 12
```

「`flip_false_to_true` 必须为 0」所走的那条分支,**正是对调那一次必须报出整个域(12)的那条分支**。
删掉任一分支现在都会让一个**非零**列动。补了 **M14b**(镜像分支)和 **M14c**(对调探针本身),三发全 CAUGHT。

## 5. ⭐⭐⭐ 本轮唯一的合成标量,以及为什么必须是两列

shipped 函数最后一条是 `if not bHasRegen and bot:GetGold() < 90 then return false end`。
**gold 不进 `.dem`(GH #495)**,mock 的 `^Get -> 0` 让 shipped 在 1012 帧里只有 **13 帧**答 TRUE,
**而那 13 帧一帧都没有塔** ⇒ 单列 `flips` 会打出一个 **0**,和「这条杠杆没用」逐字节相同。

做法:**语料跑两遍**(gold 0 / 200),**两列都断言**,并把 gold 覆写**声明成本次测量里唯一的合成标量**
(sweep 顶、测试顶、`state.json` 三处各写一次)。gold=200 那遍 shipped TRUE 集 = **125 = 前缀行走逐位相同**,
这证明 gold 子句是前缀与 TRUE 之间**唯一**的东西。变异台 **M10** 就是这条构造的变异体。

⚠️ **方向与四个兄弟相反**:`stayattr`/`staysrc`/`staybottle`/`staybag` 全是**加法**,
本 id 是这个函数上**第一个减法 id**。已写进交棒。
