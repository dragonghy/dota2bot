## 4. 改动(gated,turbo-only,一次一个小杠杆)

`bots/FunLib/jmz_func.lua`:

```lua
function J.ShouldStepOutBeforeTpChannel( bot )
	if not J.IsModeTurbo() then return false end
	if not J.IsSoakCandidate( 'tpchew' ) then return false end
	if bot == nil or not bot:IsAlive() then return false end
	if bot:IsRooted() then return false end
	if not bot:WasRecentlyDamagedByCreep( 3.0 ) then return false end
	local tNeutrals = bot:GetNearbyNeutralCreeps( 700 )
	return tNeutrals ~= nil and #tNeutrals > 0
end
```

⭐ **接入方式是 append 不是 insert。** 已 promote 的 `J.ShouldNotStartInterruptibleTp` 里,
英雄谓词**仍然第一个被问**:

```lua
	if J.CanEnemyInterruptTpChannel( bot ) then return true end

```

⇒ unarmed 时整个包装器与旧的一行式**逐字节同答**,读的顺序也没动。这正是 `fieldcreep`
当年 append 进 `J.IsFieldRegenSituation` 的同一形状、同一理由 —— 而「顺序没动」是一条
**关于源码次序**的主张,所以它由一条**读源码**的断言钉住,不由返回值钉。

⛔ **唯一调用点**是 `ability_item_usage_generic.lua` 的 tpscroll 分支,且被
`nMode ~= BOT_MODE_RETREAT` 限定 —— **撤退腿归 `tpsafe`/`tpgap`,本 id 不碰**。
