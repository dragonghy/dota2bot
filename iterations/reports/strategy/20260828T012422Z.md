## 2. ⭐ 本轮主产出:一条可复用主判据

> **一个修复从表里拿走条目时,所有另外问「这张表空不空」的谓词必须按同一条规则过滤。
> 否则这个修复会造出一个任何分支都没覆盖的状态——没有东西可做,也没有理由离开——
> 而失效方向是「死锁」,不是「选错」。**

**失效方向的隐蔽处**:每个站点单独看**都没改、都站得住**,所以**没有任何东西会为此转红**。

这是 GH #257/#261/#266 那一族**往上一层**。那边是一个**工具**把文件级推断成站点级;

## 3. 缺陷:两个问题按构造用两张不同的表回答

`bots/mode_farm_generic.lua` 用**两个引擎 API** 读中立,不是一个:

| API | 站点 | 位置 | 被 `campfarm` 包? |
|---|---|---|---|
| `bot:GetNearbyCreeps` | 3 | Think() | ✅ 3/3 |
| `bot:GetNearbyNeutralCreeps` | 2 | `GetDesireHelper()`(只盖 `teamTime` 时间戳,**不发动作**) | ❌ |
| `bot:GetNearbyNeutralCreeps` | **1** | **`Think()`,小兵出口** | ❌ ← **本轮杠杆** |

那一处出厂长这样:

```lua
local nNeutrals = bot:GetNearbyNeutralCreeps(nSearchRange)
if J.IsValid(farmTarget) and #nNeutrals == 0 then   -- 去打小兵
```

**它的极性与 filter 相反。** `campfarm` armed 且 bot 低于 `ANCIENT_MIN_LEVEL(12)` 时,
**攻击表是空的**(那是 `campfarm` 自己声明的后果);而**被它删掉的那些远古**在这里
**仍然被数着**,数着它们**就把出口锁死**。
⇒ **bot 不能攻击它站着的那个营,也不能离开。出厂代码没有覆盖这个状态的分支。**
