## 2. 落地的杠杆:`pgchannel` —— 读条中的 TP 就是撤退本身

### 2.1 缺陷

`J.ShouldAbortDeepSoloPush` 是 **PROMOTED**(每局 turbo 都活),它的撤退消费点是
`mode_retreat_generic` **守卫链上的第一条**(0.92,一个专门挑来压过追杀的数)。
这条路径上**没有任何一处问过「我是不是已经在走了」**。

后果不用我论证,**这棵树自己在两屏之外写着** —— `J.ShouldAbandonTpChannel` 的抬头:

> "the caller raises retreat desire so the move order cancels the channel"

⇒ 一个正在读条 TP 的英雄被 0.92 顶回去:**卷轴花掉,人留在原地**,而那个原地正是
这条守卫刚刚判定他不该待的地方。

### 2.2 证据帧(不是论证,是量出来的)

**`f_260819_222030_jugg_tp_start`,t=437.1(7:17)**:juggernaut 深度 >2500、
最近队友 4,000+、lich **476u** / viper **739u** 在身上、`modifier_teleporting`
**elapsed 0.1**(读条刚起)、`tp_cd 0`。
把 `mode_retreat_generic` 的**真** `GetDesireHelper()` 开在这一真帧上:**0.92**,
逐位等于 pushguard 那条闸(`tests/_pgchannel_sweep.lua`)。

**同一局下一帧,录像组自己冻的 `f_260819_222030_jugg_tp_eaten`,t=439.5**,是结果:
**没有 `modifier_teleporting`**、**`tp_cd 37.7`(卷轴已花)**、hp **733 → 313**、
人还站在 240u 外的**同一个深处**。

**⚠️ 因果的界,写在文件里**:`.dem` 说不出**哪一条指令**打断了那次读条。
TP 读条**不被伤害打断**,所以「自己发的移动指令」是首选解释,而那条 0.92 是**量出来的**;
但同一 2.4s 内的一次晕眩会产生完全一样的两帧。无 bot 侧日志可闭合(`print()` 到不了控制台)。

### 2.3 ⭐ 本轮最该被读的一段:**第一版是个 no-op,而只有把真链开在真帧上才说得出来**

第一版按「最窄」原则写成 pushguard 那条闸上的 `and not <exempt>` 合取项。
在**它自己的证据帧**上实测:**0.92 → 0.75**。接手的是 **`J.ShouldRetreatLaneBurst`**
(`lanesurv` 族,**PROMOTED、活的**,7:17 仍在它的对线期域 `t < 8*60` 内)。
**0.75 取消一条读条和 0.92 一样彻底** ⇒ 那一版**只改了一个数字**。

**而那一版的每一条 gate-plumbing 断言都会通过**:id 在、闸在、调用点在、方向是严格子集。
抓住它的**唯一**东西是「把 `mode_retreat_generic` 的真 `GetDesireHelper` 开在真帧上、
shipped / armed 两条腿都读」。

⇒ **缺陷不是 pushguard 的,是整条链的**:链上没有一条守卫有「我已经在走最快的那条路」
这个概念。⇒ 改成 **VETO**,和另外两条 veto(`ShouldStayAndRegen` /
`ShouldRegenNotWalkHome`)一起坐在**链之上**。
这一条钉在 `tests/test_pgchannel_veto.lua` 的第四条断言(拿掉 pushguard 那条闸后必须
读到 0.75,且 `ShouldRetreatLaneBurst` 必须真的在这帧上触发)+ 变异台 **M6**。

**可复用的一条**:一个「窄」的修法窄到只压住**一条**竞标者时,它是不是修复,
取决于**第二条竞标者是谁** —— 而那是个读数,不是设计判断。

### 2.4 落地的形状

`bots/FunLib/jmz_func.lua` 新增 `J.ShouldLetTpChannelFinish( bot )`,
`bots/mode_retreat_generic.lua` **唯一调用点**,坐在 `RETREAT GUARD CHAIN: BEGIN` 标记**之上**:

- 闸:`J.IsModeTurbo()` **且** `J.IsSoakCandidate('pgchannel')` ⇒ **shipped 一字未变**。
- 域:`bot:HasModifier('modifier_teleporting')`。
- **释放腿两条**:
  - **(a) 活的** —— `J.IsIncomingBurstLethal( bot, 3.0 )`,一个**没有闸的纯谓词**,
    armed 当天就生效:可见敌人此刻就能在读条窗口内打死我,那读条就不是出路。
  - **(b) 今天是哑的** —— `J.ShouldAbandonTpChannel`(`tpwatch`,**从未 armed**)。
    **如实登记:今天这条 veto 只由 (a) 释放**,而 **(a) 在本语料 0/23 帧上触发过**
    ⇒ **释放腿未被见证**(不是构造性豁空 —— 它是活代码,能触发)。
    它是 `not`,所以 arm / promote `tpwatch` 只会把 veto 变**窄**,永远不会变宽。
- **方向**:veto 返回 `NONE`,且只在读条在身时返回 ⇒ **只能降低撤退欲望**,
  永远不能新建或抬高一条闸。

**⚠️ 杠杆的界(第二条,它界定整条杠杆)**:撤退欲望**不是唯一竞标者**。任何别的 mode
赢下拍卖照样发指令、照样取消读条,而本轮测的东西**看不见那些 mode**。
**本杠杆移走撤退那条闸,不承诺读条落地。**
