## §1 缺陷:同一个 `if` 体里的两个域,相隔十一行

出货代码(`bots/mode_retreat_generic.lua:712-730`,改动前):

```lua
function X.LowChanceToRun()
    local nEnemysHeroes = J.GetNearbyHeroes(bot, 900, true, BOT_MODE_NONE)
    if #nEnemysHeroes >= 3 and #nEnemysHeroes >= #nAllyHeroes and botHP < 0.4
        and bot:WasRecentlyDamagedByAnyHero(1) and bot:GetCurrentMovementSpeed() < 330
    then
        if J.IsValidHero(botTarget) and J.CanKillTarget(botTarget, ...) then   -- ← 无界
            return true
        end
        for _, enemy in pairs(nEnemysHeroes) do                                 -- ← 界在 900
            if J.IsValidHero(enemy) and J.CanKillTarget(enemy, ...) then
                ...
                return true
            end
        end
    end
    return false
end
```

外层门**整个都是本地的**:900 环里有三个以上的人、比我方人多、我血 <40%、一秒内挨过打、
移速 <330。它已经确立了「有一群人压在我身上」——然后**第一条腿转身去问一个跟这个圈子无关的人**
能不能被我杀掉,而**下面十一行的兄弟循环把同一个问题问在 `nEnemysHeroes` 上**。
同一个 `if` 体、同一个判定、两个域:一个界在 900,一个**一个距离项都没有**。

**而调用方供得出那个无界的东西**:`botTarget = J.GetProperTarget(bot)`
= `bot:GetTarget()`(当前**命令**目标)退化到 `bot:GetAttackTarget()`,唯一的过滤是
「不是我方英雄/建筑」。测试 §1(c) 把「这个 helper 体内 6 个距离/位置词一个都不出现」
**写成会红的断言**,不是写成说明 —— 哪天有人给它加了距离界,本文件立刻红,而不是继续
声称一个它已经不再拥有的域。

⭐ **这是同一个无界句柄的第三个消费者**:`divepocket`(今天 13:43Z)、`chasering`(16:15Z)、
`runring`(本轮),三个调用点在同一个文件 380 行之内。

**(乙) 按树数站点**:`X.LowChanceToRun` 全仓 **1 个定义 + 1 个调用**(`:452`)。
true ⇒ 撤退出价短路成 `BOT_MODE_DESIRE_MODERATE` 并**跳过它下面的整条梯子**。测试 §1(d) 钉住 1/1。

### ⭐⭐ 为什么必须数分支:答案层面的零是 **by construction**,而本文件把它**证出来**

## §4 反事实:一个真实帧,**只声明一个事实**

真实帧 `f_260820_043039_cm_cask_close` / CM。**声明的那一个事实,逐字**:

两个世界答案相同、`J.CanKillTarget` 调用次数相同(各 1 次)、第一个被问到的单位相同。
⇒ 收窄在它该无为的地方**逐字节无为**。

### ⭐⭐ 本轮挣到的那一条:**一个没有变异体指着的断言,台子不能给它背书**

第一版把 **M3**(反转成员判定)标成「§3(b) 正对照的变异体」。**实测把这个标法打回来了**:
反转**先**打坏环外读数(`b_off` 变 1)⇒ **§3(a) 在 §3(b) 被执行到之前就红了**,§4 也跟着红,
**§3(b) 一次都没被指到过**。而计分板照样打 `caught=7 ... STAND GREEN` ——
**那条正对照当时是未经检验的,而台子看起来在给它背书。**

补法是加一条**只**打坏它的变异体 **M3b**:把那条腿在所有地方关掉,而不是收窄它。
于是 `b_off` 仍是 0 ⇒ §3(a) 全绿;环外反事实 §4 也全绿(armed 本来就该在那里答 false);
**只有 §3(b) 与 §5 看得见「收窄变成了删除」**。

⇒ **通用形式:每一条断言都要能说出「哪个变异体只打坏我」。做不到的那一条,台子对它一句话也没说。**
这是(癸)的下一层:(癸) 问「断言在数答案还是数分支」,这一条问「**这条断言有没有被指到过**」。
两者的共同点也一样 —— **只有跑一遍才分得开,读是读不出来的**。

⚠️ 附带把 M3 的标签改成**实测到的那个**(§3(a)),并在脚本里写明「第一次运行时这里名错了」。
