## 3. ⭐ 本轮真正的产物:检测器学到一种**新的躲法**

`tests/test_corpus_scale.lua` 的判据逐字是「一个**等于今天 fixture 数**的整数字面量,
出现在 `==` **右边**」。**三条红全躲过去了,而躲法有两种、不是一种:**

1. **换分母**(`1012` live frames / `73` pairs)—— 上一轮(`state.json:corpuspin_20260907`)
   已经点名过:「躲过去**只因为 1012 今天不等于 109**」。
2. **⭐ 新:经由具名常量的间接。**
   `local SIGN_SUBSAMPLE = 109` + `assert(tonumber(sub) == SIGN_SUBSAMPLE)`。
   **109 在它落地那天正好就是 fixture 数**,检测器**照样看不见** —— 因为 `==` 右边是个**标识符**。
   **把字面量提升成具名常量(这套件在别处到处推荐的、更整洁的写法)等于给它发了张豁免证。**
   检测器自己那段「WHAT IT THEREFORE DOES NOT CATCH」把 (1) 的近亲写到了,**(2) 一个字都没有**。

**修法**:`assignment_literal` + `equality_compared_names` —— `local NAME = <整数>`
**只在 NAME 在同一文件里被 `==` 比较过时**才算命中。

**⛔ 第二个合取项不是调参,是用测量买来的。** 今天 N=110:
- tests/ 里赋值式整数常量共 **594** 个;
- 其中**恰好 1 个**等于 110(`local Q_MANA_R3 = 110`,Axe Q 三级蓝耗,`test_axe_call_staged_frames.lua:84`);
- 而它**只在 `>=` 下被用过** ⇒ 相等性要求把它排掉,**本次扩展今天多花 0 条豁免**。

朴素写法(「任何等于 N 的赋值」)今天就要多付 1 条,并把 `NOT_A_CORPUS_PIN` 已经在付的
**「每落一个 fixture 一次碰撞」**的账**大致翻倍**。**这是这个更窄的谓词拒绝掉的交易,
而它是靠一次测量拒绝的,不是靠品味。**

**端到端正控制跑了,不是只跑 parser 单测**:往 `tests/test_gate_claim_consistency.lua`
尾部临时插 `local PC_PIN = 110` + `local _ = (0 == PC_PIN)`,检测器**当场红并点名该行**
(`RC_EXIT=1`);还原后 `git diff --stat` 为空。
另有六条负控制钉在 `[detector] the indirection hop is wired, and it is narrow`:
注释掉的声明 / 浮点 / 表达式 / 字面量只是表达式的一部分 / `>=` 用法的名字**不**收集 /
`==` **左**边的名字要收集。
