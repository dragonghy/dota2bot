## 2. 挑中的那一行,和它为什么是同一个谓词写了两遍

`mode_retreat_generic.X.ShouldRun`「前期谨慎冲塔」块:

```lua
if botLevel <= 10 and DotaTime() > 0 and (#hEnemyHeroList > 0 or bot:GetHealth() < 800) then
    if ( botLevel <= 5 or DotaTime() < 5 * 60 ) and nEnemyTowers[1] ~= nil then return 2 end
    if botLevel <= 9 and nEnemyTowers[1] ~= nil and nEnemyTowers[1]:CanBeSeen()
       and nEnemyTowers[1]:GetAttackTarget() == bot and #hAllyHeroList <= 1 then return 2 end
end
```

`botLevel <= 5` 与 `DotaTime() < 5*60` 问的是**同一件事**:「我还是不是脆的前期英雄」。
普通模式里两者几乎重合(5:00 时约 5 级),所以这个析取近似是一句话说两遍;
**turbo 双倍经验之后,同一个墙钟时刻站着的是 7-10 级英雄** ⇒
**时钟腿恰好为等级腿已经放行的那些等级继续开火**。

而这个 `return 2` **不是微调**:`GetDesireHelper` 把 `ShouldRun` 的非零返回变成
**`BOT_MODE_DESIRE_ABSOLUTE * 1.1`**,**压过竞价里每一个模式**。

## 3. 杠杆(一个)与常数的出处

armed(turbo + `towerfear`)**只把时钟腿折半**到 2:30。等级腿、898/980 塔环、
下面那条校准判据**一律不动** ⇒ **armed 谓词是出厂谓词的子集**,这个 return
**只可能少开、不可能多开**。放掉的帧由紧挨着的**校准判据**接 —— 同一个塔环,
但它问的是「塔是不是真的在打我」「我是不是一个人」。
**与同文件 `towerreach` 同形**:接到消费方上的是**粗**的那个,**校准的那个在旁边闲着**。

**折半不是这里发明的(`0NUM`)**:引擎自己把 turbo 的阶段计时器折半,而本仓库**凡是有人
看过的地方都已经照做** —— `Buff/NeutralItems.lua` 四档中立掉落 17/27/37/60 →
**8.5/13.5/18.5/30(四档全是 0.5)**,`J.IsEarlyGame` 10\*60 → 5\*60。
本修法是把时钟腿**对齐到它自己那条兄弟腿声明的成熟度**,不是发明新判据。

**⭐ 语料独立佐证了这个边界**(966 存活英雄帧):被放掉的窗口 `150 ≤ t < 300` 有
**206 帧、均值 4.60 级、其中 42 帧(20.4%)已经过了等级腿**;而 `t < 150` 的 **80 帧
里一帧都没有过**(**0/80**)。**2:30 正是我们自己的 turbo 局里 6 级人口开始出现的地方。**
两个方向都已成断言(0/80 那条**故意留成等式**:它是选 2:30 而不是别的比例的唯一理由)。
