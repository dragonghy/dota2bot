## 1 立案句:两个常数不同意「什么叫残血」

| 函数 | 状态 | HP 带 |
|---|---|---|
| `J.ShouldStayAndRegen` | **PROMOTED**(`tphome`,每一局 Turbo 都活着) | `nHP < 0.18 or nHP > 0.75` |
| `J.IsFieldRegenSituation` | 三个 gated 家族(`stayfield` / `stayfield2` / `fieldbuy`)共用的情境谓词 | `nHP < 0.18 or nHP > 0.55` |

上面那一行是这棵树**自己**对「伤得够重,回家这件事已经摆上桌面」的定义;
下面那一行决定**野外方案到底提不提供**。

⇒ **0.55 与 0.75 之间**:一个残血、**安全**、**两手空空**的 bot 被 PROMOTED 的否决**放行回家**
(那条路上只剩 `bot:GetGold() < 90`,而 90 块钱过了开局几分钟拦不住任何人),
而**唯一一个职责就是「改成买大药」的 id(`fieldbuy`)结构性地说不上话** ——
它的情境谓词认为这个 bot 还没受伤。

## 2 域价钱(先跑,再写第一行代码)

同一份语料(**109 fixture / 1012 活英雄帧**),前置三个数由本轮**独立的前缀行走**复算,
与 §EY / §FA / §FC **逐位对上**:turbo **1012/1012**、走到补给子句 **125**、被否决 **112**。

**112 的三分法(断言为恒等式,不是三个各自独立的计数):**

| 桶 | 帧 | 归谁 |
|---|---|---|
| 主格位有补给 | **44** | `staysrc`(§EY) |
| 背包里有大药 | **2** | `staybag`(§FC) |
| **什么都没带** | **66** | **没有任何 id** —— 不是「读数缺陷」,是**真的没东西可读** |

44 + 2 + 66 = 112 ✅(`test_buyband_hp_band.lua` 断言这条恒等式;三个桶要是不再相加,
就是有一个在重复计数,「66 帧没人管」那句话就变成算术而不是证据)

**owner P2 对这 66 帧的答案是供给侧:买一个。** 那么 `fieldbuy` 为什么没买?

| 66 帧里 | 帧 |

| **> 0.55** | **28** |

`hurt_domain == ns_only_ceiling_blocks + hurt_outside_stay_reach + hurt_with_bag_salve`):

## 3 ⭐ 主判据(立法级,可复用,超出本主题)

**在一棵检测器**按源码文本**解析的树上,函数签名是一个已发布的接口:
动一个共享谓词的代价,由「解析它的声明」的那些文件付,而它们对这次改动无话可说。**

到达这个行为有三条路,**两条走不通**:

| 路 | 为什么不走 |
|---|---|
| (a) 直接把 `J.IsFieldRegenSituation` 的 0.55 抬高 | **一条臂同时动三个家族**(`stayfield` / `stayfield2` / `fieldbuy`)—— `lanefix` 那个 bundle 形状,两次都测出强负 |
| (b) 从 `J.ShouldFieldBuyRegen` 内部传一个 gated 上限 | 那个函数的**第一行就是它自己的 gate**,于是新 id 只有在 `fieldbuy` **也** armed 时才动得了 —— **`pullcad` 陷阱的第二形态**(GH #542,昨天 §FC 立的案) |
| (c) 给 `J.IsFieldRegenSituation` 加一个**可选上限参数** | 「看上去最干净」的那条。**写完了,然后撤销了** |

**(c) 的代价是量出来的,不是猜的**(把那两行改动重新打在副本上、跑完解析这个函数的 8 个文件、
再还原):`function J.IsFieldRegenSituation( bot )` 与 `nHP < 0.18 or nHP > 0.55`
被当作**字面文本**读,于是 **8 个里 7 个同时变红**:

```
RED   test_healthy_walk_home_gap          RED   test_itemtrip_wasteful_trip
RED   test_stayfield_hp_window_reach      RED   test_bagsalve_backpack_source
RED   test_stayfield2_marginal_domain     RED   test_stayattr_global_ult
RED   test_fightback_world_assertion
green test_stayfield_callsite_domain
--- 7 of 8 detector files go RED on the reverted signature edit
```

**第 8 个保持绿色的那个才是信息量所在**:`test_stayfield_callsite_domain` 读的是**调用点**,
而带默认值的参数让调用点**逐字节不变**。⇒ 代价**精确地**落在解析**声明**的那些文件上。
七个里没有一个对这条杠杆有话要说。

**所以本轮的形态**:一个 standalone 函数,**重复**三条环境子句而不是调用兄弟 ——
和 `J.HasNearbyHeroDamager` 当初从同一个扫描里拆出来时**完全一样的理由**
(它的注释逐字写着:把 shipped 调用点改写成与 gated 代码共享,会把一杠杆改动变成一次 shipped 行为的重构)。
重复的代价**付在看得见的地方**:两份拷贝里的**每一个常数**都被解析出来两两比对
(1600 / 1200 / 3000 / 3.0 / 0.18),任一边漂移就红。

## 4 单臂可见性(这条设计的全部理由)

| 量 | 读数 |
|---|---|
| `flips_buyband`(**只** arm 本 id,驱动购买点谓词对) | **20** |

| `flips_fieldbuy`(只 arm `fieldbuy`) | 33 |
| `overlap_buy_hurt`(两臂在同一帧都为真) | **0** |
| `flip_true_to_false`(arm 之后 TRUE→FALSE) | **0** |
| `arm_leak` / `raises` | **0 / 0** |
| `overlap_probe_runs` | **== live(1012)** |

- **`flips_buyband > 0` 是本轮最该被读的一个数**:它是「(b) 那条路走不通」的反面证据。
  零 ≠「语料太薄」——`hurt_domain` 那条独立行走就是用来把这两件事分开的。
- **两域不相交是构造性的**(≤0.55 对 >0.55),`overlap == 0` 仍然实测一遍。
- **⭐ `overlap_probe_runs` 这一列是本轮新加的,理由是 GH #171 的形状**:
  `overlap_buy_hurt == 0` 是一个**全部内容就是一个零**的断言,而
  「探针跑了 1012 帧、什么也没找到」与「探针不跑了」**打印出来一模一样**。
  于是探针现在**数自己跑了多少次**,并断言等于活帧数。变异体 M16 就是这个。

**7.1 值得单独说一句,它是一个「计数不是性质」的教科书例**:
那条断言的自述理由是「**新的调用者可能没继承 turbo**」——
`J.HasFieldRegenSource` 自己**没有** `IsModeTurbo`,安全性全靠调用顺序。
`staysrc` 在 09-05 加了第三个调用点(在 `J.ShouldStayAndRegen` 里,行为是对的:那个函数第一行就问 turbo),
**没人更新这个数**,于是一条职责是「查 turbo 继承」的守卫,有一整天只会说「这个数变了」。
已改成**逐调用者断言那条性质本身**(两条合法路径:先问情境谓词,或自己先问 `IsModeTurbo`),
计数只留作**反真空下限**;两条可证伪性检查改成写 `nCalls ± 1` 而不是字面量,
**这样下次合法新增调用者时,不会连它们一起被静默重新基线**。

7.2 / 7.3 是同一个族:断言想说的是「没有未 gated 的**调用点**」,而一句提到谓词名字的**散文不是调用点**。
两处都改成**先 strip 注释**,并各自补上两条可证伪性检查(真调用仍然触发;引用调用形式的注释仍然不触发)。
