## 1. issue 说什么,我做了什么

采购门 `Item.GetEmptyInventoryAmount`(槽 0..8)与这一族自己的持有判据
`J.HasFieldRegenSource`(槽 0..5)读的槽位不一样,建议把采购门换成

## 2. ⭐ 承重发现:`TrySwapInvItemForFlask()` 每帧都在跑

`bots/mode_team_roam_generic.lua:1854` 有一个出厂的、**无 gate 的**搬运工:
背包里有大药就把它换进主槽。关键是它**不是 roam 专属行为**:

```
GetDesire()        <- 引擎每帧对每个 bot 轮询【每一个】mode 文件的 GetDesire
  GetDesireHelper()
    ItemOpsDesire()            (:271)
      TrySwapInvItemForFlask() (:1775)
```

`GetDesire` 与 `Think` 的区别是这条链的全部要害:`Think()` 只有**赢下这一帧的
mode** 才跑,`GetDesire()` 每个 mode 文件每帧都跑。搬运工挂在后者上。

**这一条不是我对引擎的推断,是本仓库自己的文档白纸黑字写的**
(`docs/BOT_API_REFERENCE.md:49`):

> `GetDesire()` is called **every frame for ALL modes simultaneously**. The mode
> returning the highest desire value wins and becomes the active mode. Only that
> mode's `Think()` is then called.

⇒ **「它写在 roam mode 文件里,所以它是 roam 专属的」是错的**:mode 文件的
`GetDesire` 那一半是**共享的、每帧的、全体的**代码,只有 `Think` 那一半归赢家。
**本轮整个结论压在这条上,所以它引的是文档而不是我的记忆。**

从 `GetDesireHelper` 开头到那次调用之间**只有一条 early return**
(`IsInvulnerable / not IsHero / not IsAlive / 名字不含 hero / IsIllusion`)⇒
**一个站在野外的活英雄一定走到它**。节流是 `SwappedFlaskTime + 6.2`,而
`SwappedFlaskTime` 初始化成**静态字面量 `-90`** ——
**不是第十四条世界断言那个形状**(不是用它稍后要比的那个时钟初始化的),
所以节流真的会放行,大约 6.2 秒一次。全仓库**只有一个 roam mode 文件、没有任何
英雄级 override** ⇒ 没有英雄逃得掉。

以上每一条都在用例里**从源码断言**,不是复述。

## 3. 代价与覆盖,量在同一批帧上

扩了这一族自己的普查(`tests/_fieldbuy_supply_sweep.lua` 新增 `SPLIT` 行),
100 fixture / 930 存活英雄帧:

| 读数 | 值 |
|---|---|
| dry 域帧(这个 id 的域) | **28** |
| 其中六个主槽全满、背包有空位(= 修法会打掉的那些) | **13**(46.4%) |
| 其中出厂搬运工**有主槽物品可换**(`GetMainInvLessValItemSlot ~= -1`) | **13** |
| 真正卡死的(没有可换物品) | **0** |

⇒ 摆在桌上的交易是:**用「放弃 owner P2 要的那个行为的 46.4%」去换「止住一次
12.9% 的浪费」**。而录像组的 12.9% 是**搬运工之后的残差**,不是总体。
**这是 lanefix 的形状**:一条局部站得住的子句,配一个局部论证从没看过的聚合。

**口径(自己先说)**:上面两个数都量在**域谓词**上(`J.ShouldFieldBuyRegen` 的
situation ∧ dry 两条腿),**不是**量在完整的采购合取上(后者还带 stash / 金钱 /
库存 / modifier 几条,本语料答不全)⇒ **13 是「丢掉的采购数」的上界**;
但**28 因为同样的理由也是同一个上界**,而论证压的是 **46.4% 这个比值**。

这一条是一条不可达分支**悄悄替一个它其实在阻止的缺陷背锅**。

## 8. 诚实边界(写在前面,不写在脚注里)

1. **快递投递是建模的**,在 `GetItemInSlot`/`FindItemSlot` 这一层。
   **必须建模**:语料里没有任何一帧背包里带大药 —— 快照是瞬时的,而搬运工
   6.2 秒内就把这个状态清掉了。注入的把手**下游全是出厂代码读真实帧的真实主槽内容**。
2. **换掉哪一件物品这里量不了**:离线 `GetItemCost` 答 0 ⇒
   `GetMainInvLessValItemSlot` 的比价是退化的,返回第一个可换槽。
   只有「**存不存在**可换槽」——搬运工那句 `~= -1` 唯一读的东西——是真结果。
   已断言,免得 `SWAP 6 <-> 0` 被读成「它挑了最便宜的那件」。
3. **本文件不主张那 12.9% 的残差是假的**。它主张**采购门不是它的成因**。
   找真正的成因是另一个工作单元。
