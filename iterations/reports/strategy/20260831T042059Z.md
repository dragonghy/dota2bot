## 2. ⭐ 主判据:旧句子的预设是「每帧都被问到」,而那正是 §CK 否掉的东西

旧句子的两个数就是闭式 `(nBeat − 0.5) / nBeat`:

```
nBeat = 3.0 → (3.0 − 0.5)/3.0 = 83.3%
nBeat = 1.2 → (1.2 − 0.5)/1.2 = 58.3%
```

**算术无误,预设有误**:它假定 `if / elseif / else` 这三条臂在**每一个引擎帧**上都被问到。
`Think()` 开篇的节流阀否掉这个假定 —— 刚右键完的英雄按构造待在 `ACTIVITY_ATTACK` 里一整个
攻击周期 **R**,节拍**只在重开帧上被问到**(§CK / GH #326)。

⇒ 那两个数描述的是 **R → 0** 的世界。而 **R → 0 就是 `creepthink` armed 的世界**,
`creepthink` 2026-08-30 才入集、**至今 gated 未 promote** ⇒ **那不是发货中的世界。**

## 3. ⭐⭐ 重推:真帧上驱动出来的四行,不是重算出来的

驱动世界与 `tests/test_creepthink_anim_throttle.lua` **同一帧、同一驱动器、同一动画模型**
(`f_072738_zuus_mana`,当年钉住 `pullbeat` 的那张压线帧;拉线计划由**真实的 GetDesire**
在该帧上产生)。30 s = **901 帧**/次,R 扫过语料里**唯一测到过的攻击周期带**
1.4 / 1.5 / 1.6 / 1.7 s(GH #326 的四次右键 252.4 / 254.0 / 255.4 / 257.0,gap 1.6 / 1.4 / 1.6)。

| armed | R=1.4 | R=1.5 | R=1.6 | R=1.7 | 登记读数 |
|---|---|---|---|---|---|
| 都不 armed | 0/901 | 0/901 | 0/901 | 0/901 | **0.0%** |
| 只 `pullcad` | 451/901 | 451/901 | 411/901 | 371/901 | **41.2–50.1%** |
| 只 `creepthink` | 526/901 | 526/901 | 526/901 | 526/901 | **58.4%**(R 无关) |

**关掉节流阀(nCycle = 0,即 R → 0)复现**:都不 armed **526/901 = 58.3796%**;
只 `pullcad` **751/901 = 83.3518%** —— 与上表 `creepthink` 那两行**逐位相同**。
⇒ 「旧数字 = R → 0 读数 = `creepthink` armed 读数」不是措辞,是**等式**,
已写成 `[limit L1]` 的两条断言。

**因此不删数字是有理由的,不是照办**:删了就删掉了这张表里两行**真实存在**的读数。

## 4. ⭐ 这条重推把 `pullcad` 抬高而不是压低,而且改变了它的**形状**

- 旧措辞:58% → 83%,**+25pp**,一条「加宽」型杠杆。

⇒ **两条 id 强烈次可加**(单独 0→50 与 0→58,合起来 0→83,朴素相加是 108),

叠在 `creepthink` 上只 +25.0pp),这就是非可加性本身。**本轮不放宽任何并池许可**,

## 7. ⚠️ 诚实边界

1. **41.2–50.1% 是下界**,不是点估计:动画模型**不把走路中的英雄放进 `ACTIVITY_RUN`**,
   而它也在 `meaningfulActivities` 里;引擎里那只会**推迟下一次 poke**,拉长 drag。
2. **0.0% 那一行两样都不靠**:一个从未被下过移动指令的英雄不会在跑,所以模型那个口子够不到它;
   而且它对**任何 R ≥ nBeat** 成立,不只是这条带子(`[control C2]` 钉住带子确实跨在两个 beat 之间)。
3. **R 的带子来自一个 episode(三个 gap)**,是**引用**不是本组的测量;
   本文件**不主张**任何跨波分布。
4. **本轮不裁任何人**:`pullcad` 不 promote、不退回、不改级,`creepthink` 仍 gated,
   成员串一字未动,`queue.json` 一字未动。
5. **动画模型是模型**,它不是从 dump 读出来的(`GetAnimActivity` 在语料上恒 0,
   兄弟文件的 `[W1]/[W2]` 拥有那对世界断言);`[control C1]` 是它不惰性的证据
   —— 同一套驱动在 R < nBeat 时**照样发 drag**。
6. **拉长 drag 会不会赢**是波次问题,本轮未触及;本地settled 的只是**指令发不发得出去**。
7. **全量单进程套件本轮未跑完**(GH #124,~100 min);跑了的是新文件 11/11 + 铁律 6 静态门。
