### 1.1 主判据(闭式,零数据)

`creepthink` 在 `bots/` 里**只出现一次**,是 `and` 的**右操作数**,左操作数是
`bot.roamCreepPull ~= nil`(`mode_roam_generic.lua:265`)。Lua 的 `and` 短路 ⇒
`roamCreepPull == nil` 的帧上 `IsSoakCandidate` **根本不被调用**,合取项恒 `not false = true`,
**armed 与否同值**。记 `R = (roamCreepPull ~= nil)`、`C = (roamCampPull ~= nil)`,
到达 `J.GetLanePullDragTarget`(`:404`,`pulldrag` 的调用点)需要 `C`,而:

1. **控制流**:该调用在 `if C then … return end` 块内,该块**排在** `if R then … return end`
   之后 ⇒ 到达即 `¬R`。只用 `Think` 自己的函数体,不需要知道谁写这两个字段。
2. **互斥**:两字段在 `GetDesireHelper` 里**恰好三处**被写(`:98–99`、`:104–105`、`:108`),
   每一处都令另一个为 `nil` ⇒ `C ⇒ ¬R` 在**任何时刻、对任何调用方**成立。

任一条单独成立即得:**在 `pulldrag` 的调用点上 `creepthink` 的字面量是不可达代码。**

### 1.2 ⭐⭐ 可复用判别式

**共臂行的空性 = 「内层 id 的字面量在外层调用点上可不可达」,而短路 `and` 把它变成一个纯语法问题。**
三步、零数据:(1) 取内层 id **唯一出现处的左操作数**(短路 `and` 的左边就是它的必要条件);
(2) 取外层调用点的**支配条件**(它上面每一个提前 `return`);(3) 问二者是否互斥。
互斥则该行**可证空**,并把蕴含钉成测试。

区别不是措辞:「读一遍判一句」的有效期是读它那个人的记忆;**一条钉住的蕴含会在实现变形那天自己红**
(本轮 M3/M4 就是这个:删掉那个 `return`、或让勾线计划不再 nil 掉营地计划,文件立刻红)。
