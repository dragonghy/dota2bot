## 1. 一句话

GH #344 的 127 条「满血步行回家」落在一条**闭式的、任何 id 都够不到的带子**里 ——
`hp > 0.55 ∧ 4000 ≤ d_泉水 < 10000` —— 而且**没有一条由 (hp, mp, 1600 环, 距离)

## 2. 主判据（闭式，零语料）

| id | 谓词 | 拒绝条件 | 有距离子句吗 |
|---|---|---|---|
| `stayfield2` | `J.ShouldRegenNotWalkHome` → `J.IsFieldRegenSituation` | `nHP > 0.55` | **没有** |
| `itemtrip` | `J.IsWastefulItemTrip` | `hp < 0.55` | 有：`d_泉水 < 10000` |

血量轴**没有洞**（同一个常数两边取，`J.IsWastefulItemTrip` 头注释写明是刻意的）。
洞在**距离轴**上，而且两个 id 里只有一个带距离子句：

    hp > 0.55  ∧  4000 ≤ d_泉水 < 10000     ← 两个 id 都拒绝

其中 **4000 = `FAR_U`**，正是 #344 自己 `walk_home_trips` 定义的起点门槛
（`tools/batch_test/behavioral/stayfield2_margin.py:98`）。

掉头点 **7,065u**、hp **1.000**、mp **1.00**。
**一帧、两个 id、两个彼此独立的拒绝理由**（一个败在血量上界，一个败在距离下界）。

## 4. 第三条，也是最重要的一条：帧级谓词给不出价（**实测**）

在本仓库自己的语料上跑一次一次性普查（**只读**，与 `tests/_itemtrip_sweep.lua`
同一套 glob 与同一套加载器；**107 个 fixture / 993 个存活英雄帧**）：

| 量 | 计数 | 占存活帧 |
|---|---|---|
| `J.IsWastefulItemTrip` 成立（出货常数） | 146 | **14.7%** |
| 健康 + 1600 环空 + `4000 ≤ d < 10000`（**无人管的带子**） | 209 | **21.1%** |
| ↑ 且 `mp > 0.95` | 83 | **8.4%** |
| 健康 + 1600 环空 + `d ≥ 10000` | 146 | 14.7% |

（头注释的历史读数是 135/966 = 14.0%；语料从 104/966 长到 107/993，14.7% 与它一致。）

**把距离下界按 `mp > 0.95` 分档降到 4000，会把帧域从 14.7% 抬到 (146+83)/993 = 23.1%。**
那正是 `itemtrip` 在 33.1% 上被按条件 (b) 退回时的同一个数量级
（总监 2026-08-23 14:58Z，X = gpm −26.44）。
**而且是同一个已经付过一次学费的错误**：这个谓词选的是**帧**（「健康、安全、离家远」
就是一句普通打钱帧的描述），#344 数的是**行程**；那 127 条行程的判别特征
——**掉头回来、手里什么都没多** —— 是一个**行程级**的量，**没有任何一帧带着它**。

⇒ 所以 #344 的「先只观测」不是保守，是**这条路上目前没有别的走法**。
