## 1. 主判据(闭式,零语料)

`J.IsFieldRegenSituation`(`bots/FunLib/jmz_func.lua:5253`)的 HP 带:

```lua
if nHP < 0.18 or nHP > 0.55 then return false end     -- nHP = J.GetHP( bot )
```

`stayfield` 的**唯一**调用点是 `ability_item_usage_generic.lua` 的「撤退:3」分支
(`:5626`),进入条件的 HP 帽:

```lua
if ( botHP < 0.34 or botHP + botMP < 0.43 ) and not J.ShouldRegenNotTpHome( bot ) ...
```

**承重的一步(已写成断言,不是默认)**:该分支的 `botHP` 绑定在 `:5224`,
是 **`local botHP = J.GetHP( bot )`** —— 与谓词读的**同一个函数**。
⇒ 两条带**不需要换算就可比**,它们是同一个量上的两组约束。
(树里另外两处 `botHP` 用的是 `bot:GetHealth()/bot:GetMaxHealth()`,不是这一处;
`binding_before()` 取的是锚点前最后一次绑定,变异 M5 证明它有牙。)

`botMP = J.GetMP( bot )`,而 `J.GetMP` 返回的是**非负量的比值**
⇒ `botMP >= 0` ⇒ 第二个析取项蕴含 `botHP < 0.43`。于是

```
sup( botHP | 「撤退:3」被进入 ) = max( 0.34, 0.43 ) = 0.43      (开,两个帽都是严格 <)
```

**0.43 < 0.55** ⇒ **⭐ `nHP > 0.55` 这条子句在 `stayfield` 唯一的调用点上不可满足。**
下界不是:`0.18 ∈ [0, 0.43)` ⇒ **`hp<0.18` 是两条边里唯一能在 TP 腿上做决定的那条。**

**方向是保守的**:分支其余**十二个**合取项(`itemFlask == nil` / `level >= 9` /
`CanJuke` / 七个 modifier / 攻击目标 / 英雄名 / 离泉水距离)**一律当成已满足**,
在全部给定下结论仍然成立。
