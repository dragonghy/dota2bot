## 1. ⭐ 主判据:`rm -f` **之前**跑,控的是「陈旧文件」,不是「运行中被别人删」

#365 §3 把三条红判成真红,给出的唯一理由是:

> 我特地把 gate 文件删干净后再复跑 —— **删了仍然红**,因此排除了那条解释。

**这个控制不覆盖这个危险。** 开跑前 `rm -f` 关掉的是「树上留了一个陈旧开关文件」;
它对「**运行期间**另一个进程把文件删掉」一句话都没说。两者是同一个共享物理开关的
**两种**失效模式,而只有第一种被开跑前的删除关掉。

而 #365 §2 自己记下了当时并发还在:本轮变异台的 M1/M2 **故意禁用管道守卫**,各自拉起
一个**真的 `routine_selfcheck.sh`**(45s 后被 `PG_TIMEOUT` 杀掉)。那些进程的 Lua 腿
跑的正是这些文件,而**每一个这样的文件都会 `os.remove` 同一个路径**(见 §3)。

## 2. ⭐⭐ 三条失败的读数**逐位等于它们自己文件里的 unarmed 值**

三条全是 armed 腿断言,而它们观测到的值,正是**同一个文件的 unarmed 用例所断言、
并且在同一次运行里绿着**的那个值:

| 文件 | #365 published `got` | 同文件 unarmed 用例断言的值 |
|---|---|---|
| `test_salvepool_missing_floor.lua:398` | `got 500`(anchor pool 890) | `SalveSelfMissingFloor(nMax) == FLOOR`,`FLOOR=500`,sweep 列表**含 890** |
| `test_salveyield_arbitration.lua:354` | 「did not yield」= `false` | `ShouldYieldSalveToAlly(bot, ally, true) == false` |
| `test_tpreach_retreat_exclusion.lua:381` | armed 给出 `false` | **同一个用例体内、往上三行**:`CanEnemyInterruptTpChannel(bot) == false` |

**要用「断言写错了」解释这个,需要三个独立写成的文件各自错到恰好落在自己文件的
unarmed 值上** —— 而那个值每个文件都另外断言了一遍并且通过。
一个共享原因一次解释三条:**armed 腿没读到开关**。

`tpreach` 那条最锋利:published 的红说「ARMED 给了 false」,而**同一个用例体**在它上面
三行断言「开关不在时,同一帧同一个函数给 false」。

## 5. 机制的形状:危险不是「有个流氓进程」,是**套件自己**

`tests/*.lua` 里 **25** 个文件出现这个路径,**22** 个逐字声明
`local SIDE_PATH = 'bots/Customize/soak_side.lua'`,**22** 个含 `os.remove(SIDE_PATH)`;
**0** 个取锁(`flock`/`LOCK_EX`),**0** 个派生进程唯一路径。

关键的一半:**删除不是只发生在 armed 用例的收尾**。`load_with(nil)`(**unarmed 腿**)
第一件事就是 `os.remove(SIDE_PATH)`。所以 **A 文件的 unarmed 用例,就是能在同一瞬间
剥掉 B 文件 armed 腿的那个删除者** —— 两个 lua5.1 进程重叠就够,不需要任何异常进程。

## 8. ⚠️ 诚实边界

1. **强制并发下的复现证明该机制"充分",不证明总监 13:xxZ 那一次确实在并发下**。
   后者是推断,依据是 #365 §2 自己对 PG_TIMEOUT 被杀自检的记述 + 同一棵树上多次
   干净顺序运行全绿。
2. **干净腿是 3 次(加自检那次 54/54,加复跑那次 55/55),不是 soak。** 一个 1/50 概率
   的真缺陷不会被它排除。**被排除的是"确定性的断言错误"** —— 确定性的东西不会绿这么多次。
3. **本文件不裁 `salvepool`/`salveyield`/`tpreach` 是不是好杠杆**,只裁它们的测试为什么红。
   三个 id 本轮**不入集/不出集/不改级**。
4. **补救不在这里。** S3 度量的是「锁与进程唯一路径都还不存在」;落地哪一种是 GH **#229**
   的工作,落地当天 S3 会**故意变红**。
5. 全量单进程套件**未跑**(~100min,GH #124),所以「只有这三条」的上界是 54(现 55)
   个快检测器,不是整棵树。
6. #365 §2 的**泄漏**(跑完文件还在)本轮**没有**复现;本组只报「顺序干净运行下不泄漏」,
   **不反驳**总监的观测(他那次有被杀掉的进程,那正是不会走到 `os.remove` 的那一种)。
