## 1. 缺陷

`bots/FunLib/utils.lua` 的 `HasTeamMemberWithCriticalItemInCooldown` /
`HasTeamMemberWithCriticalSpellInCooldown`:

```
GetTeamPlayers(team)  给的是 玩家 id (天辉 0-4 / 夜魇 5-9)
GetTeamMember(n)      收的是 队伍槽位 (1..5),越界答 nil
```

出厂把前者喂给后者 ⇒ **扫描按侧静默缩水**。pid→slot 家族第六、七处
(前有 `slotarb` #406、`slotdust` #411、`slotpush` #415),也是 `utils.lua` 那一簇八处里
**最后两处活的** —— 另外五处 GH #467 已普查为 `bots/` 内零消费者。

### 1.1 与 `slotpush` 的两处不同,都让这一对**更好推理**

1. **没有 guard/subject 撕裂**。`slotpush` 用 `IsHeroAlive(playerdId)` 守卫、再看
   `GetTeamMember(playerdId)`,是两个英雄;这两个函数的守卫是 `teamMember:IsAlive()`,
   问的是**取回来的那个成员自己** ⇒ 两个世界里守卫与主语都一致。剩下的是**纯漏扫**。
2. **符号相反,而且单调**。唯一消费者 `aba_push.ShouldWaitForImportantItemsSpells`,
   **TRUE = 先别推**。漏扫只能让 TRUE 更难成立 ⇒ **出厂系统性提前开推,只会多推、不会少推**,
   而且是在**夜魇 5 个队友里 4 个从没被看过一眼**的情况下开的。
   出厂 TRUE 集 **⊆** armed TRUE 集,**没有 over 方向**。
   ⇒ 「别在队友 BKB / 大招都没转好时开高地」是标准打法,验证哲学条件 (c) 这一条自带。

## 2. 落地形状:**一个 id 盖两个函数,闸只读一次**

- 闸点唯一:`bots/FunLib/jmz_func.lua:12436` `J.ShouldWaitForTeamCooldowns`,
  `J.IsModeTurbo() and J.IsSoakCandidate('slotwait')` **读一次**、穿给两条腿。

- 消费者的中后期守卫原样保留(**闸不许拓宽定义域**)。
- `typescript/` 三个文件同步(`utils.ts` / `aba_push.ts` / `jmz_func.d.ts`)。

### 3.2 ⛔ 没买到:**决定**

未动的语料上,两个谓词 **98 次求值(49 fixture × 2 函数)0 次 TRUE、0 次 flip**,

**⭐ 本轮最该被带走的一条:那个干净的零是一个语料事实和一台瞎仪器叠在同一张脸上。**
逐条拆开量之后是两件**互相独立**的事:

| 腿 | 性质 | 读数 |
|---|---|---|
| item | **语料事实** | `ImportantItems` 只有两项(BKB / refresher);**223 个存活成员帧里 0 个**持有其一。仪器好的,帧上就是没有 BKB。 |
| spell | **仪器事实**(危险的那个) | 181/223 个成员**在** 88 英雄的 `ImportantSpells` 表里,技能等级与冷却**是从帧上真加载的**(1050 个句柄里 216 个 cd>0)。它依然不可能为真:`IsValidAbility` 最后一个合取项是 `not ability:IsActivated()`,而 `IsActivated` **不在 `tests/mock/bot_api.lua` 任何 spec 上** ⇒ 落到通用 `^Is` 默认 **false** ⇒ **每一帧、每一个技能都结构上为假**。实测 181 个里 **149 死在 `IsActivated`、32 死在 `IsTrained`、0 存活**。 |

⇒ 与 `mock/replay_fixture.lua` 里已登记的 `GetManaCost` / `GetActualIncomingDamage`
两个零同族:**一个静默默认值不是一个小数字,是另一个谓词**。
**新意在于这一次两个原因叠在同一个读数上,而其中一个是良性的** ——
只要有一个良性解释在手,就不会有人去问第二个。
⚠️ 这台仪器的洞**不是本轮新发现**:`test_lf_rescue_final_action.lua:57` 已经逐字点名

**已知 ≠ 已被想起** —— 它从没出现在任何一处「本语料上这个谓词从不为真」的登记旁边,
而那正是它改变读数含义的唯一位置。**本轮不修这台仪器**(改默认值会把大量绿的推红,
属于另一个工作单元的爆炸半径);把它钉在读数旁边,并在测试里加了断言:
