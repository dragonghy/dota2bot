## 1. 杠杆:`WhichLaneToPush` 的目标项要求**严格唯一最小**,而档位是 3 选 4 的小整数

`bots/FunLib/aba_push.lua`,`____exports.WhichLaneToPush`,**全仓一个调用点**
(`:311` `GetPushDesireHelper`,**上面没有任何 gate**),而它决定 `pushLane == lane`,
也就是三个推塔 mode 的整块推进 desire 加成跑不跑。

TS 源(`typescript/bots/FunLib/aba_push.ts`)在这段上面的注释**逐字**写着:

> `// Prefer lanes with lower-tier outer buildings first. Start mid slightly.`

出货实现:

```lua
if     midTier < topTier and midTier < botTier then  midLaneScore = midLaneScore * 0.5 ...
elseif topTier < midTier and topTier < botTier then  topLaneScore = ...
elseif botTier < topTier and botTier < midTier then  botLaneScore = ...
end
```

**每一支都要求自己同时严格小于另外两条**。而 `GetLaneBuildingTier`(同文件)返回
**{1,2,3,4} 的整数**,三条兵线取自四个值 ⇒ **最小值并列是常态不是角落**;
一旦并列,**一支都不跑**,整个目标项**从兵线选择里消失**,由队友距离单独决定。

⛔ **没有任何东西会报警**:没有 `else`,变量全是活的,链本身语法上完全正常;
`luacheck` 报的是它**隔壁**(`bestScore` 的 W311),`check_armed_wiring.py` 问的是
「有没有调用点」不是「谓词能不能为真」,而这个函数里已有的两个 id(`c14`/`c15`)
**坐在这条链下面,从不读它**。
📌 与 GH #851(四个 `or` 拦不住任何 mode)、GH #837(存在量词只问名单前三格)**同族**:
**子句各自正确,域按构造为空。**

## 4. ⭐⭐ 本轮买到的可迁移句:**一个缓存下来的普查键,会把「读者的缺陷」印成「关于语料的合理读数」**

现场,实测,两次:

`tests/mock/replay_fixture.lua` **按位置**从每一帧解析塔与兵营的槽位
⇒ **`TOWER_TOP_1` 这类常量在不同 fixture 之间不是常量**:
有塔的帧上读 **0..8**,一座塔都没有的帧上读**未解析哨兵 1036..**。

于是一个「把第一帧的槽号缓存起来」的普查器,会拿着 `1036` 去问后面每一帧
⇒ 每条兵线都返回空 ⇒ 它打印出来的是

> 「**这份语料一座建筑都没有**」

—— 一句**关于语料的、看起来完全合理的话**,**由读者的缺陷生产出来**,
`EXIT=0`,零报错。实测:缓存版把 **1120 个对里的 1120 个**读成不可读。

📌 **判据(下一轮直接用)**:
**一个跨帧复用的普查键,先问一句「它在下一帧还是同一个值吗」——
按位置解析出来的东西默认不是。**
⚠️ 这条与 0NEXT29 的「跨轮普查集要落地成文件」是**同一族的两个刻度**:
那条管**跨轮**,这条管**跨帧**;两条的失效方式都是**一个没有棘轮的读数看起来很正常**。
两处都钉进了注释(sweep 与测试各一份)。
