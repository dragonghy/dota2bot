## 4. ⭐⭐⭐ 立法级(量具):**presence flag 不能承载一个 COUNT 形状的论据**

变异台第一次跑 **STAND RED / 3 unexpected**,而**两条是锚不是杠杆**。

**(1) M6:`anchor 1` 被回答 `occurs 5 time(s)`。** 变异体要删掉 tpscroll
`'撤退:3'` 那条灵龛否决。item 层在**五处**拒绝
(5585 / 5619 / **5663 = `'撤退:3'`** / 5977 / 6230,其中 **5663 与 5977 连续五行
逐字相同**),`perl s///` 不带 `/g` ⇒ **删掉的是第一处**,`'撤退:3'` 那份
**原封不动**,sweep 的 presence flag **照样读 1** ⇒ **SURVIVED**。

**两件事同时错,而只有一件是变异体**:针不唯一,**并且**它攻击的那个事实是个
**存在标志**,而论据是个**计数**。两处都改 —— sweep 现在**数站点**
(`ITEM_URN_MOD_SITES == 5`),于是**删掉五处中的任何一处都 5→4**,变异体
**不再取决于 `perl` 先够到谁**,而条件 (c) 的论据也从「有一处这么写」升级成
「**item 层五处这么写,PROMOTED 那条零处**」。

⇒ **可复用的一条**:凡是「树里另外几处已经这么写了」型的条件 (c) 论据,
**量具必须数站点,不能打存在标志** —— presence flag 在**删掉五分之一**的时候
是**绿的**。

**(2) M9/M10:同一行在 sweep 里出现两次。** `return armed and sId == 'stayurn'`

## 5. ⭐⭐⭐⭐ 恒零的断言先证明它数得动(承 `staytower` 那轮的 M14)

`flip_true_to_false` 必须为 0(加宽 `bHasRegen` 只能移除否决)。构造沿用上一轮:

`flip_true_to_false_swapped = 2 = flips`、`flips_swapped = 0`。

## 6. 诚实边界

1. **域是 2 帧**,是测量不是道歉。每个 carrier **一行 B 记录并自带停在哪一条子句**
   (band / chase / ring / shipped_ok / domain),五个桶**相加 == `mod_carriers`**
   (数出来的,不是减出来的)⇒「语料里没有灵龛治疗」与「有,但被前面三条子句挡掉」
   **永远不是同一份读数**。M14 把 carrier 普查改读魂之灵瓮 modifier(0 帧携带)
   ⇒ **所有 B 行消失**,CAUGHT。
2. **魂之灵瓮的 `modifier_item_spirit_vessel_heal` 故意不加**:1012 活体帧里
   **0 次**携带,加它就是**未定价的加宽**。由 `STAY_READS_VESSEL == 0` 与
   `vessel_carriers == 0` 各钉一次 —— **它是下一个问题,不是本轮的结论**。
3. **金钱贫穷超集**:gold 不进 `.dem`(GH #495),`gold_nonzero == 0` 断言这一点,
   所以测得的 flip 集是真实集的**超集**;**方向固定、大小不作声明**。
4. **一帧是一个瞬间,治疗有尾巴**:本条只说 t 时刻的决策错了,不声称剩下那一口
   一定够留下 —— 那是 `fieldsip` 在 gated 那一族的问题。灵龛的 **400 血是这套词表里
   单次量最大的一味**,所以它是**最不暴露于这一条**的成员。
5. **GH #89 仍然成立**:fixture 上 `GetActiveMode()` 不是 `BOT_MODE_RETREAT`,
   所以这个缺陷的**另一条腿(item 层的回城 TP)在 fixture 上结构性不可驱动**。
   本文件把它断言下来,那一天缺口补上时套件会报红并要求升级这句话。
