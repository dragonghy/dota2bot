## 3. ⭐⭐ 常数是被实测逼出来的 —— 照抄那个数在唯一存在的帧上域是空的

`bot:WasRecentlyDamagedByCreep` 在证人帧上:

```
1.0 → false    2.0 → false    3.0 → false    3.5 → TRUE    6.0 → TRUE
(五次命中的 dt = 3.2 / 4.2 / 4.2 / 5.8 / 5.9)
```

**`fieldcreep` 和 `tpchew` 都用 3.0**,所以 3.0 就是会被照抄的那个数 —— 而它在这里
**一次都不会响**。那正是本族反复付过钱的形状(GH #13 的视野子句、#277 的 800 否决、
#648 的 `nLane`),**这是第四例,靠给常数定价而不是继承它抓到的**。

**推导是关于「守的是哪个决定」而不是关于那个数**:抄 3.0 的子句否决的是**瞬时状态**
(「我现在是不是正在挨打」);本条守的是**承诺** —— 离开兵线、走到一个箱子那儿、
戳醒里面的东西 —— 而**这个决定是在脱离之后做的**。短窗口于是在提问的那一刻**系统性地
为假**:它要求的正是「脱离」这个动作刚刚移除的状态,逐字就是 GH #13 那句
「the trigger demanded the very state the pull is supposed to produce」。
**证人帧是这个论证的证据而不是它的插图** —— 最后一颗牙在决策瞬间是 **3.2 秒**大。

⚠️ **诚实边界(写在最前)**:**6.0 不是两个已测类别之间的分界**(那是 `pullreach`
上一轮能做的事),而是**仪器能看见的最宽值**(`make_fixture.py` 记录的 `recent_window`、
loader 的 `NEUTRAL_LOOKBACK`)。**一帧一个间隔,本语料分不开 3.5 和 6.0。**
能测的只有 anti-SILENT 那一侧;太宽那一侧由**第二个合取项**兜着,不由这个数兜着。

## 4. ⭐ 承诺豁免是强制的,不是谨慎

```lua
if J.IsSoakCandidate( 'pullchew' ) and bot.roamCampPull == nil
    and J.IsPullCampChewing( bot )
then
    return nil
end
```

**没有 `bot.roamCampPull == nil` 的版本会掐掉它本该保护的每一次拉野**:戳营**就是**
拉野的开始方式,所以 aggro 之后每一帧「有营在打我」都为真,计划每帧被清 ⇒ 拉野
被静音。而**没有任何计数器会报告一次从未发生的拉野** —— 这就是 `lanefix` 那笔交易,
也是 owner 两次点名的机制(「拉野是肯定要做的」)。**变异体 M3 专打这一条**,
它读起来像一次化简。

字段是**读**不是传:`J.ShouldPullNeutralCamp` 只有**一个**调用点
(`mode_roam_generic` 的 `GetDesire`,它在下一行赋同一个字段),而加宽 arity 会把
GH #188 棘轮那个「16 个调用点」的形状交出去 —— `abilanc` 就是为此被退回过的。

(`~=`/`>=`/`<=` 本来就匹配不上)。**下面的声明一字未动,也一点没变弱。**
