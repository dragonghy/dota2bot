## 1. ⭐⭐ 头条:`#hAllyList <= 1` 的意思不是「我一个人」

`J.IsOtherAllysTarget( unit )` 回答的是全队最常问的仲裁问题:**「这个目标已经有人在打了吗」**。

```lua
local hAllyList = J.GetNearbyHeroes(bot, 800, false, BOT_MODE_NONE )

if #hAllyList <= 1 then return false end        -- ①

for _, ally in pairs( hAllyList ) do
    if J.IsValid( ally )
        and ally ~= bot                          -- ②
        ...
```

`J.GetNearbyHeroes(bot, 800, false, ...)` 答的是 **`bot` 周围的别人**;
**调用方不是自己那个圈的成员**。可是 ① 与 ② **编码的是同一个信念:「这张表包含我」** ——
① 的「至多一个」只有在我是其中一项时才等于「除了我没别人」,
② 则花一项去排除一个**不可能在里面的**条目。

⇒ **信念是假的,于是 ① 的实际意思是「至多一个队友」,
而它在循环读到之前就把那唯一一个队友的 claim 扔掉了。**

⭐⭐ **判别子在同一个文件下方二十行、读同一张表**:`J.IsAllysTarget` 用
**完全相同的实参**建同一个圈,却**两行都没有** —— 没有 `<= 1`,也没有 `ally ~= bot`。
两个函数**不可能同时对「这张表装了什么」判断正确**,而语料证实的是后者那一种读法。

**爆炸半径**:`J.IsOtherAllysTarget` **21 个调用点 / 15 个文件**
(数法:屏蔽注释后 grep 全部出现,减去定义行)。无 TypeScript 孪生实现
(`typescript/bots/FunLib/jmz_func.d.ts` 只是声明),故只改 `.lua`。
