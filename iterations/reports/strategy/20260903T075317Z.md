## 1. 主判据(可复用,超出本主题)

> **⭐ 一个审计不能从它的审计对象那里取证。**

`tests/test_gate_claim_consistency.lua` 的整个裁决是一行:

```lua
local function is_violation(claim, wired)
    return not claim.promoted and not wired[claim.id]
end
```

`claim` 来自**注释**(它就是被审计的东西),而 `wired` **也**来自注释 ——
`wired_ids_in` 的四条正则跑在**原始文件**上,于是一个 id 只要在**注释里**以
`IsSoakCandidate('id')` 的形态出现过,就被登记成「有闸」。
**注册表和被注册者是同一批字节**:这个文件用来管注释的那个集合,由注释自己投票产生。

两个活载体**都是自指的**,而且这才是这条判据值得写下来的地方:

| id | 它为什么在 wired 集合里 |
|---|---|
| `pullbeat` | **2026-08-23 已 promote,代码里没有任何闸引用它**。它在集合里,是因为 `bots/mode_roam_generic.lua` 的**三段注释**(`:253` / `:331` / `:416`)在**讲 `pullcad` 陷阱**,讲法是把那个会冻成 FALSE 的合取**原样引出来**。 |
| `X` | `bots/FunLib/jmz_func.lua:1909`,同一条陷阱的表述里的**元变量**:`IsSoakCandidate('X') and IsSoakCandidate('abilanc')`。 |

⇒ **那段解释「promote 掉的 id 不在任何 armed 串里」的散文,正是把一个 promote 掉的 id
重新塞回 armed 串普查的东西;而一个占位符被铸成了一个闸 id。**

**失效方向是被遮住的 OVER-claim,恰好是这个文件被写出来要抓的那一种。**
一句 `-- Gated (turbo + 'pullbeat')` 今天**能干干净净地通过**;arm `pullbeat`
**什么都不 arm**,波次读回来是「测过了,中性」—— 这就是文件头自己写的
`nochaselow` 事故,**换了一扇门进来**。而且 `pullbeat` 正是这棵树上**最可能**发生的那次
over-claim:它 promote 一个月了,名字还铺满 roam 那几段注释。

**⚠️ 本轮不是把一片红改绿:修改前后这棵树都是绿的。** 拿掉的是**遮蔽**,不是红。

## 3. 落地

### 3.1 `tests/test_gate_claim_consistency.lua`

- 新 `strip_lua_comments(src)`:注释字节变空格、**换行保留**。
  - **字符串保留**(不是剥掉):`IsSoakCandidate('pullcad')` **本身就是一个字符串字面量**;
    这个函数只需要知道字符串**在哪结束**,好让字符串里的 `--` 不被当成注释开头。
  - 长形态都处理:`--[[` / `--[=[` / `[[` / `[=[` —— `bots/` 里前者 **80** 处、后者 **204** 处。
  - **不是 `gsub`**,而且每个 mutant 都是「朝 `gsub` 走一步」的可信编辑。
- 提取器一分为二:`wired_ids_in_text`(**唯一**装着四条正则的地方)+
  `wired_ids_in = wired_ids_in_text ∘ strip`。
  棘轮要**两种读法**读同一棵树,而**只许走一条代码路径** ——
  用第二份正则算出来的「修改前」数字会同意任何一侧的漂移(GH #67 的形状)。
- `census()` **记忆化**并多返回一个 `raw`:一趟走树、每文件一次 strip。

### 3.2 六条新断言(10/0 → **16/0**)

五条**机制**控制(合成源,注释改写了也还站得住):

1. 只在注释里出现的调用形态**不算 wired**,且它遮住的那条 over-claim 现在**是 violation**;
2. 一段讲**别的 id** 的注释旁边的**真调用**仍然 wired;
3. 字符串里的 `--` **不**把本行剩下的部分变成注释;
4. **跨行**长注释被剥掉、长**字符串**被保留;
5. 剥注释**不扰动它周围的行**(`SoakStrArms%b()(.-)\nend` 靠 `\n` 锚定)。

一条**真实树**读数(**双侧**,按 `0CKTWIN` 的规矩):只由注释产生的 id 集合
**恰好是 `{X, pullbeat}`**。多 = 有人新写了引出调用形态的注释(可以写,但普查得知道);
少 = 这两处演示被改写掉了,这个文件就只剩合成证据。
**按 id 锚定,不按行号**(`0B3FRAME` 立的规矩)。

## 4. 变异台自己教的那一条(值得单独记)

> **⭐⭐ 文件头声称的性质,可能比任何读者需要的都多;哪一半承重,变异台说了算。**

**M5 前两稿都活下来了,而且它们活得对**:

- **第 1 稿**:把注释字节**删掉**而不是刷成空格 —— 依据是文件头写的「位置被保留」。
  可这里每个提取器都是**位置无关**的 `gmatch`,**字节偏移在本仓没有读者**。
- **第 2 稿**:让行注释**吞掉自己那个换行**(`stop = j` 而不是 `j - 1`)。也是空操作 ——
  刷空格用的 `[^\n]` **恰好放过**它刚吞下的那个换行。

**真正有读者的是下游的行结构**(`SoakStrArms%b()(.-)\nend`),而毁掉它**要两处编辑同时发生**,
M5 现在就是这么写的。文件头那句话已按实测改写:换行是**被测的主张**,偏移是**防御性性质**,
并把残留缺口点名留着(没有读者去读偏移之前,也不该有)。

**⭐⭐⭐ 顺带一条控制自己的教训**:M2(砍掉长注释分支)第一次活下来,
是因为控制里的 `--[==[ ... ]==]` **写在一行上** —— 那种情况下行注释分支
**恰好也能把它刷对**。`bots/` 里 80 段长注释多数跨行,控制现在也跨行。
**把多行构造写成单行样例的控制,是一个跟 bug 意见一致的控制。**
