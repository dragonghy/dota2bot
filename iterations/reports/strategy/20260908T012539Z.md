## 1. 缺陷

`J.ShouldAbandonTpChannel`(soak id `tpwatch`,dossier #24)判「这条 TP 正在被吃掉」,
靠的是**当前血量与 `bot.tpChannelStartHealth` 的差 >= 最大血 30%**。

而那个 stamp 在整个 `bots/` 里**只有一个写入者,且它住在谓词自己的函数体内**:

```lua
-- bots/FunLib/jmz_func.lua, J.ShouldAbandonTpChannel
if bot.tpChannelStartHealth == nil then
    bot.tpChannelStartHealth = bot:GetHealth()
end
```

⇒ 基线**不是**「channel 开始时的血量」,而是
**「channel 期间第一次有人调用到这个谓词的那一帧的血量」**。

而两个调用点**都是有条件的**:

- `mode_retreat_generic` 的退却链在**第一个开火的守卫处 return**,而这个调用
  **排在 PROMOTED 的 `J.ShouldAbortDeepSoloPush`(pushguard,0.92)地板之下**
  ⇒ **一帧只要踩到 pushguard,就永远走不到 stamp**;
- `J.ShouldLetTpChannelFinish` 在自己的 `J.IsSoakCandidate('pgchannel')` 那一行就 return 了,
  **根本到不了它下面那条调用**。

**方向不是噪声**:晚取的基线取在「守卫本该注意到的那部分伤害**之后**」,
差值因此偏小 ⇒ **`tpwatch` 系统性欠开火**,偏向让一条正在被吃掉的 channel 跑完 ——
**恰好就是 dossier #24 那个结局**。

## 3. 修法

`J.StampTpChannelHealth( bot )`(新 helper,`bots/FunLib/jmz_func.lua`)+
**唯一一个 record-only 调用点**,放在 `mode_retreat_generic.GetDesireHelper` 的**最上面**,
和已经在那里的两个记录器(`J.ShouldAvoidDeathZone` 死点、`J.NoteProvenKillerOnDeath`)并排 ——
**理由一模一样:它必须看见每一帧,而它下面的每一个 return 都会藏起一帧。**

```lua
function J.StampTpChannelHealth( bot )
	if not J.IsModeTurbo() then return end
	if not J.IsSoakCandidate( 'tpwatch' ) then return end
	...
end
```

**两道闸都排在写入之前** ⇒ id 未 armed 时这个函数**一个字节都不写**,出厂对局逐位不变。
它**不返回任何 desire**,所以在未 armed 的树上**不可能**改变 `GetDesireHelper` 的答案。

### ⭐ 为什么**没有**新 id(可复用,是章程 0OCMID 那条的又一个实例)

宿主 `J.ShouldAbandonTpChannel` 自己就是一个**未 promote、而且从未 armed 过任何一波**的候选
⇒ 这一族里**不存在**任何能产生**可读**单臂零的落点:任何
`J.IsSoakCandidate('<新 id>')` 都是合取 `tpwatch AND <新 id>`,单臂波必然读 0,
**而那个 0 是结构上不可能的**;`check_armed_wiring.py` 照样答 WIRED(GH #606),
verdict 读回「测过了,无效应」而没有人举手 —— GH #576/#600/#607 那一族。
⇒ **改宿主自己的函数体、继承宿主的 id。**

**代价照例登记,而这一次代价是零**:`tpwatch` **从未 armed 过任何一波**
(`J.ShouldLetTpChannelFinish` 的 header 自己写着 "its own 'tpwatch' gate has never
been armed"),所以**没有任何既往读数描述修前的杠杆**,没有读数需要作废。

### 方向,按构造

stamp 只写一次(`if == nil`),所以 hoist 只能让它取得**更早** ⇒ 记下的基线 **>=**
出厂会记下的那个 ⇒ `startHealth - currentHealth` **>=** 原值 ⇒ `tpwatch`
**只会更常开火,不会更少**,而且只在它本来就已经有 channel、有新鲜英雄伤害、
且掉了 30% 血的帧上。这条**是断言不是句子**(见 `[direction]` 那条测试)。
