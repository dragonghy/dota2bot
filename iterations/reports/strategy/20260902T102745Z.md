## 1. ⭐ 主判据(可复用,超出本主题)

> **一个合取项的操作数是「量出来的数」而不是「比出来的真假」时,它不是条件,
> 是一个长得像条件的占位符。**

与 `hpbool`(GH #397)**逐字同一条判据**,换了一种量:那次丢比较的是**比值**
(`J.GetHP`),这次是**距离**。

**判别特征可数、不需要帧、不需要跑。** 全仓 `bots/` 里三个位置距离函数
(`GetUnitToUnitDistance` / `GetUnitToLocationDistance` / `GetLocationToLocationDistance`)
共 **1173 个调用点**(算上 `DistanceFrom*` 一族是 1308),其中**只有 2 个**把调用写成
**裸真值操作数** —— 而且**两个都在 `bots/mode_retreat_generic.lua`,相隔十二行,
同一个表达式、同一个变量**。其余每一处都带着自己的比较。

**1171 : 2。** `hpbool` 是 64:6,#397 是 64:6,#385 是 249/227/1 —— 同一族证据,
这一条是其中比例最悬殊的。⇒ **这是缺陷,不是房规。**

## 2. 缺陷

`bots/mode_retreat_generic.lua:426`,「肉山死了就别赖在 `BOT_MODE_ROSHAN` 里」
那段(它自己的注释写着 *when roshan dies, every desire sometimes drops to 0 somehow
and it lingers in Roshan mode*)的第三个合取项:

```lua
if botActiveMode == BOT_MODE_ROSHAN
    and not J.IsRoshanAlive()
    and GetUnitToLocationDistance(bot, vRoshanLocation)   -- ← 这一行
    and IsLocationVisible(vRoshanLocation)
then
    if not C.aegisNearby1200 then
        return BOT_MODE_DESIRE_MODERATE
    end
end
```

距离是个**数**,而 Lua 里**任何数(包括 0)都是真**。这一行因此不是条件。
语言不报、luacheck 不报、整套测试一路绿 —— **行是合法的、值是被用的、文件是绿的**。

### 失效方向:朝「开」(档案里第四条,继 #393 / #397 / #406)

**一个谁都拒绝不了的门,等于没有门。** 撤退欲望会开给**地图上任何位置**的 bot。

而旁边那个 `IsLocationVisible(vRoshanLocation)` **是对地点的可见性判断,
不是对距离的判断** —— 一个队友、一个眼、一只信使守着坑口视野,就替全队满足了它。
⇒ **被丢掉的那个距离比较,是这条规则里唯一一个能把它绑回 bot 自己位置的东西。**
