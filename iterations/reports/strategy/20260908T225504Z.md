## 4. ⭐⭐⭐ `fieldsip` armed 在本语料上不是量级判断,是「身上有没有大药」

这句是**两个被解析常数之间的除法**,不是描述。门槛是
`FieldRegenSipValue >= MIN_FRACTION * GetMaxHealth()`,每一口都是解析表里的常数:

```
最大非大药口 135 / 0.25 = 540   ← SIP_NONFLASK_MAX_BAR:超过这个血量上限,
                                   非大药一律过不了线 ⇒ 谓词退化成「有没有大药」
大药       400 / 0.25 = 1600  ← SIP_FLASK_MAX_BAR:超过这个上限,连大药都过不了
                                   (fs_maxhp_le_flask_bar 944/1021 ⇒ 77 帧上
                                    这个谓词无论带什么都不可满足)
```

### ⛔ 而「大药专属」这句在全语料上是**假的**,本文件把它断言成假的

`fs_maxhp_le_nonflask_bar` = **17**,**不是 0**:17 个活帧真的小到一口树精就能过线。
这句话只在**结论依赖的那个集合**上为真,于是就在那个集合上断言:

* `fs_sf2_killed_above_nonflask_bar` **19/19**
* `fs_sf2_killed_le_flask_bar` **19/19**

**一个论证闭式而不去量它的文件,会发表一句假话。** 这是 GH #171(「没量过」和「零」
不许是同一句话)的**姊妹形状**:「闭式成立」和「闭式在我引用它的那个集合上成立」
也不许是同一句话。

## 5. 结构钉(六个地址,以及为什么单独 arm 它动不了供给侧)

* **定义不是调用点**:全文件计数要减掉 `function J.IsFieldSipEnough(` 那一次,
  否则 hold/buy 拆分**恰好差一**(第一版就是 7)。
* 六个调用点 = **1 个持有侧**(`J.ShouldRegenNotGoHome`)+ **5 个供给侧**
  (`ShouldFieldBuyRegen` / `...Hurt` / `...Tower` / `...Ring` / `...Deep`)。
* **5/5 的自身 gate 都排在 sip 调用的上游**(`SIP_BUY_SELFGATED 5`)⇒ **单独 arm
  `fieldsip` 动不了供给侧**。这条**按源码顺序推导、再被驱动确认**
  (`fs_sip_alone_moves_buy 0`)—— 源码顺序和运行中的代码,谁也不替谁作证。
* 门**fail-open**(`SIP_GATE_FAILS_OPEN 1`)⇒ promote 时**必须删整行不能只删 id**
  (`wandbleed2` 陷阱,state.json 早已对这个 helper 记过)。
* sip 守卫是持有谓词的**最后**一条(`SRNGH_SIP_IS_LAST_GUARD 1`,`SRNGH_GUARDS 3`)。
* 分割保持:`fs_partition_both 0` / `fs_partition_neither 0`(`campvoid` / GH #265 的形状)。
* 方向经**换腿的同一个 `tally`**:`fs_hold_gains 0` 而 `fs_hold_gains_swapped 22`;
  `fs_buy_losses 0` 而 `fs_buy_losses_swapped 22`。

### ⭐⭐⭐⭐ 本轮最可复用的一条(被变异台逼出来的)

**`must()` 保护不了一个「干净值是零」的列 —— 零初始化把它的 key 焊死了。**

第一版 M8 改名 `fs_sf2_live_survives` 的 `bump()`,**SURVIVED**,而 `must()` 就压在那个计数上。
两层原因叠着:

1. sweep **零初始化**每个 bucket(GH #171,好让「没到过」和「量出来是零」对解析器不同),
   于是改名**永远不会让 key 消失,只会多出一个** ⇒ 这种列需要的是**对 key 集合的闭包检查**,
   不是对单个 key 的 nil 检查。**M13** 就是补上的那条腿:改名一个**会开火**的 bump,
   新 key 真的出现,闭包检查才有东西可看。
2. 但 `fs_sf2_live_survives` 的 bump **根本不执行** —— 它的零是**死分支**不是空统计 ——
   所以那次改名连新 key 都没造出来,**是个等价变异体**。**任何基于 key 的守卫都看不见
   一个从不运行的分支**;能查的只有「两个出口对活域是穷尽的」(`survives + killed == 19`),
   于是 M8 改成**翻转分支极性**。

⇒ 「一个计数读作 0」和「一个计数被读过且返回 0」是两句话,而**第三种「写它的分支
从没跑过」对 `must()` 和闭包检查都是隐形的**。
