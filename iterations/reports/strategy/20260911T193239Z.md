## 2. ⭐⭐ 本轮最该被下一轮读到的五句

### (甲) ⭐ 这根兄弟的形状和前三根不一样,而不一样的地方是本文件自己的发现

**主语不是发问的那个 bot。** `X.CanAttackTogether` 收**英雄参数**,它的**四个调用点里三个传的是友军**
(`X.GetCanTogetherCount` 走整条友军表;另两处在支路里对某个指定 `ally` 调用)。
⇒ 这条守卫**同时**在回答「**我的友军**旁边有没有危险敌人」,而那个答案被**计进「我们能一起上几个」**。
前三根兄弟(`lvlany`/`lvlcarry`/`lvlgroup`)**没有一根**会对发问者以外的人求值。

§1 把这个人群**单独量了**:非发问者求值 **868** 次、其中 miss **1** 次、协同人数变化 **0** 行。

第二处不一样:**一个谓词、一个源码站点、但四条支路读它** —— 与三根兄弟「一个 id 一个调用点」相反。
⚠️ **这不是 lanefix 捆绑**(捆绑 = 一个 id 下挂**若干不同**杠杆;这里是**一个**杠杆,缺陷恰好长在
共享 helper 里,「在调用点修」意味着**把同一个修复写四遍**),**但它确实意味着这个 id 动的行为
比三根兄弟都多** ⇒ 结论是「继续单独、继续 gated」,不是「顺手放宽」。§5c 把 **4** 钉成数字。

### (乙) ⭐⭐ 这里能说出 `lvlgroup` 说不出的那一句,而且它是个等式

零照旧:arm 改变**函数返回值**的行数 = **0**(`cat_flip == 0`),因为 4 个 miss 行**全部**栽在
`#allies >= 2`(1200 内友军 < 2)。`lvlgroup` 当时只能说到这里。

本轮**多量了一步**:那 4 行**全部满足函数的其余每一个合取项**(alive / 非幻象 /
`GetProperTarget == nil`)⇒ **`miss_preterms == site_miss == 4`,按等式钉**。
⇒ **横在这些行和一次 flip 之间只有「两个友军」这一个词项,没有第二个原因。**
这句话直接就是一条 fixture 规格(见 §5 交棒),而且**等式一旦破了,那个零就有了第二个成因,
结论必须重取而不是重新基线化** —— 断言正文逐字写着这句。

零**不是结构性的**:候选形状(1200 内 ≥2 友军 **且** 600 内 ≥2 敌人)本语料有 **11** 行,
没有一行恰好是 miss ⇒ **小样本零**。

### (丙) ⭐ 零还立着时扛住杠杆的仍然是「方向」,而这次这条界伸得更远

armed 答 `not any(level >= nLevel)`、出货答 `[1] < nLevel`;`[1]` 存在时**前者蕴含后者**
⇒ armed 是**纯收紧**。因为有三个调用点在**数**这个答案,「永不发一个 baseline 没发的」
就等于**协同人数只会往下走** —— bot 只会对「一起上」更谨慎,不会更莽。

三层各自防空转:
- helper 层 §3e:`dir_violation == 0`(等式)+ `armed_true > 0` + `dir_narrows == site_miss == 4`
- 函数层 §5:`cat_dir_violation == 0` + `cat_armed_true (124) <= cat_true (124)`
- 友军层 §1b:`together_count_rose == 0`

⛔ 这是对**改动方向**的界,**不是命中率**;本文件任何地方都没有声称命中率。

### (丁) ⭐⭐ 变异台当场改了测试自己的一处缺陷,而这是它挣来的、不是事后补记

M18(让友军侧的 oracle **变宽**:armed 该收紧却放宽)第一次跑时,**是被 §1b 的「零」断言接住的**,
而那条断言的失败文案写着「**⭐ 这是好消息,有 fixture 落进形状了**」。
⇒ 对一个**变宽了的 oracle**,那是**把祝贺递给了 bug**:读者拿到的诊断和真相正好相反。

修法不是改文案,是**改顺序**:§1b 与 §5 里**方向断言一律调到零断言前面**,
于是「变宽」被命名为**禁止的方向**,只有**真的长出驱动帧**才会走到那句好消息;
两条零断言的文案也各自补上「上一行已经排除了另一个方向」。M18 的 `want` 随之改成方向那句,
**改完复跑 19/19**,M18 的命中行现在是:

```
19 腿 · M18 caught: 49 row(s) have MORE co-attackers armed than unarmed.
        Arming may only ever withdraw a "can attack together", never grant one
        ... ⛔ This is NOT the good-news case below.
```

⚠️ **诚实标注**:改之前 M18 也是「红」的,`19/19` 两次都成立 —— 变异台**换掉的不是通过与否,
是红出来的那句话对不对**(evidence-discipline 第 4 条:结论对不等于理由对)。
