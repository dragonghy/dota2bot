## 逐步分析

### 现状
`bots/FunLib/jmz_func.lua:5862`:
```lua
if DotaTime() < 8 * 60 and J.IsCore( bot ) then return nil end
```
`J.GetRescueTpTarget(bot)` 的核心豁免:t < 8:00 且 rescuer 是 pos 1–3 ⇒ 不启动救援。

### 与 canonical `J.IsInLaningPhase()`(8933–8961)对比
Turbo 下 `J.IsInLaningPhase()`:
- hard floor:`nTime < 8*60` ⇒ true
- soft extension:`nTime < 10*60 and GetBot():GetNetWorth() < 8000` ⇒ true

⇒ 硬底和现有 hardcoded `8*60` **相同**;差别只在 **t ∈ [480, 600] 且 rescuer 净值 < 8000** 那段窗口:
canonical 下仍算对线期(⇒ 核心豁免继续生效 ⇒ 不救),shipped 下 hardcoded 已经放开(⇒ 核心可救)。
Turbo 均局 670s、九分钟核心净值 < 8000 是常态(见 13:30Z §5 三帧域实测,DP/CM/necro 在 t=490–575 都
是 3068–3997)。

方向依据 (c):#37 第 3 节实测 20/50 attributed rescues 目标在 15s 内死了 ⇒ **rescue 已经过多**,
canonical 会让 t=8–10min 低净值核心少发一批 rescue,方向单调向 #37 的病灶更靠近一步。

### 想 gate 但**做不到 (a) 的**当前语料考察
候选 gate:`lfcorelane`,armed 时把该行替换成 `J.IsInLaningPhase()`(turbo-only)。armed 效果集是
shipped 效果集的**父集**(严格更多帧 return nil),不新增动作,不碰别的出价。

要在真实帧上钉 (a),需要一帧「rescuer=核心 + `IsCore(bot)` + `DotaTime() ∈ [480,600]` +
`GetNetWorth() < 8000` + 有 TP 卷 + 触发链其余通过」。语料清点:

- `f_260819_123012_dk_rescue_far.lua` (t=568.4, subject=DK): DP 在这帧 net_worth=3566、
  level 8、tp_cd=0,`items = {'power_treads','ring_of_health','quelling_blade','magic_wand','bracer'}` ——
  **无 `item_tpscroll`**。DP 在这帧之前已经把 TP 用掉(下一步就是 `dp_landed_dead`),所以在 subject=DK
  的可寻址视角下,`J.GetItem2(DP,'item_tpscroll') == nil` ⇒ `GetRescueTpTarget(DP)` 早退于 line 5865,
  gate 那一行**结构上不可达**。同帧其余核心(DK 本人是 subject 不能自救;jakiro/lich/axe 是辅助,不触发核心豁免)。

- `f_260819_123012_dp_landed_dead.lua` (t=574.4, subject=DP): DP 的 TP 已消耗、tp_cd=33.9 ⇒ 同样早退。

- `f_260819_122930_lich_rescue_doomed.lua` (t=201.3, subject=lich): t < 480 属于豁免生效窗口,但
  lich 是辅助不是核心 ⇒ `IsCore(bot)==false` ⇒ 那一行不触发。

- `f_260819_123546_axe_rescue_ok.lua` (t=145.4, subject=axe): axe 是核心,但 t<480 是**豁免生效**
  帧,shipped 与 armed 逐位相同(两者都 return nil)。

- `f_113638_cm_chain_rescue.lua` (t=256.0, subject=cm): 辅助;t<480。同上。

**结论**:本组现有 fixture 里,**一帧都不满足** `lfcorelane` 的 armed-vs-shipped 差集(核心 + TP 在身 +
t ∈ [480,600] + nw<8000)。特别是 `123012` 那一局 —— 表面看是最贴的语料 —— 决定发起 TP 那一帧发生在
t=568.4 **之前**几秒(dumper 3s 采样,能到 t=567 或 t=565),subject=DK 视角看不到 DP 的物品栏改
`self` 才能查(生成器现在支持 `--subject`,但要有原始 timeline)。
