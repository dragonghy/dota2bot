## ⭐⭐ 本轮最该被下一轮读到的六句

**(甲) ⭐⭐ 本族第一次换到一个 `[1]` 根本不是「最近的那个」的站点,而这是结构性的、不是程度差别。**
`lvlany`/`lvlcarry`/`lvlgroup`/`lvltogether`/`lvlhitcreep` 读的表**都继承一个距离序**,
所以 `[1]` 至少**是**「最近的那个」,缺陷是「最近的不等于最危险的」。
本站点的 `nEnemyHeroes` 是 `C.enemyHeroes`,由 `buildContext()` 从
**`GetUnitList(UNIT_LIST_ALL)`** 填 —— **一张世界表,对每个观察者是同一个对象序** ——
只按队伍和半径过滤,**路径上任何地方都没有排序**。
⛔ **一张不依赖观察者的表,不可能处在该观察者的距离序里,除非碰巧**
⇒ `[1]` 是 1600 内一个**任意**敌方英雄。
§4a 在源码上把「生产者 + 无排序」钉死(`table.sort` 计数 == 0);
§4b 量到全语料 **162** 行(占 682 的 23.8%)`[1]` 不是最近敌人,**43 个撤销行里 28 行**如此。
⚠️ **162 是这个论证在本语料上的一个实例,不是它的证明** —— loader 的 `UNIT_LIST_ALL`
是花名册序(先友后敌),那是**一个**世界序,未必是引擎的那个;
**经得起两种序的论证是上面那条观察者无关性,本文件靠的是它**,§4b 的失败文案也这么写。

**(乙) ⭐ 作者自己的证据在同一个文件里给足了,而且是同一张表。**
`#nEnemyHeroes` 作为群体词项在本文件被花掉**八次**(:449/:492/:493/:495/:517/:565/:600
及其中的 `> #nAllyHeroes` 比较),而 `#nAllyHeroes <= 1` 就压在这条竞速词项**上面两行**。
这正是 backlog 第 (0) 项点名要找的形状(`#list >= N` 挨着 `list[1]:...`)。
⛔ 顺带:`X.ShouldRun` 里还有 `#nEnemyTowers >= 2`(:1368)挨着 `nEnemyTowers[1]:...`——
**那是兵营分支(GH #713),本轮只把它当作者群体思维的证据引用,一个字都没碰。**

**(丙) ⛔ 方向纯收紧,钉成等式;而「循环从 i = 1 起」不是风格是界本身。**
armed 答 `forall e: d(bot) < d(e)`,出货答 `d(bot) < d([1])`;
循环从 `i = 1` 起且调用者已确立 `[1]` 是有效英雄 ⇒ **`[1]` 永远被求值**
⇒ armed TRUE **蕴含** shipped TRUE ⇒ 只会**撤回**一个今天就在发的 `return 5`,
**永不发一个 baseline 没发的**。全部 1306 行上 `DIR_VIOLATION == 0`(等式),
外加 `shipped_true − armed_true == site_miss`(防常数谓词)与
`miss_ge2 == site_miss`(等式:**单元素表上两个答案是同一个表达式**,撤销行必须带第二个成员)。
变异台 **M17**(把循环改成 `for i = 2`)专打这条界。

**(丁) ⭐ 43 行是本族到目前为止最大的谓词层驱动,但本 id 取的仍是较弱那把杆 —— 这句排在数字前面。**
`live` **1306**、`nonempty` **682**、`ge2` **349**、`shipped_true` **513**、
`armed_true` **470**、**`site_miss` 43**(前五根是 2/4/10/9 那一档)。
**但 `X.ShouldRun` 的 `return 5` 在其中零行上移动**,原因是**实测**不是推理:
支路外层要 `J.IsRealInvisible(bot)` 与 `J.IsRetreating(bot)`,§5 把**两者都量到 0 行**。
⇒ **不作任何命中率声称**;**`cutoff` 欠一帧**,与四根 `cat_flip == 0` 的兄弟同类。
⛔ **GH #756 欠的两帧是它们的,与本 id 无关,不许拿本 id 的 43 行去销。**
半径 sweep 800/1200/1600 = **13 / 33 / 43**,⚠️ **登记不断言单调**:
加宽环带既加成员也**换掉 `[1]` 是谁**,对这个非排序生产者单调性并不蕴含。

**(戊) ⭐⭐ 变异台买到一个真洞,而那个洞是浮点数造成的、任何语料都买不到。**
**M6**:把 armed 的 `>=` 放松成 `>`,**死平**(bot 与追兵到遗迹等距)就不算被切断了 ——
而出货那侧是**严格 `<`**,于是 armed 会在那个成员上 TRUE 而 shipped FALSE,
**正是 §3c 禁止的方向违例**。距离是浮点数,精确相等在本语料、也在任何造得出的语料上都不出现
⇒ **M6 第一轮 SURVIVED**。修法是给 §4d 补一条 `>=` 源码钉并在注释里点名 M6。
⚠️ 同节还有第二条本语料不可证伪的守卫(armed 循环的无效成员跳过,§4d 量到 **0** 个无效成员),
**两条都逐字标注「这是源码钉代替行为钉,它更弱」**。

**(己) ⭐ 另一处改的是「红出来的那句话对不对」,不是通过与否。**
**M7**(pullcad 陷阱:把已 promote 的 `fight` 并进闸)第一轮记成「RED 但消息不对」——
它**不**被任何闸形状的断言接住(**闸读起来仍然对,只是永远不可能为真**),
接住它的是 `site_miss` 的 **ratchet 掉到 0**。改的是 stand 的 `want` 字符串,**不是加一条钉**。
