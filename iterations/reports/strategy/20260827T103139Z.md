## 3. ⭐ 主判据(本轮主产出,可复用)

> **一条「语料里没有 / 买不到」的断言,是关于一个只会增长的集合的断言 —— 它写下时为真,而后不需要任何人碰这个文件就会变假,并且没有任何东西会红。**

失效方向是**假绿**,而且形状固定:**替身长期顶着承重案例的名字**。

**与 `tests/corpus_scale.lua` 是镜像,不是重复。** 那个模块治的是语料增长把**计数等式**打成**假红**(`== 100` 因为落了第 101 枚 fixture 而红),并对存在性断言**刻意沉默**(它自己的头注列了「什么故意不放松」)。区别是**响与哑**:增长把计数打红是响的,把否定性存在断言打假是**哑的** —— 之前**只有响的那一半有把手**。

**修法不是改注释,是把断言变成可执行的:让测试自己问语料。** 一条被改对的注释明天还会被同一台机器碾过;一条会红的测试**在正要犯这个错的那一刻**才响。(这条与 `0SALT` 登记的操作规则「标记能做成红测试就不要做成注释」同源,但那次治的是**标记**,这次治的是**论据**。)

## 6. ⚠⚠ 方法自伤三条(方向全是「把没通过报成通过」,修法全是**换仪器**不是补断言)

**(i) 针的集合也要唯一,不只是针。** `ABSENCE_TOKENS` 第一版同时收了 `'is not in the tree'` 与 `'not in the tree on any ref'`;杀掉内层那条的变异**活了下来**,因为控制项那**一句**样本同时含外层那条。**重叠的针集合无法逐条做变异测试。** 这是 GH #237「`"10 failures"` 含 `"0 failures"`」的**高一层**:那次是**一根针**有歧义,这次是**一套针**互相遮蔽;也是 `0SALT`「针必须唯一」的**集合版**。修法 = 集合改成两两不含,**并把不含关系写成断言**。

**(ii) 用被测对象造样本的控制项是同义反复。** 改好针集合后 per-token 控制项写成「拿 token 自己拼一句,断言它被抓」—— 对**任何** token 都成立。**7 条 token 删除变异活了 6 条,而控制项全绿**。修法 = 样本句**独立于列表手写**(7 句,每句是测试作者真会写的那种话),并**双向**断言覆盖:每句都被抓 ∧ 每条 token 都是某句被抓的原因 ∧ 两者**一一对应**。

**(iii) 干净树上的零,`== 0` 与 `>= 0` 分不开。** 两条棘轮的收尾断言换成 `>= 0` 时**全部活下来** —— 今天本来就没有发现,两者观测等价。修法 = 把收尾断言抽成**一个共享仪器** `require_clean()`,让控制项在**植入的违规**(写到 `os.tmpname()`、含各一条 (A)/(B) 违规的假源文件)上**看着它 raise**;于是那个变异从「没人看得见」变成「控制项会红」。**同一份 sweep 函数吃 file list 作参数**,控制项与棘轮跑的是**同一段代码**,不是复刻。

**变异三批 14 / 5 / 12,活下来 3 / 2 / 3**,每批两端控制项干净,全程顺序执行不并发。判定读数打在 runner 的**汇总行** (`" 0 failures"`) 上。
**还原路径走 scratchpad 快照 `cp`,不走 `git checkout`**(`0CAMP` 教训:后者会擦掉本轮未提交的被测改动)——事后 `git status` 坐实工作树只剩预期的两个文件。

**剩下的活口全部是「放松一条防真空/防歧义的护栏」**(`nRefs >= 250` 改 `>= 0`、样本数与 token 数的双射规模检查、植入文件的引用计数):在干净树上它们是**等价变异**。**本轮明确登记为等价、不补断言** —— 再补一条只会造出另一个同样分不开的零,这正是 (iii) 刚学到的东西。
