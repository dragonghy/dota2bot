## 1. 本轮做了什么(一句话)

`bots/FunLib/minion_lib/illusions.lua` 的移动节流器 `nNextMoveTime` 是 **module 级**的,
而它节流的决策是 **per-unit** 的;`aba_minion.lua` 把这个 bot 的**所有**幻象与无技能小兵
经**同一个模块实例、同一个调用表达式**送进来 ⇒ **同一帧里第一个走到移动分支的小兵
替所有人把预算领走,兄弟们直接从 `X.Think` 末尾掉出去,零命令**。
真实帧上 20 个周期、4 个小兵实测 **20 / 0 / 0 / 0**。

## 2. ⭐ 主判据(可复用,超出本主题)

> **一个节流器的作用域必须等于它所节流的那个东西的作用域。**

两者一旦不等,节流器**不再是限速器,而是抽签**:每个窗口第一个进门的人替所有人领走预算,
而输的人**不是晚一点拿到,是什么都没有**。没有任何东西会举手,因为
**从模块内部看,每一次调用都长得像一次被正确节流的调用**。
**判别特征可数、不需要帧**:生命周期是模块的状态,被写在一条**每单位每帧各跑一次**的路径上。

**与前四条同族划清界限** —— 这不是修辞,四条各自的因不同:

| | 是什么 | 本条不是它的原因 |
|---|---|---|
| GH #348 | **顺序**(nil 守卫排在它守护的索引之下) | 本条没有任何一次读写顺序是错的 |
| GH #368 | **词法作用域**(`local` 遮蔽,守卫与消费者读两个变量) | 本条只有一个变量,大家读的都是它 |
| GH #370 | **未汇报的副作用**(被调方像查询,实际下令) | 本条的被调方没有隐藏动作 |
| GH #373 | **闩记错后置条件**(记「看过了」不记「找到了」) | 本条的时钟记的正是它该记的东西 |

**本条里,时钟的每一次读和每一次写都正确且自洽 —— 错的是「有多少东西共用这一个时钟」。**

## 3. 机制(可核查,每一环都跑过而不是读过)

1. `bots/FunLib/aba_minion.lua:11` **`dofile`** 该模块 —— 注意是 `dofile` 不是 `require`,
   全仓共 3 处 `dofile` 它(另两处在 `minion_with_skill.lua` / `vengeful_spirit.lua`),
   于是**每个 dofile 点各有一份自己的 `nNextMoveTime`**。**本轮的主张只用 `aba_minion` 那一份**,
   不依赖「全队共享一个 Lua VM」这个更强的前提。
2. `aba_minion.lua:48-53`:`hMinionUnit:IsHero() and IsIllusion()`(非复仇之魂)**或**
   `U.IsMinionWithNoSkill(hMinionUnit)` ⇒ 全部走 `Illusion.Think(bot, hMinionUnit)`
   (**全仓唯一一个调用表达式**,已源码计数)。
3. `illusions.lua` 的 `X.Think`:攻击分支(`:31`,**无节流**)之下,移动分支挂在
   `DotaTime() >= nNextMoveTime` 上;**判假就直接走到函数末尾,没有 else,没有兜底**。
4. **两道闸的相互作用,是「损失是全额而不是部分」的原因**:`aba_minion.lua:33-35` 那道
   **自己的** per-unit 0.5s 闸对每个单位初值为 0 ⇒ 一起召唤出来的一群小兵**同一帧**过闸、
   此后**永远同步**。同帧里赢家把共享时钟推后 0.2s;输家被自己的 0.5s 闸扣住,
   0.5s 后再来时共享时钟又被当帧的赢家推后了。**所以不是 20/6/6/6,是 20/0/0/0。**

**执行实测,不是阅读**:出厂腿 `20/0/0/0`,armed 腿 `20/20/20/20`。

## 4. ⭐⭐ 它是缺陷而不是设计取舍 —— 理由写在同一个调用者身上

`aba_minion.lua` 在它调用 `Illusion.Think` 的**二十行之上**,对**同一批单位**做**同一件事**
并且做对了:0.5s 节流,存成 `hMinionUnit.lastItemFrameProcessTime` ——
**一个挂在单位句柄上的字段**(4 处提及,**处处索引到句柄**,已源码计数)。
所以 per-unit 字段**不是本修复发明的新机制**:往句柄上写小写状态是**发货代码已有的做法**,
`illusions.lua` 自己就写了五个(`attack_desire` / `attack_target` / `move_desire` /
`move_location` / `to_farm_lane`)。
