## 二、缺陷:两个同心圆,一个比较,而宽的那个是他们的

`bots/mode_side_shop_generic.lua`,同一个函数(`GetDesireHelper`)里的三行:

```lua
:61   local tInRangeEnemy = J.GetEnemiesNearLoc(bot:GetLocation(), 1600)
:220  local tInRangeAlly  = J.GetAlliesNearLoc (bot:GetLocation(), 1200)
:221  if not J.IsRealInvisible(bot) and (#tInRangeEnemy > #tInRangeAlly) then
          return BOT_MODE_DESIRE_LOW
```

两个圈**同心**(都以那个刚被选去打 Tormentor 的最近非核心 bot 为心),两个计数**只喂这一个比较**,
全文件没有第二个消费者(`tInRangeEnemy` / `tInRangeAlly` 各自只出现两次)。
⇒ **一个 1400u 外的英雄,是他们的就算战力、是我们的就不存在。**
那层壳是圆面积的 **78%**(1600² / 1200²),而且**只往他们那边加**。

### ⭐⭐ 本轮买到的可迁移句(它管的是【上一轮的修法能不能照抄】那一格)

**一个缺陷的形状可以逐字重现,而它的【符号】决定了修法;
⛔ 而符号不在缺陷里,在两半各自的【别的不对称】里 —— 于是「同一个缺陷的第二个站点」
读起来像「同一个修法的第二个站点」,两者在阅读时长得一模一样。**

现场:`roamring`(`mode_team_roam_generic`,盟友 **2200** / 敌人 **2000**)宽的那个圈是**我们的**,
于是它把**敌方**那半加宽到盟友的圈上,并在头注里明确写下这么做**不会过度修正**的理由 ——
`J.GetEnemiesNearLoc` 走 `UNIT_LIST_ENEMY_HEROES`(受视野限制)、滤掉可疑幻象与 Meepo 分身,
而 `J.GetAlliesNearLoc` 走自家 roster 全收 ⇒ **敌方那半在半径进场之前就已经是被低估的一半**。
⭐ **那条理由在这里逐字仍然为真,而它的结论翻了个个儿**:这里宽的圈是**他们的**,
照抄 roamring 的动作 = 把敌圈**收进** 1200 = **统一了圆,同时加重了那个低估**。
⇒ 该动的是**我们**那半。

📌 **判据**:认出「这是上一个缺陷的同一个形状」之后,不要接着问「上次怎么修的」,
要问 **「上次那条『为什么这个方向不会过度修正』的理由,在这里指向哪一边」** ——
理由是可迁移的,动作不是。

## 三、修法(一次一个小杠杆)

`bots/FunLib/jmz_func.lua`,`J.GetRoamParityRadius` 正下方:

```lua
function J.GetTormentorParityRadius( nEnemyRadius, nAllyRadius )
	if not J.IsSoakCandidate( 'tormring' ) then return nAllyRadius end
	if not J.IsModeTurbo() then return nAllyRadius end
	return nEnemyRadius;
end
```

调用点把 1600 **命名一次**,两半都从这个名字取:

```lua
local nTormentorParityEnemyRing = 1600
local tInRangeEnemy = J.GetEnemiesNearLoc(bot:GetLocation(), nTormentorParityEnemyRing)
...
local tInRangeAlly = J.GetAlliesNearLoc(bot:GetLocation(),
    J.GetTormentorParityRadius(nTormentorParityEnemyRing, 1200))
```

⇒ 两半**再漂开就会把测试顶红**(第 1 节的 `nDecl == 1` 与两条逐字 `find`)。

**一个杠杆**:只动「同一个比较的两半是不是数同一个圆」。⛔ **不碰**敌方半径、不碰比较的算符、
不碰 `J.IsRealInvisible` 那一项、不碰视野规则、不碰幻象过滤,也**不主张 1600 是团战邻域的正确大小**。

**方向由构造定死**:更大的圈是**超集** ⇒ `#tInRangeAlly` 只能变大 ⇒ 比较只能 TRUE→FALSE。
⚠️ **armed 是放宽不是收紧**(与 roamring **相反**,写明免得被当成同一种杠杆读):
它只能**放行**一次出厂树会 bail 掉的 Tormentor 提交,永远不能 bail 掉出厂树放行的那一次。
⇒ 批测读数若反向,只能读成**那些多出来的提交本来是坏的**,不能读成「bot 不打 Tormentor 了」。

### ⭐ 那个更大的杠杆为什么不发

把**敌**圈收到 1200(`tight`)同样单向,`down 19` > 本杠杆的 13,
**而且文件自己的习惯站在它那边**:1200 是这个文件在**另一处**近身读数上用的数

- 加宽**我们**那半 = **停止丢弃** bot 已经拿到的英雄位置(1400u 上活着的真队友);

  几秒就能进到 Tormentor 战场)。

⛔ **两者都让 bail 变少,所以方向列分不开它们** —— 分得开的只有这一条。
