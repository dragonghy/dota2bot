### 算术

`bots/mode_roam_generic.lua` 是 `J.ShouldPullNeutralCamp` 的**唯一**调用点:

```lua
local vCamp = J.ShouldPullNeutralCamp(bot)
if vCamp ~= nil and J.IsLanePullSafe(bot) then
```

- helper 内自带:`#J.GetEnemiesNearLoc( bot:GetLocation(), 800 ) > 0 → nil`
- `J.IsLanePullSafe`:`J.GetNearbyHeroes(bot, 1800, true, ...)` 里任一有效非幻象敌方英雄 → false

两者同过 `J.IsValidHero`(→ `utils.IsValidHero`,**要求 `CanBeSeen()`**)与 `IsSuspiciousIllusion`。
800 ⊂ 1800 ⇒ **`pullsafe` 蕴含 `no800`** ⇒ 那条 800 子句**在结果上永远改变不了答案**。

| peacetime lane-support(**800,已发表口径**) | **39** |
| peacetime lane-support(**1800,shipped 链**) | **22** |
| 旧窗口 chain(800 / 1800) | **10 / 4** |
| 新窗口 chain(800 / 1800) | **18 / 9** |

⇒ 场景比 DoD 报的**稀缺约 44%**;「加行程提前量多买到 +8 帧」在活的门下是 **+5**。
