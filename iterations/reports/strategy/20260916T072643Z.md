## 1. ⭐⭐ 头条:`ourPower` 每次调用算一遍,然后丢掉

`bots/FunLib/jmz_func.lua` 的 **`J.WeAreStronger(bot, nRadius)`** —— 团战强弱谓词,
**56 个调用点**在读(`mode_farm` / `mode_laning` / `mode_team_roam` / `mode_roam` /
`aba_defend` / `override_generic/mode_attack` / 13 个英雄文件…)。

它给己方**同时累两个总量**,并且**每一个分支都同时写**(英雄项、幻象项、
带/不带 glyph 的己方塔项、团战加成项):

```lua
ourPower    = ... math.log(1 + unit:GetOffensivePower())    ...
ourPowerRaw = ... math.log(1 + unit:GetRawOffensivePower()) ...
```

两边表达式**逐字相同,只差一个 getter**:

| getter | 文档(`docs/BOT_API_REFERENCE.md`) |
|---|---|
| `GetOffensivePower()` | :1170 「Estimated total damage output (**respects cooldowns/mana**)」 |
| `GetRawOffensivePower()` | :1171 「Damage output **ignoring cooldowns and mana**」 |

敌方总量 `enemyPower` **只**用 raw —— 函数里**根本没有**敌方的状态感知版本。

而出货的比较是:

```lua
local res = ourPowerRaw > enemyPower
```

⇒ **`ourPower` 是死存储**:半径内每个队友都算一遍,每次调用都算,然后丢掉。
它是整个函数里**唯一**知道「我方没蓝了 / 大招在冷却」的那一项。

### 为什么这是缺陷不是风格

raw-vs-raw **看着**对称,但两边在「bot 能知道什么」上**不对称**:
它**精确知道**自己的冷却和蓝,**看不见**敌方的。
标准的保守开团判据正是另一种配对 —— **自己按现在真能打出来的算,敌人按他全套都在算** ——
而**那正是第二个累加器存在的理由**。作者把它建好了,然后比较了另一个。

**方向按构造单向**:`GetOffensivePower() <= GetRawOffensivePower()`
⇒ arm 只能**压低**我方那一侧 ⇒ 「我方更强」这个答案**只会变少,不会变多**。
⛔ 于是负读数**只能**读成「bot 本来就该按满状态算自己」,
**永远不能**读成「这根杠杆挑起了一场团战」。
Turbo 正是它咬人的地方:团战不断,**卡住的是蓝不是伤害**。

## 6. 改动(gated,turbo-only,一个小杠杆)

`bots/FunLib/jmz_func.lua`:

```lua
function J.ShouldRateOurFightPowerByState()
	if not J.IsSoakCandidate( 'fightstate' ) then return false end
	if not J.IsModeTurbo() then return false end
	return true
end
```

`J.WeAreStronger` 的尾巴:

```lua
local nOurPower = ourPowerRaw
if J.ShouldRateOurFightPowerByState() then
	nOurPower = ourPower
end
local res = nOurPower > enemyPower
```

⭐ **惰性 claim**:un-armed helper 返回 false ⇒ `nOurPower` **就是** `ourPowerRaw`
⇒ 出货表达式**可证地**与改前逐字相同 —— 不是「这份语料上没观察到移动」,
是**任何一帧上都不可能移动**。

**同一个原子里的一个伴随 token**:`ourPower` 英雄项的 `math.sqrt` 补上了
**它自己兄弟行早就有的** `Max(0, ...)`。理由是杠杆的良定义性:
不加时一个负乘积让总量变 `nan`,而 `nan > x` 恒 false
⇒ **armed 腿会以一个与杠杆无关的理由答「我方不更强」**。
un-armed 时它守的那个值仍然无人读 ⇒ **也是可证的 no-op**。
