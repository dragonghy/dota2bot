## §2 缺陷(用出货代码自己的话)

```lua
-- representative lethal target: the caller's target if it is one of the
-- flanking enemies, else the lowest-HP enemy in the pocket (most killable).
local hTarget = J.IsValidHero( target ) and target or nil
```

注释说「**如果它是包围圈里的敌人之一**」。谓词说「活着、可见、是英雄、不是我方」。
**「包围圈」三个字在代码里一次都没出现过。**

这不是措辞问题,因为 `hTarget` 是**整个安全判读被取在哪里**的那个点:

- `J.SafeToCommitFight( bot, hTarget )` 数的是 `hTarget:GetLocation()` 周围 **1200** 内的敌我人数;
- 自危分支读的是 `J.GetAlliesNearLoc( hTarget:GetLocation(), 1200 )`。

出货的、**已 promote** 的调用点是 `bots/mode_retreat_generic.lua:345`:

```lua
if J.ShouldSuppressDive(bot, botLocation, botTarget) then
    return BOT_MODE_DESIRE_HIGH
```

其中 `botTarget = J.GetProperTarget(bot)` = `bot:GetTarget()`(当前**命令**目标)退化到
`bot:GetAttackTarget()`,**唯一的过滤是「不是我方英雄/建筑」,没有任何距离界**
(§1 的断言把这条写成了会红的形式,不是一句说明:三个距离函数名逐个断言**不出现在**
`J.GetProperTarget` 体内)。

⇒ **一个声明域是「700 内 2+ 敌人的包围圈」的守卫,可以拿它根本不在的那片地方的胜负判读,
给这个包围圈叫 `BOT_MODE_DESIRE_HIGH` 的撤退价——或者不叫。**

与 GH #782 一族同形(出货注释说的比它的谓词窄),但**仪器不同**:那边是**名字测试**,
这边是一条**从来没被写过的成员资格测试**。0NEXT5 说名字测试那一半收口了——**收口的是仪器,不是形状。**
