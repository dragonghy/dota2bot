## 2. 为什么这条腿是真的缺口(不是「已经有人管了」)

`mode_retreat_generic:222` 上面确实已经坐着一条**已 promote、每局 Turbo 都在跑**的回复否决
`J.ShouldStayAndRegen`。但它在 P2 钉的那一帧上**说不出话**,而且**两个盲点和 item 层那次一模一样**,
两条**各自单独就足够**让它闭嘴(所以两条都单独钉了用例,不能只归因一条):

| 盲点 | 已发布的读法 | 这一帧的事实 |
|---|---|---|
| 危险判据不做归因 | `bot:WasRecentlyDamagedByAnyHero(3.0)` | 决策前 2.6s,**7,533 码外**的宙斯全图大招打了 204 ⇒ 标志为真,而**最近的敌人在 6,596 码外** |
| 回复品只认 flask/tango + 金钱 ≥90 | `IsItemAvailable('item_flask')` / 两个 modifier / `GetGold() >= 90` | 她带的是 **faerie_fire**,金钱 < 90 ⇒ 三条全不成立 |

新核心谓词 `J.ShouldRegenNotGoHome` **把受击做归因**(只有那个英雄**此刻仍在 3000 内**才算危险),
回复品读**背包槽 0-5 的实物**(`J.HasFieldRegenSource`,09:33Z 那半条已建立)。

## 3. 结构:一个核心 + 两个各带 gate 的薄包装

09:33Z 落地的 `J.ShouldRegenNotTpHome` 把条件和 gate 写在一起。本轮拆成:

```
J.ShouldRegenNotGoHome( bot )   -- 核心,turbo-only,【无 gate】,没有任何人直接调
  ├─ J.ShouldRegenNotTpHome( bot )   -- gate 'stayfield'  → aiug 的 撤退:3
  └─ J.ShouldRegenNotWalkHome( bot ) -- gate 'stayfield2' → mode_retreat_generic
```

**两个 id 而不是一个,是故意的**:同一个谓词、两个独立调用点。若共用一个 id,arm 它就同时动两处,
**per-id A/B 当场失去意义** —— 这正是 GH #29 重排撤退 guard chain 要杀掉的那种不独立性。
P2 的完成定义要两条路都覆盖,**所以这两个 id 是一起 arm 的**;分开只是为了事后**分得开**。
用例把这条独立性钉住了(arm `stayfield` **不动**撤退出价 0.1441;arm `stayfield2` **不打开** TP 那半)。
核心无 gate ⇒ **多一个直接调用者就等于把行为发布出去**,所以两个文件各有一条「调用者恰好 3 处/0 处」的断言。

## 4. 本轮真正的发现:全语料扫一遍,把一条**会误伤**的设计当场拦下

把 `mode_retreat_generic.GetDesire()` 在**全部 100 枚 fixture**上各驱动两遍(gate 开/关),
第一版谓词(没有塔那条腿)在 **4 帧**上为真,其中 **2 帧**真的动了撤退出价。
**动得最狠的那一帧不是好事**:`f_260819_142047_zuus_ult_denied` 的撤退出价是 **ABSOLUTE×1.1**
(全系统最高),而那个出价**根本不是回家** —— 用 `debug.sethook` 逐行追出来,它来自
`X.ShouldRun` 的 **前期谨慎冲塔**(`mode_retreat_generic:885`:等级 ≤10、`DotaTime()` < 5:00、
血 < 800、**898 内有敌方塔**)。那是一个 7 级宙斯 40% 血、**站在敌方塔 727 码处**、
最近的敌方英雄在 7,000 码外。**把它压成 0 = 让他继续泡在塔的射程里。**

⇒ 核心谓词加第五条腿:**1200 内没有敌方塔**(1200 是那几条塔子句自己用过的最大半径,
因此仍然**严格比它守的每条分支更保守**)。加完之后:**3 帧为真 / 1 帧动出价**(动的就是钉住的那帧)。

**这条正是 charter 反复记的那件事的又一例**:局部正确的谓词,放到真实竞价里会碰到**别的意思**的分支。
`mode_retreat_generic` **不只是「回家模式」**,它同时承载**局部后撤**出价 —— 一条一刀切的
`return DESIRE_NONE` 比它看上去宽得多。这条读数建议写进任何以后动 retreat 出价的工作单元。

**诚实边界(写进用例了)**:100 枚 fixture 里 **43 枚不带 buildings**(第十七条世界断言,GH #100),
那些帧上塔这条腿**是空真、不是被验证过**。
