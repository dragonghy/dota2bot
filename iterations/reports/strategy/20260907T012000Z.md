## 2. ⭐ 落地的杠杆 `wkreinctr`:一个 `GetAbilityByName` 的把手,被当成「技能存在」

`J.IsWkReincarnationArmed`(`bots/FunLib/jmz_func.lua`)是 **SHIPPED**,它唯一的调用点
`bots/mode_retreat_generic.lua ~:198` 也是 **SHIPPED、无 candidate gate**,而那个调用点
把它的答案花在 **`return BOT_MODE_DESIRE_NONE`** 上 —— **整个撤退模式**在那一帧被清零,
位置在**整条 retreat guard chain 之上**。语义是「站着打,大招是我的安全网」。

它凭两个引擎读数下这个判断,**而两个都不是要紧的那个**:

```lua
local abilityR = bot:GetAbilityByName( 'skeleton_king_reincarnation' )
if abilityR == nil or abilityR:GetCooldownTimeRemaining() > 1.0 then return false end
...
return bot:GetMana() >= nReq          -- nReq = 160
```

- `bot:GetAbilityByName` 对一个**没点技能点**的技能**照样返回一个活的把手** ——
  未学习的技能不是 `nil`,是一个 **level 0 的技能**;
- 一个 level 0 的技能**不在冷却里**,`GetCooldownTimeRemaining()` 答 **0.0**,
  上面那条守卫**放行**;
- 剩下的 `bot:GetMana() >= 160` 是任何一个骷髅王从第一分钟起都满足的。

⇒ **一个没点大招的骷髅王读作 ARMED**,团战里**整个撤退模式被关掉**。
`bot:GetLevel() >= 6` 是**英雄等级**,它对技能点去了哪里**一个字都没说**。

**⭐ 树在八行之外就已经知道该问什么**。`mode_retreat_generic` 自己的 huskar 块,
**同一个函数体内**:

```lua
local hAbility = bot:GetAbilityByName('huskar_berserkers_blood')
if hAbility and hAbility:IsTrained() and hAbility:GetLevel() >= 3 then
```

同一个引擎调用、同一个文件、同一个函数 —— 而它**先问 `IsTrained()` 再相信那个把手**。
`axeblink` 也是(「the bot is Axe and has actually LEARNED Call」)。
**这一行只是没被带过来。**

**落地**(gated、turbo 显式、STANDALONE):

```lua
if J.IsSoakCandidate( 'wkreinctr' )
and J.IsModeTurbo()
and not abilityR:IsTrained()
then
    return false
end
```

**方向由构造固定**:一条排在所有其它判据**之前**的否决 ⇒ 只能把 TRUE 变 FALSE,
armed 的 TRUE 集是出厂的**严格子集**,它在调用点上唯一能造成的行为是
**把出厂压制掉的撤退模式还回来**,永远不可能压制一次出厂允许的撤退。
未 armed 时 `J.IsSoakCandidate` 是**第一个合取项**,turbo 与引擎的 `IsTrained()`
**都不求值**,兄弟 `wkreincarnmp` 的那条子句**逐字节同构**。
