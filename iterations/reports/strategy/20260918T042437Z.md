## 二、缺陷

三个站点问同一个问题、写同一个式子:

```
#allies + 1 >= #enemies          -- `+ 1` = 发问的 bot
```

| | 文件 / 函数 | 我方那一半的生产者 | `bot` 为什么在里面 |
|---|---|---|---|
| A | `mode_team_roam_generic.lua:507` `ConsiderHelpAlly` | `J.GetAlliesNearLoc` | 绕**队友的位置**走**队伍花名册**,谁都不排除 |
| B | `mode_team_roam_generic.lua:1884` `X.ConsiderHelpWhenCoreIsTargeted` | 同上(逐字孪生) | 同上 |
| C | `jmz_func.lua` `J.EvalTeamfightIdle` | `J.GetNearbyHeroes( hFocusedAlly, 1200, false, … )` | 它**确实**排除了一个自己 —— `hFocusedAlly`,**不是 `bot`** |

⭐ **C 的重复计数是无条件的,由构造不是运气**:`hFocusedAlly` 取自
`J.GetNearbyHeroes( bot, 1000, … )` ⇒ `dist(bot, hFocusedAlly) ≤ 1000 < 1200`
⇒ `bot` 在那个圈里,**这条分支能到达的每一帧都成立**。语料逐位同意:`c_self` **69 / 69**。

⭐ C 自己的注释写着 focused ally *"is deliberately not counted (it may die), keeping the
numbers check pessimistic"* —— **那句是真的**。它写的是一个**真命题**,而那个真命题
恰好让人不再去问「那 `+ 1` 补的是哪个自己」。

## 三、⭐⭐ 本轮买到的可迁移句(全队)

> **「这张表里有没有我」是一个信念,它有两个极性,而修好其中一个极性
> 不会让任何人去找另一个。**

现场:**`soloclaim`**(同一个文件,**一天前**,**同一组**,`jmz_func.lua:3374` 的注释)
修的是**反向**的同一个信念 —— 那里代码相信 ally 表**装着**发问者(`#hAllyList <= 1` 当成
「只有我」、`ally ~= bot` 排除一个不存在的条目),而 `J.GetNearbyHeroes` 以发问者为心、
**从不装它**。本轮是同一个信念的另一极:代码相信表**不装**发问者,而它总可能装。

📌 **判据**:两个「附近队友」的生产者差别**只在这一点上**,而**名字看不出来** ——
`J.GetNearbyHeroes(bot, …)` 以**我**为心(排除我),
`J.GetAlliesNearLoc(vLoc, …)` 以**一个点**为心(不排除任何人),
`J.GetNearbyHeroes(ally, …)` 以**别人**为心(排除**别人**)。
**看到 `+ 1`,先问这张表是以谁为心的;看到 `ally ~= bot`,问同一个问题。**

⚠️ 这一条和 0NEXT42(「一条已经被写进注释的诊断,只修在它被发现的那一个调用点」)
**不是同一条**,但它们串在一起就是本轮的做法:0NEXT42 说**去数那个分支有几个调用点**,

## 四、修法(一次一个小杠杆)

`bots/FunLib/jmz_func.lua`,`J.GetRoamParityRadius` 正下方:

```lua
function J.GetHelpParityAllyCount( bot, tAllies )
	local nCount = #tAllies
	if not J.IsSoakCandidate( 'helpself' ) then return nCount + 1 end
	if not J.IsModeTurbo() then return nCount + 1 end
	for _, hAlly in pairs( tAllies ) do
		if hAlly == bot then return nCount end
	end
	return nCount + 1
end
```

三个站点全部改走它。**没有新常数,不是算术** —— 修的是**成员资格**,
`#tAllies - 1` 在证人帧上答对、在对照帧上答错(变异体 M7 钉这个)。

**方向由构造定死**:armed 的答案是 `#tAllies + 1` 或 `#tAllies`,**永远不多于** shipped
⇒ `>= #enemies` 只能 **TRUE→FALSE**;三个消费者**无一例外**把 TRUE 读成「有人数,去帮」
⇒ armed **只能收回一次支援,开不出一次新的支援**。
⇒ 批测读数若反向,**不能**读成「杠杆让 bot 过度支援了」。
