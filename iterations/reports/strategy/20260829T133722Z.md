## 3. ⭐ 主判据乙(更尖):(A) **照字面写不出来** —— 门藏在被调用者体内

`J.ShouldHoldBlinkFlee` 体内自带 `J.IsSoakCandidate( 'blinkflee' )`。**一个自带门的 helper 就是一个合取式**:把它挂到新站点的新 id `blinkproj` 下,新杠杆其实是 `blinkproj AND blinkflee` ⇒ **只 arm `blinkproj` 的隔离波量到的是 no-op**,而 `check_armed_wiring.py` 照样判 WIRED(它查「调用点存在」,不查「谓词可能为真」),裁定读回来是最贵的那句「测了,没效果」。

这是 AGENTS.md 的 `pullcad` 一族,但**两处不同,而且都朝更难看见的方向**:

1. **pullcad 的判别法在这里是瞎的。** 它教人 grep「这个 id 有没有出现在**别的门的条件里**」,而第二个 id **不在新门的文本里** —— 它在**被调用者的体内**。
2. **吃亏的时刻换了。** pullcad 在 **promote 那天**冻死;这一条**从落地第一天就 inert**,于是那一波隔离测的钱直接白花。

**判别便宜,而且已经写成运行中的代码**(`[census]`):**对每一个当守卫用的 helper,grep 它的函数体有没有 `IsSoakCandidate`。** 本仓这个集合是 **50+ 个 helper**(断言是**下限**不是等式 —— GH #273 的教训:一条自己定义为「加一个 gated helper 就 +1」的量用 `eq` 钉死,会把合规的活打红,同时对「解析器悄悄漏掉成员」是瞎的)。

**而且这个形状已经实现过一次**:`J.ShouldFieldBuyRegen`(`fieldbuy`)调用 `J.IsFieldSipEnough`(`fieldsip`)——**上一轮本组自己造的**。那一处**安全,而且理由能写成算术**:内层 helper 未 armed 是**字面量 `true`**,即它所在合取式的**单位元**,所以只 arm 外层与出厂逐字节相同。`ShouldHoldBlinkFlee` 未 armed 是 `false`,在出厂调用点的 `not` 底下同样是单位元 —— **对出厂树中性(所以 (A) 是 inert),但对新 id 不中性**。

⇒ 这条顺带给出 §CE.6 那个次序问题的**一般形式**:**要么在同一条腿上 arm 被调用者的 id,要么让被调用者未 armed 的取值是它所在合取式的单位元。** 两者都不满足时,那个 id 买不到读数。

## 4. ⚠️ 方法自伤:一次**假的**变异幸存者

第一轮 battery 里 **M7(伤害窗口 `2.0 → 5.0`)记成了「幸存」**(14 例全绿)。**错了 —— 那个变异从来没被应用到目标上**:补丁用的是**首次出现的字符串替换**,而 `WasRecentlyDamagedByAnyHero( 2.0 )` 这一行在 `jmz_func.lua` 里出现 **20 次以上**,首次出现在 **:1302**,离 `ShouldHoldBlinkFlee`(**:9471**)**8000 多行**。

> **一个按「首次出现」打补丁的变异 battery,会静默地把变异打在别的站点上,然后把「没打上」记成「打上了但没被抓到」。** 后者会让人去加断言(去修一个不存在的洞),前者要修的是 battery。**判别便宜:变异后先 `git diff` 看落点,再看读数。**

**修法是加固,不是删掉那一条**:补丁器改成**按函数体锚定**,并补两条断言 ——

- **`[boundary]`**:语料**能**钉住这个窗口,而且钉得动:`v2_dmg5 = 112`、**伤害年龄落在 (2.0, 5.0] 的帧 = 32**、`v2_quiet5 = 261` ⇒ 把窗口放宽到 5.0,压制域 **275 → 261(−14)**。同时断言即使在最宽的窗口下结论不变(仍 > 55%)。
- **`[source]`**:两个出厂常数 `0.70` / `2.0` **在函数体内**钉住(锚定到函数,正是为了防止 pin 漂到那 20 多行同文本的其中一行上 —— 就是造出假幸存者的那次漂移)。

重打之后:**M7b(2.0→5.0,函数锚定)3 红**、**M14(2.0→2.5,能动的最小一步)1 红**、**M15(sweep 的边界探针塌回 2.0 的读数)1 红**。

**与上一轮(GH #300)方法自伤(甲)同族但反号**:那次是「让常数不承重的那条空隙,同时让它的边界测不出来」;这次是「**看起来测不出来,其实是量具没搭上**」。两次都要靠**在语料上把敏感度真读出来**才分得清。
