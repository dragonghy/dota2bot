## 1. 改的是什么

`bots/FunLib/jmz_func.lua`,`J.ShouldTpSupportTowerFight` 的建筑循环准入式:

```lua
if J.IsValidBuilding( building )
and string.find( building:GetUnitName(), 'tower' ) ~= nil
and not J.IsOutpostBuilding( building )          -- ← 本轮
and GetUnitToUnitDistance( bot, building ) > J.TP_RESPONSE_FAR_FLOOR
```

`npc_dota_watch_tower` 含 `tower`,被占领的瞭望塔属于本队 ⇒ 它就在
`UNIT_LIST_ALLIED_BUILDINGS` 里,于是一场瞭望塔边上的仗被当成「我方塔下的仗」,
可以引一次防守 TP。语料实测 **8/113** 个站点是瞭望塔,其中 **5 个深在敌方半场**
(最深处离敌方遗迹比离我方近 5,827)—— 那正是应答者最赢不了的地方。

谓词 `J.IsOutpostBuilding` 是上一轮为同一族的另一个调用点
(`J.ShouldRefuseUnsupportedPunish`,`ohnum`)落的无闸纯谓词,本轮直接复用。

## 2. ⭐⭐ 为什么在**没有端到端证人**的情况下落地(这条是本轮的方法论产出)

GH #782 立案时明写「REGISTERED, NOT REPAIRED」,理由是语料买不到一次瞭望塔应答,
§4 要一帧。本轮**照落**,理由不是等不及:

> **方向是闭式的就要证明,不要证人;证人数只用来定价 —— 而这里它把效应量定在零。**

合取项加在**准入式**上 ⇒ 候选集是未收窄集的**严格子集**;循环 `return` 第一个准入的
建筑 ⇒ **收窄后能应答的帧,未收窄时也能应答**。响应集只可能变小,唯一可达的差别是
把瞭望塔换成真塔 —— 而那正是修复本身。这个论证**不依赖语料**,所以没有任何一帧能让
它更真。一帧能买到的是**效应量**,而 §3 把它**直接量了**(不是留白)。

这比 issue §4 在「帧回答不了的那一半」上要求的更多。先例同族同谓词:
`ohnum`,2026-09-12(`tests/test_ohnum_outpost_anchor.lua`)。

## 4. ⭐⭐ 本轮真正的发现:**命名一种拼法的门守的是拼法,不是事件**

`tests/test_tpdeftower_anchor_pricing.lua` §7 **昨天**专门写了这道门来在收窄落地时报警:

```lua
assert(host:find('watch_tower', 1, true) == nil,
    'the host now names `watch_tower` in CODE, i.e. the outpost narrowing has landed. ...')
```

落地的写法是调用共享谓词 `J.IsOutpostBuilding( building )` ——
**宿主里从头到尾没有出现过 `watch_tower` 这个串**。⇒ 这道门在**它唯一存在理由的那个
事件上保持全绿**,而 §6 会继续给一个出货代码已经放弃的域定价 8 个站点。
**守卫在场,守卫不承重。**

与 2026-09-12 的 M8 同型、方向相反:那次是**死量具**免费证成一次定价,
这次是**活量具**给一个它**自己重建、而不是读取**的过滤器免费证成。
两者的解药是同一条:**让测试解析出货表达式,而不是复述它**。

2. **§6 改走显式反事实**:收窄落地后,驱动**出货**宿主是**死量具** ——
   `outpost_answered == 0` 由构造恒真、永久免费证成(GH #171 形状的另一面)。

   出货宿主必须逐行拒掉瞭望塔。§6 抬头改注为「未收窄过滤器的定价,**存作历史**」。
