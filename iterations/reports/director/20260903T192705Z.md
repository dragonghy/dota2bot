## 二、本轮产品:五条「按日程变红的闹钟」换成五条不会随落地变红的断言

### 2.1 缺陷的形状(它比这两个文件大)

五条红,分布在两个文件里,**是同一个缺陷的五个实例**:一条 check 的**名字**
说的是一个不动的性质,而它的**断言**钉的是一个每次落地都会动的数。

| 站点 | 名字声称的性质 | 断言实际钉的 | 谁把它推红 |
|---|---|---|---|
| `test_chain_member_census.py:241` | `denominator: and/or chains scanned` | `== 10946` | `zeusaghs5`/`arbheart` 落地动了 `bots/` ⇒ 10950 |
| 同上 `:243` | `denominator: locals with an initializer` | `== 16088` | 同上 ⇒ 16094 |
| 同上 `:245` | `denominator: guard-only locals` | `== 45` | (今天恰好还是 45) |
| 同上 `:490` | **`the fixture archive is NON-EMPTY`** | `== 107` | 新 fixture 落地 ⇒ 108 |
| 同上 `:511` | **`…is non-zero, so the zeros above are not an artefact`** | `== 53` | 新 CM fixture ⇒ 54 |
| `test_threshold_chain_census.py:360` | `the archive does reach the 750 s rung, but only just` | `len(late) == 2` | 一份过 750s 的新 fixture ⇒ 3 |

**最后两行是最干净的证据**:名字里逐字写着 `NON-EMPTY` 和 `is non-zero`,
**性质是对的,数是多余的** —— 多余的那一半就是唯一会响的那一半。

⭐ 上一轮 §DU.3 的判据在这里第二次被买到,而且这次是在**测试**里而不是在档案里:
**一个分母只有在「它不该动」的时候才配被冻住;钉一个每次落地都会变的分母,
买到的不是棘轮,是一个按日程变红的闹钟。** 这一队**每周都在往
`tests/fixtures/` 里加帧**(那是铁律 4 要求的),所以 `== 107` / `== 53` 这类断言
**是被本队自己的正确工作推红的** —— 09-03 十四小时内推红两条,就是这么来的。

### 2.2 修法,逐条

- **三个分母 → floor**,并把「这是塌缩探测器,不是棘轮」写进 check 的名字里
  (`denominator floor: … -- collapse detector, NOT a pinned count`)。
  floor 取当日读数的约 2/3(chains ≥7000 / locals ≥10000 / guard-only ≥30)。
- **fixture 档案 → `>= 90`**,与**同一个档案在隔壁文件里已经在用的形状逐字一致**
  (`test_threshold_chain_census.py:311` 早就是 `len(fixtures) >= 90`)⇒ 这不是发明,
  是**把已经存在于仓库里的正确形状搬到剩下那半边**。
- **CM 对照 → `> 0`**(名字怎么说,断言就怎么写)。
- **两种拼写的对照 → 关系而不是两个数**:`vs_a > 0 and vs_b > 0 and vs_a != vs_b`。
  这条**当天还是绿的**,和红的那些是同一族,**同一轮一起改** ——
  留着它就是留一个已知会在下次归档 vengeful spirit 帧时响的闹钟。
- **750s 那条 → 「非零 + 占比上限」**:`len(late) >= 1`(那句「语料够不到 750s」
  是本轮档案自己记着的、**错过的第一稿**,必须继续钉住)`and len(late)*100 <= len(times)`
  (「只是刚够到」= 晚帧占比 <1%;写这条时的读数 3/620 = 0.48%,约 2 倍余量)。
  **它会在「only just」真的不再成立的那天响**,而不是在有人归档了一帧的那天响。

### 2.3 ⭐ floor 买不到的那一半,单独买了(本轮唯一的新机制)

把 `== 10946` 换成 `>= 7000` 是**净损失一项**:两者对「走查掉了一两个文件」
**同样是瞎的**(10945 既不等于 10946,也照样 ≥7000 —— 前者响是因为它对**任何**
变化都响,不是因为它对这个变化敏感)。而变异台 M4 的注释写着「只有分母能把
『走查走了个空』和『树是干净的』分开」——那句话对**全瞎**成立,对**半瞎**不成立。

⇒ `chain_member_census.scan()` 新增 `visited=None` 出参(**不改返回元组**,
十个既有 5-tuple 调用点逐字不动 —— 让新断言不必编辑它要认证的东西),
测试侧断言一条**关系**:

```
visited == cmc.lua_corpus.bots_lua_relpaths()
```

「这次走查读了**恰好**那份语料,不多不少,顺序也一样」—— **bots/ 长大它不会响,
掉一个文件它一定响**。新增变异 **M13**(`bots_lua_files(root)[:-1]`,少读最后一个
文件)专门证明这条断言承重:M13 对 floor 和对旧的 `== 10946` **都不可见**,
findings 棘轮也只在被丢的那个文件恰好装着十二个发现之一的那天才看得见。
