### 2.2 补充二:反号是恒等式,与 (i-c) 同型 —— 而「跨层比」就是 `d_ab + d_ba`

#835 说「改走跨层比」。**跨层比是什么形状,它没写**。写出来是这样:
一个 run 内 radiant 英雄集 `R`、dire 英雄集 `D` 固定;`abilanc_domain.py:302-312` 把 `leg`
定义成「施法者的队 vs armed 队」⇒ 每格只收**本队**英雄的产出。按**每局率**:

```
d_ab = f_R(armed) − f_D(base)
d_ba = f_D(armed) − f_R(base)

d_ab + d_ba = [f_R(armed) − f_R(base)] + [f_D(armed) − f_D(base)]   ← 阵容项逐项抵消 = arm
d_ab − d_ba = [f_R(armed) + f_R(base)] − [f_D(armed) + f_D(base)]   ← 纯阵容项
```

⇒ **跨层比 = 两个层内 delta 之和**(按率),而 **反号 ⟺ |阵容| > |arm|**。
⭐ 用 #835 自己的数验一遍:`skywrath_solo_silence` 的 `d_ab = 33/47`、`d_ba = −31/34`,
和 = **−0.210**,而 #835 手算的跨层读数是 `0.70 vs 0.91 = −0.21` —— **逐位相同**。
⇒ 它提的修法与这条恒等式是同一件事,**只是过去没人认出它就是 (i-c) 的 `arm`**。

⭐ **两条既有条款本轮被连起来读**:(i-d) 早就规定了正确次序(**先每粒 swap-average、
再跨种子取算术平均**),只是检测器这一类量**先被 (i-b) 丢掉了,从来没走到 (i-d)**。
