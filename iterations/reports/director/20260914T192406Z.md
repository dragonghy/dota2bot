## 三、⚖️ RULING 40 — `selfcheck_recursive_fork_amplifier` 退休(机理被实测否决)

### 立行的证据本轮照样出现了,而它不是它看起来的东西

```
1961  bash tools/agent/routine_selfcheck.sh     <- 顶层(我自己起的)
 └ 3240  bash tools/agent/routine_selfcheck.sh   <- ppid 1961,argv 逐字相同
    └ 3241  bash tests/run_py_tests.sh
```

⭐ **3240 不是第二个自检,是 `1961` 的一个命令替换子 shell。**
`routine_selfcheck.sh` 的 python 腿逐字写着 `suite=$(bash tests/run_py_tests.sh 2>&1)`;
bash 为命令替换 fork 一个子 shell,而**子 shell 在 `ps` 里沿用父进程的 argv**。

🔧 **最小复现(脚本里没有任何递归),本轮当场两向实测**:

```bash
# /tmp/subshell_demo.sh 全文:
#!/bin/bash
out=$(sleep 5; echo hi)
```
⇒ `ps` 同时显示 `8866`(ppid 8863)与 `8868`(ppid 8866),**两行 argv 都是 `bash /tmp/subshell_demo.sh`**。

**⇒ 「N 个 `routine_selfcheck` 进程」这个读数本身就会把 1 个自检读成 2 个**,而计数里没有任何东西说明这件事。
本轮收尾时自检在跑,`pgrep -c -x -f` 稳定读 **2** —— 那是 1 个自检,不是 2 个。

### 第二处 falsification:被点名的文件根本不跑完自检

本行裁定正文逐字说放大器是 `tests/test_selfcheck_pipe_guard.py` 的「必须不被拒」两个 case。
现读该文件,它对自检的**全部**调用只有三处,**本轮逐条隔离实测,三条全部被守卫当场拒绝**:

| 调用 | 实测 |
|---|---|
| `… 2>&1 \| cat` | `REFUSED` |
| `… > >(cat) 2>&1` | `REFUSED`(`> >(cat)` **确实是 FIFO**,本轮实测 `[ -p /dev/stdout ]` 为真) |
| `… 2>&1 \| tail -1` | `SELFCHECK_EXIT=2  REFUSED` |

而它那两个「必须不被拒」的 case **压根不起自检**:case 2a 是一句 `[ -p /dev/stdout ]` 探针;
case 4 带 `--bogus-arg`,**停在参数解析器**。⇒ **该文件没有任何一条路径会把自检跑完。**

### 第三处,最该被读的一处:真正的缓解早就落地了,只是在另一个文件里

会把自检**跑完**的是 `tests/test_selfcheck_timeout_guard.py` 的 case 2/3(裸跑 + opt-out)。
而那个文件**已经**带 `start_new_session=True` + `os.killpg` + `PROCEED_BUDGET_S = 6`,
注释逐字留着立它的现场:`measured before this was added: 11 stray routine_selfcheck processes and a load average of 4.88`。

⇒ **本行描述的真实代价是真的、也确实被修了 —— 修它的正是登记本行的那同一个 commit(`ab537b95`),
只是作者把病根和功劳都记到了隔壁文件头上。**

🔧 `killpg` 现读:`test_selfcheck_timeout_guard.py` = **2**;`test_selfcheck_pipe_guard.py` = **0**。
⛔ **于是本行的 `done_when`(`path_contains_all` / `pipe_guard` / `killpg`)是任何一个正确的修法都买不到的**:
正确的修法落在另一个文件,而在 `pipe_guard` 里加 `killpg` 只会让一个**不需要它**的文件出现这个词
—— 本行 note 自己引的 **LIMIT 11「mention is not correctness」反着成立一次**:这里连 mention 都不该有。

### ⛔ 三件事分开记账,不是「查无此事」地撤销

- **(甲) 真实代价确实存在过**(11 个游离进程 / load 4.88,timeout_guard 注释里逐字留证);
- **(乙) 它已经被修好**(同一 commit,`start_new_session` + `killpg` + 6s 预算);
- **(丙) 本行的裁定正文、`done_when`、`unmet_at_ruling` 三处指的都是一个不成立的机理和一个错的文件。**

⇒ 退休理由是 **(乙) 已买到 + (丙) 判据不可能被正确修法满足**,**不是** (甲) 不存在。

### 📌 可复用,而且这一条比它修掉的东西值钱

⭐ **`ps` 的进程计数是「界限穿着测量值的衣服」那个家族的近亲,但更狠一格:
它是一个 argv 的计数,不是一个程序的计数**,而两者在**有命令替换的脚本上系统性地不等**。
