## 3. 处方:`done_when` 加一种 `kind: "text_absent"`(GH #523)

那一行的 `done_when_note` 从**正确的前提**推出了 `manual`:「注释说得对不对没有任何断言读得出来」
—— **这句话是真的**。**但它从来没问过容易的那一半:那两句写错的话还在不在。**

它们是字面串,当时在文件里逐字存在:

```
the whole "75% of capture attempts are aborted" finding is about that missing guard
if this fails, the guard landed
```

一个 `text_absent` 键会在 **07:01Z 当场读 DONE**,那一行**根本不会被登记**。

> **通则:凡是「把这句写错的话改掉」形状的裁定,正面那一半(新说明对不对)不可读,
> 反面那一半(旧说明还在不在)永远可读。**

⛔ **三态,不是两态**:文件读不到 = `UNCERTIFIABLE`(**不是 DONE**);文本还在 = `OWED`;
文件在且文本没了 = `DONE`。**必须同时要求 path 存在** —— 文件被整个删掉时读 DONE 是这种键
唯一的假阳,而「文件没了」已经被 `path_absent` 占走了。失效方向与 GH #171 同一条:
**读不出来的条件永不读成已执行**。

**已登记为 `owed_executions.json:text_absent_done_when_kind`,而这一次机器键是买得到的**:
`done_when: {kind: path_exists, path: tools/agent/mutstand_text_absent.sh}`。
**本轮不自己实现**(值一个工作单元,且需要一台每发都是假阳方向的变异台)。
