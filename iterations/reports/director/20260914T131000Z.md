### 2.1 验收测试与变异台 —— 而这里才是本轮最该被读的一段

`tests/test_selfcheck_timeout_guard.py`,**9 checks**,基线 `9 checks, 0 failed`(`RC_EXIT=0`)。

| 变异 | 改动 | 结果 |
|---|---|---|
| M1 | 守卫整体停用(`if false &&`) | **CAUGHT**,6 条失败(1a/1b/1d/1e/1f/4a);1a 逐字「did not answer within 60s」⇒ 抓它的机制是**自检真的跑起来了**,不是别的 |
| M2 | 守卫无条件触发(`if true ||`) | **CAUGHT**,2a(裸跑必须不被拒)⇒ 假阳性那一侧不是空断言 |
| M3 | 祖先回溯 3 层 → 1 层 | ⛔ **SURVIVED,`9 checks, 0 failed`** |
| M3′ | 同上,但 case 4 已修 | **CAUGHT**,4a |
| M4 | 去掉 `SELFCHECK_TIMEOUT_OK` 逃生门 | **CAUGHT**,3a |

⭐⭐⭐ **M3 活下来,而它揭发的是我的测试在假装测一件它根本没测的事。**
case 4 原本写作 `timeout 600 bash -c 'bash <script>'`,本意是「祖先不是父亲」这一层;
而 **bash 对单条简单命令的 `-c` 体会 `exec`**,于是中间那个 bash 根本不存在,`timeout` 成了**直接父进程**。
当场两向实测(13:1xZ):

    timeout N bash -c '<one command>'        -> 父进程 comm = timeout
    timeout N bash -c '<one command>; true'  -> 父进程 comm = bash

⇒ 该 case **一直在用父亲检查冒充祖先回溯**,而它读绿。修法是把体变成复合命令;
⚠️ 第一版修成 `; true` 又踩到第二个坑:`; true` **把脚本的退出码换成了 `true` 的**,
于是 4a 读到 `rc=0` 而拒绝文本明明在。最终用 `|| exit $?`(同样复合,且保码)。
📌 **两个坑是同一个形状的两半:一条「看起来在测 X」的命令,实际测了 X 以外的东西,而两次都读绿。**

⭐⭐ **同型的第二发,在同一个文件里,早两小时**:该测试第一版**没有**设 `SELFCHECK_PIPE_OK=1`,
而 `subprocess.run(capture_output=True)` 的 stdout 是 FIFO ⇒ **管道守卫抢先应答**。
结果是 **1a/1b/1c 三条全 PASS** —— 因为**两道守卫都打 `REFUSED`、都 exit 2** ——
只有「要求拒绝**说出自己的原因**」的 1d 把它们分开。
⇒ 已把这一条写回**管道守卫自己的注释**,并**更正它那句已经过期的自述**
(它逐字写着 `Measured cost of that today: ZERO call sites`;**现在不是零了,第一个 call site 就是这个测试**)。
**可复用的一条:两道共用词汇的拒绝可以互相冒充,而分不开它们的测试两边都读绿。**

### 2.2 顺带修掉的一个真实副作用

must-not-refuse 那两个 case **本来就该跑到预算到期**,而 `subprocess.run(timeout=)` 只杀直接子进程
⇒ 自检与它派生的各条腿被**孤儿化**。实测:**11 个游离 `routine_selfcheck` 进程,load average 4.88**
(一台没别的事干的容器),而这反过来拖慢正在被测量的那些跑。
已改为 `start_new_session=True` + 超时 `killpg`。
