## 1. [harness] 修绿:**一个楼层搬了家,两个读同一份源码的仪器只有一个跟着搬**

### 1.1 成因(裸读,不是照抄 commit message)

英雄组 `1642591b`(`cmfarcreep`,09-07T20:09Z)把 CM 打钱块里 far 半边的宽松楼层
从内联比较 `nEnemysStrongestCreepsHealth1 > 390` 改成了**函数调用的第三个实参**:

```lua
-- bots/BotLib/hero_crystal_maiden.lua:1282-1285
if ( nEnemysStrongestCreepsHealth2 > 460
        or ( X.cm_IsFarCreepFloorMet( nEnemysStrongestCreepsHealth1, nEnemysStrongestCreepsHealth2, 390 )
                and nMP > 0.45 ) )
    and nEnemysStrongestCreepsHealth2 <= nCreepCap
```

**同一个 commit 教会了 Lua 那把尺子**(`tests/test_cm_ranged_creep_health.lua:189-203`,
它连「调用没带字面量楼层」的报错句都写了),**没有教 python 这把**
(`tools/batch_test/behavioral/cmrangedhp_domain.py:consumer_floors`)。
后者按行扫,判据是「这一行含 `nEnemysStrongestCreepsHealth` **且**含 `>`」——
新那一行**没有 `>`** ⇒ **390 静默掉出读数**,函数照样返回一个干净的三元素列表。

⭐ **为什么这条红值得写这么长:掉的那个楼层恰好是四个里最窄的那个。**
下游两条断言分别是「四个楼层」和「`500` 清得过每一个楼层」。第二条在少了 390 之后
**照样为真**(500 > 460/410/360),所以**这个缺陷只在第一条上举手**;
真正的失效方向是**将来**:谁把 390 抬到 550,这把尺子**看不见**,而
「arming 只会让域变窄」那句话会**静默地**变成假的。
⇒ **修法是教它认新家,不是把期望值降成三个** —— 降成三个等于给一个文件不再具有的形状发证。

### 1.2 修法

`consumer_floors()` 改成**两个形状都读**(与 Lua 那把尺子逐条对齐,让两个仪器不会再各走各的):

- `nEnemysStrongestCreepsHealth[12] > <字面量>` —— 内联那三个;
- `X.cm_IsFarCreepFloorMet( ..., <字面量> )` —— 搬走的那个。

⭐ **外加一件 commit `1642591b` 没有做、而本轮顺手买掉的事:先剥注释再扫。**
那个块**自己的注释**里逐字写着 ``…Health1 > 390``,**今天它没被当成代码读,
唯一的原因是它把标识符缩写成了 `...Health1`。** 把标识符拼全,一个不剥注释的扫描
就会在**散文里**「找到」那个楼层,而代码里的真楼层可以在任何地方。
这就是本仓库已经记了四发的「文本裁判把注释读成代码」;**这一发是在它发生之前堵掉的,
不是抓到的**。

另:调用还在、但楼层不再是字面量时,返回 **`None`(unknown)** 而不是短列表 ——
**一个短列表和一个真的只有三个楼层的文件长得一模一样**。
