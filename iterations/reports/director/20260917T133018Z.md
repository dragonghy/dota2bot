## 一 本轮的活:GH #865 (A) —— 第三腿的 scope 改从 stdin 取 remote sha

取自上一轮「下次触发」清单 **①**(欠条 `gh865_prepush_scope_from_stdin`)。

### 缺陷(复述,因为修法只有对着它才讲得通)

`.githooks/pre-push` 第三腿的 scope 取数式是

```
git diff --name-only origin/main...HEAD
```

`origin/main` 是**本地** ref,而 `git push origin HEAD:main` **会把它挪到 HEAD**
⇒ 紧随其后的孪生推问同一个表达式、得到**空 diff**,按 fail-closed 读成「无从判断 ⇒ 跑全集」。
09-17T04:20Z 实测:一次 markdown-only 补推,`origin/main` 已等于那棵树,
打出 `scope EMPTY -> running the WHOLE manifest` 然后**真跑 567.4s,而那棵树 main 上已经有了**。
⛔ 这个表达式**不是对仓库判断错了,是对「正在推的是哪个 ref」判断错了** —— 而只有 git 知道。

git 本来就逐 ref 在 stdin 上给了:`<local ref> <local sha> <remote ref> <remote sha>`,
第四个字段就是这次 push 真正要加到的底,且**不会被同一轮里更早的一次 push 挪动**。

### ⭐ 对 RULING 69 的 (A) 改了一条,理由是实测不是偏好

69 逐字写:「新 ref 时为全零 ⇒ **那才是真正的「无从判断 ⇒ 跑全集」**」。

**那句话对 git 是对的,对本仓是错的**,而差别是量得出来的:

| 读数(2026-09-17 当场) | 值 |
|---|---|
| origin 上 `claude/*` 分支数 | **1264**(每会话一个) |
| 本会话分支 `git ls-remote --heads origin claude/compassionate-albattani-he6j0n` | **空 = 新 ref** |

⇒ **每个 Routine 会话推自己的分支 ⇒ 分支推每一轮都是新 ref**
⇒ 照字面落地,会把**每一轮的第一次 push**(常见情形,含每一个 markdown-only 轮)
**从一个 scope 读数变成一次跑全集**。
📌 **那是拿常见情形的回归,去买一个罕见情形的修复。**

**改法**:新 ref 回落到与 `origin/main` 的 **merge-base**。
⭐ **为什么这不是把缺陷放回去**:分支推**不移动** `origin/main` ⇒ 孪生推那个缺陷**够不着这条路径**;
而真被 main-first 污染时,merge-base 即 HEAD、diff 为空、**空仍然等于跑全集**。
⇒ **回落会丢精度,不会 fail open** —— 而这条路径上只有后者要紧。

### 落地物

| 文件 | 是什么 |
|---|---|
| `tools/agent/prepush_scope.sh`(新) | scope 计算单元:stdin remote sha 权威 / 新 ref 回落 merge-base / **一切失败态 `unknown` + 空表 = 跑全集** |
| `.githooks/pre-push` | 第三腿改用它;**stdin 在任何一条腿之前读走**;播报行带 `base=` 出处 |
| `tests/test_prepush_scope_from_stdin.py`(新) | **27 checks / 0 failures**,八个入口 + 变异台 4 个 |
| `tests/test_push_order_contract.py` | **重锚**(见 §三) |

⭐ `while read` 落在单独的脚本里而不是钩子本体,是为了**能被单测喂 stdin**;
钩子在**任何一条腿之前**读走 stdin(只能消费一次,而 **memo 命中会直接 exit 钩子**),
钉子对这个顺序**单独断言一次**。

### 真树上的端到端读数(两条路各一次)

```
A) 新 ref(本轮分支推真实的样子)   -> fallback-merge-base ,6 条路径(本轮改的那 6 个)
B) 已存在 ref,base=origin/main     -> stdin-remote
```
⛔ **照字面的 69 (A) 在 (A) 这一格会打 `unknown` ⇒ 跑全集** —— 这一格就是那条修改的全部理由。
