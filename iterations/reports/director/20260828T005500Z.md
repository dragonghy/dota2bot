## 2. ⭐ 主产出:`[bug] #257` 落地(交棒清单第 ①,按流血速度排的那一条)

### 2.1 修了什么

`abilanc_domain.py` 的 `layered()` 用 `max(ngames[side], 1)` 做分母、`verdict()` 从不问这一层有没有局。
W17-R 那种**只有 ab 一层**的语料上,`dire` 层 `delta` 恒为 0 ⇒ 表尾打 `one layer flat (not a contradiction)`、
verdict 打 `WORKING-WITH-RESIDUAL`。按 issue 的**首选**方案:

- `layered()` 增 `absent`(缺席 side 的元组)+ 每 side 的 `row['absent']`;
- `show()`:absent 非空 ⇒ note 为 `LAYER ABSENT (0 games: dire) -- NOT a flat layer`;
- `verdict()`:增 **`SINGLE-LAYER`**,排在 `EMPTY-DOMAIN` 之后、**一切** armed/baseline 分支之前。

用 issue 复现里那组数字(18 局全 radiant,armed 1 / baseline 2)渲染出来:

```
  arm side    games     armed  baseline     delta
  radiant        18    1/0.056    2/0.111    -0.056
  dire            0          -          -    ABSENT
  pooled          -         1         2   two-layer: LAYER ABSENT (0 games: dire) -- NOT a flat layer

=== VERDICT  SINGLE-LAYER
```

### 2.2 比 issue 多做的两处(都是落地时才暴露的)

1. **absent 那一行不再印速率。** issue 只要求改 note。可**只改 note 的话那一行仍是 `0/0.000 0/0.000 0.000`,
   而那正是「量过且为零」的长相** —— 缺陷主体还留在行里,note 只是给它加了个标签。
2. **新增 `NO-CORPUS`,排在 `EMPTY-DOMAIN` 之前。** 零局语料原本落进 `EMPTY-DOMAIN`,而它的话术是
   「没有任何存活的 under-tier 英雄帧进入过营地半径」——**那句话断言扫描发生过**。零局时什么都没扫。
   **同一族缺陷在同一个函数里的第二处。**

`SINGLE-LAYER` 特意排在 `a == b` 那条 SILENT **之前**:单层语料上,「armed 与 baseline 打了一样多次」
同样是一句关于我们没有的那个对照的话。
