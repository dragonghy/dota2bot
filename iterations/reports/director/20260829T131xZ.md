## 二、⭐ 本轮的工作单元:那条红不是过期的等待,是检测器的错误归属

### 立案

`test_stale_waits` 点名 batch-desk 12:19Z **活 当前状态** 的这一行:

> `` `odbuild`(§CC/§CF)+ `wkqdmg`(§CD/§CF);同轮提出的 `fieldsip`(§CE)**未裁 ⇒ 不在串里**。``

它把 `odbuild`/`wkqdmg` 判成「等一个已经落地的入集裁定」。
**这一行没有任何一处是假的**:那两个 id 正是我 10:xxZ 同轮双双入集的,
批测台写的是**记录**;而 `未裁` 属于 `fieldsip` —— 那个 id **确实没裁、确实不在串里**。

⇒ 按测试自己的规矩(「fix the charter line, do not loosen this test」)
本该去改章程行,**但这次该改的不是章程行**。这正是 `INVARIANT 5`
(「入集**记录**不是入集**等待**」)要保护的形状,而那条不变量
**只在「行」这个尺度上成立过**:两个半边只要出现在**同一行**的任意位置就算数。
于是「一行里记了一条已落地的裁定 + 顺带注一句另一个 id 未裁」——
**streams 每次入集都会写的那种行** —— 让记录继承了隔壁的等待。
这是 `INVARIANT 2` 的失效方向(检测器在活棒/真话上变红 ⇒ 一轮内被关掉)
**往旁边挪了一个标点**。

### 修法:两个半边改到**分句**尺度,并给它配一条借位规则

`tools/agent/stale_waits.py` 新增 `CLAUSE_SPLIT = [;;。]` 与 `wait_scopes()`:
未决标记只对**它自己那个分句**里的 id 生效。

**借位规则是这个修法能不能立住的关键**:一个带未决标记却**一个 id 都不点名**的分句
(`` `campexit` 的入集裁定;仍欠``)否则就能**靠一个分号把自己消音**。
所以「不点名任何 id 的分句」向前借上一个分句的 id。
**逗号刻意不作为边界**:立案形状本身就是用逗号分隔两个半边的
(`① `campexit` 入集裁定**仍欠**,只提醒`)。

顺带一个**收紧**(不是放松):`RE_RULING`(重裁豁免)也跟着降到分句尺度,
于是「等总监重裁 `A`;另 `B` 入集裁定仍欠」里的 `B` **不再被 `A` 的豁免盖住**。
