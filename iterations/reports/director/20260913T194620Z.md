## 3. 修法:界在**成本**上,不在**存在**上

- **`tools/agent/py_gate.py`**:把 fail-open 测试的秒数**累加**,把**这次运行的真实秒数**
  打在预算旁边,超过 `unmeasured_slack_seconds` 就打 `STALE MANIFEST` 并 **exit 2**(拒 push),
  同一行给出唯一那条补救命令。
- ⛔ **为什么不是「有未登记测试就红」**:那会把一次 ~4min 重测定价进**每一次 push**,
  而失效方向是 `RULE6_BYPASS` 变成常规路径 —— 正是 **GH #707 / #669** 已经点名的那个方向。
  一个便宜的新测试仍然免费(`4g` 钉死这一半),29.5s 的漂移不免费。
- **`tools/agent/py_gate_measure.py`**:新增 `unmeasured_slack_seconds = 3.0` 写进 manifest
  (闸读它,不自己推导;`5g` 钉死)。
- **`tests/test_py_gate.py`**:`5d` 措辞改成精确说明它界的是**选中集**并指向运行期的界;
  `5f` 改成**读磁盘**的覆盖率(带 5 个的 slack + 点名未覆盖文件),老地板降级为 `5f2` 防塌陷;
  新增 `4e/4f/4f2/4g` 行为断言。

**两条界为什么都要留**(纪律 4:同一个结论不是同一个理由):它们**在不同的地方失效**。
20 个 0.1s 的新测试 = 2.0s,**在闸的 3.0s slack 之下永远不红**,而 manifest 已经落后 20 个文件、
它的 `selected_*` 摘要越来越是虚构。**闸界的是一次 push 花多少;`5f` 界的是 manifest 离它声称
描述的那套测试集有多远。**

## 5. 🔧 顺带修掉一个**活的陷阱**:重测会给下一个组留一道红,而 `git status` 是干净的

腿 3 第一次跑出 **`LUA_EXIT=3`,20+ 条 Lua ratchet 红** —— **会拒掉我自己的 push**。
根因不在我的 diff 里:

`py_gate_measure.py` 用 `subprocess.run(timeout=20)` 卡每个测试,而 subprocess 的超时路径
**以 `kill()` 收尾(SIGKILL)⇒ `finally` 不执行**。
`tests/test_lua_corpus_stability.py` 在测试中途写 `bots/Customize/soak_side.lua`
(`SWITCH_BODY` 逐字 `return { side = 'radiant', cand = 'x', seed = 1 }`)、在 `finally` 里删。
**它在本容器上耗时 >20s** ⇒ 两次重测**都**把它杀在那一步之间
(`/tmp/measure1.log`、`/tmp/measure2.log` 同位置 `20.00s TIMEOUT`),开关被留在**armed**。
留下的文件内容与 `SWITCH_BODY` **逐字相同**,这是认定作者的依据(另一个候选
`test_luacheck_gate_soakswitch.py` 写的是**未闭合**的坏串,形状对不上)。

一个 armed 的开关让 ~20 条 Lua 测试的 setup 断言失败(它们自己说得很清楚:
「gate off is NOT what this measures」)。**控制读数**:只删这一个文件、别的什么都不改,
`lua_gate.py` 从 `exit 3` + 20+ FAIL 变成 **`exit 0`,0 findings**。

⛔ **它的全部危险在于它被 gitignore**(`.gitignore:76`)⇒ `git status` 干净、diff 里没有它。
一个重测过的组就这样把**一道没有 diff 可以解释的红**交给下一个组 —— **GH #624 的形状**,
而面对它最自然的两种反应是「别人把 main 弄红了」和 `RULE6_BYPASS`。

✅ 修法:`snapshot_arming_switch()` / `restore_arming_switch()`,在 `try/finally` 里包住整个测量遍。
**窄在刀刃上**:只还原**已知会被杀出来的那一个文件**,不假装给测试套件做沙箱 ——
*一个杀进程的工具,只欠它叫得出名字的那部分清理*。`7k`–`7o` 五条钉死,`M10`–`M14` 五发全 CAUGHT。
