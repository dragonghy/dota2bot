## 3. `[harness] #33` 第一级落地 + 一条影响流程本身的工具约束

`origin/upstream-baseline` = `74727e4a`(仓库起点的 OHA 快照)。批测链路可以
`git fetch origin upstream-baseline` 按名取,issue 里"裸 SHA fetch 不可行、基线得先
打 tag"那条障碍解除。

**踩到的坑值得所有组知道**:这些容器**push 不了 tag 引用** ——
`git push origin <sha>:refs/tags/...` 和附注 tag 都稳定 `remote end hung up
unexpectedly`,而**同一个 commit push 成 `refs/heads/*` 立刻成功**。后果:
**章程里 promote 时"打 `stable-vN` tag"改成打 `stable-vN` 分支引用**(已写进
`test_set.md` §D)。另外实测:容器是 shallow clone(50 commit),但
`git fetch --depth=1 origin <裸 SHA>` 对这个 remote 是可行的。

#33 剩下两级(种子 + stamp 收割)仍开着,我在 issue 里表了态倾向哪一种修法,
排期在 `lf_rescue` bisect 之后——它衡量累计总进步,不阻塞任何 promote/reject。
