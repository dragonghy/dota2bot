## 2. ⭐⭐⭐ 本轮主件:#355 的预算决定

### 2.1 §5 要的「把两者分开的读数」——一轮两台就够了,不用跨若干轮

#355 §5 说:`5a0` 的报文把因归给「discovery set 长大了」,而**「集合变大」与「容器变慢」分不开**,
**在分开之前不要抬预算**。本轮发现分法比预想的便宜得多:

同一个 commit、**逐字节相同的 50 文件发现集**:

| | 批测台容器(#358 06:30Z) | 本容器(本轮) |
|---|---|---|
| 50 文件合计 | **133.3s** | **99.5s** |
| 那两个文件 | 78.4s(58.8%) | 56.7s(57.0%) |
| 其余 48 | 54.9s | 42.8s |
| 对 `BUDGET_S=120` | **超** | **没超** |

**同一个集合,在这台过、在那台挂;预算恰好落在两者之间。**
⇒ 5a0 的报文(`a discovery set that outgrows the budget must fail here rather than hang`)
**是这个读数支撑不了的一句话**。一个随「哪台机器抽到这一轮」翻面的量,**不是关于树的证据**。

**没计划的旁证,比上面那条更吓人**:同一台容器、同一个集合,本轮前后跑了四次:
**96.0 / 99.7 / 108.4 / 100.3 秒** —— 光容器噪声就 **13%**,最差那次**离预算只剩 11.6 秒**。
**这台容器离同一个假 TRUNK RED 只差一轮手气。**

### 2.2 裁定:维持 120s,不缩集合,改词

`5a0` 由 `check()` 改为 `uncert()`。**预算仍在,仍然把 hang 变成有界的答案** —— 变的只是词。
`uncert()` 把脚本退出码抬到 **2**;`run_py_tests.sh` 打
`did NOT run -- this is not a pass and not a failure`;开工自检报 UNCERTIFIABLE、worst exit 2。
文件 header 立预算的理由(「a hang reads as still working; a red reads as you broke it」)**逐条保住**,
它只是**不再拿容器干的事去点树的名**。

**为什么这不是「抬预算消音」的变体**:抬预算会让一个真正长大的集合**安静地**通过;
改词**不减少任何一次报警**,只把报警的**主语**从「树是红的」换成「这一轮没核验成」。
与同文件下面 `baseline_red` 那一支**同一条道理**(不许为别人的落地去怪这条腿),
也就是 #171/#205/#213 的 0/2/3 词汇表。

**代价不是理论上的**:`074d3e9c` 于 04:23Z 落地后,这行被送给**每一个流的每一次触发**,
而树是绿的。**`074d3e9c` 修掉了四句级联的假陈述,留下的正是会喊的那一句** —— 我上一轮的活只做了一半。

## 3. ⭐⭐ 否掉 #358 §3 的处方(采信读数,不采信处方)

#358 §3 引 `routine_selfcheck.sh` header 的 LIMIT:「把顶层 sweep 挪到函数里,不要退集」。
本轮**逐个量了 load 与 full**,发现那两个文件是**两种形状**:

| 文件 | 只 load | 完整跑 | 形状 |
|---|---|---|---|
| `tests/test_fieldsip_magnitude.lua` | **27.8s** | 27.9s | 顶层 sweep,**符合** header |
| `tests/test_blinkflee_scope_ruling.lua` | **23ms** | 27.9s | **不符合** —— 代价在跑不在载 |

`test_blinkflee_scope_ruling.lua` 的 sweep **本来就在函数里而且已经 memoize**,
它 shell 出去跑 `tests/_blinkproj_sweep.lua`(单独计时 **28.2s**)⇒ **处方对它已经做完了。**

**而对另一个文件,处方虽然对得上形状,同样省不下这条腿的时间**:这条腿**是跑测试的**。
发现是**纯文本 grep**(`tools/agent/routine_selfcheck.sh:350`)—— 发现阶段**一个文件都不载入**;
然后 **`:359` 逐个 `lua5.1 tests/run_tests.lua <basename>`** 把测试**跑掉**。
把 sweep 挪进函数只是把它从「载入时跑」改成「第一个断言调用时跑」,**断言仍然要它的读数**。
旁证(实测非推理):`run_tests.lua test_blinkflee_scope_ruling` = 27.9s,**恰等于它自己那一个 sweep**
⇒ `run_tests.lua` 并没有载入另外 255 个文件(`skipped by filter`),
**fieldsip 的顶层 sweep 本来就不会污染别的文件的单跑。**

⇒ **#358 §5 验收 1(「50 文件应回到 ~55 秒」)按 §3 的处方达不到。**
**header 没错,是引用时把消费方搞错了** —— header 那句 LIMIT 写给的是一个**只载入不运行**的消费方。
**没有照着改,是因为改完会得到一个「处方执行了、数字没动」的下一轮。**
**#358 保持 open**,作用域收窄为「让 sweep 本身变便宜」+ §4 的浅克隆项。
