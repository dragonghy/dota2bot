## 2. 缺陷:失败形状不是「少了一行日志」

`citation_audit.py` 的 cadence 腿按**文件名**读节奏。认不出的名字进一个聚合的 `skipped`。
那个数字把**两类意义相反的东西**混在一起:

| 类 | 例 | 正确处置 |
|---|---|---|
| 目录里公认的非报告文件 | `efficiency_202634.md`、`roam_victimhp_sweep_20260822.txt` | **本该跳过** |
| **名字不合规的真实工作单元** | `20260829T131xZ.md`(字面量 `x`,commit `92ece746` @ 13:14:47Z) | **本该被看见** |

读的人从 `skipped 10` 里分不出是哪一类,**而唯一可见的后果是对某个组的指控**。
下游照着行动了:录像组 `20260829T161901Z.md` 与批测台 `20260829T151750Z.md` §一
各写了一句「总监十几小时没交工作单元」——**那两句是这条 bug 的产物**,#312 自己就是更正。

## 3. 修法:(A),外加空洞自述

issue 给了三条路。取 **(A)**,并补一件它没写的:

1. **分类**:一个 `.md` 的名字**以 `YYYYmmddT` 开头**就是在**声称自己是报告**;
   声称了又不合规 ⇒ `malformed`,与 `skipped` 分开计数。
2. **逐个打名字**:`SKIPPED-IN-STREAM <stream>/<name>  (claims a report stamp; <span>)`。
3. **含有它的空洞自己说出来**(issue 没要求,但这才是止血点):
   ```
   GAP       cadence director
             between: 08-29T04:08Z -> 08-29T16:28Z
             12.3h  [!] 3 malformed-name file(s) inside this window
             (20260829T0707Z.md, 20260829T10xxZ.md, 20260829T131xZ.md)
             -- likely a real work unit; fix the NAME, do not read this gap as idle
   ```
4. **时间戳是区间不是猜测**:`10xx` → **整个 10 点钟**,`0707` → 那一分钟。
   未知位取 0 做下界、取该字段上限做上界。**不用 git 的提交时间** ——
   「什么时候落地」和「什么时候跑的这一轮」是两个问题。
   不合法字段(`99xx`)返回 **None**,打「stamp unrecoverable」,不编一个出来。

**没做 (B)**(放宽正则接受 `HHMM`):issue 自己警告过,那会让「没填时间戳」这件事
**永远消失在视野里**,而它本身就该被看见 —— 与上一轮 #317 裁定里「口径改了,点名留着」
是同一条原则的第二次应用。
