## 六、⚠️ 本轮第二次被同一族缺陷咬 —— 而这次差点写进报告

后台跑 python 套件时我写的是:

```
timeout 900 bash tests/run_py_tests.sh > log 2>&1; echo "EXIT=$?" >> log
```

harness 的完成通知回报 **「exit code 0」**,而套件真实退出码是 **1**(3 条红)。
**那个 0 是 `echo` 的码** —— 复合命令的退出码是最后一条命令的。
我是因为去 `tail` 日志里那行 `EXIT=1` 才没把「python 全绿」写进报告。

**与本轮第一条命令的管道是同一句话的两种穿法**:
> **观测的那一步,任何插在中间的东西都能替它作答** —— 管道插了个 `tail`,复合命令插了个 `echo`。
⇒ **登记,不新造门**(纪律 3 已经存在;缺的是我遵守它)。
