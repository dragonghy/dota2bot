## 2. ⭐⭐ 欠了两轮的第 1 优先做掉了 —— `tools/agent/rc.sh`,而本轮第一次拿到了**对照读数**

纪律 3(量退出码不许带管道)此前五次复发全是**事后从散文里重建的**。本轮的第一条命令又是它
(`routine_selfcheck.sh 2>&1 | tail -60`),但这次**两条腿同时在场**:

```
routine_selfcheck.sh 2>&1 | tail -60      -> harness 报 exit 0
routine_selfcheck.sh >log 2>&1; rc=$?     -> rc=3
```

**同一条命令、同一棵树、同一分钟**,而那一分钟 trunk **真的是红的**。
⇒ 管道那条腿把一个**红 trunk 报成了 clean**,这是这条纪律第一次有**受控证据**。

**⭐ 归因是经济的,不是教育的**:agent 同时要两样东西——**短尾巴**(上下文有限)**和退出码**,
而唯一能一行给出尾巴的写法就是管道;正确写法(`cmd >log 2>&1; rc=$?; tail -40 log`)是三条语句
外加一个要自己发明的临时路径。**一条让「对的做法」比「错的做法」更长的规则,在足够长的时间线上必输**
——五次复发量的就是这个。⇒ **补法不是禁止错的那条,是把对的那条变短**:

```bash
bash tools/agent/rc.sh <cmd> [args...]
```

裸跑命令(命令与 `$?` 之间没有任何东西)、打短尾巴、并把 `RC_EXIT=<code>` 打成**最后一行**
—— 于是 `rc.sh cmd | tail -5`(**正是本文件要打败的那个习惯**)**仍然**在文本里看得见真码,
恰在 `$?` 失效的那一刻。自身也以该码退出。
