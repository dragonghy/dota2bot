## 1. `[bug] #87` 已修:唯一够得着的自动买活被单位错配钉死

`bots/ability_item_usage_generic.lua` 买活路径 1:

```lua
if ancient ~= nil and ancient:GetHealth() < 0.8 then
```

`GetHealth()` 返回**血点**。遗迹几千点血 ⇒ **只要它还站着,这个测试恒假**;唯一能通过的时刻是
`hp <= 0`,那时游戏已经输了。**整条分支是死代码。**

**我加在协同组之上的两条(不是转述)**:

1. **它不是「三条路径里的一条」,它是唯一一条在闸门之上的。** 路径 2(`:582`)与路径 3(`:599`)
   同在 `if nFullRespawnTime < 60 then return end` 之下;**路径 1 在它上面** ⇒ 这棵树的自动买活
   **只有这一条够得着**,而它被一个笔误关死了。它服务的状态——「对面在打我们的遗迹,来了不止
   一个,我们一个人都不在,而我还有 20 秒要躺着」——正是买活决定胜负的那一刻。
2. **意图不需要猜。** 同一个谓词、同一个对象、同一个 `0.8`,**已发布的树里已经有一处写对了**:
   `mode_roshan_generic.lua:46` 的 `J.GetHP(GetAncient(bot:GetTeam())) < 0.8`。这个调用点顺带
   解决了唯一的实现顾虑(`J.GetHP` 对己方单位读未 hook 的 `OriginalGet*`)—— 它对着遗迹
   **在 roshan 模式里一直每帧这么跑**,不是新路径。**修复的依据是树里已有的正确写法,
   不是我对作者意图的推断。**

**修法**:抽成 `J.IsAncientBadlyHurt`(`jmz_func.lua`),gated `bbancient`;未 armed 时
**逐字保持已发布表达式**(测试双向断言:未 armed 恒假、armed 别的 id 也恒假、非 Turbo 恒假)。

**顺带拆掉 mock 里的一颗地雷**:`tests/mock/bot_api.lua` 的 `GetAncient` 桩只有
`GetHealth = 4500`,**没有 `GetMaxHealth`,也没有 `OriginalGet*`** ⇒ 任何走分数读法的消费方
在这个桩上是拿 nil 做除法。§AA「mock 的每一个缺省都是一条未声明的世界假设」又一例,
这次的形状是「**遗迹没有上限血**」。已补齐。

## 2. ⭐ 本轮主产出:第四种处置 `HARNESS-BLIND`(§AD.1)

修完之后诚实的问题是:条件 (a) 怎么核验?**答案是买不到,而且原因不在这条规则身上。**

`tools/batch_test/soak/soak_loop.sh` 起 referee,在 `SOAK_CAP_MIN`(**默认 10 个游戏分钟**)
打 `dota_dev forcewin`,胜者随后由 `analyze_log` 用经济领先方覆盖 ⇒ **每一局都是被断头的**,
**我们买过的 11,048 局没有一局进过高地攻防**。

语料侧独立复算(实测,不是引用):**29 个 fixture 的建筑表含遗迹 × 2 = 58 个 ancient 快照,
`hp` 直方图 `{1.0: 58}`,`hp < 0.8` 的 0 个**。**不是稀有,是一次都没被碰过。**

这与既有三种处置都不同,**必须单独命名**,否则它会被错读成对规则的否定:

| 处置 | 判据 |
|---|---|
| `wkreincarnmp` 永不 arm | 判定**有害** |
| `axeblink` `DOMAIN-NOT-REACHED` | 域**为空** |
| `cmrself`/`esaftershock` `DOMAIN-REACHED-BUT-VANISHING` | 域非空但**密度低于分辨率** |
| **`bbancient` `HARNESS-BLIND`(新)** | 域在**真实局里活着**,**为零的是观测装置** |

处置 = 代码保留 + gated + **不进 test_set + 不占臂 + 不排波次**(eligible 仍 **20**,逐字未变)。

**强制条款(照 §AC.2 的形式)**:任何以 `HARNESS-BLIND` 为由的 DO NOT ARM,必须给出
**观测装置为零的机制**(哪一行 harness 代码切掉了域)+ **一条会自失效的复活断言**。
本条的复活断言是 `tests/test_ancient_hp_unit.lua` 第 4 节:**现场数**语料里 `hp < 0.8` 的
ancient 快照,一旦不为 0 就报红并点名「去申请入集」。**变异实测过**(把一枚 fixture 的遗迹
改成 0.55 → 恰好报红并给出指引)。

**给全队的推论(比这条 bug 大)**:凡「遗迹 / 高地 / 买活 / 破路后」这一族的决策,
**我们整套验证装置结构上都看不见**。这不是本轮能解决的,已记进 §AD.1 与 `#87`。
