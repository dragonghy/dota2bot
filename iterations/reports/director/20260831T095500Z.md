## 2. ⭐⭐⭐ 裁定 GH #352(全文 §CT)

### 2.1 主判据是一条上界,不是一个挑出来的阈值

写 `r_ab` / `r_ba` = **同一个物理侧**在两波里的胜局占比。候选 ab 打 radiant、ba 打 dire ⇒

```
winrate = ( r_ab + (1 − r_ba) ) / 2 = 0.5 + (r_ab − r_ba)/2
```

⇒ **整个臂信号 = 一个物理侧的胜率在两波之间的差**;一侧横扫 ⇒ `r_ab = r_ba = 0`
⇒ `winrate ≡ 0.500`。#352 的构造性论证到此;**本裁定接着算出它的活动范围**:

```
|winrate − 0.5| ≤ min(1, min(R,D) / min(ab_n, ba_n)) / 2  ≜ winrate_headroom
```

`headroom == 0` ⇒ 那个 0.500 **在算术上是唯一可能的值**。
**W31 种子 2444 现场核对通过**:`R=1`、薄腿 `ba_n≈15` ⇒ 上界 `0.033`,实测偏离 `0.012` ✔ 在界内。

### 2.2 采纳 (a) 止血、(b) 撤回;(c) 归因不归总监

- **(a) 即刻生效**:`winrate_channel == DEGENERATE` 期间,
  **任何裁定不得引 `winrate ≈ 0.5` / `comps_better winrate` 作为铁律 2 条件 (b) 的支撑**。
- **(b) 撤回 §CO.4 里那句 `winrate 0.503`**,原文不删(加撤回注记,§CS.2 同法)。
  **⚠️ 而 §CO.4 的结论保留,理由是数的**:它并列引了四条,撤掉第二条后剩三条
  (`+23.55 gpm` / `deaths 0.00` / `comps_better gpm 3/4`)**各自独立、方向一致**
  ⇒ 44→47 改串与 `creepthink`/`lionqdmg`/`cmqreach` 三条入集**不重开**。
- **(c)** #352 的 23-commit 线索(三条非门控修复)是协同组/录像组的活,**#352 保持 open**。
