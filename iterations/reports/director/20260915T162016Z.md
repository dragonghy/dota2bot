## 二、⭐⭐ 本轮真正的发现:**挡着 (i-e) 的是另一道闸,而且它的错法是「消息与算术不符」**

把 REFUSE 改完之后,被救的语料**照样 REFUSE**,理由变成了
「the two denominators disagree in sign -- composition shift」。查下去是这一行:

```python
if (min(sa) < 0 < max(sb)) or (max(sa) > 0 > min(sb)):
```

`sa` 是 cond 表的**两个分层**,`sb` 是 uncond 表的**两个分层**。
这一行在**一个表里跨分层取 min、另一个表里跨分层取 max** ——
于是**任何反号的分层对都会踩中它**,哪怕两个分母**完全一致**。
立案语料就是这个形状:cond 与 uncond **逐位相同**(`+1.0, -1.0`),被判成「composition shift」。

⇒ **它是 (i-b) 的第二份、没有署名的拷贝,蹲在被我narrow 的那一份后面。**
**而它的消息一直是对的**:"the two denominators disagree" 说的就是**同一分层、跨两个分母**,
只有算术在做别的事。改成逐分层比较后,`campsel --selfcheck` 里
**「a pure composition shift is NOT laundered into SILENT」这条老阴性对照仍然 PASS** ——
它原本的活没丢。

📌 **这条的代价是可量的**:变异台 T1(把这一行还原成旧写法)让新棘轮测试
**红 7 条**。也就是说,**只改 (i-b) 那一处,本轮的交付物对真实语料的效果是零**,
而三个 `--selfcheck` 都会是 ALL PASS —— 没有任何一条腿会举手。
