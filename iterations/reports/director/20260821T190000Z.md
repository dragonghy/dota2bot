## ② ⭐ 通例:**镜像两臂 bisect 里 DiD 被禁用;估计量是 ARMED A−B**

录像组提议「报 DiD 时必须同时报 null 通道」。**我采纳发现,把结论收得更紧**,
而且理由**不依赖那个 −12.8pp 到底是噪声还是干扰** —— 它是从装置构造推出来的:

- **DiD 的用途是消掉臂级混杂;这套装置里臂级混杂按构造不存在**(两臂同一棵树、
  同样 4 个种子、同样阵容、同样镜像双向)。**没有东西要消。**
- **唯一含代码差异、且两侧对手代码相同的对比是 `ARMED A−B`**:臂 A 候选面对臂 A 基线,
  臂 B 候选面对臂 B 基线,**两条基线是同一份 shipped 代码**。它本身已按种子配对。
- 把基线腿差进来**只可能加方差**:候选侧与基线侧**在同一局里互为对手**,负相关 ⇒
  `Var(DiD)=Var(ARMED)+Var(NULL)−2Cov`,`Cov<0` ⇒ 更大。**若干扰是真的,还加偏。**

⇒ **规矩**:镜像两臂 bisect 的行为读数**一律报 ARMED A−B**,基线腿差值**只作诊断**。
**历史上用 DiD 登记过的 (a) 全部需要重算**:`roamstale`(本轮已做)、
`lf_rescue`(+8.57,同一份 32 局语料可直接跑,**免费**)、`capmono`(#72,DiD −7.9pp ± 9.3)。

**机器化落地(不是口头规矩)**:`roam_conversion.py` 打的是**臂内那条腿**,而它把
**传进来的所有目录汇成一个 `armed` 格** —— 把两臂一起喂给它,它会把受治疗的候选侧
和未受治疗的候选侧平均成一个**长得和正常测量一模一样**的数(§0b 家族)。
不是假想:那波语料就是**八个 run 目录并排躺在同一个前缀下**(批测台 18:13Z「flat
`replays/` 前缀分不出谁是谁」),顺手就会全传。现在它**从每个 run 的
`games_manifest.jsonl` 读出 cand id 串**(**读,不从目录名猜** —— 目录名是人打的标签,
stamp 是实例真正 arm 的东西),不一致或缺 stamp 即 `exit(2)`;`--allow-unattributed`
是**显式**逃生口且在输出上盖 `UNATTRIBUTED` 章(不兜底猜一个臂,§AE.1)。
常驻横幅写明「这是一条腿不是估计量,别把两张表差成 DiD」。

## ③ `roamstale` 条件 (a) **撤回**,但 id **保留**,并新增第五种处置

同一份语料按 ② 重算(2117 个 episode,**不是登记的 1855** —— scanner 08-19 后改过):

| 窗口 | ARMED A−B(唯一含代码差异) | 基线腿(该读零) | 供给比 |
|---|---|---|---|
| 域外(**承重、登记的那个**) | hit_hero **+7.7pp,p=0.0997**,n=78/104 | **−12.8pp,p=0.0079** | — |
| 域内(**功效更高**) | hit_hero **−7.2pp,p=0.0128** / no_dmg **+7.1pp,p=0.0091**,n=409/417 | **+0.4pp,p=0.93**,n=909 | **0.98** |

**登记的 +22.9pp 里约 63% 住在两条跑同一份 shipped 代码的基线腿之间**
(`DiD +15.2 = ARMED(+5.7) − NULL(−9.5)`)。

**那个 −12.8pp 是噪声还是干扰?我判「小格涨落」,而这不改变结论。** 两条独立证据,
第二条是**我自己算的、录像组没做的**:(i) 域内基线腿 +0.4pp(n=909,功效 5 倍);
(ii) **`#45` 自己独立收的 ≥600u 数**按 ② 重算,基线腿 = 18.0% − 18.1% = **−0.1pp**。
三个基线读数里两个干净,显著的那个 **n 最小**(89/111)且出自 **16 个格子的扫描**
(多重比较后 p≈0.13)。**无论走哪一支,登记的那个数都不是这条 reset 的效应量。**

**裁定:撤回 (a),不回滚,不重新 gate。保留依据是 (c)+(b)。**
- **(c) 近乎恒真**:这不是策略主张,是缺陷 —— 变量名、唯一写者、唯一读者三者都指
  「本帧的小兵」,只有缺失的复位不同意。**08-01 那条验证律是为策略改动立的**
  (「locally-correct ≠ emergently-good」);对**缺陷修复**,回滚 = **故意重新 ship 一个
  陈旧句柄**,不对称的方向是反的。
- **(b) 仍成立**且是功效最好的读法(A−B 四指标全 null,gpm +5.48)。
- 新增的**成本**是行为账,**经济后果实测为零**(见 ④)。

**第五种处置(继 `CARRIER-UNAVAILABLE` 之后)**:
**`(a)-RETRACTED / RETAINED-ON-(c)+(b)`** —— 已 shipped 的 id 的 (a) 被推翻时**不自动回滚**;
判据是「(c) 是缺陷性的还是策略性的」:策略性 ⇒ 回滚;缺陷性 ⇒ 保留 +
**当场钉一个可证伪的回滚触发条件**。**裁定必须落在源码注释里**(已落),
否则下一个引用者读到的还是被撤回的数。

**诚实边界,我自己加的**:撤回本身**与阈值无关**(它是对登记数字本身做的算术,
换任何域都成立);但**域内那笔成本不是**——它扫在 `VICTIM_HP = 0.40`
(`roam_conversion.py:61`),**正是 `#92` 刚刚 0.40→1.01 走出单调翻号的那个自由参数**。
它的供给是平衡的(0.98),恰好在 `#92` 那个伪影为零的地方,**这令人安心但不是一次扫描**。
⇒ 域内成本一律标 **PROVISIONAL**。
