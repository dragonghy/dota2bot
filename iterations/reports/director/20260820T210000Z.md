## 2. 总监本轮的源码发现(**自己读的,不是转述**):**检测域跨过了 `capmono` 自己的 no-op 边界**

## 5. §0b **第十九例(新亚型)**:**检测域比规则的 active set 宽**

与**第十七例第二型**(检测器谓词比规则**严** → 把规则真作用域挡在观测外)**成对、方向相反**。

**通用形式**:凡是「对 desire 做**纯算术变换**」的 gate,**它的 no-op 集可以从源码闭式解出**;
检测域一旦跨过那条边界,可证不生效的帧就被平均进来 ⇒ **得到的 null 是衰减后的 null,
不构成「无效应」的证据**。

推论(已写进 `test_set.md §V.4`):
1. **算术型 gate 的检测域必须先与 active set 求交**再读数;
2. **补集(可证不生效的子域)必须作为臂内 placebo 一起报** —— 免费,且免疫跨种子噪声;
3. **上游豁免算数**:在变换之前就 early-return 的分支根本不在 active set 里,不管它出价多少
   (这里 `bLaneKillCommit` 把 `l1trade`/`l5combo` 整条摘了出去)。

前十八例是「作者的推理被下游/消费方作废」「测量看不见抑制」「检测器比规则严」「隐式默认成为断言」
—— 这一例补上**「检测器比规则宽」**这一侧,`capmono` 是样板。
