### 1.1 §22 要的「定价」:判据是 **FIFO**,不是 `[ -t 1 ]` —— 而这个区别是实测的

§22 自己写了一条 ⚠️:**「自检本来就有被合法重定向的用法,判据不能只是『不是 tty』」**。
本轮把四种调用形状逐一探针实测:

| 形状 | `/dev/stdout` | 判定 |
|---|---|---|
| `cmd \| tail` | **FIFO** | ← 要拦的那个 |
| `cmd > file` | REGFILE | 合法(本轮后台自检就是它) |
| 裸跑(harness 捕获) | REGFILE | 合法 |
| `$(cmd)` | **FIFO** | 安全,但**分不开** |

⇒ **`[ -p /dev/stdout ]` 恰好把前两行分开,而 `[ -t 1 ]` 会把第 2、3 行一起误杀。**
§22 担心的那个假阳**是真的存在**,只是**换一个判据就没有了**。

### 1.2 **诚实登记一个 §22 没预见到的假阳类**

第 4 行:**命令替换 `$(...)` 与 `subprocess.run(capture_output=True)` 也是 FIFO,
而它们是安全的**(两者都拿得到真退出码)。**从进程内部看不出它们与 `| tail` 的区别。**
⇒ 它们走环境变量豁免 `SELFCHECK_PIPE_OK=1`。

**这个豁免今天的实际代价 = 0 个调用点**,已实测:
仓库里**没有任何脚本**用管道调它;三个碰它的测试文件
(`test_selfcheck_lua_leg.py` / `test_push_gate_hook.py` / `test_selfcheck_exit_attribution.py`)
**没有一个执行这个 wrapper 的入口** —— 它们跑的是**切片**(`HARNESS_PRE + LEG_SRC`)、
tally,或者把它当文本读。所以本轮**一个调用点都不用改**。

### 1.3 载荷不是「它 exit 2」,是「那行字穿得过 `| tail -1`」

这一条值得单独写,因为**第一版差点把它做丢**:

**被这个缺陷伤到的人读的是 tail,不是退出码** —— 退出码正是他拿不到的那个东西。
所以真正送达的是**文本**,而文本能送达**只因为拒绝发生在任何一条腿之前**,
输出短到任何 tail 窗口都装得下。`tests` 的 case 3 就是这条:断言
**`SELFCHECK_EXIT=2` 在 `2>&1 | tail -1` 下仍是最后一行**。

**第一版这里是错的,而且是测试抓出来的**:我把 stderr 那句写在了 verdict **后面**,
于是 `2>&1` 下**最后一行变成了那句旁注**,verdict 被挤出 `tail -1`。
修法:stderr 那句**提到最前面**(它服务的是**另一种**形状 —— 写了 `| tail` 但**没写** `2>&1`,
此时 stderr 绕过管道直达 harness)。已由源码级检查 `5c` 钉死。

### 1.4 变异台:**M5 一开始活了下来,而它活下来揭出的是我的测试在空测**

| 变异 | 内容 | 结果 |
|---|---|---|
| CONTROL | 不改 | GREEN ✅ |
| M1 | `[ -p /dev/stdout ]` → `[ -t 1 ]`(§22 担心的那个错判据) | RED(9 条) |
| M2 | 守卫整体禁用 | RED(11 条) |
| M3 | stderr 旁注移回 verdict 之后 | RED(3a + 5c) |
| M4 | **文字仍写 `SELFCHECK_EXIT=2`,进程 `exit 0`** | RED(**只有 1f**) |
| M5 | 删掉 `SELFCHECK_PIPE_OK` 豁免条件 | **第一次:GREEN ❌** |

**M4 是 1f 存在的全部理由**:它打印的字与它的退出码**互相矛盾**,而除了 1f
之外**每一条检查都是绿的** —— 一个「did-not-run 穿着 pass」,正是这个守卫本身要防的族。
1f 用 `> >(cat)` 让 stdout 是 FIFO(守卫照常开火)**同时**保住 `$?`。

**M5 那次存活是本轮最有价值的读数。** 原因不是守卫弱,是**我的 case 4 在空测**:
我最初把守卫放在**参数解析之后**,而 case 4 用 `--bogus-arg` 触发早退 ——
于是它**根本没走到守卫**,两条断言都因为一个与豁免无关的理由变绿。
⇒ 把守卫**移到参数解析之前**(顺带也更对:拒绝应当发生在最早)。移完 M5 立刻转红。
并补 `5d` 直接钉住「守卫必须先于参数解析」,让这个空测**不能再悄悄回来**。
**一个什么都没测的绿检查,和一个测到了的绿检查,长得一模一样** —— 只有变异台会说话。
