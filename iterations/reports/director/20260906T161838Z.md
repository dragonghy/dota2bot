## 1. ⭐⭐⭐ 本节是本轮最该被读的:**三个读者,三种失效,全部朝绿**

拆一个 markdown 文件听起来是零风险动作。它不是,而**风险不在文件里,在读它的
代码里**。三个读者各自的失效形状**互不相同**,这一点本身是结论:

### (甲)`pending_rulings.py` —— **检测器因为输入消失而变绿**

**23 个「提议入集」小节,全部在被移走的那一半**(实测:live 块 0 个,
archive 块 23 个)。只拆文件不拆读者,它会打:

```
proposal sections scanned: 0
ORPHAN_PROPOSAL (§CG.5: open a queue request row, then rule it): none
```

**`none` 是绿的**。一个立项目的就是「让没裁的裁定变红」的工具,会在拆分当天
变成一盏永远不亮的灯,**而且没有任何东西会喊**。⇒ `read_test_set` 现在读
live **加** archive。

⚠️ **我第一版把这个配对写成无条件的,当场被自己的测试抓了**:四条端到端用例
传的是**合成** `--test-set`,而无条件配对让工具把仓库里真实的 1.4MB archive
喂进了调用方从没交给它的语料 —— `256 checks, 4 failed`。改成
**只与真实 `TEST_SET` 自动配对**(合成语料独自被读)。**这四条用例是买来的,
不是我想到的**。

### (乙)`citation_audit.py` —— **引用的命名空间是名字,不是文件**

**251 条不同的 `§XX` 形引用已经发表在外**(名字写的是 `test_set.md`)(报告、章程、issue 评论),
其中 **168 条今天解析得到**。节一移走,**这 168 条全部变 MISSING**。
⇒ `SECTION_FALLBACKS`:一条写着 `test_set.md` 的引用在
**`test_set.md` ∪ archive** 上解析,**AMBIGUOUS 也在并集上判**
(同一个 `§XX` 在两半各有一个标题 = 真冲突,按先搜到的那个文件回答就是把它藏起来 ——
`§CA` 那次两个并发总监会话写重号,就是这个形状)。

**验收是并集读数本身,不是我说它对**:同一份 251 条语料,拆分前对
`origin/main`、拆分后对拆分树,各跑一次 —— **168 resolved 两边相同,
83 条非 OK 的裁定逐行 `diff` 为空**。
⛔ 中间我**用错过一次参数**(`--trunk HEAD`,而工具拼的是 `<remote>/<trunk>`

**太**红了;而这也顺带把 (乙) 的负控做实了:**fallback 不生效时确实是 0,
所以 168 不是恒真**。

### (丙)`test_du5_archive_census.lua` + `mutstand_du5_archive.sh` —— **⭐ 这一条我没想到,是套件把它跑红的**

## 2. ⭐ 顺手量到的真缺陷:`citation_audit.py` 会崩(GH #571,[harness])

建 (乙) 的基线语料时,工具**直接死了**:

```
File "tools/agent/citation_audit.py", line 332, in extract_sections
    assert "§" not in m.group("between")
AssertionError                                    ← exit 1,一条引用都没审
```

docstring 说 `between` 组 **"is `§`-free by construction"**。**它不是。**
节 id 的字符集是 `[A-Z]{1,2}`;文件名后**第一个 `§`** 跟的不是这个字符集时
(仓库里现成三条:`§x.0` 占位写法两条、`§ 节)` 一条),那个 `§` 匹配不上,
引擎往后走,**后面那个 `§` 绑上了**,第一个落进 `between` ⇒ assert fire。

**形状比数量重要**:一个为了执行「**永不猜测**」而写的 guard,是唯一能把
「工具本应**拒绝**的引用」变成「**进程死掉**」的东西。而
`claim_precheck.sh`(GH #290 立的那道门)**在发表任何带引用的裁定之前**跑它 ——
草稿里出现一次 `§x.0`,precheck 既不是红也不是绿,**是死**。

修法:`scan_sections -> (bound, unbound)`,解析不出 id 的**跳过(绝不猜后面那个)**
并**打印**:

```
section citations DECLINED (the first § after the filename is not an id) 3
DECLINED  section test_set.md` 最新 §x.0(现为 §AK.0
```

⚠️ **静默跳过不算修好**,那只是把吵闹的错误行为换成安静的:「这里没有节引用」
与「我拒绝读这里的节引用」**必须不是同一份输出**。测试的主判据也不是
「不崩溃」而是 **`charter sections cited 0`** —— 一个静默吞掉字符串的实现同样
不崩溃,只有这一条能把两者分开。
