## 2. ⭐⭐⭐(甲)便宜的修法是放宽正则继续跑,而那是错的——它会把响亮的仪器故障变成预期结果

这个文件的核心论证是**"baseline 腿是空对照"**:两臂同一个 clone、同样 turbo,
唯一的不对称是 `J.IsSoakCandidate`,所以未 armed 那条腿上
`botHP < 0.08 and botHP >= 1` 在 0..1 分数上**按算术恒假**,那里出现任何一次发火
都是仪器故障。

**promote 删掉的正是那个不对称。** turbo 两条腿现在都跑 `botHP < 0.08` ⇒
这个文件打印的 armed/baseline 分层**不再是对照**,而是同一个总体的两份样本。

⇒ 落地的不是"多认一种拼写":

- `read_source()` 报 `gate_state ∈ {gated, promoted}`,并在 promoted 时要求
  **摘闸是完整的**(此处摘、别处仍 gate 的半 promote 现在响亮地抛);
- `verdict()` 在闸没了时答 **`PROMOTED-NO-CONTROL`** 而不是 `WIDENING`,且这一支
  **排在**出厂子句的算术判断**之前**——算术一字未变,**变的是读法**;
- `run()` 打横幅说 leg 列不是对照;"零发火"那段文案按 `gate_state` 分叉
  (原文「BASELINE 腿零是**必须**的」在 promote 之后是**假的**)。

📌 *放宽正则会让 leg 列继续打印、继续长得像一个 A/B 读数,而一次 baseline 腿的发火
——原本是响亮的仪器故障——会**静默地变成预期结果**。一个正确的句子被用来许可一个
错误的读法。*

钉子:`tests/test_detector_source_constants.py` 现在同时钉住
①`gate_state` 是**读出来的**、②这棵树上它 = `promoted`、③verdict 跟着 `gate_state` 走、
④promoted 的 verdict **说出**"NOT a control"这句话、⑤**重新 gate 回去仍读 WIDENING**
(算术没动,这一条防止修复把旧读法一起删掉)。
`--selfcheck` **31 PASS / 0 FAIL**(两种 gate 状态都被反事实走到,所以这条自检
不会在 id 状态再翻一次时自己变哑)。

⚠️ **这是一族不是一发**:任何 `read_source()` 钉了 `IsSoakCandidate('<id>')` 的检测器,
都在断言一个**该 id 自己的 promote 会删掉**的形状;而 promote 期的三个普查**只读
`bots/`** ⇒ promote 那一轮全绿,红留给下一个开工的组。已写进 `tpdeathbuy_domain.py`
的模块 docstring,并追评 GH #787。

## 4. ⭐⭐(丙)换收集器时量出的第三条:一个漏 6/24 的静默漏读

`stale_waits.PROMOTED` 要求 `PROMOTED`、`(`、`was soak-candidate 'x'`、`)` 四者相邻。
注记拼写此后朝**三个方向**各漂过一次:

1. 中间插日期 —— `PROMOTED 2026-09-11 (was soak-candidate 'tpdeathbuy')`;
2. **跨行** —— 四条注记在 `PROMOTED` 与 id 之间换行;
3. id 后面跟逗号不跟右括号 —— `(was soak-candidate 'tpcommit',`。

24 条注记漏掉 **6** 条,**`stable-v7` 两个 id(`tpdeathbuy` / `liondrainstop`)都在里面**。
后果:一条等待"某个已 promote 的 id 入集"的记录会**永远读作 LIVE**——
而"已 promote 的等待更陈旧"正是本模块 docstring 自己写的立身之本。
**失效是静默的:一个漏掉的 id 与一个从未 promote 的 id 长得一模一样。**

原来的钉子只检查**一个**例子(`"creeppull" in settled`),而 `creeppull`
恰好用三种拼写里**最老**的那一种 ⇒ 一个例子看不见 6/24。
改成**钉形状**:`bots/` 里每一条 `was soak-candidate` 注记都必须被 `promoted_ids()`
读到,并单独钉住 stable-v7 那一对。**这条钉子落地当场又抓到第六个**(`tpcommit`,
跨行 + 逗号)——即"钉形状"这一步本身在同一轮里付了它的房租。
`promoted_ids()` **18 → 23**。`tests/test_stale_waits.py` **52 检查 0 失败**。
