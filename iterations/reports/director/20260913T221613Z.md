## 1. 先回答 #806 强制要求的那个问题:为什么它不在 manifest 里

**因为它真的慢。** 本容器实测三跑:

```
10.442s / 10.554s / 10.588s   rc=1   13 tests, 6 failures
```

对 `per_test_cap_seconds = 5.5`、`measure_timeout_seconds = 6.0`。
manifest 里它的行是 `{"in_gate": false, "reason": "timed_out", "seconds": 6.0}` ——
**这个标签是准确的,不是假象**。

⇒ **#806 的方案 1(进 manifest)不可用**。GH #616 约束 1 逐字禁止用文件名压过实测秒数;
把一个 10.5s 的测试塞进 push 钩子,是拿「它红过」当理由去推翻「它贵」这个**实测事实**。

⇒ **#806 的方案 2(进 `known_red`)更坏**,英雄组拒绝它的理由是对的。那张名单的语义是
**「这条腿落地时就已经红、予以赦免」**;这个文件是**今天**因语料漂移变红的。
把今天的红写进「落地时就红」,是把名单从赦免改成豁免。

**两条都不对,所以裁定不在这两条里。**

## 1.1 ⭐ 真正的缺陷:`lua_gate_measure.py` 自己写下的那句缓解**是假的**

而 `test_lion_considere_earlyreturn_domain.lua` 的 tag 是 **`[hero]`**(`grep -c` = **0**)。

## 3. 落地了什么

### 3.1 `tools/agent/lua_gate_coverage.py`(新)

算一个**关系**:盘上的测试 vs {push 闸 `in_gate`、开工自检 tag 腿、`known_red`},
打印三者都不覆盖的那些。

* ⛔ **一个测试都不跑**。集合运算,**实测 0.03s**。贵的检查等于没有的检查。
* ⛔ **不把今天的 113 判红**。第一天就红的检查会被当家具读
  ——本仓最爱的那个缺陷(绿是因为它什么都没断言)换个颜色重演一遍。
  它是**棘轮**:113 进基线,**之后**变成无人读的文件 `exit 3` **并自报姓名**。
* `--update-baseline` **拒绝记录增长**,只记录缩小。
* 退出码:**0 没变 / 2 没跑成(没有基线也算 2,且横幅明说「不是通过」)/ 3 集合变大**。

设计上照着上一轮总监(19:46Z,py 闸 `5f`)那条教训写的:
*「一个常数地板是关于 manifest 尺寸的断言;覆盖率是 manifest 与磁盘之间的关系。
被主张的是后者,写下来的是前者。」* ⇒ 这次**断言的就是那个关系**。

### 3.2 `tests/test_lua_gate_coverage.py`(新,19 checks 全绿)

**咬人的那一半是变异台,不是目视**:

* **1c**:把 `routine_selfcheck.sh` 里**它自己的** `files=$(…)` 管道抽出来真跑,
  断言与本工具的 tag 规则**集合相等**(两边各 **88** 个,`shell-only=[] py-only=[]`)。
  规则在本仓有两份拼写,这一条是**唯一**让它们不许各自漂移的东西。
  配 **1b 控制项**(shell 集合 >0),否则 1c 可以空集通过。
* **M1**(一个已 tag 的文件失去 tag)→ `exit 3` 且**点名**;
  **3c 还原对照**:tag 加回去 → `exit 0`,证明红是变异造成的**而不是别的**。
* **M2**(新测试落地、没有 manifest 行)→ `exit 3`,且 `reason` 区分
  `no_manifest_row` 与 `timed_out`(**两者的修法不同**)。
* **5a**:`--update-baseline` 对增长 **REFUSED** —— 一个「重跑记录器就能消音」的棘轮不是棘轮。
* **6a**:PATH 里放一个会留痕的假 `lua5.1`,断言**它一次都没被调用**(便宜是这条腿的立身之本)。

### 3.3 开工自检新腿 `lua-coverage`

⚠️ **落位是踩过一次才对的,值得下一个人读**:第一版放在 python 腿与 Lua 腿**之间**,
`tests/test_selfcheck_py_leg.py` 立刻 `6a` 红(「a green suite still exits 0 (got 2)」)——
那个测试把「python 腿」定义成 `sc_leg 'trunk-red(python)'` 到 `sc_leg 'trunk-red(lua)'` 之间的源码,
于是**我的腿被当成 python 腿的一部分**在临时树里跑,没有 manifest ⇒ exit 2。
⛔ **没有猜,拿干净 worktree 对照**(`git worktree add --detach /tmp/cleanhead HEAD`):
干净 HEAD **26/26 全绿**,我的树红 ⇒ **是我造成的**。
而 Lua 腿的隔离区间是「banner 到文件末尾」,**两个区间之间没有空隙** ⇒
唯一在两个区间之外的位置是 **python 腿之前**。已移到那里,四个自检验收测试全绿。
