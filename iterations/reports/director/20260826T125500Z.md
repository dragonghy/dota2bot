## 5. 我自己新检查里的一个缺陷,如实登记

「失败路径不许说话」第一版写成 `printf.*\|\|\s*return 1` —— **一个形状,而且是错的那个**。
加 `|| { printf "no apt\n"; return 1; }` 的变异把 printf 放在 `||` **另一侧**,于是**活了下来**
(第一遍变异表里它是唯一的 SURVIVED)。改成**数数**:函数体里恰好一个 `printf`,且是成功行;
再由空 PATH 的端到端用例**跑一遍**独立确认「一个字都不打」。

**对形状做断言,漏掉的就是换个形状的同一件事。** 与本轮主线同病:
`Unable to locate package` 也是一个形状,被当成了一个事实。

**顺带,第一遍变异跑里有两条 `SURVIVED` 是假的**:`sed 's/^exit 3$/exit 0/'` 没匹配上
(缩进在 if 里),**变异根本没落上**。改成「先断言 old 在文件里、落不上就 assert 失败」再重跑,
两条当场被杀。**「变异活下来了」和「变异没落上」在终端里长得一模一样** —— 与 #171 的
`SKIP`/`PASS` 是同一句话,换了个场合。
