## 5. §0b 第十五例(新亚型:**两个 id 用同一批帧却得到相反处置**)

前十四例都是「某个 id 自己的证据链断在哪」。本例是**跨 id 的不一致**:`axeblink` 与
`axebuyblink` 共享同一个前提「Axe 会跳进人堆」,英雄组在**同一份报告**里用 0/10 否掉前者、
却建议保留后者。**通例:两个 id 的价值论证共享同一个可测前提时,该前提的实测结果必须
同时作用于两者;只在其中一个上执行,等于把同一份证据用了两套标准。**
排期推论:**立案时就把「本 id 的价值前提」写成一句可测的话,并登记它与哪些 id 共享**——
前提被证伪时一次性重审全部共享者。
