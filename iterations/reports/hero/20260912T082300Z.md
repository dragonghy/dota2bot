## 2. 修法

```lua
function X.wk_IsCommitBlastPermitted()
	return J.IsModeTurbo() and J.IsSoakCandidate( 'wkqcommit' )
end
```

调用点只**追加一个析取项**,四个出货析取项一个字节没动:

```lua
	or X.wk_IsCommitBlastPermitted()
```

- **闸关 = `false`** ⇒ 析取式逐字节等于出货式。
- **闸开 = `true`** ⇒ 放弃支路本地那层配给,把**已经问过的**储备规则当作这次
  「已承诺施法」的蓝量权威。**不新造、不移动、不重抄任何阈值。**
- **方向是代码的性质不是数据的性质**:用 `or` 追加 ⇒ armed 释放集对任意输入都是
  出货集的**严格超集**,只能**加**一次施法,永不删。⇒ 波次读负只能读成
  「多出来的那几次先手硬控是坏的」,**永远不能读成「丢了一次硬控」**。
  §3.4 从源码断言这个形状:哪天它变成合取项,方向论证反号并自己报红。
