## 3. 为什么仍然 DO NOT ARM:同族杠杆把它包住了

`X.lion_ShouldStopDrain`(`liondrainstop`)**就是** `X.lion_IsDrainSafeToStart`(`liondrain`)
把极性翻过来,谓词一字不差(同一个 `X.nEDrainDangerRadius`、同一个 2.0s 窗口、同一个
`J.GetNearbyHeroes` 调用形状 —— 这三条本轮已写成 `tests/test_detector_source_constants.py`
里的断言,任一 gate 把常量内联掉都会红)。而 **`X.ConsiderStopDrain()` 是
`X.SkillsComplement` 的第一行**(`hero_lion.lua:199`),**在 `J.CanNotUseAbility` 早退之上**
⇒ 读条期间每个 think tick 都跑一次。

于是:**一个「开读条那一刻谓词就为真」的帧,`liondrainstop` 在下一个 tick 就把它切了。**
`liondrain` 的独占价值 = 那一个 tick 之内发生的事。

实测这正是域的形状:

| # | 局 | t | 频道长度 | 谓词开读条时就真? | `liondrainstop` 切完还剩 | Lion 12s 内死? |
|---|---|---|---|---|---|---|
| 1 | `162821` | 307.2 | **1.0s** | 是 | 0.8s(上界,见下) | **是,+1.7s** |
| 2 | `163337` | 585.3 | **0.3s** | 是 | 0.2s | 是,+2.8s |
| 3 | `182906` | 605.8 | **5.0s** | 是 | 4.8s | 否(整局再没死) |
| 4 | `183451` | 617.1 | **0.0s** | 是 | —(频道里没有快照) | 否(+16.9s) |

「切完还剩」的 0.8/0.2/4.8 是 **0.5s 采样网格下的上界**;游戏里的界是**一个 think tick**,
不是半秒。所以第 1、2、3 号上 `liondrain` 相对 `liondrainstop` 的增量 ≈ 一个 tick;
第 4 号频道本身就是 0.0s(`MODIFIER_ADD` 与 `MODIFIER_REMOVE` 同一个 0.1s 时刻,
已回原始事件流核对,**不是配对错误**),**否决它在结果上是空操作**。

⇒ **`liondrain` 的独占域 = 空。**

反过来,`liondrainstop` 有 **3 个 `liondrain` 结构上够不着的**频道(开读条时干净、
读条中途才转危)。**两个杠杆不是并列关系,是包含关系:`liondrainstop` ⊃ `liondrain`。**

## 6. 建议(请总监裁定)

1. **`liondrain` 出核验队列,DO NOT ARM**,理由 = 第六类处置。建议名
   **`SIBLING-DOMINATED`**:载体在、域可达、消费点对、谓词也对,但**一个已入集的同族 id
   在一个 tick 之后覆盖了它的全部决策**。它与已有五类都不同(不是空、不是够不到、
   不是消失、不是无载体、不是消费侧不路过)。
2. **排期约束升级**:登记在案的「`liondrain` 与 `liondrainstop` 永不同臂」**不够**。
   本轮的读数说:即使**分在两臂**,两臂在那 3 个共享频道上的行为也几乎相同 ⇒
   镜像对照在这些帧上对比度≈0,只有 3 个 `stop_only` 频道能把两臂分开。
   建议改成:**`liondrain` 在 `liondrainstop` 拿到 (a) 读数之前不进任何波次**;
   若 `liondrainstop` 的 (a) 成立且 (b) 不负,`liondrain` 的增量论证就必须**先拿出
   「一个 think tick 值多少」的证据**才配占一个 arm slot。
3. **可复用先验(建议进 §Y.2 旁)**:**上机一个新 id 之前,先问「测试集里有没有一个 id
   跑同一个谓词、只是接在决策链的另一端?」有的话,先算包含关系,再谈排期。**
   与 `wkreincarnmp`(「同分支上有没有更弱的否决已经拦了」)、`zusultx`(「我拦的地方
   动作路不路过」)同族,补上第三个方向:**「别的门是不是已经在下游把同一件事做了」。**
   三条**都是桌面可查的**(读一遍调用点),本轮唯一需要语料的是**域的形状**
   (全部 4 个都是「开读条即为真」而不是「中途转危」)—— 桌面只能证 EMPTY,不能证 RARE(§Y.2)。
4. `liondrainstop` 的状态不变:gated / eligible / **NOT-YET-EXECUTED**;本轮为它多了一条
   证据 —— 它的域在本语料上是 **6 个频道**(3 共享 + 3 独占),严格大于 `liondrain` 的 4。
