## 4. 但 0/21 到底是不是巧合?—— 真正的 n 是 3,不是 21

0.5 秒采样的相邻帧不是独立观测。按 episode(同局、间隔 <= 2.0s 合并)重数:

```
                                        帧    episode   有队友   最长连段
  全部候选                              167      25     12 (48.0%)   23 帧
  Call 不可用                            63       8      3 (37.5%)   22 帧
  谓词为真(门自己的域)                 21       3      0 ( 0.0%)   17 帧
    20260820_042539 t=542.5        1 帧  allies_max=1
    20260820_042539 t=547.0-548.0  3 帧  allies_max=1
    20260820_043124 t=631.4-639.4 17 帧  allies_max=1   <-- 21 帧里的 17 帧来自这一个 episode
```

**21 个「观测」其实是 3 个**,而且一个 episode 独供 17 帧。以同层(Call 不可用)的 episode 结队率
37.5% 计,**3 次全部落在「落单」上的概率 = 0.625³ = 24.4%** —— 毫不稀奇,**与巧合无法区分**。

**因此我上一轮那个上界是错的,而且已经被写进 `state.json`,必须更正**:

| 口径 | 上一轮公布 | 正确值 |
|---|---|---|
| 每个谓词真**帧** | 0/21 ⇒ <= **13.3%** | (帧不独立,这个口径本身无效) |
| 每个谓词真 **episode** | —— | 0/3 ⇒ <= **63.2%** |
| 每次**可被本门处置的**施放 | 0/11 ⇒ <= 23.8% | 0/**6**(只有 offensive 那 6 次归本门,retreat 那 5 次是 `blinkflee` 的域)⇒ <= **39.3%** |

**这个语料对「域有多稀」几乎没有约束力。** 63% 的上界等于没说。

**顺带一条方向性观察(明确标注 n=3,不据此做任何事)**:结队率沿漏斗单调下降
48.0% → 37.5% → 0%。若为真,它的意思是「**恰恰在 2+ 敌人聚到落点附近时,Axe 最可能是一个人**」
—— 那正是这个门设计出来要拦的局面,方向上**支持**门的立意而非反对。但 3 个 episode,p=0.24,
**不足以当证据**,只当下次取语料时的预注册假设。
