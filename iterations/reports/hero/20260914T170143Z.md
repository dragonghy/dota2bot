## 1. ⭐⭐ 本轮的产出不是那根杠杆,是「这个问题不必答」

`X.ConsiderW` 的第一道守卫是

```lua
or not bot:HasModifier( "modifier_skeleton_king_bone_guard" )   -- -> return 0
```

它**排在**两个 t20 旁路(`talent6:IsTrained()`)**上面**。仓库从 **2026-08-27** 起在
**两个地方**逐字挂着同一条 residual(`hero_skeleton_king.lua` 的 talent6 注释、
`tests/test_wk_bone_guard_talent_bypass.lua` §5):

> if the engine applies `modifier_skeleton_king_bone_guard` only while charges are >= 1,
> then the guard at the top of `X.ConsiderW` re-imposes exactly the ammunition requirement
> the t20 bypass exists to lift, and the "+5 from an empty bank" case can never happen
> no matter how the disjuncts read.

两处都把读者送去**一个局内读数**(`queue.json` hero-21,重 dump 把 dumper 的天赋丢弃规则解掉),
理由正确:`HasModifier` 是引擎状态,§3 已证明没有 fixture 能答它。
**18 天里没人问的那一步是:这个答案会改变决定吗?**

**不会。** 它是个**两世界问题**,而**同一根杠杆在两个世界里都是对的**:

| | 引擎行为 | armed 后发生什么 |
|---|---|---|
| **世界 A** | 0 弹也挂 modifier | 出货那条析取项**已经为真**,Lua 的 `or` 短路,helper **一次都不被调用** ⇒ armed 文件与出货**字节相同**,**no-op** |
| **世界 B** | 只在 charges ≥ 1 挂 | 出货守卫在每一个空弹仓帧上 `return 0`,两个 t20 旁路在**它们最值钱的时候**不可达,t20 那一行买到的全部(`min_skeleton_spawn` 0 → 5)**被拒** ⇒ 杠杆把它还回来 |

⇒ **「是哪个世界」定的是杠杆的大小,不是它该不该存在。**
这不是论证,是**驱动出来的**:`tests/test_wk_bone_guard_stock_gate.lua` **§5** 用
**一个计数器**在**同一帧**上跑两遍(modifier 注入 / 不注入),世界 A 读到 **0 次调用**、
世界 B 读到 **1 次**。

⛔ **安全性靠的是天赋不是弹仓。** 空弹仓 + t20 **未点** ⇒ 释放出 **0 个骷髅**并烧掉
42 秒平冷却,**比不放更差**。所以天赋句是**合取项**而不是客套:
`IsTrained()` 是**引擎读数不是 soak id** ⇒ **不是 pullcad 陷阱**(§1 断言 helper 体内
恰好一个 candidate id 且就是本 id)。

## 2. 落地物

```lua
function X.wk_IsBoneGuardEmptyBankOpen( hTalent )
    if not ( J.IsModeTurbo() and J.IsSoakCandidate( 'wkbonespawn' ) ) then return false end
    if hTalent ~= nil then return hTalent:IsTrained() == true end
    return talent6 ~= nil and talent6:IsTrained() == true
end
```

调用点(**出货那条读数仍然是 `or` 的左操作数**):

```lua
    or not ( bot:HasModifier( "modifier_skeleton_king_bone_guard" )
                or X.wk_IsBoneGuardEmptyBankOpen() )
```

- **方向单向,按构造不按数据**:helper 只在出货析取项**已经失败**之后被问,
  它唯一可能的贡献是把一条拒绝链上的一个析取项 `false → true` ⇒ arm 只能**加**释放。
  负向波读数只能归因「多出来的空弹仓释放是坏的」,**永不**归因「杠杆吃掉了一次出货释放」。
- **gate-off 等价包括报错行为**,这是 gate 检查写成 helper **第一条语句**的原因:
  把 `HasModifier` 挪进一个**以 `talent6:IsTrained()` 为实参**的 helper 会**提前**解引用手柄
  (出货链在那些帧上根本不碰它),把一个 nil 手柄变成**更早的 raise**。§1 钉住调用点形状。
- ⚠️ **声明不碰的东西**:branch 2 仍是**精确相等** `nStack == maxStack`(`max_skeleton_charges`
  读到 0 的角落照旧成立,与本杠杆无关);弹仓**下界**是 `wkbonebank`、交战计数是 `wkbonefight`,
  三者是同一 branch 的独立合取项,**bundle 读数不得归因给其中任何一个**。§6 断言。
