## 4. ⭐ 界怎么选:KV 买不到的那一半被**界住**,不是被采纳

唯一仍然买不到的是**量级**:Damage Return 是「受到伤害的 85%」,而
**致死那一击的溢出算不算「受到」**是 C++ 的事,离线台答不了。于是反伤落在

```
[ 0.85 × 目标当前血 ,  0.85 × 伤害实例 ]
```

**下界对两种读法都成立**(循环只在 `目标血 < nKillDamage` 时出价,所以下界确实是下界)。
杠杆就用下界:

```lua
return nSelfHealth <= nCullReflectShare * nTargetHealth   -- 0.85
```

⇒ **只在两种读法都判 Axe 会死时才否决**,未决机制一个字都没漏进杠杆。

⚠️ **代价写下来**:按伤害实例那种读法,还有一批帧 Axe 同样会死
(rank 3 上反伤可达 **0.85 × 475 = 403.75**),**本杠杆故意一帧都不碰**,等机制被买到。
**它是这个缺陷的窄的那一半,是故意的。** 变异台 **M6** 就是「把界换成伤害实例」那一版。
