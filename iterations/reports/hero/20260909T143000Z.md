## 2. ⭐ 缺陷的形状:**用 staging 的仪表去量 admission**

(33 个文件,33→6 红→33 绿),并把同一次挪动的读数当成入集价发表。

* 对 **staging** 来说这个清单**完全正确** —— 只有读 `tests/frames/` 的文件才看得见 staging。
* **入集不改 `tests/frames/`。它改的是语料 glob**,所以它的作用域是**枚举语料的那一集**:
  跑 `ls tests/fixtures` / glob `tests/fixtures/*.lua` / 走 sightings 助手的 **88** 个测试文件。
* 而且两份清单不只是大小不同 —— 在入集这个问题上,staging 清单与答案**反相关**:
  **同时枚举两个目录的文件,在帧从一个目录搬到另一个目录时不可能动**,
  而那恰恰就是 staging 清单找出来的那批。
  **worked example**:`test_cm_ult_reach_meter_domain.lua` 自己的注释写着
  「Every corpus file from BOTH directories」—— 旧表给它记了 **2 个断言的入集价**,

这不是「数错了」。**同一次挪动、同一个 diff 读法、同一条 README 告诫全都照做了**,
错的是**被挪动的那个目录**和**被观察的那个集合**不是同一个问题的两侧。
