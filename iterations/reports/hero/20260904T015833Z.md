## 2. ⭐⭐ 缺陷:半接线的模板拷贝

`bots/BotLib/hero_zuus.lua` 是 BotLib 那份 Aether Lens 模板的**半接线拷贝**:

| 模板的三件 | Zeus 有没有 |
|---|---|
| `local aetherRange = 0` 声明(`:339`) | ✅ |
| `SkillsComplement` 顶部重置 + `IsItemAvailable('item_aether_lens')` 赋值 | ✅ |
| 三个 `abilityX:GetCastRange() + aetherRange` 消费者 | ❌ **一个都没有** |

`X.ConsiderQ` / `X.ConsiderW` / `X.ConsiderW2` 各读一个**裸** `GetCastRange()`。
对照组是同一棵树里的 `hero_lich.lua` / `hero_pugna.lua` / `hero_riki.lua` 等
——它们逐字写着 `abilityQ:GetCastRange() + aetherRange`。

**域是活的,不是死枝**:`sRoleItemsBuyList` 在这个英雄真正会打的**两条辅助位**
(`pos_4` `:199`、`pos_5` `:216`)**都买** `item_aether_lens`;`zeusaghs5`
候选的整套论证就架在那次购买上。一个按自己买表出装的辅助 Zeus,
**到手的正是这个文件扔掉的那个加成**。

### 2.1 这是一个类,不是一处笔误(全树普查,2026-09-04)

`bots/` 下 **33 个文件声明 `aetherRange`;26 个至少接了一处;7 个算了不读**。
本轮之前 Zeus 是**第 8 个**,**也是其中唯一的焦点英雄**。
已钉成单调棘轮 `DEAD_PRODUCER_CEILING = 7`(降 = 好;升 = 又有人只抄了生产者)。

### 2.2 ⭐ 方向与 GH #459 相反,这是它值一个闸的理由

三处 `nCastRange` 都是英雄**自己的搜索环**半径 ——
`J.GetNearbyHeroes`(Q / W2)、`J.IsInRange` 与 `J.GetVulnerableWeakestUnit`(W)、
以及交给 `bot:FindAoELocation` / `J.GetCastLocation` 的那个 reach。

- GH #459 量的是**高估**,代价是**一次计划外的贴近**:决策层以为原地能打,
  下了令,引擎把人走进去。
- **低估不下达任何移动。** 它让一个**确实在道具延长后射程之内**的敌人
  **对决策不可见**。具体地:带着透镜,`ConsiderQ` 的处决循环
  (`J.GetHP(npcEnemy) <= 0.2`)**看不到** 900–1150 之间那个残血目标;
  `ConsiderW` 拒绝去 Bolt 一个它其实打得到的人。

⇒ 恢复这一项**只能加上一次英雄已经花钱买下的施法**,
**不能**凭空造出道具没给的射程(已断言),**也不能**下达任何贴近。
