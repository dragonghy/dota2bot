## §2 缺陷

`X.ConsiderW` 用**一个** cast range 造**两个**搜索环:

```lua
local nCastRange       = abilityW:GetCastRange() + aetherRange   -- 600/700/800/900 (+225 aether)
local nInRangeEnemyList = J.GetAroundEnemyHeroList( nCastRange )
local nInBonusEnemyList = J.GetAroundEnemyHeroList( nCastRange + 200 )
```

然后从**八个**落单点出价。**六个**把目标绑在 `nCastRange` 上,用的是这个函数自己写的两种约定之一:

| 落单点 | 它自己的到达约定 |
|---|---|
| 击杀低血 | `nInRangeEnemyList` |
| 先手(`J.IsGoingOnSomeone`) | `J.IsInRange( botTarget, bot, nCastRange )` |
| 对线消耗 | `nInRangeEnemyList` |
| 撤退保护 | `nInRangeEnemyList` |
| 肉山 | `J.IsInRange( bot, botTarget, nCastRange )` |
| Tormentor | `J.IsInRange( bot, botTarget, nCastRange )` |

**团战**那个是**唯一**一个遍历 `nInBonusEnemyList`(`nCastRange + 200`)且**一个距离项都没有**的**英雄**落单点。(打野那个读 `GetNearbyNeutralCreeps( nCastRange + 100 )`,同样无界 —— **本轮故意不动**,理由见 §6。)

### ⭐ 承重的那句话:这不是又一次「多走 200 码」,是一次**交换**

本流之前四条到达项(`lionrreach` #617 / `wkqlane` #621 / `cmlaneband` #630 / `zusjumpland` #634)全是**首次命中**循环:一个候选不合格就交给下一个,错的是**一次**出价被拉长。

**这一条是最小值搜索**:

```lua
for _, npcEnemy in pairs( nInBonusEnemyList ) do
    if <四条过滤> then
        if npcEnemyHealth < npcWeakestEnemyHealth then npcWeakestEnemy = npcEnemy end
    end
end
if npcWeakestEnemy ~= nil then return BOT_ACTION_DESIRE_HIGH, npcWeakestEnemy, 'W-团战…' end
```

它只留下环里**血最低的那一个**。所以环外的赢家**不只是多走一段路,而是把同一个循环刚刚认证为合法的射程内候选挤掉** —— 选那个远的弱敌,**就是**决定不打近的那个。

而且**被挤掉的那个下面没有任何落单点接得住**,这一条是**闭式**的、不靠语料:armed 子集为空 ⇒ 射程内没有任何敌人通过 `{J.IsValid, X.axe_IsBattleHungerFresh, J.CanCastOnNonMagicImmune, J.CanCastOnTargetAdvanced}` ⇒ 而下面两个**英雄**落单点(对线消耗、撤退)读的正是 `nInRangeEnemyList` 且施加**同一组四条过滤**外加各自额外的合取 ⇒ **它们也开不了火**。被拒的那一帧是**没有英雄施法**,不是「施法挪了个地方」。

**代价那半边**:出货把目标交给 `bot:ActionQueue_UseAbilityOnEntity( abilityW, castWTarget )`,射程外的实体单 ⇒ 引擎**先给一个移动单**。近战 Axe 在团战里朝「最快要死的那个敌人」走,通常就是**朝后排走** —— 正是 `nodive` / `deathzone` 这些已 promote 的守卫存在的理由。

## §3 改动(`bots/BotLib/hero_axe.lua`)

新 helper(带完整 note)+ 团战过滤末尾**一条合取**:

```lua
function X.axe_IsHungerFightTargetInReach( hTarget, nCastRange )
	if not ( J.IsModeTurbo() and J.IsSoakCandidate( 'axebhreach' ) ) then return true end
	return J.IsInRange( bot, hTarget, nCastRange )
end
```

- **闸关 = 出货逐字**:对任何输入返回 `true`,合取是 no-op。§5.1 在**两个方向**上驱动(闸关、非 turbo)。
- **`nCastRange` 是参数不是重算**:aether lens 的 +225(`X.SkillsComplement` 设 `aetherRange`,本文件两张购买表都带 `item_aether_lens`)与另外六个落单点看到的**完全一样**地复合。变异台 **M7** 就是把它冻成今天正确的常数 600 —— 被 §5.2 抓住。
- **方向由形状保证(严格子集 + 取最小值)**:
  1. 出货选不出人 ⇒ armed 也选不出;
  2. 出货的赢家在射程内 ⇒ 他也在 armed 子集里且**仍是其最小值** ⇒ armed **选同一个人,逐位相同**;
  3. 出货的赢家在射程外 ⇒ armed 选**射程内最弱的那个**,或者不选。
  ⇒ **永远不能新增一次施法,也不能把施法挪到更远的目标上。** 负读数只能归因于「那些走位是值得的」。
