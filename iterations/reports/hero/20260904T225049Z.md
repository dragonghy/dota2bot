## 2. ⭐⭐ 主发现:四个文件的立案句是**同一句**,而它今天分裂成**四个互不相容的结论**

`-76` 是按「09-01 修法力量具的余波」立的。**读下来发现真正的余波不是法力,是 09-04 那三撮

服务 `GetManaCost` / `GetCastRange` / `GetSpecialValue*` / `GetCastPoint` /
`GetCooldown` / `GetAbilityDamage`,**只对焦点五英雄**。

在那之前,测试里写手写常量是**代替一个哑掉的 getter**;在那之后,同一行变成了
**覆盖一个活着的 getter**。**没有任何东西举手**——读数不动、测试不红、grep 搜不到。

## 3. ⭐⭐ 承重的那一格:`zuus_script` 的**两句**立案句都是假的,第二句更值钱

### 3.1 第一句:它一直在覆盖修好的 loader

四个手写数**没有一个**是 KV 的数,也不是舍入差 —— 它们读起来像写文件那天凭记忆
写下的、与 rank 无关的值,而 loader 答的是这一帧的真实 rank(arc 2、bolt 1)。
**这个文件一直在用四个既不是 fixture 也不是引擎的数跑真实英雄脚本。**

已改:`run()` 默认读 loader;`ANCHOR` 只作为 §B 的**被测对象**保留。

### 3.2 ⭐ 第二句(本轮最硬的一格):归因被阴性对照打掉了

> "on a 30%-mana laning frame it must NOT cast a harass nuke (Q/W) — **both the
> lf_mana guard and Zeus's own nKeepMana reserve agree here**"

这句话**点名了一个机制**。实测:

- `SkillsComplement` 在这一帧 **queue 零个 action**(两条 gate 腿都是)
  ⇒ 两个 `assert_no_harass` 循环**遍历空表,一次都没比较过名字**。**域是空的。**
- **阴性对照**:把这句话点名的两个杠杆都给满 —— **满蓝(495/495)+ Q/W 冷却清零**
  —— **仍然是零个 action**,而且 `ConsiderQ`/`ConsiderW`/`ConsiderW2`/`ConsiderE`/
  `ConsiderR` **五个全部返回 desire 0**。
- **也不是可施法性挡的**:原帧 arc lightning 按 KV 价(90 / 148 蓝)
  `IsFullyCastable() == true`。
- **也不是 `J.CanNotUseAbility` 挡的**(实测 false,脚本跑过了 `:634` 那道门),
  **也不是量具坏了**(`rf.record_actions` sanity:注入一个 action,捕到 1)。

⇒ **法力可证不是这一帧的判别式。**是什么让它沉默,本轮**不判**——那要另一个工作单元,
而且它是「这一帧该不该出手」的问题,不是「理由句真不真」的问题。

哨兵**留着**(脚本级真出 cast 它照样抓),但空域已经**登记成会响的断言**:
域一旦非空就红,消息里写明「**这是好消息,去重新推导**」。
