## 4. ⭐ 两个解释,从 dump 里看完全等价 —— 本轮**不**下结论

- **H1 量具**:dumper 丢掉专属天赋。`tools/batch_test/behavioral/dumper/main.go` 的
  `isRealAbility()` 在「保留已升级天赋」那条分支**之前**,先无条件丢弃类名含
  `Special_Bonus_Base` / `Special_Bonus_Attributes` 的实体 —— 而**那第一行只可能作用在
  已升级的实体上**(未点天赋在下一行就被 `level > 0` 丢了),**它是专门对已点天赋起作用的**。
  另一条旁证:**活下来的名字是类名不是 KV 名**(`special_bonus_h_p200`,KV 写的是
  `special_bonus_hp_200`)⇒「通用行有自己的 C++ 类、专属行共用一个基类」是活的解释。
- **H2 世界**:bot 从来没点过专属天赋,那一点被压着没花。

**后果差一个数量级**:H1 ⇒ 所有语料天赋读数都是瞎的;H2 ⇒ **TALENTPRICE 五轮定的价
买的是没人会点的行**,而 Axe 与 skeleton_king 的出厂 t10 正好都在这一侧。

### 4.1 语料里最接近判决的一格(以及它为什么还不是判决)

**27 个 fixture 在同一个冻结瞬间里既显示了一个英雄的天赋、又对另一个 ≥10 级且点数对不上的
英雄显示为空** —— **量具不可能在同一帧里既瞎又不瞎**。最尖的一格在焦点五里面:
**Lion 今天的 t10 是通用行**,语料在**一帧**里显示了他这个天赋
(`f_212636_tide_ancient`),在**另外四帧**里(11 级、少一个技能点)什么都没显示
(`f_230124_viper_roshan_abort` / `f_260820_043120` / `f_260820_102030` / `f_260822_063559`)。
其中 `f_260820_102030_tide_illusion_burst` 这一帧里 **CM(10 级)与 Zeus(10 级)各自的通用
t10 都在 dump 里**,而同一帧的 Lion(11 级)是空的。

**诚实边界**:这一格只有在「那四局(2026-08-20)当天 Lion 的出厂选择与今天相同」时才是判决。
**本容器的 git 历史从 2026-08-26 开始**,查不了。所以**本轮不下结论**,把它写成测试里的
一条「棘轮 + 待判」而不是写成结论。

### 4.2 独立的点数账

与名字无关:`缺口 = 等级 − 技能上可见的点数 − dump 出来的天赋数`。
**228 个 ≥10 级帧里 79 个缺口 ≥1**。
**下界不是测量** —— facet 赠送的技能与学来的技能在 dump 里分不开,会把可见点数抬高、
把缺口压低(缺口分布里那 66 个 `+1` 就是这一项在反方向的表现)。
