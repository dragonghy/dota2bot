## 1. ⭐⭐ 主读数:`IsFullyCastable` 的法力项**从落地起一次都没能开火**

`tests/mock/replay_fixture.lua` 自 `test_set.md §F` 起就把技能的可施放性写成

```lua
GetLevel() > 0 and GetCooldownTimeRemaining() <= 0
               and owner:GetMana() >= (self:GetManaCost() or 0)
```

而它上面那段注释**点名**了它是为什么写的:

> "a 246-mana ultimate reading 'fully castable' while the hero held 190 mana,
> **which is the real reason X.ConsiderR bails on its first line in game**"

**那一项从来没有能力为真或为假。** `GetManaCost` 不在任何技能 spec 上,于是掉进
`tests/mock/bot_api.lua` 的泛型 `^Get` 兜底、**答 0**。`GetMana() >= 0` 是恒真式
⇒ 合取塌成「等级 + 冷却」,fixture 世界**白送每一个技能**。

**修前实测**:

| 读数 | 值 |
|---|---|
| 全语料技能句柄 | **4376** |
| 其中 `GetManaCost() == 0` | **4376(100%)** |
| 答非零的 | **0** |
| 焦点五「已学 + 报 fully castable」 | **381** |
| 其中真实 KV 价钱**撤销**掉的 | **40(10.5%)** |

**那段注释自己的举例就在这 40 个里面**:`f_260819_142047_zuus_ult_denied.lua`
握着 **190 法力**、对着 **250** 的大招,读作 **CASTABLE**。同族的还有
**11 法力**的 Zeus(`f_260820_103644_necro_pinned_dying.lua`,对 250 的大招)、
以及 `f_260819_142047_zuus_ult_**manalock**.lua` —— **名字就是法力锁**的那枚帧 ——
在 **99 法力**上把大招读成可施放。40 个撤销覆盖焦点五**全部五个英雄**。

**失效方向朝危险那侧**:恒真的合取项**高估**决策分支的可达性
⇒ 一切经过 `IsFullyCastable` 的「这帧走到了分支 X」的 fixture 论断,
**都是踩在免费法力上得出的**。与 `GetActualIncomingDamage` 的零(本组 08-29)、
`GetAbilityDamage` 的零(GH #175)**同族**:
**未 spec 的 getter 吐出来的 0 不是一个小数字,它是另一个谓词。**

## 2. ⭐⭐ 它已经在骗一个绿色断言,而且是**和该文件自己的观测打架**

`tests/test_replay_260819_zuus_ult_manalock.lua` 的端到端节断言
**出货 Zeus 在锁帧上放的是 Lightning Bolt**,而**同一个文件的文件头**
记着录像真值是:

> `t=225.5  He spends 94 on **Arc Lightning** into a dragon_knight ... (90.6%)`

**断言和观测点名了两个不同的技能,绿了两周,没有任何一条腿举手。** 原因就是第 1 节:
Lightning Bolt rank 1 要 **120**,而 Zeus 手上只有 **99** —— 只有免费法力的世界
才让它压过 Arc Lightning。

⚠️ **这个文件恰恰也是全仓唯一部分收过钱的地方**:`load_zeus` 把**大招**句柄手工锚到 246。
**这正是它两条 ground-truth 节一直诚实、而端到端那节不诚实的原因** —— 那个 workaround
只盖住了大招,基础技能仍然免费,于是端到端那条腿**从它声称复现的那帧上漂走了**。

修好之后,该帧的算术是:

```
99 法力 | Arc Lightning   rank 3 =  95   付得起(剩 4)
        | Lightning Bolt  rank 1 = 120   付不起
        | Thundergod's Wrath     = 246   付不起
```

⇒ **`zusult` 这条杠杆的前提不但没被削弱,反而更锋利**:出货 Zeus 仍然把大招的储备
漏给一个 90.6% 血的目标,而且漏掉的是**手上 99 法力里的 95**。
订正后的断言把 Lightning Bolt 钉成**付不起**(不只是「没被选中」),
**这一节因此不可能再在免费法力的世界里变绿**。

**修好量具让模拟**落回**了观测到的行为**,不是让它离开。

## 2b. ⭐⭐ 一条**为这次改动预先写好的绊线**如期打红,而且它要的和解成立了

全量套件里第二条红是 `tests/test_cm_t10_payoff.lua:176`,它的失败文本**就是写给本轮的**:

> "the loader now answers a non-zero GetManaCost by itself. **That is an improvement,
> but this sweep anchors costs externally — reconcile the two before trusting either.**"

那个文件自己按 **datafeed(hero_id=5,2026-08-23 读)** 给技能定价,
并断言 loader **答 0**,好让树里不会**悄悄**冒出第二个价钱来源。本轮 loader 开始收钱 ⇒ 它红。

**和解干净,而且比它替换掉的那份沉默更值钱**:两个**相隔九天、彼此独立**的来源
(datafeed 与游戏自己的 KV 快照)**逐位相同**:

| 技能 | datafeed(08-23) | KV 快照 | |
|---|---|---|---|
| Crystal Nova | 115/135/155/175 | 115/135/155/175 | **AGREE** |
| Frostbite | 125/135/145/155 | 125/135/145/155 | **AGREE** |
| Freezing Field | 200/400/600 | 200/400/600 | **AGREE** |

⇒ 该节改成断言**一致**而不是断言**缺席**。**这是严格更强的形式**:
旧写法只能发现「第二个来源出现了」,新写法能发现它**出现并且不一致** ——
而后者才是真正会腐蚀那份 sweep 的情形,因为
**CASTABLE 通道由 sweep 自己定价、DECISION 通道由 loader 定价**,
两者漂移会把它们放到**两个不同的世界**里,而**谁都不会因此变哑**。

**这是本仓库第二次有人把这种 baton 触发到**(第一次是 08-29 的两条)——
绊线自带「如果这条不再成立就去做 X」,本轮照做了。
