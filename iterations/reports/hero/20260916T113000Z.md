## 4. 改了什么

```lua
X.nWPanicLevelShipped = 10

function X.lion_IsPanicHexLevelOpen( nHeroLevel )
    if J.IsModeTurbo() and J.IsSoakCandidate( 'lionwpanic' )
    then
        return true
    end
    return nHeroLevel >= X.nWPanicLevelShipped
end
```

调用点:出厂的 `and nLV >= 10` → `and X.lion_IsPanicHexLevelOpen( nLV )`,**其余三项一字未动**。
闸关或非 turbo ⇒ **逐字节就是 `nLV >= 10`**。

- ⭐ **方向是放宽**:armed 后谓词是常量真 ⇒ 准入集是出厂集的**真超集** ⇒
  arming **只能多出一次防守 Hex(等级 1-9)**,永远不能删掉一次、也不能改靶。
  ⇒ 负面波读**只能**读作「多出来的那些防守 Hex 不值它花掉的蓝与冷却」。
- ⚠️ **搬家可能且有界,写下来而不是辩掉**:`GetActiveMode() ~= BOT_MODE_RETREAT`
  **不是** `J.IsRetreating` 的补 —— 后者在 `BOT_MODE_EVASIVE_MANEUVERS`、血魔破裂、
  `BOT_MODE_FARM` 绝对欲望下也答真(`jmz_func.lua:1494`)。在这三种形状下,新增的保护自己出价
  可以拿走撤退分支本会拿的那次 Hex。**界**:两个循环走**同一个 `nInRangeEnemyList`、同一顺序**,
  而撤退的过滤器**严格更强**(还要求 4.0s 内被这个敌人打过、或距离 ≤ 600)⇒
  被搬走的 Hex **只能落到同一个环里更靠前的成员**,永远不会更远、不会出施法距离。
  §6 从 `jmz_func` 与出货源码**两侧**钉住,**M13** 专打。
- ⛔ **闸只点一个 id**(pullcad 陷阱:合取一个 id 会在那个 id 被 promote 当天冻成 FALSE,
  而 `check_armed_wiring.py` 仍然叫它 WIRED)。**M1 / M3** 两面钉。
