## 2. ⭐ 它为什么被走到:那条路是**别人特意为它铺的**

一个 nil 句柄不被调用就不要钱。这个被调用:

```lua
nCreepTarget = J.GetMostHpUnitAnyTier(nCreeps)      -- :331
...
if nCreepTarget:IsAncientCreep()
and DevourAncientTalent:IsTrained()                 -- :337  ← nil 解引用
```

`J.GetMostHpUnitAnyTier` 是**全仓唯一的 tier-盲选择器**,`jmz_func.lua` 的注释写着
「**One caller in the whole tree, hero_doom_bringer.lua's devour path**」,而它之所以保持盲,
是 **GH #196 特意裁的**,理由就写在 `hero_doom_bringer.lua` 的注释里:

> the three branches below already decide the ancient case themselves — devour it with the
> talent, devour a non-ancient without, fall through when it is an ancient and the talent is untrained

⇒ **为了保住三条分支而写的 opt-out,喂给了第一条分支一个空指针解引用。**
普查把「附近**可能**有远古」变成了「**这个选择器是按设计瞄着远古的**」——
这是本条从「一处理论隐患」变成「一条活缺陷」的那一步。

## 5. ⭐ 本轮最该被拿走的一条:判据第一版**朝着它唯一不许错的方向**错了

guard 判据初版**无条件往上看一行**。它把

```lua
local a = Foo ~= nil and Foo:IsTrained()   -- 一次**跑过**的检查
local b = Foo:GetLevel()                   -- 但它不守这一句
```

判成 **GUARDED** —— **被本轮自己写的 py 测试当场抓住**(`0 != 1`)。收窄到「`if` 及其同类」之后
**还剩第二处**,而且落在**全仓唯一一处真的做了检查**的站点上:`hero_silencer.lua:747-748` 是
**经由一个中间布尔量**守的,判据看到当前行以 `if` 开头就往上看,把上面那条**已经写完的
`local` 语句**当成了这个条件的守卫。**`if` 开启一个条件,它不延续上一行。**

⇒ **「跑过的检查」与「守住的检查」不是一回事。**
分不清两者的扫描器**只许朝过报的方向错**(过报会打印一行,有人能来吵),
**绝不许漏报**(漏报 = 把一次活的空指针解引用判成安全);
并且**必须拿它被允许错的那些形状去驱动它** —— 第 ④ 节现在把三条如实的过报写成断言
(早返回守卫、中间布尔守卫、已闭合的 `if` 块),它们是**决定**不是意外。

**顺带一条同族的**:M8(快照不再声明生成器)第一遍**只被 py 抓到**。Lua 那侧搜的是整段
header,而 header **把脚本名写了两遍**(provenance 一次、regenerate recipe 一次)⇒
**擦掉 provenance 那一行仍然绿**。改成钉**第一行逐字相等**后两侧都红。
**推论:一个只要「文本里出现过」的断言,在自我描述的文件里几乎必然是空的。**
