## 2. ⭐⭐ 缺陷:一行 `local nRadius = 600` 和它旁边的真常量长得一模一样

运行时代价是 **0**(没人读)。**代价在读的一侧**,而这棵树已经付过不止一次:

```lua
local nCastRange = abilityR:GetCastRange()
local nRadius = 600                          -- ← 谁也不读
local nCastPoint = abilityR:GetCastPoint()
```

文件里**没有任何东西**说明这三行里哪一行驱动决策,而 `.luacheckrc` 也说不了 ——
它配置成 `only = { "1" }`(**只启用全局相关的 1xx 告警**),luacheck 的
unused-local 家族(2xx)**按策略在全树关闭**。那条策略本身不错(1xx 那半正是抓
typo 和漏写 local 的那半),但它意味着**这一类从来没有过任何计数器**。

### 2.1 两个给这一类定价的站点(都在焦点五英雄,都不是「读出来」的)

| 站点 | 常量 | 活 KV(`tests/mock/special_value_shapes.lua`) | 性质 |
|---|---|---|---|
| `hero_axe.lua` `X.ConsiderR` | `nRadius = 600` | `axe_culling_blade`:`AbilityCastRange 175`,唯一的 `*_aoe` 键是 `speed_aoe 900`(**击杀后友军移速 buff 的半径**) | 技能里**没有任何 600** |
| `hero_zuus.lua` `X.ConsiderR` | `nCastRange = 1600` | `zuus_thundergods_wrath`:**完全没有 `AbilityCastRange` 键** | 大招是**全球**的 |

- **Axe 那一个坐在全仓注释最密的杠杆上方第 8 行** —— 就是已登记的 `hero-2`
  (Culling 伤害硬编码),那段注释是**四个不同轮次**分别写下的 ~20 行。
  **四轮的最高注意力从它上面走过去了。**
- **Zeus 那一个是更危险的形状:不是无害的残留,是一个假前提。**
  一个来审「Zeus 是不是隔太远就开大」的读者,会被这行展示一道

## 3. 修法与「这是 no-op」的证据

**5 个站点全删**(其中 4 个换成一句写明活 KV 的注释;`nDamage = 0` 无 KV 故事,直接删)。

删掉一个**没人读**的 local 是**可证的 no-op**,而这不是 `lanefix` 那个形状 ——
那次是每一笔都站得住、**bundle** 被终局门拒了两次;这里没有一笔改变任何谓词。

三条证据,按强度:

1. **作用域证据**:标识符在该函数 span 内**不出现在任何其他行**(扫描器 + 逐个手读,
   §2 的表就是手读结果)。歧义**一律往「活」的方向解**(嵌套闭包、后续重声明、
   字符串里的提及都算「被读」),所以读数**低估**这一类。
2. **静态门**:`bash tools/agent/luacheck_gate.sh` → **`GATE_EXIT=0` /
   `luacheck bots game: 0 warnings`**(冷启自装 `lua-check`,**没用 `RULE6_BYPASS``)。
   这一条是有牙的:如果哪一次删除留下了悬空引用,它会变成一个**全局读**,
   而 1xx 正是 `.luacheckrc` **唯一**启用的家族 —— 「accessing undefined variable」。
3. **定向动态 A/B**:干净 HEAD(`git worktree` 里的 `485d049e`)与工作树上跑同一组过滤器,
   见 §6。**⚠️ 第一次的基线读数作废并重取**:它是在后台跑的,而我同时在改同一棵树 ——
   与昨轮 `aetherlens` 报告里那条「变异台 + 后台自检共享 inode」**同族**
   (GH #365 §3 / #229)。这次按那条报告自己给的处置办了:**跑在 `git worktree` 里**。

## 5. 常设普查 `tests/test_dead_numeric_local_census.lua`(6 用例)

- `[scope]` 焦点五英雄 **强制 0**
- `[ratchet]` 全树 `<= 46`,红了会**把新站点的路径:行号:标识符打出来**
- `[negative control] ×2`:(甲)`hero_zuus.lua X.ConsiderW2` 的 `nRadius = 325`
  (`zuus_lightning_bolt/spread_aoe`,真被读)必须判为 **LIVE**;
  (乙)全树 sweep 必须**还能看见死站点**(否则 §焦点五的那个 0 是空的)
- `[shape] ×2`:`nDamageType` 不算 `nDamage` 的使用(**这一对就在 `hero_axe.lua`
  `X.ConsiderQ` 相邻两行**,子串匹配会把死站点判活并藏起来);
  字符串里的提及算使用、**只活在注释里的不算**

**⚠️ 供给量断言是硬要求,不是装饰**(昨轮 `aetherlens` 的账):
**天花板断言单独无法区分「没坏」和「扫描器一个都没匹配到」** —— 那轮第一版解析器
锚在 `%s*$` 上、全树读到 **0**,而 `<=` 天花板**静默通过**。
所以本文件的每个天花板/零旁边都钉了 floor:实测
**全树 2590 spans / 643 live**,**焦点五 65 spans / 22 live**;floor 取
2000 / 500 / 45 / 12。
