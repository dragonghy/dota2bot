## 1. ⭐⭐ 主读数:`GetAbilityDamage()` 的零在这个站点是**天花板**

`lion_impale` 在本 patch 的 KV 里**不声明顶层 `AbilityDamage`** —— 那一块的
`// Damage.` 段是**空的**,105/170/235/300 住在 `AbilityValues/damage`
(d2vpkr 镜像 2026-08-30 重取;离线佐证是 `lion` **不在**
`tests/mock/ability_damage.lua` 的 `NONZERO` 表里,而这条证明**不需要解析句柄**:
`hero_lion.lua` 里的读只可能落在 Lion 自己的技能上)⇒ 读数恒 **0**。

`X.ConsiderQ` 把这个 0 交给 `J.WillMagicKillTarget` 当作斩杀分支能主张的伤害。
那个函数的估值是

```
EstDamage = dmg * ( 1 + bot:GetSpellAmp() ) - HealthBack / MagicResistReduce
```

**`dmg` 只通过这一个乘积进入**——这条前提**不是重打的**,是从 `jmz_func.lua`
解析出来的:`dmg` 在整个估值里出现且**仅出现一次**,而收尾必须仍是
`return nRealDamage >= npcTarget:GetHealth()`;两条都由 §4b 钉住,变异 M7
(把 `dmg` 用第二次,哪怕乘 0)当场见红。

⇒ dmg=0 时第一项在**任何**法术增强下都是 0,EstDamage ≤ 0(回血非负),
对任何活着的目标(血量 ≥ 1)恒 false。
**每个等级、每件装备、每个目标、每一档增强:这条斩杀分支从来没能开过火。**

**这句话是驱动出来的不是推出来的**:两枚真实帧(`f_260820_182906_lion_drain_survived`
Q rank 4、`f_222428_lion_lich_burst` Q rank 2)上跑**真的** `J.WillMagicKillTarget`,
对射程内每一个活着的敌人、在增强档 **0 / 0.15 / 0.5 / 4.0** 上,全部 false。

## 2. ⭐⭐ 代价比「Lion 从不斩杀」**窄**,而窄的那一半才是本轮的第二个产出

一个自然但**错**的读法是「斩杀分支死了 ⇒ Lion 不会去秒人」。不成立:
`X.ConsiderQ` 后面**每一条**分支也返回 `BOT_ACTION_DESIRE_HIGH`。
**丢的是覆盖,不是欲望。**

把后续分支的前置条件从源码里读出来(§6 把这个顺序钉成断言):
AoE 要 3 个英雄、团控要 `J.IsInTeamFight`、攻击要 `J.IsGoingOnSomeone`、
撤退要 `J.IsRetreating`、farm/推线要兵数,而兜底的「常规」要 **`nLV >= 15`**。
斩杀循环是**唯一一条没有任何 mode / 上下文前置**的分支。

> **没被覆盖的集合 = 15 级以下 + 不在上述任一 mode + 面前站着一个能被秒掉的敌方英雄。**

那就是 **Turbo 对线期**,而那正是 105–300 魔法伤害相对英雄血量最大的窗口。
它也是唯一自己伸进 `nInBonusEnemyList`(施法距离 **+200**)的分支。

**这个「窄」被写成了验收条款而不是散文**:`hero-24` 的 (4) 单独要一格
「(3) 的帧里等级 <15 且三个 mode 谓词皆假的占比」,并**预先登记**了否定读法
(丙):若这一格接近 0,正确结论是「本 id 只改目标选择、不改是否开火」,
那是一条**弱得多**的理由,本组据此下调优先级。**先写死,免得读数回来再挑切法。**

## 3. 修法的形状:纯**解冻**,单向,门关时逐字节等价是结构性的

新 helper `X.GetImpaleKillDamage( hAbility )`,门 `J.IsModeTurbo() and
J.IsSoakCandidate('lionqdmg')`,形状照抄 `hero_zuus.lua` 的 `X.GetBoltKillHealthCap`:

- 出厂表达式 `hAbility:GetAbilityDamage()` 是该函数的**最后一条语句**,
  armed 分支是**唯一的绕路** ⇒ 门关时等价**是结构性的不是断言出来的**(§1 钉住 tail 与 return 数);

  ⇒ **armed 永远不可能比出厂更窄**,方向**单一**(GH #166 的教训:别把两个方向塞进一个谓词);
- 法术增强**没有**折进来(`J.WillMagicKillTarget` 自己会乘),否则就是一次加宽搭着一次解冻的车。
