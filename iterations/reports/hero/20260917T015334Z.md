## 一、主体:`10000` 是两样东西,两样都买不到

```lua
function X.cm_GetWeakestUnit( nEnemyUnits )
    local nWeakestUnit = nil
    local nWeakestUnitLowestHealth = 10000            -- <== 本轮的主语
    for _, unit in pairs( nEnemyUnits ) do
        if J.CanCastOnNonMagicImmune( unit ) then
            if unit:GetHealth() < nWeakestUnitLowestHealth then
                nWeakestUnitLowestHealth = unit:GetHealth()
                nWeakestUnit = unit
            end
        end
    end
    return nWeakestUnit, nWeakestUnitLowestHealth
end
```

### 读法 A —— 它是一个**被返回的血量**

挑不出人时函数交回 `nil, 10000`:一个**不属于任何单位**的血量。这与同文件里**兄弟选择器已经
挂着一个 gated id** 的缺陷是同一个形状(`cmrangedhp`,在 `X.cm_GetStrongestUnit` 的提前返回上)。

⭐⭐ **区别是:这一个没有消费者。** 本轮逐个读完**两个**调用它的文件里**全部 14 个**调用点,
第二个绑定在**每一个**上都是死局部:

| 文件 | 调用点 | 第二绑定活读数 |
|---|---|---|
| `bots/BotLib/hero_crystal_maiden.lua` | 7(711/712/716/717/1764/1765/2646) | **0** |
| `bots/FunLib/rubick_hero/crystal_maiden.lua` | 7(135/136/140/141/417/418/668) | **0** |

⇒ 一个改这个常数的 id **在任何一波的任何一帧上都是 no-op**,而 `check_armed_wiring.py` 仍会读它
**WIRED**(它查的是调用点存在,不是谓词能不能为真),波次读回「测过了没影响」而**没有任何东西举手**
—— GH #606 的零域形状。**这就是不落 id 的第一条理由。**

⚠️ **量词是作用域不是文件,这一点本台第一版量错了。** `nWeakestEnemyHeroHealth1` 在 CM 文件里

## 三、⭐⭐ 头条其实在这里:一个常数,三个调用点,三个**互不相同**的「它为什么无害」

种子安全与否**从来不是这个常数的性质**。同一个字面量 `10000`,在 `bots/` 里还给一个
**距离**选择器当种子:

```lua
-- bots/mode_outpost_generic.lua  GetClosestOutpost()
local dist = 10000
... and GetUnitToUnitDistance(bot, Outposts[i]) < dist ...
```

候选集是**两个地图静态的哨塔**,循环**没有任何搜索环**——没有东西约束它量的距离。
拿同一份语料定价:语料里**最远的一对建筑相距 16026.6u**(4184 个建筑行里逐对取最大),
即种子的 **1.60 倍**;而血量天花板是种子的 **0.43 倍**。
⇒ **那边的盖子是碰得到的,这边的碰不到,差别是维度**,而**在写常数的地方一个字都看不出来**。

⛔⛔ **而它仍然不是一份 bug 报告 —— 这才是本轮真正的收获,而且是本台差点发错的地方。**
草稿里「outpost 那个 10000 是个活缺陷」已经写好了,**然后才去读它唯一的消费者**:

```lua
ClosestOutpost, ClosestOutpostDist = GetClosestOutpost()
if ClosestOutpost ~= nil and ClosestOutpostDist < 3000       -- <== 遮罩
```

盖住的答案是 `nil, 10000`,**倒在第一个合取项**上;它本该给出的那个远哨塔带的距离 ≥ 10000,
**倒在第二个合取项**上。**两条腿都走到 `BOT_ACTION_DESIRE_NONE`** ⇒ 盖子在后果上不可见。
`Think()` 是那个模块变量的唯一另一个读者,而它只在本函数已经出价之后才跑。
⇒ 遮罩机制是**一个下游阈值**,**第三种**机制,与血量那边的域天花板、与读法 A 缺消费者
**都不是一回事**。

⇒ **三个调用点、三个不同的失效理由、没有一个在种子处可见。** `bots/` 里还有约**六十个**
同族的有限 min/max 种子(`99999` / `100000` / `999999` / `9999` / `20000` …),
**全队从来没有人数过其中哪些被遮住了、被什么遮住**。那份普查是交出去的棒,**不归本组**
(`mode_*` 与 `FunLib/` 是别组的文件)。测试 §6 **两半都钉**:种子被改 **或** `< 3000` 遮罩被放松
(那正是盖子变活的那一天),这个文件就会红着说出来。

⛔ **§6 不是 bot→哨塔距离的读数,也不是缺陷率**:语料里没有哨塔行,§6 定价的是
**这个维度的天花板**,不是「一个 bot 有多常离最近敌方哨塔超过 10000u」。那个数在 `hero-101` 里要。
