## 问题(代码事实)

`bots/ability_item_usage_generic.lua` 的 `X.ConsiderItemDesire["item_blink"]`
里 `J.IsGoingOnSomeone(bot)` 那条**进攻性闪烁**分支是完全通用的:只要目标在
500..施法距离之间、可被攻击、目标周围的人头数不吃亏,就闪到
`J.GetProperTarget` 身上。**它从头到尾没有看过嘲讽(Berserker's Call)。**

而且没有别的地方替 Axe 兜底:

- 同一函数上方那个 `bot.shouldBlink` 保留名单只有 batrider / beastmaster /
  dark_seer / earthshaker / magnataur / rubick / tiny / treant —— **没有 Axe**;
- `hero_axe.lua` 从不给 `bot.shouldBlink` 赋值(全仓库 `shouldBlink` 只在
  tinker / treant / batrider / beastmaster 等文件里出现)。

也就是说:**嘲讽在冷却(或蓝不够)时,Axe 照样往人堆里跳**。跳进去的后果不只是
浪费匕首:Counter Helix 的触发靠"被攻击",而"被攻击"正是嘲讽制造的;Culling
Blade 的重置假设目标走不掉。没有嘲讽的 Axe 落地就是一具没有控制、没有脱身手段
的近战身体,匕首进 CD、被伤害打断,人死了还没换到东西。

## 修复(gated)

在上述分支里作为 `return BOT_ACTION_DESIRE_HIGH` 的前置条件。**同时满足**下列
全部条件才压住闪烁:

1. turbo **且** soak-candidate `axeblink` armed(否则函数第一行就 return false,
   线上行为字节级不变);
2. bot 是 `npc_dota_hero_axe`;
3. `axe_berserkers_call` **已学**(level >= 1)—— 没点嘲讽就没有要等的连招,
   通用规则照旧;
4. 嘲讽**这一瞬间不可用**:`not IsFullyCastable()`,或 `GetMana() < GetManaCost()`;
5. 落点是**人堆**:落点的嘲讽半径(`GetSpecialValueInt('radius')`,回退 315)内
   **当前可见**的敌方英雄 >= 2 个。

**刻意不动单人跳**:嘲讽没好但对面只有一个残血,跳过去收掉是匕首的正当用法,
压住它只会丢人头。所以判据是"人堆 + 没吼",不是"没吼"。

**理论依据(验证哲学条件 (c))**:Axe 的匕首不是追击道具也不是逃生道具,它是
嘲讽的投送工具,标准打法就是 blink→call 一气呵成;等待的代价只有嘲讽剩余冷却的
那几秒,不等的代价是匕首 CD + 一条命。
