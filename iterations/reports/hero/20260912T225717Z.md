## 2. 缺陷

`bots/BotLib/hero_lion.lua` `X.ConsiderQ` 的 推线 出货点,出厂原文:

```lua
if ( J.IsPushing( bot ) or J.IsDefending( bot ) or J.IsFarming( bot ) )
    and J.IsAllowedToSpam( bot, nManaCost )     -- 蓝量配给器
    and nSkillLV >= 4 and DotaTime() > 9 * 60   -- ← 一个代理
    and #hAllyList <= 2 and #hEnemyList == 0    -- 直接安全量度
    and not bot:HasScepter()
then ... Impale 一波 >= 5 个兵的兵线
```

9 分钟是**普通模式常数**,而本项目的优化目标是 Turbo(`docs/PROJECT.md`:~20 分钟
对 ~35-40)⇒ 宵禁吃掉大约**前一半**比赛。

**这座钟不在做钟能做的任何一件事**,而这是数出来的不是散文(测试 §5.2):

- **不是蓝量政策** —— 同一个 `if` 里已经有 `J.IsAllowedToSpam( bot, nManaCost )`
  (`bots/FunLib/jmz_func.lua:2119`:施法**后**仍保留 `fKeepManaPercent` 的配给器)
  ⇒ 再加一个时间形状的配给器是**配给两遍**;
- **不是安全项** —— 同一个 `if` 里已经有 `#hEnemyList == 0`(施法圈内无敌方英雄)与
  `#hAllyList <= 2`,这是「站在这里清兵安不安全」的**直接量度**。代理坐在量度旁边
  并压过它,与 `cmtfclock`(GH #758)、`axecallclock`(GH #788)**逐字同形**。
