## 3. 第二个失效方向:一份读数的**根因句**可以过期,而行看上去照旧是读数

`hero-3` / `hero-4` 是候选表里两行**档案侧分母**(批测台 2026-08-23 同一轮交付,
`hero-1`/`hero-2`/`hero-10` 也带数字,但那三行 `-137` 已警告过是裁定或已消费)。
它们的数字没错,**错的是它们把上界归给了一个已经被取下的常数**:

- `hero-4` 逐字:「part (2) **不可做**……77 局 Lion **局终等级上限 14,0/77 到 15**……
  根因是 **Turbo + SOAK_CAP_MIN=10 的裁判上限**(本波局时 min 9.1 / med 11.0 / max 15.2)」;
- `hero-3` 的等级栏位同源:「zuus lv>=15 只有 **37/306**、crystal_maiden **12/306**」。

**那道上限已经不在了**:owner 优先项 P3 / GH #108 取下 10 分钟经济封顶,而本仓在
**2026-08-27(GH #235)** 就按同一理由改了五个英雄文件里**所有**引 GH #84 等级普查的段落
(`hero_axe.lua:41`、`hero_zuus.lua:22`、`hero_lion.lua:33`、`hero_crystal_maiden.lua:17`、
`hero_skeleton_king.lua:106/310/1108/1177` 逐处可查)。**同尺度旁证**:`hero-23` 的
W25/W26 并池普查读到 WK **局终等级 100% ≥13**(armed 均值 24.6 / baseline 23.5)。

⇒ 两行的 `result` 各补了一段**申请方自己的登记**(不动 `status`、不动 director 裁定、
不动路由与优先级),说清:**分母与「结构上买不到」这一句都要按封顶后的语料重扫才算数**。

**⛔ 这条登记刻意不主张「现在可以买到了」**,只主张「买不到」的那个**理由**不再成立。
把它读成前者,就是拿一行待重扫的行当读数用 —— 与它自己批评的那件事同形。

**顺带量到的一件事,登记为仪器的性质**:我加的这两段注记里引用了「结构上买不到」
「裁定」这些词,于是 `hero-4` 的 class 从 **DOMAIN-READING 变成 RULING**(`hero-3` 仍是
DOMAIN-READING,但 marker 列多了那两个词)。
**这不是 bug,是 LIMITS 第一条的现场**:class 是关于**文本**的证据,而下一轮真正能花的
就是那段文本。marker 一直印在标签旁边,所以这次漂移一眼可见。

   本轮不动(不为了产出而制造 diff)。

GH #658 的那句话本轮又被独立验到一次:**「我这条 lever 的域是空的」十几轮来是一个关于
