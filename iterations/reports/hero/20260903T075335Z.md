## 1. #447 说了什么,以及本轮把它的范围**扩大了**

#447 请求的是**一句注释更正**:`hero_chaos_knight.lua` 的 `ckpush` 注释头写着

> Over the 24 fixture frames carrying a chaos_knight, Phantasm is first LEARNED at
> t = 306.0s and **NO frame at or below 240s carries it at all**. So the shipped 240
> never binds in turbo.

W41 全部 82 局逐帧扫过后:**2/82 局在 t≤240 就学会大招,最早 t=220.5s**(比注释的 306.0s 早 85.5s),
t≤240 携带已学会 Phantasm 的快照帧 **38 个**(存活 20)。⇒ 那句**全称否定是假的**。

**本轮发现这句话不止住在一个地方,而第三个地方是一条活断言。** 这是把工作单元
从「改一句话」变成「改一个守卫」的理由:

| # | 载体 | 形态 |
|---|---|---|
| 1 | `bots/BotLib/hero_chaos_knight.lua:454-459` | 注释散文(#447 点名的那一处) |
| 2 | `tests/test_ckpush_minute_unit.lua` 文件头 | 同一句话,逐字 |
| 3 | `tests/…:['[domain price] no frame at or below the shipped 240 has Phantasm at all']` | **活断言**,`early_with_ult == 0` |

### ⭐⭐ 本轮的主产物是这一句:**那条断言在它说错的整段时间里是绿的,而且只能是绿的。**

它的域是 `tests/fixtures/*.lua`(27 个 CK 帧,约一局的量),而**证伪它的帧结构上不在这个域里**。
所以它不是「碰巧没抓到」,是**它的域装不下自己的反例**。
⇒ **一个域装不下反例的绿不是证据**,而这一条的修法**不可能是同一个域上的另一条断言** ——
必须是一条**关于散文**的守卫(§3 的 4a),因为域是在散文里被丢掉的。

### 顺带查出**另外三个数也已经从树上漂走**(#447 没点名,本轮量的)

注释里 restate 的每一个数都对不上今天的树:

```
CENSUS by60=127 by30=1          注释写 "138 sites ... against exactly 2"
ARCHIVE ck_frames=27 dead=3 alive=24   注释写 "24 fixture frames"(是存活数,歧义)
        band=12 band_with_ult=5        注释写 "10 frames sit in the disagreement band"
        first_learn=306 early_with_ult=0
```

⇒ **散文只要 restate 一个被测量的数,就多出一份没被钉住的拷贝。**
本轮的注释**一个数都不再 restate**,改成指向测试里被 COUNT 的读数。

## 3. `tests/` 侧:两个登记读数 + 一条守卫

### 3.1 两个读数分开登记,因为**它们的分歧就是发现本身**

- `ARCHIVE`(域 = `tests/fixtures/*.lua`,§4 **活算**):`ck_frames=27 / dead=3 /
  first_learn=306.0 / at_or_below_240_with_ult=0 / band=12 / band_with_ult=5`。
- `CORPUS_W41`(域 = W41 全 82 局 `.dem`,`ckpush_domain.py --learn-census`):
  `games=82 / learn_at_or_below_240=2 / earliest_learn=220.5 / carrying_frames_le_240=38(存活 20) /
  casts_at_or_below_240=0`。

**⚠ 归属讲清楚,不冒领**:`CORPUS_W41` 这组数**本轮没有复算,也不声称复算过** ——
timelines 不在树里(S3 只存 `.dem` + `analysis.json`,`rs/` 下只有一份 2026-07-20 的 timeline),
本容器无法 re-derive。它们**引自 #447 / `iterations/reports/replay-check/20260903T072000Z.md` §4.4**,
并在常量块里逐字写明「NOT RECOMPUTABLE FROM THIS SUITE」。
**本轮实际复算的是 `ARCHIVE` 那一组**(§1 的读数),以及 `ckpush_domain.py --selfcheck`
= **`12 PASS / 0 FAIL`, EXIT=0**。

### 3.2 那条断言:**从全称否定翻成登记读数,但不是删掉**

翻法照 backlog `-78` 立下的档案/活断言二分,并且**刻意做成等式**:读数一漂就红,
**红的消息分两个方向讲**,因为两个方向意思相反 ——

- **朝 `CORPUS_W41` 漂**(first_learn 变早 / t≤240 携带帧变多)= 档案**印证**了语料,
  **不是矛盾**:更新 `ARCHIVE` 即可,**裁定不受影响**,因为裁定压在
  `casts_at_or_below_240 = 0` 上,不压在这个数上。
- **朝反方向漂** = 档案正在**偏离**它本该抽样的语料,同样更新,但要写进报告。

⇒ **这一条把 `-78` 那种「人质」结构提前拆了**:#447 建议加的那个 t=222.5 帧落地时,
**最便宜的脱身办法是把常量改成它印证的值**,而不是删掉断言。M6 就是量这一格的(§4)。

### 3.3 §4a:**本轮真正的产物** —— 一条关于散文的守卫

规则:那句全称否定**不得**作为文件自己的主张出现在两个载体里的任何一个;
允许**引用**它(否则守卫就禁止解释它自己防的是什么),判据是
**出现位置落在「更正区」内 = 600 字符窗口内出现 `#447` / `used to` / `falsif` / `UNIVERSAL` 锚点**。
外加两条路由断言:源注释必须仍**引 GH #447**、必须仍**点名两个登记读数**、
必须仍以更正后的形态陈述幸存命题(`IN EFFECT`)。

**⚠ LIMIT,主动写出来不等被人发现**:在**更正段落内部**新写的全称命题,这条守卫**放行**。
窗口买到的是「那句话不能远离它自己的更正再次出现」,买不到「以后再也没人写全称命题」。
**没有任何文本手段买得到后者。**
