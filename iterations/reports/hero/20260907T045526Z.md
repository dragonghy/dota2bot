## 1. 立案:同一个函数里,同一类目标,两个相反的答案

`bots/BotLib/hero_lion.lua` `X.ConsiderE` 在**三处**挑 Mana Drain 的目标:

| 位置 | 目标 | 谓词 |
|---|---|---|
| 补蓝那圈 | `GetNearbyCreeps` 里的**小兵** | `J.CanCastOnNonMagicImmune( nCreep )` |
| 团战吸蓝 | 敌方英雄 | `J.CanCastOnMagicImmune( npcEnemy )` |
| **打架抽蓝** | 敌方英雄(`botTarget`) | `J.CanCastOnNonMagicImmune( botTarget )` |

两个 helper 的差正好一项:`not npcTarget:IsMagicImmune()`
(`bots/FunLib/jmz_func.lua:961` 对 `:988`)。

**三处不是同一个问题的三个实例。** 后两处挑的是**同一类目标**——敌方英雄、在
850u 施法距离内、>200 蓝、没被 Finger 定住——**答案相反**。第一处挑的是小兵,
是**另一个域、另一个基率**,本轮**明确不动**(理由见 §3)。

**为什么「接受」那一侧是对的**:GH #566(本组 `-108` 轮)在真实帧上证伪了相反
方向的 `liondrainbkb`,三条腿:魔免亮起 **7.1s** 后引擎仍接受下单;引导整条
**5.1s** 嵌在 BKB 窗口内部;**蓝真的在动**(Lion +157,对前两秒 +8/s 的基线;
目标 −87)。**这三条腿是关于 `lion_mana_drain` 这个技能的,不是关于哪个 `if`
块下的单** ⇒ 它们**及于**打架抽蓝那一支。这才让本轮是一根杠杆,不是一个猜想。

**而它们只及于这么远**:它们说的是**引擎接受这次施法**,**不是**在这里放它是
好主意。后者是 §6 的域请求要买的东西。

## 2. 改动

`bots/BotLib/hero_lion.lua`:

```lua
function X.lion_IsDrainCombatTargetCastable( hTarget )
	local bShipped = J.CanCastOnNonMagicImmune( hTarget )
	if bShipped then return true end
	if J.IsModeTurbo() and J.IsSoakCandidate( 'liondrainmi' )
	then
		return J.CanCastOnMagicImmune( hTarget )
	end
	return bShipped
end
```

打架抽蓝那一支的 `J.CanCastOnNonMagicImmune( botTarget )` 改为调用它。
**另外两处选靶一个字没动。**

**WIDENING,由构造保证**:出货谓词是**第一条语句**且被绑定,为真时在 gate 被
求值**之前**就 `return true` ⇒ armed 支路**只在出货已经说 false 时可达** ⇒
armed 放行集 **⊇** shipped 放行集,对每个 `hTarget` 成立。gate 关(或非 turbo)
时函数**逐字等于** `J.CanCastOnNonMagicImmune`。
⇒ 负读数**只能**读作「那些多放出来的抽蓝本来不该放」,**永远不能**读作
「杠杆把抽蓝指到了新的地方」。

**STANDALONE**:body 里恰好一次 `IsSoakCandidate` 调用,`liondrainmi` 在整个
`bots/` 里只出现在一个文件。(pullcad 陷阱:`IsSoakCandidate('X') and
IsSoakCandidate('Y')` 会在 Y 被 promote 的当天冻结成 FALSE,而
`check_armed_wiring.py` 仍说 WIRED。)两条都写成断言。

**顺带修一处引用**:PREMISE-FALSIFIED 注里那枚冻结帧的路径写的是
`tests/fixtures/f_260905_004847_lion_drain_bkb.lua`,而**回滚当天它就 staged 在
`tests/frames/`**。注是挡住下一个读者重新推导那条被证伪的否决的唯一东西,
一条打不开的证据引用正是它要防的失败形态。新测试把「注里出现的每一条
`tests/….lua` 路径都必须能打开」钉成断言(变异 M11)。

再做**一次带标注的注入**,断言注入生效,然后读 gate off / on 两个答案:
gate off **拒绝**(出货未漂移),armed+turbo **接受**,armed 但**非 turbo** 仍

**并且即便有 target 通道,这一帧也到不了**:`J.IsInTeamFight( bot, 1000 )` 为真,
团战吸蓝那一支接受同一个目标并**先 return**。——这正是本支**独占域**是
「**IsGoingOnSomeone ∧ ¬IsInTeamFight**」的原因。**新测试把这三件事测出来,
而不是绕过去。**

**补蓝圈为什么本轮不取**:`#bot:GetNearbyCreeps(1600, true) == 0` ——
这台生成器**没有小兵通道**,那一支即便被取了本轮也**验不了**;而且它是另一个
域,GH #566 的证据一个字都没测过它。这句同样写成断言,免得「本轮不取」悄悄
退化成「顺手取了」(变异 M6 就是这个手法:一行看起来像「保持一致」的改动,
**而且它是未 gated 的,会直接出货**)。
