## 1. 主体:合取项拒掉的那个状态,同一个 `if` 自己写明了是什么

出厂支路(`bots/BotLib/hero_axe.lua` `X.ConsiderQ`):

```lua
if ( J.IsPushing( bot ) or J.IsDefending( bot ) or J.IsFarming( bot ) )
    and J.IsAllowedToSpam( bot, nManaCost )   -- 蓝量配给器
    and bot:GetAttackTarget() ~= nil
    and DotaTime() > 6 * 60                   -- axecallclock,不是本 id
    and #hAllyList <= 2                       -- 本 id
    and #hEnemyList == 0                      -- 直接量度
then ... 把 >= 4 只兵的兵线嘲讽到 Axe 身上
```

⭐ **`#hEnemyList == 0` 就在同一个 `if` 里** ⇒ 人数帽拒掉的状态是
「**几个队友站在兵线里,视野内没有敌方英雄**」。那不是危险,那是**抱团推进** ——
而 `docs/PROJECT.md` 逐字写着 Turbo 的性质是「weaker towers, shorter games,
**grouped pushing pays off more**」。**帽子最紧的地方,恰好是本模式自己的教条
最想把兵线快点删掉的地方。**

两条「它不是别的东西」是**数出来的**(§5.1 断言),与 `axecallclock` 的 header
同两条同理由:同一个 `if` 已有 `J.IsAllowedToSpam` ⇒ 再加一个人头形状的配给器
是配给两遍;同一个 `if` 已有 `#hEnemyList == 0` ⇒ 那才是直接量度。另加一条机制
项:**Counter Helix 按挨打次数触发,队友站在旁边不降低它的触发率** ⇒ 队友数
不是这条支路的收益项。

**落地**:`X.axe_IsLanePushCrowdOpen( nAllyCount )`,帽子写成
`X.nQLanePushAllyCapShipped = 2` / `X.nQLanePushAllyCapTurbo = 4` 两个具名量
(测试**从源码读数字**,stale-mirror 族)。闸关或非 turbo = `#hAllyList <= 2`
**逐字节不变**。

**方向:WIDENING,严格超集** —— 任何满足 `<= 2` 的计数必然满足 `<= 4`,armed
只能**加**嘲讽,不能删一发也不能挪目标。§4.1 在全部 Axe 瞬间上用真实 load 驱动,
§4.2 再在 **0..6 全值域**上驱动一遍(语料只能给出它恰好含有的那些计数)。

## 2. ⭐⭐ 本轮头条:**初稿的杠杆是半径,而测量当场把它杀掉了**

初稿要动的是 `hAllyList` 的 **1600u**(`hero_axe.lua:426`),理由是 1600 ≈
Berserker's Call 自己 315u 的 **5 倍** —— 一个和本流最近三轮(`axebhcamp`
选举距离、`axecallring` 锚点)**逐字同族**的形状,而且这个理由是**真的**。

**先量再写**。在 16 个 Axe-subject 瞬间上把半径从 1600 收到 1200 / 900 / 800 /
600,`<= 2` 的答案移动了:

| 半径 | 1200 | 900 | 800 | 600 | 400 | 265 |
|---|---|---|---|---|---|---|
| 移动的 Axe 瞬间 | **0** | **0** | **0** | **0** | 3 | 4 |

⇒ **半径为真,但不承重;承重的是帽子。** 如果照初稿落地,产出的是一个
**构造性零域的 id**(GH #838 那个形状),而它会带着一个完全正确的 header 一路
走进测试集。

⇒ 这条测量**以断言形式活在** `tests/test_axe_q_lane_push_crowd.lua` §2.3,
并由变异台 **M10**(把半径悄悄改成 600 落地)反向钉住:
**专防后人从散文里把这根死杠杆重新推导出来。**

📌 **可复用的一句话:一个和最近几轮同族的形状,是「值得去量」的理由,不是
「已经量过」的理由。** 本轮省下的正是那次省略。

## 3. ⚠️ 两条腿都把 Axe 自己数进去 —— 帽子按人头读是差一的

`J.GetAlliesNearLoc`(`jmz_func.lua:474`)遍历每个**活着的**队友并保留半径内的,
而施法者到自己位置**距离 0** ⇒ 他永远是第一个元素。

⇒ shipped `<= 2` = 「Axe + 至多**一个**队友」;armed `<= 4` = 「Axe + 至多**三个**」
⇒ **armed 仍然恰好拒绝一个状态:满编五人。**

这一条不是读源码读出来的结论,是 §2.4 **从 loader 驱动**出来的(语料里每一帧的
`#GetAlliesNearLoc` 都 ≥ 1,且存在 == 1 的帧),变异台 **M11** 是它的对照
(让 `GetAlliesNearLoc` 不数自己 ⇒ 所有 gate 断言照绿,只有 §2.4 红)。
