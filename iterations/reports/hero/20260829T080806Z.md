## 4. 落地的改动

**`bots/BotLib/hero_skeleton_king.lua`(唯一一处 `bots/` 改动;`game/` 零行)**

```
X.wk_GetBlastKillDamage( hAbility )
  gate off : (40*(lv-1)+100) * 1.68          -- 逐字复现出厂,断言钉住
  armed    : min( 出厂, impact + dot_dps * dot_dur )   -- 两个数都从句柄读
```

- **为什么是 `min`**:诚实读数在 rank 2+ 且 t10 天赋到手后**反超**出厂(260 > 235.2),
  直接换会**增加施法**,而增加动作的改动本台只在域被量过之后才发。
  `min` 让 armed 只能**撤回**一个已声明的击杀 —— GH #165 的纪律,
  `hero_lion.lua` 的 `lionhexaoe` 注释点的同一个形状。
- **读不出来时回落出厂**:被改名的 KV key 静默答 0
  (`special_value_key_census.py` 存在的理由),armed 侧不许把它变成"这发技能没伤害"。
- **创兵那一处故意不动**:`not J.CanKillTarget( targetCreep, nDamage, ... )` 收窄会把分支
  **朝反方向**翻;源码棘轮把这一点钉住。
- **没有建模的那一半,写下来供反驳**:blast 还带 1.0–1.6s 眩晕 + -20% 减速,近战 WK
  会把它们换成平A,`1.68` 很可能正是这个的替身。本条不给它定价
  (`J.GetTotalAttackWillRealDamage` 能定,那是另一条改动、另一帧),
  所以 armed 侧是**严格保守读法:"这一发本身能不能杀"**。
