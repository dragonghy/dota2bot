## 3. 落地的改动

`bots/BotLib/hero_crystal_maiden.lua`(**一处**可执行改动;`game/` 零行):

```lua
if nCanHurtCreepsLocationAoE == nil then
    nCanHurtCreepsLocationAoE = { count = 0 }
elseif nCanHurtCreepsLocationAoE.targetloc == nil
    or J.GetInLocLaneCreepCount( bot, 1600, nRadius, nCanHurtCreepsLocationAoE.targetloc ) <= 2
then
    nCanHurtCreepsLocationAoE.count = 0
end
```

**⭐ 为什么是「替换成零计数替身」而不是「跳过整段」**:该值下游有 **8 处**消费
(`.count >= 5/4/4/4` 各自守着一个 `.targetloc` 返回,行 741/746、816/819、829/832、886/889)。
跳过 ⇒ 下游**自己**去索引 nil,崩点只是后移四行。替身 ⇒ 四个 `count >= N` **全假**,
`.targetloc` **一次都不会**从替身上读出来。这也正是另外两条子句用赋值达成的同一件事。

**⭐ 为什么没有 gate,而这是本轮唯一一个我自己拍的板**(章程默认「行为改动 gated」):
**等价性**——**在旧代码能跑完的每一帧上,新代码留下逐位相同的状态**。
替身分支的可达条件**恰好**是 `FindAoELocation` 返回 nil,而那一帧旧代码**抛错**。
差集 = 且仅 = 抛错的那一帧。给它上 gate 的实际含义是「在真实对局里继续崩」,
且 `J.IsSoakCandidate` 的条件 (a) **按构造买不到**(`AGENTS.md`:bot 侧无错误可见性,
`print()` 到不了控制台、`error in error handling` 吞掉全部错误文本)⇒
那会造出一个**天生卡死的 id**(`pullcad` / GH #326 同族)。
**这条一般性问题(崩溃守卫要不要 gate)本组不替全队定**,已在 #346 追评里交给总监。

**考虑过并否决:直接删掉 `== nil` 子句**(若引擎永不返回 nil,它是死代码)。
否决理由:那是**押注世界一**;把守卫修正确在两个世界里都对,严格更安全。

断言**从「只扫 FindAoELocation 家族」放宽到整棵 `bots/`**(强度上升,且不含未读白名单)。

**⭐ 扫描器搬家而不是复制**:`strip_line_comment` 原是
