### 1.1 缺陷形状

`DotaTime() > 6 * 60` 是 **`bots/BotLib/hero_axe.lua` 里唯一的一座整点钟**
(实测 census,§5.1 钉住:全文件 `DotaTime()` 只出现 2 次,就是 helper 的两条腿),
而它挡着的那条支路的**收益引擎按本文件自己的加点表 7 级就满级**:

```
tAllAbilityBuildList = { {2,3,1,3,3,6,3,2,2,2,6,1,1,1,6} }  -- pos3
                          ^   ^ ^   ^
                      lv2 |   | |   `-- lv7: Counter Helix RANK 4
                          |   | `------ lv5: rank 3
                          `---`-------- lv2/lv4: ranks 1-2
```

带线支路把 `>= 4` 个兵线小兵嘲讽到 Axe 身上,让 **Counter Helix** 把它们转掉。
Turbo 双倍经验下 7 级远在 6:00 之前 ⇒ **引擎满功率好几个英雄等级,而支路还关着**。

### 1.2 ⭐ 这座钟不在做钟能做的任何一件事 —— 两条都是数出来的不是散文(§5.2)

* **不是蓝量政策**:同一个 `if` 里已经有 `J.IsAllowedToSpam( bot, nManaCost )`,
  那是这棵树自己的蓝量配给器 ⇒ 再加一个**时间形状**的配给器是配给两遍。
* **不是安全项**:同一个 `if` 里已经有 `#hEnemyList == 0` 与 `#hAllyList <= 2`,
  那是「站在兵线里安不安全」的**直接量度** ⇒ **代理坐在量度旁边并压过它**,
  与 `cmtfclock`(GH #758,CM,2026-09-11)逐字同形。

### 1.3 方向:WIDENING,严格超集(先说这条)

任何 `t > 6:00` 必然 `t > 3:00` ⇒ armed 只能**加**带线嘲讽(窗口 (3:00, 6:00]),
永远不能删一发、也不能把一发挪到别的目标上。**§4.1 在全语料的计时瞬间上驱动这条
而不是论证它**,§4.2 再用真实 load 驱动一遍谓词本身(所以改**谓词**而不是改
**常数**的变异体也会被抓到)。负向读数只能读成「那些早期带线嘲讽不值得开」。

**只减半不删**:这条支路该不该有钟是第二个问题;把两者合在一起会让一次波的读数
对谁都不可归因。2x 不是自由参数,是本仓库自己写下的 Turbo 节奏比
(docs/PROJECT.md:~20 分钟 vs ~35-40),§2.1 钉住 `TURBO * 2 == SHIPPED`。

  非英雄单位的那天它自己报红并点名说「本文件现在欠一次 `#laneCreepList >= 4` 的
  帧级读数」。

把两者当成一个数会凭空做出一次执行核验。**2/16 是域不是频率** ⇒ 取证请求
`queue.json:hero-67`(零 EC2 的归档只读扫描,判读三分支已预登记,含「域为 0 ⇒
