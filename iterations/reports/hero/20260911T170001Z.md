## 1. 缺陷

`bots/BotLib/hero_crystal_maiden.lua` `X.ConsiderW` 的 `保护自己` 支路,出货原文:

```lua
if bot:WasRecentlyDamagedByAnyHero( 3.0 )        -- 触发
    and #nEnemysHeroesInRange >= 1
then
    for _, npcEnemy in pairs( nEnemysHeroesInRange ) do
        if <有效 / 非魔免 / CanCastOnTargetAdvanced / 未被控 / 未被缴械 / [cmwface] 朝向锥>
        then return BOT_ACTION_DESIRE_HIGH, npcEnemy end   -- 目标
```

**支路用一个存在量化的伤害事实开门,然后把目标交给了一把量距离的尺子。**
`J.GetNearbyHeroes`(jmz_func.lua:2856)只过滤**从不重排**,而 `GetNearby*` 按距离升序是
`docs/BOT_API_REFERENCE.md` 对整个家族的承诺 ⇒ 循环交回的是**最近的合法目标**。
**「被冻的那个,是不是正在打我的那个」从头到尾没有人问过。**

⭐⭐ **名单排序是对的,所以把名单排好修不了它。** 归 GH #731 / `zusjumpany` 那一族
(排序正确、排序帮不上忙),**不归** GH #724 `anyhero`(名单无序)那一族:
**谓词是伤害的作者,排序键是距离**,这是两个问题。

⭐ **逐候选的那个谓词,本树自己就有,而且是活的写法。**
`bot:WasRecentlyDamagedByHero( npcEnemy, t )` 在焦点五里**四个文件**都在用 ——
本文件自己的 `X.ConsiderQ`(:1566)、`hero_skeleton_king.lua`(:1118)、
`hero_lion.lua`(:786, :1085)、`hero_zuus.lua`(:1399)。
⇒ 本轮不是发明一个新判断,是**把树自己的逐候选谓词,补在唯一一处用 ANY 开门却再也没收窄的
射击点上**。

**理论依据(验证哲学条件 (c))**:Frostbite 是**单体定身 + 缴械**。它买到的防守价值
**全部**来自「伤害来源不再能施加伤害」。花在一个恰好近 20.9 单位的旁观者身上,

## 5. 本轮买到的、值得下一轮复用的

### ⭐ 第一条 —— **选杠杆之前先问语料能量什么;这是比「有没有这个英雄的帧」更早的一道闸。**

GH #714 那轮买到的是「先查 `hero_pool.txt` 再查语料」。本轮买到它的**下一格**:
池子里有、语料里也有,**仍然可能一个读数都拿不到**,因为缺的是**字段**。
实测(`tests/frames/` + `tests/fixtures/` 全量):

- **每一帧恰好 10 个单位,全是英雄** ⇒ `GetNearbyCreeps` 在全语料上恒为 0
  ⇒ 任何判据里带「我方小兵数」的杠杆,**域是结构性的零**。
  本轮第一个候选正是这样死的:`保护自己` 上面那条 `GetAllyUnitCountAroundEnemyTarget(...) >= 5`
  的支路,语料里那个计数**最大只到 2**,`>= 5` **一次也满足不了**。
- `GetMagicResist()` / `GetHealthRegen()` 在语料上**对每个英雄都是 0** ⇒ `J.WillMagicKillTarget`
  退化成 `hp < dmg`,**关于 hp 单调** ⇒ 「按最小 hp 取 argmin」在语料上**恰好就是对的**。
  本轮第二个候选(`X.ConsiderW` 击杀支路把「∃ 谁会被这发打死」交给 argmin-by-hp)
  **就是这样死的**:缺陷是真的,**但语料把产生缺陷的那个机制抹平了**。

⇒ **可用的轴只有:坐标 / hp / mp / 等级 / 物品 / 技能等级与冷却 / modifier / recent_damage。**
下一轮谁选杠杆,**先对着这张表选**,再去读源码。两次「量完再丢」各花了约一次探针的钱,
比写完一个域为零的 lever 便宜一个数量级。

### ⭐ 第二条 —— **一个 lever 可以有两个不同的「域」,而它们会差很多;必须分开登记。**

本 lever 的 **finder 层域 = 1 帧**(翻转),**端到端域 = 0 帧**(可达 ∩ 翻转)。
把前者说成后者就是一次凭空的执行核验。§3.3 / §3.4 把这两个数**各自写成断言**,
所以它们不可能在下一次引用里合并成一个。
(与 `-150` 给 `wkqdmg` 留的那条同形:「落进 band」与「当帧 Q 可用」必须分成两列,
否则两种 0 会混成一个。)

附带那一条里,四条欠账有**两条不是「登记就完事」**:
