## 2. 缺陷

`bots/BotLib/hero_crystal_maiden.lua` `X.ConsiderW`,块「无英雄目标时冰冻小兵打钱」:

```lua
nEnemysCreeps1 = bot:GetNearbyCreeps( nCastRange + 100, true )   -- 近
nEnemysCreeps2 = bot:GetNearbyCreeps( 1400, true )               -- 广
...Creeps1/...Health1 = X.cm_GetStrongestUnit( nEnemysCreeps1 )
...Creeps2/...Health2 = X.cm_GetStrongestUnit( nEnemysCreeps2 )

-- 先远:  施法对象 Creeps2
if ( ...Health2 > 460 or ( ...Health1 > 390 and nMP > 0.45 ) )   -- ← Health1
    and ...Health2 <= nCreepCap
-- 再近:  施法对象 Creeps1
if ( ...Health1 > 410 or ( ...Health1 > 360 and nMP > 0.45 ) )
    and ...Health1 <= nCreepCap
```

近半三个项全是 `Health1`,打的是 `Creeps1`,**内部一致**。远半的两个项是 `Health2`,
打的是 `Creeps2`,**只有放宽下界是 `Health1`**。这是两半里唯一一处把下界用在
「不是本次施法对象」的那只兵身上。

## 3. ⭐ 它咬得最狠的地方,恰好是这一半存在的理由

`X.cm_GetStrongestUnit` 的滚动最大值初始化为 `GetBot():GetAttackDamage()`,
没有单位合格时**原样返回**:

```lua
local nStrongestUnitHealth = GetBot():GetAttackDamage()
...
return nStrongestUnit, nStrongestUnitHealth
```

⇒ 近列表为空(或全不合格)时,`Health1` **不是 0、也不是远兵的血量**,是 CM 的攻击力。
她远程基础攻击 39-45,两张购买表(`pos_5` / `pos_4`)都不买伤害装 ⇒ 这个回退值在本块能
开的每个等级(`nLV >= 5`)上都远低于 390。

**于是:远兵是唯一候选的那一刻 —— 正是「先远」先跑的那个状态 —— 放宽下界恒假,
分支只能在 460 以上开火,和它配对的 `nMP > 0.45` 什么也买不到。**

⚠️ **这一段是照英雄属性表与购买表算的,不是帧读数,两句不许并成一句。**
`GetAttackDamage` 在**每一帧**都答 0 —— .dem 切片不带攻击力/攻速,这是量具限制
(`tests/mock/bot_api.lua`),不是 loader 的 bug,也不是频率。新文件 §4 把这个 0 钉成
**单向绊线**并**拒绝**把它读成「实战里回退值就是 0」;§4 在真实帧上钉的是
**回退值的身份**(初始化式是那个攻击力读数,不是 0 也不是 `Health2`),那才是决定形状的
那一半。变异台 **M10** 就是把初始化式改成 0:所有关于杠杆本身的行为断言照样全绿,
只有 §4 那条红。

## 4. 修法与方向

新 `X.cm_IsFarCreepFloorMet( nNearHealth, nFarHealth, nFloor )`:

```lua
if nNearHealth > nFloor then return true end
if not ( J.IsModeTurbo() and J.IsSoakCandidate( 'cmfarcreep' ) ) then return false end
return nFarHealth > nFloor
```

调用点:`X.cm_IsFarCreepFloorMet( ...Health1, ...Health2, 390 )`。
**下界仍是调用点上的字面量**,好让它跟兄弟项(上面的 460、下面的 cap、近半的
410/360)排在一起读;helper 自带副本会漂 —— 变异台 **M6** 就是这个。

**⭐⭐ 方向由构造保证,不靠单调性。** 出货那条腿**先算、自己 return**,armed 那条腿
只有在它答 false 之后才可达 ⇒ 对**任意**一对输入,接受集都是出货的严格超集。
**没有任何一句依赖 `Health1 <= Health2`,本文也不做这个论证** —— `cmrangedhp` armed 时
远程兵早退口报的是随列表顺序变化的血量,那条单调性本来就会破。把放宽写成出货项**之上的
OR**,让本杠杆的方向**与那条杠杆无关**:`pullcad` 的教训用在算术上,而不只是用在 gate id 上。
变异台 **M7** 只调换求值顺序 —— 任何输入上答案都不动,没有任何值断言看得见,只有 §3 那条
「gate 在出货腿已经接受的帧上被问了」红。

**只动这一项**:460 下界、`<= nCreepCap`、兵名宵禁、`DotaTime() > 10*60`、近半的
410/360、以及**目标本身**全不动 —— arming **改不了冻哪只兵**,只改远半开不开火。

**归因预登记**:这是 WIDENING。负读数只能读成「那些远兵不值 125-155 蓝」,
**永远不能**读成「杠杆取消了一次施法」或「杠杆换了目标」。
