## 2. 落地

### 2.1 属主长出第二个入口(`arm_body` / `with_body`)

`test_soak_cand_ref_gate.lua` 的**被测对象就是 gate 解析器本身**,它必须写两种
`ss.body(cand, side)` **构造不出来**的字节:关闭态 `return { side = false,
cand = false }`,和 GH #141 的双腿 `cand_ref`。所以属主加了 `arm_body(sBody)`
(逐字写)与 `with_body(sBody, fn)`。

**关键实现选择**:三道检查(拒绝陌生人的开关 / 写回比对 / 取得所有权)被提成
一个私有 `arm_bytes(sWant, sWhat)`,`arm` 与 `arm_body` **都从它走**。
理由是这个仓库刚吃过的教训的逆命题:**第二个入口正是一个已检查的 helper 长回
无检查副本的方式**。这不是论证,是 §3.3 的变异读数。
