## 三、定价(铁律 2 条件 (c),理论依据)

数字取自游戏自己的 KV(`tests/mock/special_value_shapes.lua`,由 `npc_heroes.txt` 生成),
**由 §5 逐列钉住** —— 补丁改了这些列时,这段散文**变红**而不是变陈旧
(这正是 `-207` 头条那个缺陷的反面:一条已发表读数,在它的输入变了之后没有任何东西去重取)。

```
axe_berserkers_call  duration 2.1/2.4/2.7/3.0   cooldown 18/16/14/12   bonus_armor 12/13/14/15
axe_battle_hunger    dps      12/16/20/24       cooldown 20/15/10/5    slow 18/22/26/30
```

- Call 的**第 4 级** = 一个 315 半径 **AoE 嘲讽**多 **0.3s** + CD 少 **2s** + 护甲 +1。
- Battle Hunger 的**第 4 级** = **单体** dps +4(12s 共 +48,未减伤)+ CD 少 5s + 减速 +4pp。

Turbo 血池下后者是四舍五入,前者是**硬控** —— 而硬控是 Axe 整套装备(闪烁 / BKB / 深渊)
唯一在买的东西。**标准 Axe 加点顺序**(可检索佐证)是 Counter Helix 先满 → **Berserker's Call
第二** → Battle Hunger 最后只留 value point;**armed 行就是这个顺序,shipped 行不是**。

⚠️ **让出去的是真的,而且落得更早**:Battle Hunger 从 1 级到 12 级停在 rank 1
(shipped 是 8 级 rank 2、11 级满)⇒ 拿**对线/追杀骚扰**换**中期锁人**。Turbo 里对线期是
这笔交易的短边,普通模式未必 —— **这正是它 `J.IsModeTurbo()` gated 而不是默认的理由**。

⭐ 顺带一句本组自己的账:`X.ConsiderQ` 上已经坐着**一整族**关于「什么时候 Call」的候选
(`axecallring` / `axecallcrowd` / `axecallnocap` / `axecallclock` / `axecallbkb_i` /
`axecallbkb_ii`)—— 它们一直在调一个**永久少一级**的技能的时机。
