### 3.2 代码事实

`hero_axe.lua` 的 `sRoleItemsBuyList['pos_3']`(实测他就是 pos_3):

```
item_tank_outfit → item_crimson_guard → item_blade_mail → item_blink → …
```

起始装约 2.7k(实测靴子完成时身价 2650-2834),Crimson Guard + Blade Mail
再压上去,**跳刀的 2250 要到约 8.5k 才开始买**;pos_1 也把 Blade Mail 排在前面。
这是一套**普通模式的出装顺序跑在 11 分钟结束的模式里**。

### 3.3 修复(gated `axebuyblink`)

`BlinkFirstBuild(tList)`:**从 shipped 表派生**一份新表,把 `item_blink`
挪到 index 2(起始装之后 —— 起始装里带靴子),其余保持相对顺序。只在
`J.IsModeTurbo() and J.IsSoakCandidate('axebuyblink')` 时替换 pos_1/pos_3
(pos_2/4/5 的别名赋值放在 gate 之后,所以别名也跟着变)。
gate 关闭时 shipped 表一个字节都没碰。

**派生而不是复制**:两份表不可能漂移,而且「是个置换」这件事由构造保证。

### 3.4 理论依据(验证哲学条件 (c))

跳刀是 Axe 全套连招的**投送工具**(blink → Berserker's Call → Counter Helix
触发 → Culling Blade 重置),不是追击也不是逃生;主流出装一律把它当**第一件大件**,
Blade Mail / Vanguard-Crimson 排在它后面。Vanguard/Crimson 买的是生存,
不是开团能力 —— 一个没有位移的近战先手,拿着它也只能打「自己走过来的人」。
Turbo 把局压到 11 分钟,「3.6k 防装排在 2.25k 使能件前面」在这里比普通模式更亏。

**可达性是量出来的,不是拍的**:按他自己的金钱曲线,靴子之后直接买跳刀会在
**558.5 / 479.4 / 584.5 / 永远买不到**落地 —— **3/4 局**能拿到跳刀,
且还剩 100-240 秒(turbo 决胜段),对比现在的 **0/4**。
