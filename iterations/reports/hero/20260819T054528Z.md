## 2. 打通 fixture 的视野(vision)管线 —— 以及为什么它现在还是空转的

### 起因

接 backlog #4 时先读了 `bots/BotLib/hero_zuus.lua` 的 `X.ConsiderR`。它的击杀
确认分支(:625-650)是:

```lua
local gEnemies = GetUnitList( UNIT_LIST_ENEMY_HEROES )   -- 全图
for _, e in pairs ( gEnemies ) do
    if e ~= nil and J.CanCastOnNonMagicImmune( e ) then   -- ← 要求 e:CanBeSeen()
```

Thundergod's Wrath 是**全图**技能,打到每一个活着的敌方英雄,不管有没有视野
(而且施放本身还提供视野)。它最教科书的用法就是**补掉刚刚逃进雾里的残血
敌人**。但 `J.CanCastOnNonMagicImmune`(`jmz_func.lua:988`)第一项就是
`npcTarget:CanBeSeen()` —— 雾里的敌人被直接排除在击杀确认之外。

这看起来是个很干净的候选修复。但要按章程做**真实帧 fixture** 验证时撞墙了。

### 撞的墙

- `tests/mock/replay_fixture.lua` 把**每个**单位硬编码成 `CanBeSeen = true`;
- `make_fixture.py` 根本不输出视野字段;
- 再往上游:`tools/batch_test/behavioral/dumper/main.go` **从不写 `vis`**
  (`grep -rn '"vis"'` 命中 0 条),所以 `build.py:413` 的 `has_fog` 恒为
  false,网页端一直用 1600 半径近似视野。

后果**不止影响 Zeus**:线上引用最多的两个判定 `J.CanCastOnNonMagicImmune`
和 `J.IsValid`(:2984)都硬性依赖 `CanBeSeen()`。任何 fixture 都在一个"敌人
全亮"的世界里判绿,而实战里那条分支可能因为雾根本不走 —— 这正是
`creeppull`/`pullcamp` 那种"批测 10/10 局全程 SILENT"的已知成因家族。

### 做掉的一半(fixture 侧,已完成并测试)

- `make_fixture.py`:snapshot 带 `vis` 时输出 `seen_by = { ... }`;v1 dump 不
  带该键时**整个字段省略**(不是输出空表 —— 空表会被读成"没人看得见")。
- `tests/mock/replay_fixture.lua`:按 `seen_by` 设 `CanBeSeen()`;并让
  `bot:GetNearbyHeroes` 变成视野受限(与引擎一致);`GetUnitList` 保持返回
  全图句柄(与 `docs/BOT_API_REFERENCE.md:624` "across the entire map" 一致
  —— 过滤是调用方的责任,全图技能合理地不需要过滤)。
- **向后兼容是硬要求**:所有已有 fixture 都没有 `seen_by`,一律保持全可见,
  行为与之前完全一致。全套 386/386 绿(基线 377 + 新增 9)验证了这一点 ——
  没有任何一个既有 fixture 测试发生位移。
- 契约由 `tests/test_replay_fixture_vision.lua`(9 例)钉住:雾里的敌人
  `CanBeSeen()` false / `J.CanCastOnNonMagicImmune` 与 `J.IsValid` 拒绝它 /
  `GetNearbyHeroes` 不返回它 / `GetUnitList` 仍然返回它 / v1 fixture 全可见。

### 没做掉的一半(诚实交代)

**dumper 不产 `vis`,所以上面这套管线目前在真实帧上是空转的。** README 已经
记录了难点:Manta 不网络化 per-team 可见性位掩码,精确雾必须从视野源重建。
这属于 harness 侧的活,已开 **GH issue #27**(`[harness]`,带复现步骤和三条
验收标准)。

**所以 backlog #4 的 Zeus 修复本次没有落地** —— 它的核心假设("雾里的残血
敌人被击杀确认漏掉")**恰恰是一个只能用视野信息证实/证伪的假设**,而现有
工具链拿不出这个信息。按章程"行为改动必须带真实帧 fixture",硬写一个
gated 修复只会得到一个自己骗自己的绿灯。这条留在 backlog,阻塞在 #27。
