## 3. ⛔ 这个 0 怎么读 —— 它不是裁决

### (A) 行为域的 0 是**语料的**,不是杠杆的

`X.ConsiderW` 在**全部 11 个**可付格上都返回 `DESIRE_NONE`,**包括 1600 内确实有
敌人的那 3 格**。它每条分支都挂在模式/目标状态上,而在**每一个 fixture 帧**上:

```
J.GetProperTarget(bot) = nil      bot:GetActiveMode() = 0
IsGoingOnSomeone=false  IsRetreating=false  IsInTeamFight=false
WasRecentlyDamagedByAnyHero(3)=false
（f_163732_sk_pull_ambush: 敌人 537u / 829u,两个都 CanCastOnTargetAdvanced=true,
  仍然一条分支都开不了火)
```

这就是 **GH #474**(「`J.GetProperTarget` 在每个 fixture 帧上结构性为 nil,
fixture 路线整条堵死」)**在第二个互相独立的现场** —— #474 立案时的现场是 `rotscope`。

⇒ 这份档案**演示不出一次 Hex 施法**,因此它**没有资格**说「储备改不了什么」。
它有资格说的是运营上真正要紧的那句:**这里没有一帧写得出 fixture**,
而本组纪律要求行为改动先有一帧。**杠杆是被帧供给卡住,不是被证伪。**

### (B) GH #73 对 `lionult` 的 strike **不能**搬到这里

`lionult` 死于**闭式**:带宽 = 最便宜的基础技能,Impale 阶梯**终止**于 150,
蓝池不终止 ⇒ 占比严格收缩,升级把域杀死。

这一根**没有那个终止**。可咬区间是 `mp <= 0.30 * maxMp + hexCost`,
即占比上限 `0.30 + hexCost/maxMp`;Hex 阶梯也终止(**200**),第二项确实收缩 ——
但**收敛到 0.30,不是收敛到 0**。区间收敛在无量纲的「Lion 蓝量低于 30%」上,
**任何等级都不会消失**。实测两端:池 510 → 上限 0.692;池 1551 → 上限 **0.429**。
这半条写成断言(§4),就是为了**不让 #73 的算术在这根上被引用**。

### (C) 两条边际都很小

11 格里线下 1 格、有敌人 3 格。这份语料整份是为别的杠杆采的,**没有一帧按 Lion
蓝量挑过**。所以 §2 的零写成**交集棘轮**而不是比例。
