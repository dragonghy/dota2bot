## 2. ⭐ 承重读数:`IsHidden()` 一直读得到,只是单向,而这个仓库一直在打印它

`test_focus_innate_index_anchor.lua` 立着一句「`IsHidden()` 在游戏 VM 外读不到」,
GH #203 的八世界枚举就是绕开它的代价。**它读不到的是「求值」,不是「观测」。**

行为 dumper 走的是**同一个** `m_vecAbilities`,过滤器写着
(`tools/batch_test/behavioral/dumper/main.go`,`isRealAbility`):

```go
if hidden {
    return false
}
```

⇒ **一个名字出现在某帧的 ability 数组里,就等于它在那一帧 `m_bHidden` 为 false。**
**存在是读数;缺席仍是析取**(hidden / 未升级天赋行 / 黑名单通用技能 / 根本不在 vector 里),
本轮从不把缺席当读数用 —— 这一条写进了测试的抬头,也写进了断言的失败信息。

**分母**(否则「缺席」与「这条管道显示不了」长得一模一样):
WK 的 innate **31/31**、Lion 的 **23/23** ⇒ 管道**显示得了 innate**;
`zuus_lightning_hands`(魔晶 grant)**1** 个 Zeus 帧 ⇒ 也**显示得了 grant**。

**CM**:51 个带数组的帧,**每帧恰好 4 个真技能**;`crystal_clone` **0**、`glacial_guard` **0**。
⇒ 两个可选技能在本仓库拥有的**每一帧上都是 hidden** ⇒ 都被丢弃 ⇒ 落到第四个世界。

## 4. ⭐ 本轮最值钱的一条:第一版模型被自己打掉,而且打在两处

第一版写的是「两个都 hidden ⇒ 都丢 ⇒ **下标 4 是 nil** ⇒ `CrystalClone:IsTrained()` 在
`X.SkillsComplement` 里抛 ⇒ 引擎错误处理器坏掉 ⇒ **整 tick 静默夭折**,而这条分支
**在 ConsiderQ/W/R 之上** ⇒ 她的整个法术派发全死」。跑出来两处不对:

1. **占位符先被按名字接住。** walk 先 `if name == generic_hidden`(`aba_skill.lua:5` 是个
   **file-local 字符串**,分支真的会走),**再**应用 `NOT_LEARNABLE and IsHidden()` 丢弃规则
   ⇒ 空槽无论 flag 如何都被保留 ⇒ 下标 4 是 `generic_hidden`,不是 nil。
   **顺带一次现场自纠**:我一度在 probe 脚本里把 `generic_hidden` 读成未定义全局并准备报成缺陷 ——
   它是 local,probe 自己的 chunk 里才是 nil。**报之前先 grep 定义**,这一条没进 issue。
2. **`#` 的边界跟着表变,不跟着 VM 变。** `#`(带洞的表)在 Lua 5.1 **未定义**:
   本 VM 对 `#{1,2,3,[6]}` 答 **3**(占位符正落在下标 4),
   而 GH #203 的 Zeus 那侧在**同一个 VM** 上对 `#{1,2,3,4,[6]}` 答 **6**。
   ⇒ **「本 VM 答 6」不是一个可以在英雄之间搬运的事实。** 两条都钉成 world assertion。

**所以那条未 gate 的空指针检查是保险,不是修复** —— 源码注释、issue、`state.json` 三处都这么写。
它守的是「`#` 答 6 的那个合法世界」:那里下标 4 才是 nil,上面那段崩溃剧本才成立。
语料说今天出货的不是那个世界。**这个区别最容易在下一份摘要里被升格,所以钉成了断言**
(`test_cm_ability_index_binding.lua` §4「and it is insurance, not the repair of an observed crash」)。
