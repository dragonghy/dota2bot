## 3. (2)(3) 重取:**五帧的裁决全部不变**,而其中一帧的余量变成 **0**

用**阶梯自己的价钱**(不加任何手钉锚)在真实帧上跑真的 helper(§4):

| 帧 | 蓝 | 阶梯 R 价 | 阶梯 spend 价 | 裁决(重取) | 文件原裁决 |
|---|---|---|---|---|---|
| CROSS `f_260820_042607_zuus_reserve_cross` | 256 | 250 | bolt 135 | `zusult` **false** / `zusultx` **true** | 一致 |
| SAFE `f_260820_042607_zuus_reserve_safe` | 380 | 250 | bolt 130 | `zusultx` **false**(放行) | 一致 |
| LOCK `f_260819_142047_zuus_ult_manalock` | 99 | 250 | — | **true**(扣住) | 一致 |
| DENIED `f_260819_142047_zuus_ult_denied` | 190 | 250 | — | **false**(击杀窗) | 一致 |
| W2LEAK `f_260819_222052_zuus_w2_leak` | 152 | 250 | — | **true**(扣住) | 一致 |

**⭐ 但 SAFE 那一格的余量塌了。** 文件自己的锚(ult 225 / bolt 129)给出
`380 − 129 = 251 ≥ 225`,**余量 26**;阶梯给出 `380 − 130 = 250 ≥ 250`,**余量恰好 0** ——
这条裁决现在**完全由 `>=` 里的那个等号扛着**。M2(把 `>=` 改成 `>`)**只红 §4c 一条**,
CROSS / LOCK / DENIED / W2LEAK / §5 全绿存活 ⇒ 刀口是真的,而且只在这一帧上。
按 README 计量 (ii)「要报中位数就必须同时给占比,让刀口暴露出来」的同一条理由,
这个 0 **写进断言**(`nMana - nSpend == nUlt`),不藏进「裁决不变」四个字里。

**六个手钉锚 vs 阶梯,符号只有一个方向**(§4d):246≤250、225≤250、225≤250、130≤135、
129≤130、91≤95。理由是可推的而不是巧合:**两次 0.5s 快照之间的回蓝只能让实测的花费显得更小**,
所以录像实测价是**下界**。⚠️ **本轮不主张阶梯的 250 比文件的 246/225 更对** —— 只登记
差的存在、符号唯一、以及回蓝的方向与这个符号一致。哪个是引擎的活数字,桌面答不了。

## 4. ⭐⭐ 新形状:阶梯之前,`zusultx` **就是** `zusult`

#416 对验收 (2) 的答案是「同一个函数体、同一条价钱行」。**比这更糟一格,而且只糟在宽 id 上**:

```lua
local nSpellCost = hSpell:GetManaCost()
if type( nSpellCost ) == 'number' and nSpellCost > 0 then nSpend = nSpellCost end
```

一个 0 在这里**不结束调用** —— 它**静默地把增量置零**,然后让**出货那条子句**去回答。
⇒ 一份阶梯之前 arm 了 `zusultx` 的 fixture,**测到的是 `zusult`,而且看起来像测到了加宽**。

驱动(§5,CROSS 帧,同一 id、只把一个操作数按回 0):

| 腿 | 裁决 | spend 价读取次数 |
|---|---|---|
| 今天(阶梯) | **true** | 1 |
| spend 价 = 0(阶梯前) | **false** | **1** |
| `zusult`(窄 id) | false | **0** |

**两条读数各有一个控制**:窄 id 那条 **0 次**证明「读 spend 价」就是加宽的全部;
塌陷那条 **1 次**证明函数体**真的跑到了**那一行 —— 否则「决策没变」与「压根没执行」
在返回值上长得一模一样(§6 是它的另一半:把 R 价按回 0 时读取次数必须是 **0**,
即门死在价钱行**之前**;M1 把 `nCost <= 0` 改成 `nCost < 0`,**只红 §6**)。

**仓库里之所以不存在这样一条被污染的读数**,唯一原因是 `zusultx` 的唯一消费方
(`reserve_cross`)**把两个操作数都手钉了**。这是运气的形状,不是设计的形状 ⇒ 已写成 §2 的断言:
删掉那行锚(M3)**只红 §2**。
