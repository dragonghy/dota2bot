## 1. 缺陷

`bots/BotLib/hero_zuus.lua`,`X.SkillsComplement`(修前):

```lua
if abilityAS:IsTrained() then abilityASBonus = 0.09 end
```

`abilityASBonus` 在全仓**只有两个消费方,两个都是击杀估算**:

| 消费方 | 表达式 | 后果 |
|---|---|---|
| `X.ConsiderW` 远程兵斩杀 | `targetRanged:GetHealth() < GetActualIncomingDamage(nDamage + GetHealth()*bonus, MAGICAL)` | 100+ 蓝的雷击喂给一个杀不掉的兵 |
| `X.ConsiderR` 的 `lowHPCount` | `nEstDamage = nDamage + e:GetHealth()*bonus`;`lowHPCount >= 1` ⇒ `MODERATE` | **~130 秒冷却的全图大招**砸在死不了的人身上 |

游戏自己的 KV(d2vpkr 镜像,与 `gen_ability_meta.py` / `special_value_key_census.py`
同源,2026-08-25 取):

```
"zuus_static_field"  { "MaxLevel" "1"  "Innate" "1"
    "AbilityValues" { "damage_health_pct" {
        "value" "3.45"  "hero_levelup" "+0.05"
        "special_bonus_unique_zeus_static_field_dmg" "+2"
        "display_type" "kMagicalDamagePercentage" } } }
```

⇒ 真值区间 **[3.45, 4.95]**(1 级 → 31 级)。`0.09` 在**整条区间**上偏大 1.8–2.6 倍。

**这条与 backlog §4 是同一个病的两扇门**:那一条量出来的结论是「Zeus 的问题在上游
—— 斩杀窗口来的时候没蓝」。本条给出了**蓝去哪了的一半**:蓝花在了一个**从来就不存在的
击杀**上。

## 4. 修法

新 helper `X.GetStaticFieldBonus( hAbility )`:

* **出厂常数是函数的最后一句**,armed 分支是唯一的绕道,`IsTrained()` 守卫在**出厂位置
  跑在最前**(操作序列与出厂逐条相同)⇒ **gate-off 等价是结构性的,不是测出来的**;
* armed(`J.IsModeTurbo() and J.IsSoakCandidate('zusstatic')`)读 `damage_health_pct`
  返回 `pct/100`;**读到 <= 0 就丢掉这一项而不是编一个默认值**(GH #162 家规);
* **句柄是参数不是文件局部量** —— 见下面的 LIMIT ①,不然两条腿离线都驱动不了。

**gate:`zusstatic`,turbo-only,未 armed、不申请入集**(先买域,同 `lionsplash`/`axebhpure`
的处置)。登记 `state.json: zusstatic_20260825`。

## 5. ⚠️ LIMIT(三条,全部量出来的)

1. 静电场是 `Innate 1` + hidden ⇒ **没有任何 .dem 带它**:Zeus 真实帧上
   `J.Skill.GetAbilityList(bot)[5]` **是 nil**,文件局部量 `abilityAS` 是「nil 名字的句柄」,
   `IsTrained()` 恒 false ⇒ **两条腿在任何未加工的 fixture 上都读 0**。与 GH #151 同族。
   **这就是把句柄改成参数的唯一理由**,不是风格偏好。
2. mock 的 `GetSpecialValueFloat` 对任何 key 恒 0 ⇒ **armed 腿离线读到 0 不是 3.45**
   (同 GH #162/#133/#145)。
3. `GetActualIncomingDamage` 在所有活人句柄上恒 0(第二十二条世界断言,GH #154)⇒
   `J.WillMagicKillTarget` 离线是哑的 ⇒ **「这一帧大招会不会开」不是 fixture 能回答的问题**。

所以那一帧只用它**能如实承载**的东西(五个敌人的真实当前血 + Zeus 的真实等级),
**条件 (a) 必须从语料买**。三条 LIMIT 在测试里是**测量**不是断言(§5 三例),
哪天 mock 长出真值,它们会自己红并点名下一步。
