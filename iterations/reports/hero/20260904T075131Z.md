## 2. 落地:`zusboltdom`(turbo-only,未 armed,未入集)

新 `X.BoltAoEKillTarget( nHealthCap, hWeakest )`:armed **且上限退化**
(`type(...) == 'number'` 且 `<= 0`)时返回 `hWeakest`,否则 `nil`。
击杀-AoE 的 return 把它作为第三个值带出。

**改了什么**:只改「储备门有没有东西可看」。
**没改什么**:分支是否开火、往哪里打,一个字都没动。
上限一旦是真数(今天 = `zusboltcap` armed;将来 = KV 补上字段,或引擎不再把 0 读成无过滤器),
它立刻回答 `nil`,GH #47 的豁免原样回来。

**⛔ 依赖写成了值,不是 id。** helper **不读** `J.IsSoakCandidate('zusboltcap')`。
条件里点名兄弟候选的门,会在那个兄弟被 promote 的当天冻成 FALSE
(promote 掉的 id 不出现在任何 armed 串里 —— `pullcad` 陷阱,AGENTS.md)。
按**上限自己的值**开关,能活过 `zusboltcap` 被 promote、被拒、或被一次 KV 修复取代。
这就是 GH #477 选项 2 的字面意思:**把这条依赖写成代码而不是散文**。

方向:**严格收紧**,而且只在 `zusult`/`zusultx` 已经 armed 的前提下才可能动。
闸关时 helper 在每一帧都返回 nil ⇒ 击杀-AoE 的 return 就是出货的两值 return 加一个 nil 尾巴。
**它只能扣住一次出价,永远不能发出一次。**

## 4. 三条兄弟绊线按名字响了,全部重新对准而不是放松

它们各自都是对的,响得也对 —— 记在这里是因为**「改一个 return 的元数」在本仓有三个下游**:

1. `tests/test_replay_260819_zuus_w2_leak.lua` —— 它把 GH #47 的不变式拼成了
   「前三个 return 的**返回值个数** == 2」。**不变式没变**(真的击杀永远不被扣住),
   变的是它**不再能用值的个数表达**:第三个值在上限是真过滤器的每一帧上都是 nil。
   ⇒ 第 1 条改判 `== 3` 并把不变式**改钉成行为**(指向本轮的新文件与变异台),
   第 2、3 条(打断 / 撤退)原样保留 `== 2`。
2. `tests/test_zuus_bolt_kill_cap.lua` —— 「`nDamage` 在 `ConsiderW2` 里恰好一个消费者」。
   现在是**两个,而且两个都点名了**:`FindAoELocation` 的 `nMaxHealth`,以及本轮的豁免判据。
   第二个**故意是同一个局部的读取**而不是第二次调 helper —— 两次调用一旦上限不再是纯函数就会分叉,
   那时分支会「按一个值豁免自己、按另一个值搜索」。
3. `tests/test_zusult_pre_ladder_claim_retake.lua` —— 它扫描 `tests/` 枚举「arm 了 zusult/zusultx」
   的文件集,**新文件不许悄悄加入**。本文件加进去了(它必须 arm `zusult`:
   未 armed 的运行**分不清**「分支没报目标」和「根本没有门在等这个目标」),
   并按 §2 的要求**自己锚住大招蓝耗**,这一条也一并断言。
