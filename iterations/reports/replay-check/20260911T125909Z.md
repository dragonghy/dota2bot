## 二、⭐ 归属:铁律 4a 问的那一句,答案是「不相交」,而且是从源码买的


三个都**够不到 `abilanc` 的域**,三条理由各自独立可查:

   且该 id **本就读 SILENT(`episodes=0`)才离开测试集**。⇒ 它在两波上都是 no-op。
2. **`pullcamp`** —— `bots/FunLib/jmz_func.lua:10817` 逐字

   `if J.IsCore( bot ) then return nil end`。**硬时间窗 60–360s,且只对辅助生效。**
3. **`pulldrag`** —— `:11200` 自带 `IsSoakCandidate('pulldrag')`,而该函数

⇒ **并池在 `abilanc` 这一条上合法**,理由是**时间不相交**,不是「都是波次所以能并」。

⚠️ **这一条只排除了「直接路由」的混杂,不排除「间接经由早期经济改变升级时间线」。**
