## 3. ⭐ 结论一:`pullbeat` 的 (a) 在 W3 的波次设计下**不可分离**

W3 的 armed 串是 `creeppull,pullbeat`,**两个一起开**;baseline 腿两个都关。
于是波内那个「同局镜像」对照测的是**这一对**,不是 `pullbeat`。
`pullbeat` 的代码位置(`mode_roam_generic.lua:194`)本身就在 `creeppull` 的执行体里
—— 它**只有 `creeppull` 触发时才有机会跑**,所以「关掉 creeppull 单开 pullbeat」在结构上也不存在。

唯一的差分伙伴是 **#143 的 06:11Z 波**(pre-fix),但那一波 armed 了 **25 个 id**
⇒ 跨波差分被另外 24 个 id 混杂,**不是干净的 pre/post**。

**波内唯一不依赖跨波比较的 `pullbeat` 观测量**是「poke 到底打没打出去」——
`creeppull_specificity.py` 的 axis 0b(右键 = `inflictor == dota_unknown` 的伤害行):

```
core_pull episodes 里带真右键的比例:  armed 815/1861 = 43.8%
                                      baseline 686/1603 = 42.8%
```

**两腿几乎逐位相同**;#143 §5 记录的 pre-fix armed 侧是「**47.0% 的 pull episode 一次真普攻都没有**」
(即 53.0% 有)⇒ post-fix 的 43.8% **更低**。但这仍是跨波比较,**不能当作 pullbeat 变坏的证据**,
只能说:**`pullbeat` 声称要修的那个量,在 armed 腿上没有相对 baseline 抬起来。**

**⇒ 判定:`pullbeat` = INDETERMINATE(不可分离),不是 WORKING,也没证据判 BUGGY。**
要买它的 (a),需要 **`creeppull` 单开 vs `creeppull,pullbeat` 双开**的差分波(见 §7 交棒)。

## 4. ⭐ 结论二:池化 armed/baseline 读数被**物理侧别 + 整数中位数刀口**双重污染

这条是本轮最贵的收获,因为它**回头打到 #143 自己的表**。

⇒ 中位数在这个统计量上**不是稳健量,是硬币**。
