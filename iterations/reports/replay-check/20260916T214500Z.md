### 8.1 ⛔⛔ 新工具坑(本轮自己造的,第一次以「活 bug」形态出现)——**等自检的循环会匹配到它自己**

W81/W82 把「`pgrep -f` 会匹配到 Claude Code 自己的 Bash 工具 shell」记成了一条**观察**
(查 PPID 后排除掉就完了)。**本轮它变成了一个我亲手写的、永远不会退出的循环**:

```bash
until ! pgrep -f routine_selfcheck.sh > /dev/null; do sleep 5; done   # ⛔ 永不退出
```

**这条命令自己的 shell 命令行里就含 `routine_selfcheck.sh`** ⇒ `pgrep -f` 永远至少匹配到它自己
⇒ 条件恒假。**后果实测**:自检其实**早就跑完了**,而我连续 ~10 分钟读到「RUNNING」,
**把一个已完成的自检当成还在跑**,并据此推迟了分支 ref 同步。

⭐ **判别子在同一屏里,而且比结论早一行**:`ps -o etime= -p 1575` **已经空了**
(真实 PID 没了),`pgrep -f` **却还在匹配** —— **两者矛盾时,信 PID 不信 `-f` 模式**。
⭐ **正解**:等一个已知 PID 用 `while kill -0 <pid> 2>/dev/null`;非要用 `pgrep` 就
`pgrep -f '[r]outine_selfcheck\.sh'` 或加 `-x`/排除自身 PID。
⭐⭐ **可迁移的那一句,与 §二/§四 是同一条**:**先问「我量到的是不是我以为的那个东西」** ——

`/tmp/w83/wkqdmg_cf.py`(域与反事实,一遍扫完、滤条一致):

```python
import json, collections, math, sys
d=json.load(open(sys.argv[1])); sn,ev=d['snapshots'],d['events']
SK='npc_dota_hero_skeleton_king'; QN='skeleton_king_hellfire_blast'
t_end=max(e['t'] for e in ev)
seen=collections.Counter((s['hero'],s['idx']) for s in sn)
real={}
for (h,i),n in seen.items():
    if h not in real or n>real[h][1]: real[h]=(i,n)
real_idx={h:v[0] for h,v in real.items()}
frames=collections.defaultdict(dict); teams={}
for s in sn:
    if s['idx']!=real_idx[s['hero']] or s['t']>t_end: continue
    frames[s['hero']][round(s['t'],1)]=s; teams[s['hero']]=s['team']
deaths=collections.defaultdict(list)
for e in ev:
    if e['type']=='DEATH' and e.get('target_hero') and e['target'] in frames:
        deaths[e['target']].append(e['t'])
def dead_at(h,t):
    last=max([t0 for t0 in deaths.get(h,[]) if t0<=t], default=None)
    if last is None: return False
    return not any(last<tt<=t and s['hp']>0 for tt,s in frames[h].items())
enemies=[h for h,tm in teams.items() if tm!=teams[SK]]
def qinfo(s):
    for a in s['abilities']:
        if a['name']==QN: return a
IMPACT={1:80,2:100,3:120,4:140}; DOT={1:20,2:40,3:60,4:80}; RES=0.25
def shipped(r): return (40*(r-1)+100)*1.68
def run(label, dur_at):
    live=noop=pair=band=0; hits=[]; hp_in_range=[]
    for t in sorted(frames[SK]):
        s=frames[SK][t]; q=qinfo(s)
        if q is None or q['level']<1 or q['cd']>0 or dead_at(SK,t) or s['hp']<=0: continue
        r=q['level']; he=(IMPACT[r]+DOT[r]*dur_at(t))*(1-RES); sh=shipped(r)*(1-RES)
        if he>=sh: noop+=1; continue
        live+=1
        for h in enemies:
            es=frames[h].get(t)
            if es is None or es['hp']<=0 or dead_at(h,t): continue
            if math.hypot(s['x']-es['x'],s['y']-es['y'])>680: continue
            pair+=1; hp_in_range.append(es['hp'])
            if he<es['hp']<=sh:
                band+=1; hits.append((t,s['level'],r,h,es['hp'],round(he,1),round(sh,1)))
    print(f"\n--- {label} ---")
    print(f"  live-domain frames {live} | no-op frames {noop} | in-680u enemy pairings on live frames {pair} | BAND {band}")
    if hp_in_range:
        hp_in_range.sort()
        print(f"  enemy HP on those pairings: min={hp_in_range[0]} p25={hp_in_range[len(hp_in_range)//4]} med={hp_in_range[len(hp_in_range)//2]} max={hp_in_range[-1]}")
    for x in hits: print(f"    t={x[0]:7.1f} heroLvl={x[1]:2d} Qrank={x[2]} {x[3].split('hero_')[1]:15s} hp={x[4]} honest_eff={x[5]} shipped_eff={x[6]}")
run("A: as armed in this wave (wkt10ls NOT armed -> shipped t10 doubles dot at ~t=437)",
    lambda t: 4.0 if t>=437.0 else 2.0)
run("B: counterfactual, wkt10ls ALSO armed (dot held at 2.0 all game)",
    lambda t: 2.0)
```
