## 3. ⭐⭐⭐ 主结论:GH #378 §10 的那一棒,答案是「窗口到处都是,而且载体不是英雄」

#378 §10 把**唯一缺的读数**交给本组:

> 真实对局里,一个 bot 同时有 ≥2 个受控小兵/幻象的窗口有多少、多长
> ⚠️ 若语料里根本没有这种窗口(**完全可能** —— 5 个焦点英雄里只有 WK 产生这种人口),
> 判 `DOMAIN-EMPTY` 退回总监重裁

**答案:窗口在 16/16 局里都有,而 #378 括号里那句话的理由是错的。**

seed 2986 的十个英雄是 `pudge / obsidian_destroyer / dragon_knight / necrolyte /
phantom_assassin / lion / zuus / bristleback / sven / ogre_magi` ——
**没有一个有召唤技能**,`bots/BotLib/hero_*.lua` 里**没有一个买** `item_manta` /
`item_helm_of_the_dominator` / `item_helm_of_the_overlord` / `item_necronomicon`

**它没有,因为载体是幻象符。** 战斗日志里的第一手事件:


## 9. 诚实边界

- **没有一个数字是效应量**;本轮**不碰胜负、不碰经济**,买的是条件 (a) 而已。
- **16 局不是 40 局**:`--rec-slots 8` 决定了只有 slot1..8 有录像;剩下 24 局**没有录像可看**,不是没看。
- **一粒种子**:所有读数来自 seed 2986 一个阵容,**不可与 W29–W34 并池**,也不可外推到别的阵容。
- **`armed` 腿等于「52 个 id 全 armed」**,不是「只 armed `illumove`」;§4.4 与 §5 给的是
  「这条路径上只有这两个 id」+「交集为空」两条**论证**,不是隔离实验。
- **armed 臂到底是「per-unit 0.2s 时钟」还是「等于没有时钟」,本轮分不出来**:
  若引擎每帧发的是新句柄,`hMinionUnit.next_move_time` 每次读回 `nil`⇒0,**门恒开**。
  1 Hz 采样下两者同判。(仓库里 `lastItemFrameProcessTime` 等 per-unit 字段能工作,
  说明句柄是持久的 —— 那是**旁证不是本轮读数**。)登记,不下裁定。
- 幻象符这一条是**本语料的观察**;它在别的补丁/模式下是否同样密集,本轮没证。
- 幻象存活窗口用 `hp>0` 截断:dumper 在实体消失后会继续吐**上一帧的存量行**
  (`154601_slot5` 里 t=1360.5 三条流都是 `hp=0`),所以一律**按 `hp` 截断**,不按行数。
