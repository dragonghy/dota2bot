## 三、⭐⭐ 第四个远古阈值:`IsValidCreep` 里的 **9**,任何 campfarm 头注都没写过

```lua
function ____exports.IsValidCreep(target)
    if target == nil then return false end

       and not target:IsHero()
       and (GetBot():GetLevel() > 9 or not target:IsAncientCreep())
```
