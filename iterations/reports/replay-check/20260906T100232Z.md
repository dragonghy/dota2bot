## 3. ⭐⭐ 主发现二:逐帧推翻了本轮排名第一的「收益」样本

### 3.1 帧证据

全语料最像收益的那一帧 —— `b30fe4__20260904_184634_slot6` **t=1393.9**,
900u 内**四个**没中招的敌方英雄(bristleback 179u / obsidian_destroyer 433u /
pudge 554u / tidehunter 698u),这是 577 个 episode 里第 (2) 列的最大值:

```
1388.2 ABILITY axe -> spirit_breaker axe_battle_hunger  (首次,ADD 同 tick)
1393.9 ABILITY axe -> spirit_breaker axe_battle_hunger  (重放,剩余 6.3s)
1395.9 ABILITY axe -> spirit_breaker axe_culling_blade
1395.9 DEATH   axe -> spirit_breaker axe_culling_blade v=265
1396.4 DEATH   axe -> bristleback    axe_culling_blade v=181
```

⇒ **那是击杀确认**,2.0 秒后 Axe 把同一个目标斩了。而 `X.ConsiderW` 的
**击杀循环正是杠杆故意不接线的五处之一**(其伤害论证按满 12s 定价,
而满 12s 只有刷新能还回来)。

**可迁移的那一句**:一个只数「射程内有没有别人」的计数,会把一个**故意的 no-op 位点**
读成**被放弃的收益**。聚合表上它是最漂亮的一行;逐帧它是反的。
**这正是章程硬规则「先逐帧后聚合」当轮兑现的地方。**
