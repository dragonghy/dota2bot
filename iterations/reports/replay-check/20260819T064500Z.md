## 2. 核验结论

### `l1xpsoak`: **SILENT(被支配 / 不可区分)**

注意措辞:**不是"门从未评估为真"**,而是**即使为真,产出的行为与已 promote
的默认规则 `lanesurv` 逐字相同**,因此用录像无法给它开条件 (a) 的合格证。

**代码级(决定性)**:`bots/mode_retreat_generic.lua:252` 是唯一消费点,
只判 `J.ShouldXpSoakLane(bot) ~= nil` 然后 `return BOT_MODE_DESIRE_HIGH`。

1. **返回的锚点 Vector 被丢弃**。20260819 重设计的头号卖点(绝对锚
   `bot.l1xpsoakAnchor`,防"死亡行军"漂移)在 rehome 到 retreat desire 之后
   **不再影响任何位置** —— 锚点如今只剩一个作用:充当退出滞回的状态位。
2. **入场条件是 `lanesurv`(`J.ShouldRetreatLaneBurst`,已 promote、默认开、
   无 gate)的真子集**,两者返回同一个 `BOT_MODE_DESIRE_HIGH`:
   敌人半径 1200 vs 1100、敌人数 >=2 vs >=1、窗口都是 3.0s、阈值都是
   `HP*0.75`(`l1xpsoak` 要求"1400 内无 >=40% 队友" ⊇ "700 内无 >=40% 队友",
   所以 `lanesurv` 的 `bPeel` 必然 false)。**两个 zoner 都在 1100 内时,
   两边求和的敌人集合完全相同 → 逐位相同的判定、相同的返回值。**
   独占窗口只剩"两个 zoner 全落在 1100-1200 的环里"。

**帧级(12/12 局)**:按入场几何条件(t∈[90,480]、HP<=85%、1200 内 >=2 敌、
1400 内无 >=40% 队友)扫全部有效局,得 335 个 episode:

| 情形 | 计数 | 含义 |
|---|---|---|
| 1100 内已有 >=2 敌 | **236 / 335 (70.4%)** | 敌人集合完全相同,lanesurv 逐位同判 |
| 1100 内 >=1 敌 | **326 / 335 (97.3%)** | lanesurv 对子集求和,极大概率同样越线 |
| 1100 内 0 敌 | **9 / 335 (2.7%)** | l1xpsoak 唯一可能独立生效的窗口 |

  本波不受影响(tpwatch 未 armed),但上一次 14-id 全集波次两者同时 armed
  —— 这是那次 -34.59 gpm 负偏差的一个**结构性候选解释**(id 之间非独立,
  违反"一次只变一个量"的隐含前提)。建议改成取 `math.max` 或把 259 提前。

## 4. 工具缺口(不硬猜,如实记录)

- dumper 不落 `GetEstimatedDamageToTarget` 的估值,离线只能验几何条件,
  "爆发 >= 75% 当前 HP"这一条**永远无法离线判定** —— 本报告 335 个 episode
  是真实触发的**超集**。`l1xpsoak` 的退出滞回带(40%-75%)因此完全不可测。
  与 #27(缺 per-hero `vis`)同类,若总监认为滞回值得单独验收,需要 [harness]
  支持;本轮未新开 issue,已写进 #28 的"工具缺口"节。
- dumper 仍缺 lane-role 字段,`J.IsCore` 只能按英雄常识推断(本轮 luna /
  sniper / dragon_knight / skeleton_king / necrolyte 判为 core,
  witch_doctor / crystal_maiden / shadow_shaman 判为辅助)。连续第四轮记录
  这个缺口。
