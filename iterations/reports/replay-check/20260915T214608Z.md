## 四、发现乙 + 丙:`arm` 这个词本身有两处问题

### 4.1 乙 — **同一部法里 `arm` 有两个差 2 倍的定义,而两边都在被引用**

逐字,四处:

| 处 | 写的是 |
|---|---|
| `iterations/streams/README.md:79` | `d_ab + d_ba = […] + […]` = **阵容项逐项抵消的 arm** |
| `iterations/streams/README.md:82` | 估计量是 **`arm = (d_ab + d_ba)/2`** |
| `tools/batch_test/behavioral/strata.py:30-31` | `d_ab + d_ba = […]` = **the arm effect** |
| `tools/batch_test/behavioral/strata.py:68` | `arm = (d_ab + d_ba) / 2.0` |

**两边都被当成读数用了**:用 #835 RULING 54 表里的 `N_ab=47 / N_ba=34` 反算 ——

```
detector                          d_ab      d_ba   SUM(pub) SUM/2(impl)
overextend_alone              -4.72340  +9.29412   +4.57071   +2.28536
skywrath_solo_silence         +0.70213  -0.91176   -0.20964   -0.10482

lowhp_limbo                   -0.57447  -0.52941   -1.10388   -0.55194
```

⇒ **published 那一列逐位就是 SUM**(`+4.571` / `−0.210` / `−0.045` / `−1.104`,与 #835 表一字不差),
**而 RULING 57 的闸 `pair_arm` 会返回它的一半**。

⭐ **哪个对,取决于问的是哪个问题,而这正是没被写下来的那句**:
`SUM = [f_R(armed)−f_R(base)] + [f_D(armed)−f_D(base)]` 是**两队效应之和**;
`SUM/2` 是**每队平均**。对 `skywrath_solo_silence` 这种**只有一个队能产出**的量,
`f_D ≡ 0` ⇒ **`SUM` 才是那个队的真实效应,`SUM/2` 系统性地砍一半**。
⚠️ **而 RULING 54 自己的自洽性检查只在 SUM 口径下成立**:它逐字写
「`skywrath` 和 = **−0.210**;§甲手算的跨层读数 `0.70 vs 0.91 = −23%` = **−0.21** —— **逐位相同**」。
**在闸的口径下那两个数是 −0.105 vs −0.21,差 2 倍,那句自洽性检查就不成立了。**

⛔ **棘轮抓不到它**:`tests/test_strata_paired_arm.py` 断言的是实现自己的口径,
恒等式 `opposed ⟺ |roster| > |arm|` 在两种口径下**都成立**(两边同时乘 ½)。
⇒ **没有任何一条腿会举手**,而**跨轮引用的两个数会差一倍且都自称 `arm`**。

📌 **根因猜测(写成猜测)**:(i-c) 的 `arm=(ab+ba)/2` 里 `ab`/`ba` 是**同一个量的两个读数**
⇒ 除以 2 是取平均,**对**;(i-e) 把同一个公式搬过来,但那里的 `d_ab`/`d_ba` 是**两个 delta,各带一队**
⇒ 求和才是全量。**公式被搬了,单位没被搬。**
