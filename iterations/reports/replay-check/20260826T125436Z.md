## 2. `tbearly` 是什么

`bots/mode_farm_generic.lua`,`GetFarmDesire` 里 `#hLaneCreepList == 0` 的 else 支:

```lua
local nEarlyClock = 25 * 60
if J.IsSoakCandidate('tbearly') and J.IsModeTurbo() then
    nEarlyClock = 18 * 60
end
local bEarlyGame = DotaTime() < nEarlyClock and bot:GetNetWorth() < 15000
local nDeaths = GetHeroDeaths(bot:GetPlayerID())
if bEarlyGame and nDeaths < 5 then   -- 优先 lane front,而不是打野
```

落地 commit `82b9a589`(strategy 08-24T19:26Z,「five turbo scalings that never ran」)。
**它的诊断完全正确**:shipped 文本是

```lua
J.IsModeTurbo() and DotaTime() < 18 * 60 or DotaTime() < 25 * 60
```

`and` 比 `or` 紧,所以解析成 `(turbo and t<1080) or (t<1500)`;第一个析取项是第二个的**真子集**,
整个表达式在任何模式下都**字面等于** `t < 1500`,18 分钟那个 Turbo 界**不可达**。
改写把它从 OR 换成 SELECT,gate 关时逐字节等于 shipped。

## 3. ⭐⭐ 结论:恢复出来的那个界**同样不可达**,而且是**同一个数**

这段代码所在的那个 `if` 块,最后一个合取项是:

```lua
if GetGameMode() ~= GAMEMODE_MO
and J.Site.IsTimeToFarm(bot)
and not J.IsDefending(bot)
and ( ... lone_druid_bear ... )
and (DotaTime() > 8 * 60 or bot:GetLevel() >= 8 or (bot:GetAttackRange() < 220 and bot:GetLevel() >= 6))
and networthAdvantage < 6000
and not J.IsLateGame()          -- <<<< 这一条
then
```

而 `J.IsLateGame()`(`bots/FunLib/jmz_func.lua:4444-4449`)在 Turbo 下是

```lua
DotaTime() > (J.IsModeTurbo() and 18 * 60 or 30 * 60)
```

⇒ **凡是能走到 `nEarlyClock` 那一行的帧,`DotaTime() <= 1080` 已经成立。**

| 腿 | 时钟项 | 在可达域 `t <= 1080` 上 |
|---|---|---|
| shipped(gate off) | `t < 1500` | 恒 true |
| armed(`tbearly`) | `t < 1080` | 恒 true,**除 `t == 1080.0` 整** |

**两条腿的分歧集 = `{1080.0}`,连续时钟上的零测集。**

⭐ **附带的算术小注**:`J.IsLateGame` 自己用的也是 `a and b or c` 这个惯用法,但它**没坏** ——
`b` 是 `18 * 60`(一个数,恒真),不是布尔比较。**同一个文件里同一个惯用法,一个坏一个不坏,
判别子是 `b` 的类型。** 这正是 `82b9a589` 的普查(25 个站点,5 个坏)分出来的那条线。

⚠️⭐ **合取项不是后来撞进来的**:`and not J.IsLateGame()` 在 **upstream OHA 快照里就有**
(`git show 74727e4:bots/mode_farm_generic.lua` 第 427 行)。⇒ 这条腿**不是被后续改动弄死的,
是从落地起就是死的**,和它试图修的那个 bug 一样死,只是死因换了一层。

## 6. ⚠️⭐ 本轮工具坑(发表前抓到)

**零值的一格,如果用裸 `Counter` 记,会从输出里整个消失,而那读起来像「没测」。**
第一版 `tbearly_domain.py` 的级联是 `collections.Counter()`,`L6` / `L7` 因为计数从未自增
**根本没打印**。输出止于 `L5 147455`,一个不小心就会被读成「这个杠杆有 14 万帧的域」——
**恰好把结论读反**。修法:`rung_names(sc)` 预置全部八格并按**格序**打印(不按计数排序),
零照印,并把每格的跌幅百分比一起打出来 —— `L6 (-100.0%)` 那一行现在**就是结论本身**。

**同族教训**:本组反复立「零要报出来」的规矩,但那些规矩针对的是**语料侧的零**;
这一次是**渲染侧**把零吃掉了。**「没打印」和「打印了 0」在下游读者眼里差一个数量级。**
