## 3. 交付:`idletrip_domain.py` —— 一个**不给任何 gate 打分**的检测器

这是本目录里**第一个明确声明自己不核 armed id** 的探针。所有兄弟工具
(`stayfield_domain.py` / `stayfield2_whynot.py` / `fieldcreep_domain.py` …)都在
arm 串里找不到自己的 id 就 `sys.exit` 拒绝跑;**本工具不能那样做,因为它量的是
稳定版默认行为**(21:58Z 登记:两条腿、两个分层同号)。它因此:

- **不因 arm 串拒绝任何东西**,但**照样打 arm 串**,并且**混串仍然拒绝**(两个引擎一个池,没有唯一正确读法);
- **每个头条数字都打满四格 `(分层 × 腿)`** —— 计数类估计量的侧偏没消掉(铁律 4(i-b)),
  它唯一扛得动的主张是**「四格都在」**,**不是**「armed 减 baseline = X」;
- 计数类量按 **4(ii)** 报**均值 + 分布**,中位数只在旁边陪跑。

**总体口径**:一次「来回」= 从 >4000u **连续步行**进自家泉水 2000u 环,
**再在到达后 60s 内连续步行**出到 >4000u 外。**去程与回程用同一套中断纪律**
(`stayfield2_margin.homeward_close` 的那套:死亡 / TP 通道 / 尸体帧 / 采样断点 /
超过 `550*1.6 u/s` 的位移 —— **终止,不跳过**)。出发帧锚点沿用
`stayfield2_whynot` 的**掉头点校正**(从到达帧沿单调下降回溯,`MONO_SLACK_U` 容忍寻路抖动)。
身份走 `stayfield_domain.Game` 的 `idx` 锁(GH #176 幻象污染)。

**解释梯子**(第一命中,顺序即纪律):`hurt`(出发 hp ≤ 0.90)> `mana`(出发 mp < 0.90)>
`shopping`(整段物品栏有变)> **`idle`(本发现)**。
`idle` **在构造上是最保守的那一格**:每一处含糊都判给「这趟不算白跑」。
