  baseline 恰好 50/50 分,armed 塌到 ~20%。

⚠️ **两条限制,写出来而不是抹平**:(i) 非撤退格 n 很小(armed 3 vs baseline 13,
swap-average 只有 2/4 同向);(ii) 那个 composition 签名**只在 p50 这张表上成立**

但"每张表都活下来"这条只由 ADDED 聚合(§4)满足,**不由这一格满足**。
⇒ 若总监按 §BC.4 的**字面**要求"必须由非撤退格单独承载",那答案是 INDETERMINATE。

## 2. ⭐ 本轮主发现(可迁移,比上面两个 id 都大)

**「一个 id 的门嵌在另一个 id 的门里」是一个结构类,不是一个个例 ——
当前 61 个 armed id 里有 5 个处在这个位置。**

扫遍 `bots/` 的嵌套 soak 门,共 8 对,其中**内外都 armed** 的 5 对:

| 内层 id | 被谁的门整体包住 | 位置 |
|---|---|---|
| `tpdying` | `tpcommit` | `jmz_func.lua:8958` |
| `tpdead` | `tpcommit` | `jmz_func.lua:8978` |
| `pulllane` | `pullcamp` | `jmz_func.lua:9195` |
| `campbind` | `pulldrag` | `jmz_func.lua:9416` |
| `pullcamp` | `pulldrag` | `jmz_func.lua:9416` |

(另 3 对内层未 armed:`zusultx`⊂`zusult`、`tpclaim`⊂`teambrain`、`ccburst`⊂`lanehyst`。
注意 `pullcamp` **同时**是 `pulllane` 的外层和 `pulldrag` 的内层 —— 这是一条**两级链**。)

**为什么这要紧**:一个门嵌在另一个门里的 id,**它自己的条件 (a) 在全开镜像波上不可分离** ——
armed−baseline 的差分永远是**这一对(或这一链)的**合力,而裁定是**按单个 id 登记**的。
不需要任何 bug,这是设计的必然结果。

**⭐ 这是 2026-09-06 `suptp` 那条发现的正好反面**,而且合起来才是完整的形状:

| | 形状 | 后果 |
|---|---|---|
| `suptp`(上一轮) | `A or B`,两者**同集 armed** | B **恒不承重** |
| `tpdying`(本轮) | B 的门**嵌在** A 的门里 | B **除非 A 同 armed 否则恒 inert**,且同 armed 时**不可分离** |
| `AGENTS.md` 已知那条 | `A and B`,B 被 promote | 门恒 **FALSE** |

**共同的那一句:一个 id 有没有效果、以及效果能不能归给它,取决于同一个臂串里的另一个 id;
而裁定是按单个 id 登记的。** 三种形状 `check_armed_wiring.py` **全部报 WIRED,而且都是对的**
(它的 LIMITS 自陈只查调用点存在,不查谓词能否为真、更不查可分离性)——
**缺的是没有任何检查在管"可分离性"。**
