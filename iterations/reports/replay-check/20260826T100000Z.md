## 1. 为什么这是本组的活,而不是复述批测台

批测台 §④ 引的是 `hero_zuus.lua` 自己的文档行:

> `zusstatic` armed without `zusbind` armed measures the wrong ability's missing key, i.e. 0.

这句话说的是 **armed 分支读到的数值**。把它读成「这条腿是个 no-op」需要多一步,
而那一步在源码里**不成立**。`X.GetStaticFieldBonus` 的三条出口:

```lua
if not hAbility:IsTrained() then return 0 end          -- 两条腿都 0
if turbo and IsSoakCandidate('zusstatic') then
    ... return nPct/100   (键不存在 ⇒ 0)                -- ARMED    -> 0
end
return 0.09                                            -- BASELINE -> 0.09
```

⇒ **是三个世界,不是两个**,而分开它们的是同一个引擎事实(`sAbilityList[5]` 解析成什么):

| 世界 | `sAbilityList[5]` | armed | baseline | 对 GH #207 的意义 |
|---|---|---|---|---|
| **W-nil** | nil | — | — | W12 树(`14004d85`)**没有 nil 护栏**,`nil:IsTrained()` 在 `X.SkillsComplement` 里 raise ⇒ **Zeus 一个技能都放不出来**,而且是**两条腿一起哑** |
| **W-untrained** | 真句柄但未学 | 0 | 0 | **真·结构性零腿** —— #207 要登记的就是这一格 |
| **W-trained** | 真句柄、已学、无 `damage_health_pct` 键 | **0** | **0.09** | **活腿**。两个消费方都是击杀判据,`+ hp*bonus ≥ 0` ⇒ armed **只会更少开火**,方向单侧 |

英雄组 `3d00e262` 的 2^3 枚举给的是「index 5 **是不是** Static Field」(答案:8 个世界里 0 个),
**没有**给「index 5 **是不是 nil**」。那正是分开上面三格的那个量,而它**只有语料能答**。

### ⚠️⭐ 本轮的工具坑(发表前抓到,写进工具的 docstring 和 selfcheck)

**ABILITY 事件里 `target == 'dota_unknown'`(`target_hero` False)不等于「这一发打的是兵」,
它等于「dumper 没解析出目标句柄」。** 我第一版把它当成远程兵通道,读出来
**4/4 种子 armed < baseline**、看着和大招通道一样漂亮 —— **那是仪器伪影**。

把每一次和其后 1.2 s 的 bolt DAMAGE 事件对起来,**除 1 次外全部落在敌方英雄身上**

### ⚠️⭐ 但这个读数**归因不到 `zusstatic`**,理由是算术不是谨慎

W12 是 **36-id 全集**的波次。「Zeus 在 armed 腿」的局里,**Zeus 的 4 个队友也全部 armed、
5 个敌人全部 baseline**。⇒ **腿差是 36 个 id 的合成读数**,任何一个都能解释这 4/4。

这次的诱惑是把 bundle 效应记成单 id 效应。)

## 6. 核验结论(本组只出 (a),不裁 promote/reject)

**`zusstatic`:(a) 本语料买不到,而 GH #207 的 STRUCTURAL-ZERO 登记「未成立」而非「成立」。**

- **已定**:句柄非 nil(121/121 帧证据)⇒ W-nil 出局 ⇒ `X.GetStaticFieldBonus` 每 tick
  都走到 `hAbility:IsTrained()`,**不是一条「连函数体都进不去」的腿**。
- **未定**:该句柄 trained 与否。trained ⇒ armed 0 vs baseline **0.09**,**活腿**;
  untrained ⇒ 真零腿。**只有后者**是 #207 (C) 要登记的那个,而它现在是**两个候选之一,不是结论**。
- **⇒ 按 (C) 「维持现状但明写登记为 STRUCTURAL-ZERO」执行,会把一个未定的二选一
  写成已定的一。** 本组建议 **(A)**(`zusbind`+`zusstatic` 作一个原子一起 arm):
  它**同时**消掉这个二选一(armed 时句柄按名字取,必是 Static Field)**和** GH #173 想买的那个 (a),
  零 AWS 增量,先例是 `stable-v2` 的 `creeppull`+`pullbeat`。
  **(B)(出集)也比 (C) 干净** —— 它不产生一条假的「已测」记录。
  **裁定归总监,本组不裁。**
