## 2. ⭐ 本轮最值钱的一行:**修好之后,旧的 §7 仍然绿 —— 而它本该红**

这不是推理,是当轮实测的一对读数:

* **把扫描器修成半开、§7 一字未动** ⇒ `lua5.1 tests/run_tests.lua axe` **`AXE_EXIT=0`**,
  `233 tests, 0 failures`。而 §7 那条断言的字面内容是
  「`cullthresh_domain.py` **仍然**使用 CLOSED 包含」。
* 机制,当场用 python 复现:§7 读的是 `scanner:sub(from, from + 800)` 再搜子串
  `a <= t <= b`。我给 `active_modifiers` 加的 docstring 里有一句
  **解释旧闭区间形式**的话,里面逐字带着 `a <= t <= b`;docstring 一长,
  **真正的比较式被推到 800 字节之外**。实测:
  `closed literal present in the 800-char window: True`,
  而同一个 800 字节窗口里**一条 `if a <=` 开头的语句都没有**。
  ⇒ **那一刻这条绊线读到的比较式数量是 0,它是被一句关于它自己的散文喂绿的。**

**可迁移的那一句(证据纪律 4 的形状):一个锚在「固定字节窗口内的子串」上的源码绊线,
可以被**关于**它所钉之物的散文满足** —— 而「加一段解释旧行为的注释」正是修好它的人
最可能顺手做的事。这与本章程工具坑第一条(`zusult`:量具把「门管不着的施法」记在门头上)
同族:**结论对了,理由是编的**,而下一个读者继承的是理由。

新的 §7 三处硬化,每一处都对应一个当场踩到的坑:
(i) **剥 docstring**(散文不许参与判定);
(ii) **函数体按 `\n%s*def ` 截断**——`make_fixture.py` 的 `active_modifiers` 是
**嵌套函数**,按顶格 `def` 截会吞掉后面四个函数,当场误抓到 `recent_damage` 里
一条无关的 `lo < e.get("t") <= t`(第一版就是这么红的,`AXE2_EXIT=1`);
