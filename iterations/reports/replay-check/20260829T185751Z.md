## 3. 逐帧(硬规则:结论在这一节)

### 3.1 相位无关的仪器:**两帧检验**

单帧「谓词成立」永远可以是采样相位造成的(1 Hz 快照读到敌人 476u,bot 自己 ~0.1s 的 tick 上
可能已经 520u —— 这正是 `wkqdmg` 那轮 `band_pair` 栽的地方)。
所以真正的问题不是「谓词成立过吗」,而是:

> **同一条还在跑的 channel 里,谓词在两个相邻 1 Hz 快照上连续成立过吗?**

连续两帧 = 谓词横跨整整一秒仍然成立,**一个能工作的 gate 不可能让那条 channel 继续跑**。

```
                 in-domain channels    其中谓词连续≥2帧    连续对数
armed   /ab            19                    2 (10.5%)          3
armed   /ba            11                    0 ( 0.0%)          0
baseline/ab            43                   18 (41.9%)         32
baseline/ba            24                   15 (62.5%)         34
```

Fisher 双侧:**ab p=0.0186**、**ba p=0.00055**、池化 **p=0.00003**。
**两个分层各自显著且同号**(铁律 4(i)),**报的是计数+占比不是中位数**(铁律 4(ii))。

### 3.4 归属:为什么这笔差分记在 `liondrainstop` 名下(章程 4a)

W25 的 armed 腿同时开着 **44 个 id**,一个聚合差分默认是**合力**。本轮买的是**触发级**归属:

1. **域外阴性对照(最硬的一条)** —— **不**在谓词域里的 channel,长度在两腿之间**没有方向**,
   而且**两层反号**(铁律 4(i) ⇒ 噪声):
   ```
   armed   /ab  域内 span 1.232 (n=19)   域外 span 3.174 (n=226)
   armed   /ba  域内 span 1.155 (n=11)   域外 span 3.086 (n=160)
   baseline/ab  域内 span 2.340 (n=43)   域外 span 3.003 (n=274)
   baseline/ba  域内 span 3.371 (n=24)   域外 span 3.354 (n=134)
   ```
   **缩短只发生在谓词域内。** 任何「让 Lion 整体少拉一会儿」的通用杠杆
   (包括**唯一那条像样的替代解释**:某个 id 让 Lion 更爱撤退 ⇒ 出厂的
   `J.IsRetreating` 释放路径更常触发)都会**同时**压低域外那一列 —— 没有。
2. **帧锁定**:30 条 armed 域内 channel 里 **23 条 residual ≤ 0.2s**,
   是在谓词成立的**那一帧**结束的,不是「平均短一点」。
3. **代码面唯一性(实测,不是推断)**:把 44 个 armed id 逐个 grep 进 `bots/`,
   **落在 `bots/BotLib/hero_lion.lua` 里的只有 `liondrainstop` 一个**
   (该文件另外三个 id `lionsplash:1243` / `lionhexaoe:1337` / `liondrain:1363`
   **都不在 W25 的 44 个里**);而该文件里唯一那句
   `bot:Action_ClearActions( true )`(:365)正是 `X.ConsiderStopDrain()` 守着的那句。
4. 出厂释放路径(`J.IsRetreating`)**两腿完全相同**,不构成腿间差。

**诚实边界**:上面买下的是「域内缩短来自这个 id」。它**买不下**「Lion 因此活得更久」——
那是条件 (b),归批测台;本轮 12s 死亡率两层**反号**(armed/ab 37% vs base/ab 51%,
armed/ba 27% vs base/ba 4%),按铁律 4(i) **是噪声,不写进结论**。
