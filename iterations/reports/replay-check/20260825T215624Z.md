## 5. Q2/Q3 拉野一族:实测免疫,上一轮 P1 的 (a) 读数不受影响

- **尸体漏血帧普查(72 局)**:死亡事件 3,801 次,漏血采样(死后仍 hp>0)**951**,
  = **0.25 帧/次死亡**。章程记的「泄漏 ≤0.30 s」在**次数**维度上得到独立佐证。
- **`pullcamp_domain` 反事实**(同一批 72 局,`by_t` 剥掉漏血帧后重跑 `scan_game`):

```
domain rows as shipped         : 5043
domain rows with leaks stripped: 5049
rows RECOVERED (leak vetoed)   : 6      (0.12%)
rows LOST                      : 0
recovered: baseline 4 / armed 2,poke=False drag=False 全部
```

- ⭐ **6 行、0 个 poke、0 个 drag ⇒ 19:18Z 那份 `pulldrag` (a)=WORKING 的每一个数
  逐位不动**(73 帧 armed / 16 帧 baseline / lane_win 49 / mean_pf −7 全部落在 poke 帧上)。
  **方向也先说清楚了**:漏血尸体只能**加**一个 `R_SAFE` 环内的敌人,而环内有敌人是**否决**,
  所以这类污染只会**制造 SILENT,不会制造 WORKING** —— 它无法把一个 (a) 读高。
- ⭐ **6 > 0 是阳性对照**:反事实管道**能动**,所以「0 个 poke/drag 被恢复」不是死管道
  (上一轮 `tpreach_domain` 的 `selfskip-trap` 同型陷阱,本轮显式规避)。
- ⭐⭐ **免疫的真实原因是时间窗口,不是设计,而且余量很薄**:72 局里**最早的幻象出生
  t=368.5 s**(p10=399.4,中位 725.5),而 `pullcamp_domain` 的域是 `T_HI=360`。
  **余量 8.5 s。** 一件更早的曼塔就会把拉野一族拖进幻象纪元。⇒ **这是每波要复查的量,
  不是一次性结论**;`entity_key_audit.py` 的 Q1 就是那个复查。
