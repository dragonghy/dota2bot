## 4. ⭐⭐ 本轮的真发现:`midtp`/`suptp` 的落点是 **NaN**,不是坐标

`ability_item_usage_generic.lua:5226`(**全仓库唯一**把**一座塔自己的坐标**喂给它的调用点):

```lua
local hTowerFight = J.ShouldTpSupportTowerFight( bot )      -- 返回的是一座己方塔
if hTowerFight ~= nil then
    local vTpLoc = J.GetNearbyLocationToTp( hTowerFight:GetLocation() )   -- nLoc := 那座塔的坐标
    if vTpLoc ~= nil then ... return BOT_ACTION_DESIRE_HIGH, vTpLoc, 'ground', 'mid支援塔战'
```

`jmz_func.lua:4348 J.GetNearbyLocationToTp( nLoc )`:

1. `nLoc` 距泉水 ≤ 2500 ⇒ 原样返回(**安全,但那只有基地塔**,见下表);
2. 否则 `for i=0,10` 遍历 `GetTower(nTeam, i)` 取**距 `nLoc` 最近**的己方塔。
   **`nLoc` 就是其中一座塔的坐标 ⇒ 那座塔的距离 = 0,必然当选,`minDist = 0`;**
   守望塔分支要求 `< minDist - 1300 = -1300`,**恒假**;
3. `return J.GetLocationTowardDistanceLocation( targetTower, nLoc, 575 )`,而
   `jmz_func.lua:2927` 的正文是
   `tempVector = ( towardLocation - npcBotLocation ) / GetUnitToLocationDistance( bot, towardLocation )`
   —— **分子是零向量,分母是 0**。

**实测(`lua5.1` + 仓库自己的 `tests/mock/bot_api.lua` 的 Vector 元表,裸读无管道):**

```
GetUnitToLocationDistance(tower, nLoc) =        0
tempVector =    Vector(-nan, -nan, -nan)
returned cast point =   Vector(-nan, -nan, -nan)
is x NaN?       true
```

`vTpLoc ~= nil` 对 NaN 向量**为真** ⇒ 走 `X.SetUseItem(hItem, hItemTarget, 'ground')`
(`ability_item_usage_generic.lua:1112/1124`)⇒ `bot:Action_UseAbilityOnLocation( hItem, NaN )`。
**这条路径上没有任何 nil/NaN/边界检查。**

**退化分支覆盖多少座塔(从本波 timeline 的 `buildings` 逐座量,泉水坐标用常数):**

| 队 | 塔位数 | 距泉水 ≤2500(安全) | ≥3260(**必然退化**) |
|---|---:|---:|---:|
| radiant(2) | 11 | 2(**2297 / 2302**,都是基地塔) | 9 |
| dire(3) | 11 | 0 | **11**(最近的两座 2667 / 2671) |

⚠️ **诚实边界**:泉水坐标是**常数假设**(radiant `(-7205,-6610)` / dire `(7000,6475)`),
**本轮没有从 dump 里核对过**。所以那 4 座基地塔(2297–2671u)**骑在 2500 刀口上,不下结论**;
但 **18 座非基地塔 ≥ 3260u**,无论泉水常数怎么小幅移动都在退化侧 ——
**而「一座被抱团推的分路塔」正是这个改动自称要救的那个场景**。

**引擎拿到 NaN 坐标做什么,本轮不声称**(铁律:没有 bot 侧调试)。两端都得写:
- 良性端:引擎拒掉这个 action ⇒ `midtp`/`suptp` **在真实对局里恒为 inert**(SILENT);
  ⚠️ 但 `X.ConsiderItemDesire` 的循环在 `SetUseItem` 之后 `return nSlot + 1`
  ⇒ **该帧的道具决策被这一发吃掉**,门为真的每一帧都如此。
- 恶性端:落到未定义位置。
**两端都不是这个改动写下来要做的事。**
