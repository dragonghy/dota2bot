## 二、⭐ 头号产出:这个估计量在「什么都没有」的地方返回什么

上一轮把 `nearmiss` 带(深度 ∈[800,1600),两腿都**不**准入)开出来当对照,做的是

```
real = [(armed−baseline) on ownhalf] − [(armed−baseline) on nearmiss]
```

**那一步是对的,但它只回答了一半问题。** 它扣掉了「地图 / 配对几何 / 腿」这些共同项,
**没有回答「这台机器对着一个已知没有杠杆的地方,会不会照样吐出一个漂亮的正数」**。

本轮把同一个函数换个参数再跑一遍:

```
placebo = [(armed−baseline) on shipped] − [(armed−baseline) on nearmiss]
```

`shipped` 带(敌人距我方存活建筑 ≤1200)的 Lua **两腿逐字相同** ——
`ownhalf` 的深度分支只在 `if not bInDomain` 里求值,所以**杠杆结构上进不去这条带**。
于是 placebo 返回的**就是这个估计量对着"无"时的读数**。

两条线**由同一个 `did()` 函数产生**,只是 band 参数不同
(`tools/batch_test/behavioral/ownhalf_domain.py`,本轮改动 29 行 / 删 10 行);
这一点由 `tests/test_ownhalf_placebo.py` 钉住,**否则 placebo 会慢慢漂成一个不是零假设的东西**。

### 4.1 `closed`:站住了,但比朴素读法小

- **`real` 单看**:ab 四粒 **+2.5 / +8.1 / +6.5 / +7.7**(四粒同号),均值 **+6.20**;

- ⚠️ **但 placebo 的 ab 均值就是 +3.17** —— **朴素 `real` 的一半以上是这台机器
  对着"无"时的读数**。真正剩下的是 `real−placebo`:**ab +3.03 / ba +5.92**,
  两层同号,**3/4 + 3/4 = 6/8 粒为正**。
- ⛔ **不登记效应量的精度**:这些是**检测器计数、侧偏未消除**;

  ⇒ placebo 自己的离散度约 ±5pp,而 `real−placebo` 的均值 +3~+6pp **落在同一量级内**。
  **方向可登记,量级不可。**

  **它比同一 run 同一分层的 placebo(+22.7)还低。**

- ⇒ **`engaged` 对 `ownhalf` 的条件 (a) 零信息**,请勿再引用那个 +17.2。
