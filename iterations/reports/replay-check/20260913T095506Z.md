## 三、判别子:`punish` / `rundown`(上一轮欠的那件「想一个判别子」)

上一轮把这件事留在本组 backlog 并明说「**它是『想出一个判别子』,不是『跑一份现成的』,
没有别的组能替本组想**」。本轮的答案:**把 `closed` 这个和拆开**。

`closed = d0 − dmin` 是**两具身体运动之和**。按**入场那一刻**的连线做投影:

- `bot_adv` = bot 自己的位移在该连线上的投影(正 = 朝追击者去);
- `chaser_adv` = 追击者位移的反向投影(正 = 朝 bot 来);
- `punish` = `bot_adv ≥ 250`(与 `closed` 同一把尺)**且** `bot_adv ≥ chaser_adv`
  **且** bot 在同一后果窗内**对追击者落了一次英雄伤害事件**;
- `rundown` = 镜像(追击者供给位移 + 只有它落了伤害)。

**两半来自两条互不推导的流**(位置来自 snapshot,伤害来自 DAMAGE 事件),
一条 episode 可以两者皆非(没人交火),**不会两者皆是**。

**控制**:`tests/test_overchase_attribution.py`(**15/15,新增**)。
⭐ **承重的不是「A 读成 punish」,是 `closed` 在 A 和 B 上都为真而判别子把它们分开**:
A(bot 转身进去并命中)/ B(bot 在跑、追击者追上并命中)/ C(谁都没动)/
D(**走过去了但一次没打中** ⇒ 几何上 `bot_driven` 为真而 `punish` **为假**)。
D 是防「`punish` 继承 `closed` 的瞎点」的那一条;B 是负控制 —— 只有负控制能分开
「收窄」与「关掉」(lanefix 教训)。

## 五、⭐⭐ 头号:堵点不是判别子,是**归因** —— `ownhalf` 在同一条通道的上游,且同波 armed

`bots/mode_team_roam_generic.lua` 逐字(本轮现读,**行号没漂**):

```

:302    if punishTarget ~= nil then ... return RemapValClamped(...) end

```

`J.ShouldPunishDive` 的**基座是已 promote 的 `punish`(两腿都开)**,
但**它的 own-half 域扩展 gated 在 `ownhalf` 上** —— 而 **`ownhalf` 就在 W67 的 armed 串里**

⚠️ **精确措辞**:重叠说的是 `ownhalf` 那把仪器的**可观测子句**也成立;
