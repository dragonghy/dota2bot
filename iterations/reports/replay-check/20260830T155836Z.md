## 1. 为什么这一轮的域是**触发级**建的,而不是留守率差分

章程 4a / `test_set.md` **§CG.4** 明文:`fieldsip` 的 (a) **不得**从
`stayfield`/`stayfield2` 的留守率差分读出 —— 那批帧上**四个 id 同时动手**
(`stayfield`/`stayfield2`/`fieldbuy`/`fieldsip`),那个差分是**四者合力**。
而且留守侧是**否决型**(生效时什么都不发生),`stayfield` 的 (a) 早就因此被判 INDETERMINATE。

所以本轮走**买药侧**,在源码上把域抄下来(`jmz_func.lua:5343` 与 `:5409`):

```
J.ShouldRegenNotGoHome = situation AND source AND     IsFieldSipEnough
J.ShouldFieldBuyRegen  = situation AND not (source AND IsFieldSipEnough)

FIELDSIP 域 := IsFieldRegenSituation
           AND HasFieldRegenSource        ← 注意是 TRUE,与 fieldbuy 的子句**相反**
           AND FieldRegenSipValue < 0.25 * GetMaxHealth()
```

### ⭐⭐ 这批帧上 baseline 是**结构性的零**,不是「小数」

域帧上 bot **身上有 accepted source**,于是 baseline 腿(`fieldsip` 未 armed,
`IsFieldSipEnough` 是字面量 `true`)`J.ShouldFieldBuyRegen = not(TRUE and TRUE) = FALSE` ——
**不是很少触发,是根本不能在那里触发**。所以这个估计量的对照臂**按构造是硬零**,
armed 腿上任何一次落到域帧的购买,**都必须由 `fieldsip` 翻开**。

**归属纪律(§BW.3 的正面应用)**:`fieldbuy` 与本 id **同串共 armed**,它是这次购买的
**执行载体不是竞争解释** —— 没有 `fieldsip` 它在这些帧上恒 FALSE,没有 `fieldbuy` 压根没有购买调用。
诚实表述是「**`fieldsip` 与 `fieldbuy` 的合取,而 `fieldsip` 的边际贡献就是全部**」。
**这是合取不是混淆**,但按 §BW.3 必须写出来而不是默认记到一个 id 名下。

真正的竞争者是 **`fieldregen`**(同波 armed、买同一件东西、**不问有没有 source**),
它由 `fieldbuy_domain.py` 自己的 **EXCL / AIRTIGHT 带**排除 —— 本轮**直接 import 复用,没有重写**。

## 2. ⭐⭐⭐ 唯一不可观测的那个子句,以及它是怎么被处理的(**不是估出来的**)

**`GetMaxHealth()` 不在 dump 里** —— 快照只有 `hp_pct`,没有任何绝对血条
(已核:`stayfield_domain.Game` 不读任何 max-health 字段)。于是
`sip < 0.25*maxHP` **无法直接求值**。

本轮**没有估计它,也没有造一张英雄血量表**。改为按「**最大可接受 sip 是哪件道具**」分桶 ——
因为 sip 值是道具的**五值函数**(`jmz_func.lua:5132`):

| 道具 | sip | 「不够」需要血条 |
|---|---|---|
| faerie_fire | 85 | > 340 |
| tango | 115 | > 460 |
| bottle | 135 | > 540 |
| flask | 400 | **> 1600 ← 中期太常见** |

**只记 CERTAIN 类**(faerie_fire / tango):要推翻它得有一个 **340/460 的血条**。
源码自己的 fixture 普查(`jmz_func.lua:5109-5114`)量到这一类落在 **0.062..0.156**、
21 行 —— 即它见过的最小血条 tango ≈ **737**。
`bottle` 另有独立理由被排除(**充能不可观测**,`has_field_regen_source` 本来就把所有瓶子算作有 source,
而 135 离 540 那条线最近);`flask` 直接排除。

⇒ **本工具记的域是引擎真实域的严格子集**。它**只会少记,不会多记**。
这个不对称正是关键:**(a) 是一个正面主张,子集足以买下正面主张**。

**边界是精确的不是近似的**:`4 × 115 = 460`,tango **恰好压在地板上**,
所以比较必须**严格**(`maxHP > 460`)。这一点在 `tests/test_fieldsip_domain.py` 里**两侧对钉**。
