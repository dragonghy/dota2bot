### 3.2 机制

`detect.py:1004-1012` 的 `alone` 谓词**在死亡瞬间求值**:

```python
s2 = tl.state_at(h2, e["t"], tol=3.0)
if s2 and s2["hp"] > 0 and dist < 2500: alone = False
```

一次打输的深推,到最后一个人死的那一刻,**并肩推进的队友已经全是尸体** ⇒
`alone` **按构造为真**。

**形状是「每次团灭一条、标签打错」,不是「每次团灭四条」**:前三次死亡时身边还有活着的
队友(853.5 时 sk/od 还活着;857.1 时 sk 距 130u 还活着)⇒ 它们都不过 `alone`。
**计数没有被四倍放大;被弄错的是挂在这条计数上的诊断。**「别一个人上去送」的修复,
**治不了一个从没一个人上去过的英雄**。
