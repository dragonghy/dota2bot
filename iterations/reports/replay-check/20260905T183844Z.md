## 三、⭐⭐⭐ 主发现:Y1 产出里 `.dem` 数量 = **0**,且**成因不是丢文件,是从没开过录**

### 3.1 读数(S3 普查,不是抽样)

真正产数据的 run 是 `run_20260905_151656_main_vs_upstream-baseline`
(**不是** `Y1_wave.json` 的 `instance` 块记的 `..._151230_...` ——那台 167s 就死,
批测台 §3.6 已登记该键指错;本轮独立复现:该前缀下**只有 1 个对象**,
就是 `batch_run.log`,**零局数据**)。

`awsx s3 ls <真 run> --recursive`(`LS_EXIT=0`)**161 个对象**,按扩展名普查:

| 扩展名 | 个数 |
|---|---|
| `.log.stdout` | 80 |
| `.json` | 80 |
| `.log`(`batch_run.log`) | 1 |
| **`.dem`** | **0** |

`grep -c 'dem' <listing>` = **0**。**80 个 `game_N.json` 逐个 0 字节**
(`awk '$4~/json$/{print $3}' | sort | uniq -c` → `80  0`)——
与批测台读数逐位一致,本轮独立复现。

### 3.2 成因:`run_batch.sh` 的启动行**没有任何录像开关**

Y1 走的是 ref-vs-ref 路径(`aws_run.sh` → `make_ab_build.py` → `run_batch.sh`),
**与所有 W 波的 `spot_run.sh` → `soak_loop.sh` 是两套 harness**。

**帧证据(源码级,两处对照):**

- `tools/batch_test/run_batch.sh:52-65` 的 dota 启动行,逐字**没有**
  `+tv_enable` / `+tv_autorecord` / `+tv_delay` / `+hostname`。
  全文件 `grep -n -iE 'dem|record|tv_|replay'` 只命中 **2 行,且都是注释**
  (66/71 行,讲 `con_logfile` 的,与录像无关)。
- 对照 `tools/batch_test/soak/soak_loop.sh:104-105`:
  `REC="+tv_enable 1 +tv_autorecord 1 +tv_delay 0 +hostname soak_$TAG"`,
  并在 `:107-112` 把 `$REC` 拼进启动行。

⇒ **引擎从头到尾没被要求录过像。** 这不是「录了但没传上来」。

### 3.3 顺带排除掉「是 sync 漏了」这个更省事的解释

`aws_run.sh:91` 是 `aws s3 sync $OUT s3://$S3_BUCKET/$RUN_ID/` ——**整目录 sync**,
真有 `.dem` 落在 `$OUT` 里它会带走。所以**同步不是瓶颈**。

但**修法不能只加一个开关**:`$OUT=/opt/results/$RUN_ID`(`aws_run.sh:52`),
而引擎写 `.dem` 是写进 `game/dota/replays`(`soak_loop.sh:53` 的 `$REPLAYDIR`)
——**两个目录不相交**。W 路径正因如此才要显式 `aws s3 cp "$MINE" "$DEM_PREFIX/$TAG.dem"`
(`soak_loop.sh:182`),前面还压着一整套 `dem_claim` 归属机制
(`:100-105` 的 `+hostname` 戳、`:157` 的 logname 抓取、`:172-176` 的 claim sidecar)
——**因为并行 16 局共用一个 replays 池,不认领就分不清哪个 `.dem` 是哪局的**。
`run_batch.sh` 的 job pool(`:83-90`)是**同样的并行形状**(`PARALLEL` 默认 16),
⇒ **同样的归属问题会原样出现,照抄开关而不照抄认领机制,买到的是一堆无主 `.dem`**
(`soak_loop.sh:62` 自己写着「an unclaimable .dem is only ...」)。

### 3.4 影响范围:不是 Y1 一次的运气,是**这条路径的全部历史与未来**

`iterations/reports/batch-desk/waves/*.json` **27 个波次记录**里,
`grep -l -E 'upstream-baseline|74727e4a'` 只命中 **`Y1_wave.json` 一个**。

⇒ **全仓库没有任何一份 upstream 臂的录像语料**,过去没有,现在没有;
且只要下一次标尺波仍走 `aws_run.sh`,**仍然不会有**。
P4.1 的「录像组对照看 2-3 局」**不是本轮没做完,是没有任何一轮做得成**。
