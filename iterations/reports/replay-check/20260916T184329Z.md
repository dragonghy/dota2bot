## 二、主产出:`_paused_spans` 的暂停盲区,从"未证实的线索"变成读数;⭐⭐ 而**证它不需要一局真的有暂停的语料**

### 2.1 W77 把它判成"这一局判别不了",而那个判断本身有一个更强的版本

W77(`20260916T034333Z.md` §四之二)写的是:原理上 `len(xs)` 恒 ≥2 ⇒ 暂停恒测不出来,
**但"本轮实测 as-is 与去幻象跑出来的 span 逐位相同 `[(-66.9, -61)]`"**,于是
**"记为线索,不是发现;要结清需要一局真的有暂停的语料(GH #849 里已附)"**。

⭐ **本轮第一件事是把那个 `[(-66.9, -61)]` 解释掉,而解释出来的东西比原结论强**:
全局 **event gap ≥ 3.0s 的候选窗口只有 5 个,而且 5 个全部起始于 `t < 0`(开局前)**,
**`t ≥ 0` 的候选窗口数 = 0**(54,185 个事件铺在 1,607s 上 ≈ 34 事件/秒,开局后再没出现过 3s 的事件空档)。

⇒ ⭐⭐ **"as-is 与去幻象相同"不是"这局判别不了",是"这局开局后一个候选窗口都没有"** ——
**两条腿都在对空集求值**,相同是**必然**的,与幻象无关。
⇒ 于是 W77 开的那张药方(**等一局真的有暂停的 `.dem`**)**并不必要**,而且它自己有个问题:
**暂停是不是稀有事件不归我们控制**,这条线索已经欠了**五轮**。

### 2.2 ⭐⭐ 判别子:暂停是一个**完全可构造**的线上产物,所以把它**注进去**

一次真实暂停在 wire 上恰好是两件事(`_paused_spans` 自己的 docstring 就是照着它写的):

1. 暂停期间**不发任何战斗日志事件** → 这正是它要找的那个 **≥3s 事件空档**;
2. 快照**照常 1 Hz 到达,每个实体的 x/y 逐字冻结** —— **真身体与幻象一视同仁**
   (暂停时站着不动的幻象,仍然站在它本来站的地方)。

`pause_inject.py`(scratchpad,源码见附录 A)在真实语料上构造它:选一个 `t0`、把 `t ≥ t0` 的
事件与快照整体 `+P` 平移、在 `[t0, t0+P)` 按 1 Hz 插入**每个实体在 `t0` 前最后一次采样位置**的冻结帧,
然后跑 **`detect.py:885` 逐字搬过来的谓词**。

⭐ **阳性对照写进构造里**:同一次注入喂给 **idx 锁定**的流(每个英雄只留真实体),
**必须在每个 `t0` 上都被看见**,否则错的是台子不是谓词。

### 2.4 机制(代码级,零成本,与上面的读数各自独立)

`Timeline.__init__`(`detect.py:65-69`)逐字:

```python
for s in d["snapshots"]:
    if s["t"] > self.t_end: continue
    self.snaps[s["hero"]].append(s)          # 键是英雄名,idx 不参与
```

⇒ **同一英雄的每一枚幻象都落进这个英雄自己的位置列表**。而 `_paused_spans`(`:885`):

```python
xs = {(s["x"], s["y"]) for s in snaps if a < s["t"] < b}
if len(xs) >= 2: frozen = False; break
```

⇒ **一枚站在别处的幻象,就让 `xs` 恒 ≥2、让 `frozen` 恒假,而且它对 `break` 是全局的**
——**任何一个英雄有幻象,整局所有英雄的暂停判定一起失效。**

def paused_spans(per_hero, events):
    """detect.py:885 `_paused_spans`, verbatim."""
    spans = []
    ts = [e["t"] for e in events]
    for a, b in zip(ts, ts[1:]):
        if b - a < 3.0:
            continue
        frozen, sampled = True, False
        for snaps in per_hero.values():
            xs = {(s["x"], s["y"]) for s in snaps if a < s["t"] < b}
            if len(xs) >= 2:
                frozen = False
                break
            if xs:
                sampled = True
        if frozen and sampled:
            spans.append((a, b))
    return spans


def inject(events, snapshots, t0, P):
    """Return (events', snapshots') with a P-second pause inserted at t0.
    A pause emits NO combat-log events for its duration (the >=3s gap the
    predicate looks for) while snapshots keep arriving at 1 Hz with every
    ENTITY's x/y frozen verbatim -- real bodies and illusions alike."""
    ev = [dict(e) for e in events if e["t"] < t0]
    for e in events:
        if e["t"] >= t0:
            e2 = dict(e); e2["t"] = e["t"] + P; ev.append(e2)
    snaps = [dict(s) for s in snapshots if s["t"] < t0]
    pose = {}
    for s in snapshots:
        if s["t"] < t0:
            pose[(s["hero"], s["idx"])] = s      # last pose strictly before t0
    tick = t0
    while tick < t0 + P:
        for s in pose.values():
            f = dict(s); f["t"] = round(tick, 1); snaps.append(f)
        tick += 1.0
    for s in snapshots:
        if s["t"] >= t0:
            s2 = dict(s); s2["t"] = s["t"] + P; snaps.append(s2)
    return ev, snaps

def dedup(snaps, key):
    """keep ONE record per (hero,t) -- satisfies W77 acceptance #3 by construction."""
    best = {}
    for s in snaps:
        k = (s['hero'], s['t'])
        if k not in best or key(s) > key(best[k]):
            best[k] = s
    return list(best.values())
