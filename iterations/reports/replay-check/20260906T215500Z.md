## 4. ⭐⭐ 主发现二:两个分支的供给**差 38 倍**,预登记的「拆 id」正是本轮的下一棒

acceptance 的预登记判读是「**两个分支的魔免占比都接近 0** ⇒ 不入集,带
`DOMAIN-NOT-REACHED` 退回门」。实测 **(i) 11.4% / (ii) 14.1%** ——
**都不接近 0,这条不触发**,本组**不**建议以「域太小」退回。

而同一份 acceptance 预登记的**归因边界**(「两个分支共用一个 id,任何负读数不能归因给
其中任何一个 —— 下一棒是拆 id」)**正好命中**,只是方向是供给而不是负读数:

```

分支 (ii) 的杠杆供给: 153 瞬间 / 36 局   (过半的局至少一个 episode)

```

**本组建议(裁定权在总监 / 英雄组)**:**先拆 id,再谈入集**。绑在一起发一波,
只能得到一个由 (ii) 主导、(i) 读不出来的合数;而 (i) 恰恰是代价上界最干净的那条腿
(申请书自己写的:正在读条的敌人不在攻击你)。

**归因边界照抄不改**:本杠杆是 **WIDENING**,armed 只**增加**这条路上的 Call ——
负读数只能读作「多放的那些放错了」,**永远不能**读作「杠杆少放了 N 次」。
