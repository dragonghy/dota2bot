## 2. 杠杆是什么,以及为什么它的域天然带三个对照

`bots/mode_retreat_generic.lua:906-914`(`X.ShouldRun`):

```lua
local nFearClock = 5 * 60
if J.IsSoakCandidate('towerfear') and J.IsModeTurbo() then
    nFearClock = nFearClock / 2          -- 唯一的杠杆
end
if ( botLevel <= 5 or DotaTime() < nFearClock ) and nEnemyTowers[1] ~= nil then

```

`nEnemyTowers = bot:GetNearbyTowers(898, true)`(`:823`;LANE_MID 在 `:883` 覆写成 980)。
`X.ShouldRun` 的非零返回在 `GetDesireHelper`(`:498-503`)被闩成
`BOT_MODE_DESIRE_ABSOLUTE * 1.1` **持续该秒数** ⇒ 出厂行为 = **2 秒强制撤退,压过一切其它模式**。

armed 谓词是出厂的**严格子集**,被放行的帧在 (时间 × 等级) 平面上是一个**矩形**:

```
R_lever :  等级 6..10  且  150 <= t < 300      <- 唯一被改动的格子

C_post  :  等级 6..10  且  300 <= t < 450      <- 两条腿在两侧都已放开
```

三个邻居**按构造不受本杠杆影响**,免费当负对照。**但它们不是"应该为 0"的对照** ——
同波还有另外 27 个 armed id,所以对照格里出现差异是正常的;判据是
**「差异是否在两个物理层里同号」**(#148(i)),以及**对照波 W7 的同一格是什么样**。

**可观测 / 不可观测**(如实登记):模式、视野、`GetAssignedLane()` 都不在 dump 里。
门的上下文 `#hEnemyHeroList > 0` 用**几何**读(1600u 内有活着的敌方英雄)——
这是引擎那份**经视野过滤**的列表的**超集**,只会把域读大不会读小;

   **p05–p50 那条尾巴**(178–312s 到 6 级的英雄),不是"7–10 级" ⇒ **效应量比注释暗示的小**。
