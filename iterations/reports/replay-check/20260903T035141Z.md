## 3. ⭐ 为什么 radiant 那两行**根本不能当对照读**(本轮新确立,#441 未涉及)

按物理队并腿:

```
radiant:  1 幸存 / 51 次扔尘  ( 2.0%)
dire   : 50 幸存 / 93 次扔尘  (53.8%)
```

**27 倍的差,跟 armed 与否无关,只跟物理队有关。** 根因逐字可查:

`slotdust_arbitration.py:407` 的 B3 判据是 `"b3" if enemy_team in radiance_teams`,
而 `radiance_teams` 是**整局普查**「哪一队**曾经**持有辉耀」。本语料实测(64 局,战斗日志):

```
辉耀伤害事件按 (英雄, 物理队):
  npc_dota_hero_skeleton_king   team=3(夜魇)   20,167 events
按队: {3: 20167}        —— 天辉侧 0 次,一次都没有
46 / 64 局有辉耀伤害;其中 armed=radiant 的 28 局、armed=dire 的 18 局,
carrier 队恒为 {3}
```

**这是镜像牌序的设计,不是缺陷**:mirrored-draft 固定英雄→物理队,**swap 的是 armed 腿**,
所以 skeleton_king 在 64 局里**恒在夜魇**。但后果是:

- `enemy_team in radiance_teams` 对 **radiant 施法者恒可能为真**、对 **dire 施法者恒为假**;
- 于是 **B3 在 46/64 局里把天辉的每一次扔尘整片挡掉**,天辉两行合计只剩 1 个幸存者。

⇒ **`ba / baseline / radiant` 那一行的 `0/11` 不是「天辉不可达」的证据,是 B3 把这一行擦白了。**
本轮的三条推翻**全部**来自 dire 基线腿那一行;**天辉侧这一波没有对照**。
引用这张表的人请连这一条一起引。

**方向说清楚,别夸大**:B3 这样建模是**偏保守**的(整局普查 ⊇ 逐帧真值,
真判据是 `bot:HasModifier('modifier_item_radiance_debuff')`,`ability_item_usage_generic.lua:7326`),
**只会少算幸存者、不会多算** ⇒ **§2 的三条推翻是稳健的,只可能被低估**。
它伤的是**天辉那一半的分辨力**,不是结论。
