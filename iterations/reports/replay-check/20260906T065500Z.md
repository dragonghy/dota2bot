## 1. ⭐⭐ 主发现:条件 (a) 的**唯一计数器**少数了 44%,方向是把已核验的 id 报成未核验

### 1.2 两处缺陷

1. **`^VERIFY` 锚点**。本组按章程 step 7 写这一行时几乎总是包在 markdown
   强调/代码跨度里 —— ``**`VERIFY id=… `**``、`` `VERIFY id=…` ``、
   ``- **`VERIFY …`** `` —— **章程自己的示例就是这么渲染的**。锚点把它们全丢了。
2. **`episodes=(\S+)`** 把尾随标记连同数字一起吞,产出 `5020**`、``7`。`` 这样的
   「计数」。而这个字段**解析了却从不打印** ⇒ 没有任何东西能反驳它。
   **解析了不打印的字段就是一台没人读的仪器。**

### 1.3 为什么它值得单独立案:量具自己制造了它随后报出的结论

**代价不是假设的,是本轮当场付的。** 本轮按 `verify=0` 这一列选题,先选中了
`rotscope` —— 而 `rotscope` 两天前(`20260904T042500Z.md`)已经以**结构性理由**裁成
INDETERMINATE(它的差集是一条 bot 命令,而 combat log 不记录 bot 命令)。
**这个量具在把各轮送回去重做已经做完的活。**

与本组「工具坑」里 `zusult` 的域内计数、以及 stale-mana(GH #491)**同族**:
量具自己造出了它随后报出来的那个结论,方向只有一边。区别是这次的方向是
**制造欠账**(把已完成的核验抹掉),不是掩盖问题。

顺带:`BLIND SPOTS` 那一节**不受影响**(narrat 列兜住了)⇒ 损伤精确地落在
**可计数的那一列**,也就是总监台账唯一读的那一列。

### 1.4 修法(已落地)

- 去掉 `^` 锚点。pattern 仍要求**字面 id + 全大写 verdict**,所以只讨论这个格式的
  元句子(`VERIFY id=… verdict=…` 带省略号、说明格式的表格行)**仍然不计数** ——
  **这是对真语料核对过的,不是推的**。
- `episodes` 收紧成 `(\d+)`,**并且改成打印出来**(新增一列)。
  `episodes=0`(域没走到)与 `episodes=4527`(域饱和、堵在归属)是两种不同的欠账。
- **同一份报告内去重**:本组按惯例在摘要头和正文各写一次同一条裁定,那是一条不是两条。
  锚点还在时头一份通常正是被强调的那份、因而不可见,**双计被掩盖了**;
  现在两份都可见,不去重就会**朝相反方向**把台账吹起来。

## 3. 深查:`towerfear` 的条件 (a)

### 3.1 为什么选它(而且它的归属比大多数 id 干净)

修好计数器之后,`towerfear` 是 `verify=0` 且已有成套量具的 id 之一。
更要紧的是**它的门在结构上是干净的**:`bots/mode_retreat_generic.lua:928`

```lua
local nFearClock = 5 * 60
if J.IsSoakCandidate('towerfear') and J.IsModeTurbo() then
    nFearClock = nFearClock / 2
end
if ( botLevel <= 5 or DotaTime() < nFearClock ) and nEnemyTowers[1] ~= nil then
    return 2;   -- 上游锁成 BOT_MODE_DESIRE_ABSOLUTE * 1.1,压过所有 mode
end
```

**唯一合取项是 `J.IsModeTurbo()`,不是候选 id**,而且它**不嵌在任何别的门里、
也不与任何 armed id 组成析取** —— 我按 GH #553(门嵌在门里,5 对)与
GH #545(`A or B` 同集 armed ⇒ B 恒不承重)两张表逐条对过,`towerfear` 都不在里面。
⇒ 它躲开了本组最近两轮抓到的两个归属陷阱。

armed 谓词是 shipped 的**严格子集**(时钟 300s → 150s),所以这个 `return 2`
**只可能更少触发,不可能更多**。被释放的帧在 (游戏时间, 等级) 上是一个**矩形**,
外加三个**零成本的负对照**:

```
R_lever :  lvl 6..10  且  150s <= t < 300s     ← 唯一两腿不同的地方
C_pre   :  lvl 6..10  且    0s <= t < 150s     ← 时钟腿两腿都真
C_low   :  lvl <= 5   且  150s <= t < 300s     ← 等级腿两腿都真
C_post  :  lvl 6..10  且  300s <= t < 450s     ← 两腿都释放
```
