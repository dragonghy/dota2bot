## 二、GH #626:通道帧退出域(先逐帧,后聚合)

### 落地内容

1. **域**:`frames()` 丢弃落在 CM **自己** `modifier_teleporting` ADD..REMOVE 区间内的帧
   —— 她已被一次**在该帧之前**做出的传送锁定,creep AoE 那条分支在这种帧上根本管不着。
   这是**域缺陷**不是打分缺陷,与 `zusult`(量具把门管不着的施法记在门头上)同族。
2. **打分器**(比域再外一圈):`movement()` 的 `MOVE_WINDOW_S` 窗口只要**触到**通道就**不打标签**。
   理由是窗口比帧宽:一次在合法 gap 帧后 0.5s 开始的通道,会让 2 秒后的位置
   要么是 ~3,500 u/s 的落点(读成 `away`),要么是通道里站着不动(读成 `stand` = 「引擎拒单」)。
   **两个方向都是伪造**,所以不打标签而不是改标签。
3. **两个计数都打印,标签分开**(`n_casters` 的纪律):
   `frames dropped for being inside CM's own TP channel` 与
   `gap frames left UNSCORED because the movement window touches a TP channel`。
   报告里明写:**`away` 的下降是量具修正,不是效应,与 #626 之前的读数不可比。**

### 语料上真的咬到了

即 #626 逐帧买到的那一例**不是孤例**,而且被排除的帧数**与 gap 帧同一量级**。

## 三、⭐ 本轮最重要的一条:四格填满 ≠ 可以读 armed−baseline

上一轮(和 GH #626 同帖)把 `cmqreach` 的不可读归因于「落盘 8 局全是 radiant,
`ab` 8 / `ba` 0」,并把**「重扫到两个分层齐」**写成下一轮的前提。
本轮重扫后四格确实全满了 —— **而那个前提是错的**,错在单位。

### 现算的事实(W56,76 局全扫,每个运行逐局核对 CM 的 idx-locked team)

```
run      CM team   (stratum, leg) 分布
0eb22d   dire      (ab, baseline) 10 | (ba, armed)  8
40e63a   —         无 CM carrier(该 run 的 draft 里没有 CM)
cd3359   radiant   (ab, armed)   11 | (ba, baseline) 7
8ef6e7   radiant   (ab, armed)   10 | (ba, baseline) 8
```

**一个 run 里 CM 的队伍是常数**(镜像 draft 的定义),而
`leg = armed ⟺ CM.team == SIDE_TEAM[side]`。两者一联立:

> **单 carrier 英雄的检测器,在任何一个 run 里,四格中最多只有两格非空,
> 而是哪两格由 draft 决定,不由抽样决定。**
> 那两个空格**不是样本量问题**,再多局、再重扫一次也填不上。

四格能填满,**只因为把 CM 抽在对侧的 run 并进来了**(0eb22d 抽 dire,cd3359/8ef6e7 抽 radiant)。
于是并池之后,**每个分层里的两条腿分别来自不同的 run / 不同的 draft** ——
四格表里的「同分层、跨腿」比较,实际是一次**跨 run 比较**。

### 那么哪个估计量才真的把侧别摁住

**在单个 run 内取腿差**(CM 的物理侧是常数,侧项逐位相消),**再跨 run 取算术平均** ——
即 4(i-d) 的形状,只是**单位从种子换成 run/draft**。现算:

| run | CM 侧 | armed gap/CM-min | baseline gap/CM-min | 腿差 |
|---|---|---|---|---|
| 0eb22d | dire | 0.4395 (8 局/220.7 min) | 0.4373 (10 局/276.7 min) | **+0.0022** |
| 8ef6e7 | radiant | 0.4202 (10 局/278.4 min) | 0.3697 (8 局/221.8 min) | **+0.0505** |
| cd3359 | radiant | 0.3087 (11 局/304.5 min) | 0.3290 (7 局/194.5 min) | **−0.0203** |

跨 run 算术平均 **+0.0108 /CM-min**(基数 ~0.39 ⇒ +2.8%),**三个 run 符号不一致**。

`walk`(cell (2) 真正的刀口)同样:**−0.0003 / −0.0162 / +0.0175**,
平均 **+0.0004 /CM-min**(基数 ~0.20 ⇒ **+0.2%**),**符号不一致**。

### 侧项有多大

```
gap   按 CM 物理侧(两条腿并池): dire 0.4383/min  radiant 0.3573/min  侧项 +0.0810
walk  按 CM 物理侧(两条腿并池): dire 0.2131/min  radiant 0.1961/min  侧项 +0.0170
```

**侧项 +0.0810 是腿差平均 +0.0108 的 7.5 倍**,也比最大的单 run 腿差(+0.0505)还大 60%。
这正是总监 §CL (iii) 立法时那一句的复现,只是这次落在**均值**上而不是中位数上:
**读数跟着物理侧走,不跟着 armed 腿走。**

### 结论行

```
VERIFY id=cmqreach verdict=INDETERMINATE episodes=575
```

**与上一轮同为 INDETERMINATE,但理由升级了,不是重复**:
上一轮是「结构性不可测 + 只有一个分层」;本轮语料**足以读**(54 局、四格全满、
1,496.6 CM-分钟),读出来的是「**腿差被侧项压制,且三个 draft 之间符号不一致**」。
上一轮的**补救方案(重扫到两个分层齐)已被本轮证伪** —— 该补的不是分层,是 draft。
条件 (a) **仍然只能走 fixture**(与 `outlatch`/#623、`campbind` 同型),这一条本轮**加强**而非改变。

⚠️ 上述腿差**不是效应量**:cell (2) 的域是上界(IsFarming/IsPushing 等 mode 谓词离线不可观测),
且本波 44 个 id 同时 armed。它只支持一句话:**没有任何腿可归因的信号从侧别分解里活下来。**
