## 三 ⛔⛔ 本轮最值钱的那条:**镜像草稿只换 gate 不换阵容 ⇒ 铁律 4(i) 的两层反号是「由构造」的**

### 3.1 现场

`skywrath_solo_silence` 这个**只对一个英雄开火**的检测器,本波读数是:

```
ab 层(radiant-arm,47 局)  armed 33 / baseline  0   delta +33
ba 层(dire-arm,  34 局)  armed  0 / baseline 31   delta −31
                                          ⇒ OPPOSED => NOISE
```

`abilanc` 自己的反向护栏(甲)在 run `65af1b` 上是同一个形状:`radiant 7/0`、`dire 0/7`,
打出 `OPPOSED => NOISE` —— **而它的真身是一个逐位保持的 7 vs 7 正控制**。

### 3.2 机制(第一手核过,不是推测)

**这波的镜像草稿换的是 gate,不是阵容。** 全 4 run × 81 局,
**40 个 (run, 英雄) 组合里,没有任何一个英雄换过物理队**:

```
heroes whose physical team VARIES within a run:
  (none)
total (run,hero) pairs: 40 | varying: 0
```

于是对**任何按英雄定位的观测量**(单英雄检测器、单英雄技能、`abilanc` 这种只有 13 个英雄够得着的
选择器),设该英雄固定在 radiant 物理队:

- **radiant-arm 那一层**:armed 格 = radiant 队(=他,armed),baseline 格 = dire 队 = **结构性 0**
- **dire-arm 那一层**:armed 格 = dire 队 = **结构性 0**,baseline 格 = radiant 队(=他,baseline)

⇒ `delta_ab = +X_armed`,`delta_ba = −X_baseline`
⇒ **只要他两条腿上都产生过这个观测量,两层就必然反号。**
**效应越真、越单边,反号越铁。** 这不是侧偏,是**「两层各自只有一条腿」**。

### 3.3 为什么这不是 #257,也不是 #830

- **#257**:某一层 **`ngames == 0`**(整层没局)被读成 flat。本波两层**各 47 / 34 局,都量过**
  ⇒ #257 的修法(`SINGLE-LAYER`)**抓不到这一条**。
- **#830**:分子里混进 gate 由构造影响不到的施法(**可达性**)。本条与可达性无关 ——
  `skywrath_solo_silence` 的分子 100% 是它自己的。
- 本条是**第三种**:**分层的坐标选错了**。正确的分层是**物理队**,不是 `arm_side`;
  正确的比较是**跨层比**(一层的 armed 格 vs 另一层的 baseline 格),不是层内比。
  换成跨层比,`skywrath_solo_silence` 读作 armed **33/47 局 = 0.70**、baseline **31/34 局 = 0.91**,
  **−23%**,一个能用的数;层内比读作 noise,**一个数都不剩**。

### 3.4 面有多大

本波 **14 个检测器里 12 个**读反号(§〇 那张表)。⛔ 本轮**不主张**这 12 个都是真效应 ——
主张的是:**在这类语料上,「反号」不携带「是噪声」这个信息**,因为它由构造必然出现。
⇒ 已开 issue(见 §四)。
