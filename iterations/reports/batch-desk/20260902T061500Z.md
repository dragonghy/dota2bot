## 6. ⭐⭐⭐ 本轮真正的发现:并池判据被证伪(GH #418,本轮新立)

W37 发波记录把并池理由写成:

> "The three commits that landed on `bots/` since W35 **all gate ids that are NOT in the armed string**,
> so this configuration is behaviourally equivalent to W35's"

本轮按章程「**要判当前状态就去读当前树的源码**」逐行读了那三个 commit 的 diff,**判据不成立**:

**(甲) 真反例 —— `87bc6b33`(slotdust)夹带了一行闸外改动。**

```diff
 	local dist = GetUnitToLocationDistance(member, loc)
-	if dist < closestDist
+	if dist <= closestDist
```

`bots/FunLib/jmz_func.lua:11520`,在 `for i, id in pairs(AllyPIDs)` 循环体里,
**不在 `if bSlotDust then` 的任何分支内** ⇒ **关闸时照样执行**。
而其上方第 11500 行的注释白纸黑字写着
`-- Unarmed this is byte-for-byte the shipped function` —— **这句话是假的**,
**而它正是下游据以判「关闸即惰性」的那句话**。

**影响面据实**:`<`→`<=` 只改**并列时的取胜方向**(先遍历到的 → 后遍历到的);
两种写法都**恰好一个 bot 拿 `true`**,不是张开型缺陷;且现役 pid/slot 缺陷把扫描域压到
dire 1 名 / radiant ≤4 名 ⇒ **dire 侧结构上不可能并列**。**风险很低,但不是零,而且从来没测过。**

**(乙) 阴性一例,明写(否则通过时它是隐形的)** —— `0b468372`(slotarb)改的
`IsTheClosestOne` **正是 armed id `campsel` 也要经过的那个包装器**
(`J.IsSoakCandidate('campsel')` 那行从 `)` 变成 `,`,函数多一个入参)。
读源码:`bSlotArb` 为假时 `nSlot = id`,函数体**归约回现役** ⇒ **这一形确实惰性**。
但**这个结论只能靠读代码拿到**,「landed id 未 armed」推不出它。

⇒ **并池判据应改写为「该 diff 在各闸关闭时逐行惰性」,并要求读源码作证。**
**失效方向是危险的那一侧**:现行判据会把 (甲) 读成惰性,两波被当成同一配置并池,
**而没有任何门会举手**。

**本轮处置**:并池**保留**(影响面见上,radiant-only 的浮点并列),
但**登记为显式保留,不再声称逐字节等价**;`W37_wave.json:arm_note` 已就地更正。
