### 3.1 缺陷:`OWNER_PRIORITIES.md:121` 的 `--old 74727e4a` 与 `aws_run.sh` 的 `origin/` 前缀不兼容

链条**三段,每段都实测**:

1. `aws_run.sh:75-76` 把两个 ref **写死加 `origin/` 前缀**后交给 make_ab_build:
   `make_ab_build.py --old 'origin/$OLD_REF' --new 'origin/$NEW_REF'`。
2. `make_ab_build.py:50` 用 **`git archive <ref> bots`** 导出,`:54` 失败即 `sys.exit`。
3. P4.1 的 baseline 在 `OWNER_PRIORITIES.md:121` 写作 **裸 commit SHA**(`74727e4a`)。

⇒ 实际会被执行的 ref 是 `origin/74727e4a66ab...`。**现测**:

```
ARCHIVE_ORIGIN_SHA_EXIT=128   fatal: not a valid object name: origin/74727e4a66ab38d16fdb09800a19ab6c0c82c6b9
ARCHIVE_BARE_SHA_EXIT=0
```

⇒ **`origin/` + SHA 不是 ref;裸 SHA 是。** 这不是风格问题:`origin/<sha>` 这种引用
**永远**不存在(remote-tracking ref 按分支名建,不按 SHA 建)。

**失效方向:安全但贵。** 追到底(逐行读 user-data):make_ab_build 死了以后,
user-data **只有 `set -x`、没有 `set -e`** ⇒ 脚本继续走 `rm -rf $VS/bots ...`、
`cp -r /opt/ab_fwd/bots ...`(也失败),然后 **`ab_guard` 接住**:三个目录都不在 ⇒
`FATAL: ... A/B build failed; refusing to run games` → 传 log → `shutdown -h now`。
⇒ ⭐ **[Y1, 2026-09-05] 那道守卫是有效的,不会产出「默认 AI 打默认 AI」的假数据**
(那正是 Y1 立案要防的「a failure that looks like data」)。
⇒ **代价不是错数据,是一次发波 + 一轮**:开机 + `steamcmd app_update 570` + 自终。
⚠️ 美元量级小(单台 spot、分钟级),⛔ **本台不给美元数**:`steamcmd` 时长未测。
**而 P4.1 已经欠了四十一轮 —— 那一轮的成本才是要紧的那个。**

### 3.2 ⭐ 修法:`refs/heads/upstream-baseline` 已经存在,且恰好指着 74727e4a

⛔ **本台的第一版诊断是错的,当场自捉,未发表。** 第一跑查的是
`git ls-remote --tags origin | grep -iE "upstream|baseline|stable-v"` → 空,
且 **`ORIGIN_TAG_LINES=0`(origin 上一个 tag 都没有)**,于是本台差一步写下
「铁律 3 的 `stable-vN` tag 根本不存在,P4.1 只能用 SHA ⇒ 缺陷不可避免」。
**开工自检当场证伪它**:`=== stable version anchors (铁律 3) ===` 腿逐字
`EXISTS ok (refs/heads/stable-v1)` … `refs/heads/stable-v9`,`9 anchor(s) checked -- OK`
⇒ ⭐ **锚点是分支不是 tag**,本台那条 `--tags` 查询**在原理上答不了这个问题**。
📌 与 `evidence-discipline`「⛔ 别让对上的结论冒充对的理由」同型:
「查不到」被读成「不存在」,而查的是错的命名空间。**改查分支,答案立刻变了**:

```
HEAD_LINES=1296
74727e4a66ab38d16fdb09800a19ab6c0c82c6b9	refs/heads/upstream-baseline
```

⇒ ⭐⭐ **一个名为 `upstream-baseline` 的分支已经在 origin 上,SHA 与 P4.1 要的 baseline
逐位相同。** ⇒ **修法是换一个词,不是改一行代码、也不是新建任何 ref**:

```
- aws_run.sh --old 74727e4a66ab38d16fdb09800a19ab6c0c82c6b9 --new main
+ aws_run.sh --old upstream-baseline --new main
```

### 3.3 零成本预演:改后的 ref 形式**端到端跑通**(这是本轮的交付物)

`git fetch origin upstream-baseline main` → `FETCH_EXIT=0`;
`git rev-parse origin/upstream-baseline` → `REVPARSE_UB_EXIT=0` = `74727e4a66ab38d16fdb09800a19ab6c0c82c6b9`;
`git archive origin/upstream-baseline bots` → **`ARCHIVE_UB_EXIT=0`**。

再按实例上那条命令的**原样**跑一遍 make_ab_build:

