### 4.1 ⭐⭐⭐ 给 #363 买到的判据:一个测量 + 一条恒等式

上一轮把 (乙) 驳回的理由是散文式的"读法 (乙) 下树几乎每波都动 ⇒ `<8` 恒真"。
**本轮把"几乎每波"变成了一个数,并且发现"恒真"这个词说重了 —— 但结论比原来更强。**

**方法(零成本、可复现)**:S3 `soak/` 的 298 个 run 前缀里嵌着发波时所测那棵树的 40 位 SHA。
按 SHA 去重取每棵树的首次起飞时刻 ⇒ **29 棵不同的树、28 个相邻波次边界**;
对每个边界跑 `git log <前一棵>..<后一棵> -- bots/ game/`,**逐个记退出码**
(unshallow 之后 **28/28 全部 rc=0,零个不可比** —— 这一条本身就是浅克隆陷阱的对照组)。

```
相邻波次边界              : 28   (可比 28 / 不可比 0)
bots/+game/ 发生变更的边界: 25 / 28 = 89.3%
未变更(逐字节相同)的边界:  3 / 28   (08-28T18:19→08-29T00:16、
                                       08-29T18:17→08-30T00:18、
                                       08-30T00:18→08-30T06:18)
```

⇒ **读法 (乙) 会在 28 个历史边界中的 25 个把计数重置回 4**,`4 < 8` 真 ⇒ 放行。
**"恒真"逐字不成立(89.3% 不是 100%),本台更正上一轮这个措辞。**

**但更正之后结论反而更硬,因为剩下那 3 个边界救不了 (乙):**

> **恒等式**:(乙) 的并池单位((树, 串) 对)比 (甲) 的并池单位(串家族)**更细**,
> 于是恒有 `count_乙 ≤ count_甲`,于是 `{count_乙 ≥ 8} ⊆ {count_甲 ≥ 8}`。
> **⇒ (乙) 会挡住的边界,(甲) 必定也挡住;(乙) 挡不住 (甲) 挡不住的任何东西。**

这不是从 28 个点里拟合出来的,**是并池单位的包含关系直接推出来的,对任何未来的波次都成立**。
合起来:采纳 (乙) 之后,闸 (ii) 第二肢**在 89.3% 的边界上不做功**,而在剩下 10.7% 的边界上
**做的功是 (甲) 已经在做的功的子集** ⇒ **它对(甲)而言是一道恒不 binding 的闸**。
**这就是上一轮想说而当时只有散文的那句话的算术版。**

**本台仍然不裁**,并把上一轮那句代价原样重复,因为它一个字都没变:
这 8 粒被本台在 W31 记录里称作 `pooled_47id`(gpm **+20.77** / sd 18.58 / SE 6.57 / 6-8),
而它们横跨一次**活的** Silencer 崩溃守卫改动(`074d3e9c`,按 #346 不走 gated-fix ⇒ 未 gate)。
**要么 (甲) 成立、并池合法、家族已厚到 8 ⇒ 不发波;要么并池不合法 ⇒ 那个已交总监四轮的
