## 4. 交付 —— 噪声底的机械拆解(本轮唯一实质产出)

起点是总监 §AD.1:harness 在 `SOAK_CAP_MIN`(默认 **10 个游戏分钟**)打 `dota_dev forcewin`。
本台先在 harness 侧原文确认(`soak_loop.sh:13`,`referee.py` 自身默认是 30 但被调用方覆盖成 10),
然后**下载上一波一个 run 的全部 78 个 `analysis.json` 实测**(72 局镜像 + 6 局暖场;
暖场 stamp = `11a8de3`,与树一致)。

### 4.1 截断落点比「10 分钟」松:实测 mean 11.14 min,sd 0.74,range 9.8–13.4

`winner_by` **78/78 全是 `economy_10min_cap`** —— 没有一局是自然结束的。
referee 靠外推估计游戏时间,**系统性过冲 +1.1 分钟且带 0.74 分钟抖动**。

且 **gpm 随局长明显爬升:斜率 +59.3 gpm / 游戏分钟**(局均 gpm 对 duration,
corr +0.233;分箱 10min→832 / 11min→923 / 12min→959 / 13min→1050)。
⇒ 单看这两条,**像是** referee 的抖动会往每局读数里灌 ±42 gpm 的仪器噪声。

### 4.2 但它**不污染 verdict** —— 镜像设计已经把它消掉了(担忧一:证伪)

关键是 `recover_verdict.py` 的真实算式(`recover_verdict.py:49-53`)是**同一局之内**
候选队减基线队(`M(radiant players) - M(dire players)`,再 radiant/dire 两 wave 取平均)。
**duration 是每局的公共属性,对局内两队同时生效 ⇒ 加性的爬升项精确抵消。**

实测(72 局镜像局):

| 量 | 值 |
|---|---|
| corr(duration, 局内 cand−base gpm 差) | **−0.130**(几乎全部由 2 局 13min 的离群局贡献,不稳健) |
| corr(duration, \|差\|)= 增益效应 | **+0.042**,斜率 +5.2 gpm/min ⇒ **≈ 0** |

⇒ **referee 的截断抖动不构成 verdict 的偏置,也不构成可观的方差来源。**
本台此前几轮报告里把 `--games` / stall 上限当成读数质量问题来记,**这一条可以撤了**。
(§AD.1 关于「域看不见」的结论**不受影响** —— 那是关于*哪些决策进得来*,不是关于*读数准不准*。)

### 4.3 噪声底 = 纯逐局采样噪声,**种子间没有剩余方差分量**(本轮最该记住的一条)

局内 cand−base gpm 差的**逐局 sd = 156.1**。按局级 bootstrap(4000 次重采样,
沿用该 seed 真实的 42 radiant / 30 dire wave 结构)预测单个种子的读数应有:

```
预测 per-seed sd(仅逐局采样)   = 15.63 gpm
实测 per-seed sd(单臂,08-19 两波) = 16.63 / 19.62 gpm
```

**两者几乎重合。** ⇒ **镜像 draft 已经把种子/draft 方差消干净了,剩下的全是「一个种子里
只跑了 ~72 局」这一件事。** 推论三条:

1. **种子数与局数在统计上可互换** —— 决定 MDE 的是**总局数**,不是种子数。
   「4 种子」不是一个统计门槛,它只是当前的机器拓扑(4 台 × 1 种子)。
2. **唯一的功效杠杆就是买更多局**(或换低方差指标)。调 referee、调换边、调种子选取
   都动不了这个底。
3. **MDE 换算表**(2σ,单臂;按上面的 15.63):

   | 种子(× ~72 局) | SE | MDE |
   |---|---|---|
   | 4 | 7.82 | **~15.6 gpm** |
   | 8 | 5.53 | ~11.1 gpm |
   | 16 | 3.91 | ~7.8 gpm |
   | 32 | 2.76 | ~5.5 gpm |

   与 08-19 实测的「4 种子 SE 9.81、z=−3.38 打在 −33.17 上」量级吻合。
   **对 GH #30 的 σ=30.24 有张力**:那个零点由 4 个种子估出,4 点估 sd 的
   95% CI 大致 0.57×–2.2× ⇒ 30.24 与 15.6 并不硬冲突,但
   **「单种子 gpm 差 ±30 才算噪声」这条纪律线大概率偏保守**,真值更接近 ±16。
   这条**归总监裁**(它是全队在用的判读线,不是批测台能自己改的)。
4. **顺带给 22:12Z 的「配对差噪声是单臂两倍」补上机理**:A−B 是四个 wave 均值之差、
   四份逐局采样噪声叠加而跨臂没有共同随机源。要把 −2.5 gpm 的单 id 效应打出来,
   需 SE ≈ 1.25 ⇒ **~156 个种子当量 ≈ 11,000 局 ≈ 我们迄今买过的全部语料**
   —— 这是用第二种独立方法复算出「路 B 逐 id 经济二分结构上不可行」。

### 4.4 dire wave 被截短:**代价只有 1.9%**(担忧二:证伪)

本台从 08-19T20:11Z 起每轮都在报「radiant 打满 `--games` 配额、dire 撞 35min stall
上限、不对称」。**实测这个不对称值多少钱**(同样 72 局,只改分配):

```
当前 42 radiant / 30 dire : per-seed sd 16.20
若平衡成 36 / 36          : per-seed sd 15.89   ⇒ 只买到 1.9% 的噪声下降
```

⇒ **不对称在统计上基本无害**(两个 wave 各自 sd 43.3 / 47.0,短的那个占 54% 方差,
但总量被平均掉了)。**建议把「补 dire 要动 harness stall 上限」从待办里降级** ——
它值 1.9%,而同样的机器时间用来多跑局是按 1/√n 走的。这条也一并撤回本台自己此前

### 4.5 本节的诚实边界

- bootstrap 是在**一个 run(一个种子)的 72 局**上做的重采样,拿去和**别的波次、
  别的树、别的候选串**的跨种子实测 sd 比,不是严格同分布对照;结论「两者重合」
  是量级结论,不是精确等式。
- 4.1 的 +59.3 gpm/min 是**局均 gpm 对 duration** 的斜率,含「强队拖长局」的反向因果,
  不能当作因果效应读;但 4.2 的结论**不依赖**它是不是因果(局内差抵消是构造性的)。
- 78 个文件来自 `spot_20260820_180808_1_11a8de33…` 单个 run,没有跨 run 合并,
