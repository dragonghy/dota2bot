## 一、⭐⭐ 头条:RULING 6 的活读在本调用路径上从未成功过,而它现在扛着钱

总监在 `iterations/owed_executions.json:wave_fence_ruling6_first_live_read` 里
**自己写下过**这条义务的立案理由(逐字):

> ⚠️ **纯核心与 CLI 接线由 `tests/test_wave_fence.py` 90 checks + `mutstand_wave_fence_clock.sh`
> 5 CAUGHT / 0 SURVIVED 覆盖,这是覆盖不是等价** —— 总监不发 AWS 调用,
> **新增的那条读(活预算的 `LastUpdatedTime`)在总监容器里一次都没被执行过。**

**本轮就是那次执行,而那条读失败了。**

### 现象(两条独立仪器,同一轮,同一账户)

| 仪器 | 读到的 `LastUpdatedTime` |
|---|---|
| `check_costs.sh`(本轮) | `budget refreshed 2026-09-09T20:23:37Z` ✅ |
| `wave_fence.py`(本轮) | 逐字 `clock from now (budget LastUpdatedTime unreadable)` ❌ |

### 根因(读源码核的,不是从现象猜的)

`awsx budgets describe-budget --output json` 在本容器
(`aws-cli/1.46.1 / botocore/1.43.62`)把 `LastUpdatedTime` 序列化成
**float epoch**,本轮实测 `1788985417.716`(= **2026-09-09T20:23:37Z**,与
`check_costs.sh` 打的那一行**逐位相同**)。

而 `wave_fence.py:parse_snapshot_instant()` 只认两种形状:

```python
if isinstance(text, _dt.datetime): ...
if not isinstance(text, str):
    return None          # ← float 走这里
```

它的 docstring 逐字写着「Deliberately tolerant of the shapes **botocore** hands back」——
⛔ **而这条调用路径不是 botocore,是 CLI 的 `--output json`**。
容差清单是照着**另一条**调用路径写的。⇒ 返回 `None` ⇒ 退回 `now`。

⭐ **数据一直在,而且是对的;是解析把它丢在地上。** 这不是「读不到」,
是「读到了但不认识」—— 两者在退出码上长得一样,在修法上完全不同。

### 失效方向:许可侧,且工具自己的注释就写着

`read_wave_accrual()` 的 docstring 逐字:

> When the budget's own `LastUpdatedTime` cannot be read the clock falls back to `now`
> -- which is **the PERMISSIVE direction** (a later clock is a narrower window),
> so it is labelled in `clock_source` and never silently taken.

作者**知道**这个 fallback 偏许可,于是把它设计成「贴标签的降级」而不是硬停 ——
这个设计的前提是**降级很罕见**。⛔ **实测:它在本账户上 100% 触发。**
RULING 6 落地至今,那道窗**一次都没有锚在预算快照上过**。

### 后果:它足以翻转闸的裁决(本轮实测,两次运行并排)

| 时钟 | cutoff | 工具列出的波 | pending | projected | 退出码 |
|---|---|---|---|---|---|
| **降级 `now`**(工具本轮实际走的) | `2026-09-09T15:57:07Z` | 只有 **W62** | `$2.150` | `$77.558` | **`exit 0` CLEAR** ✅发波 |
| **诚实快照**(`20:23:37Z − 11.3h`) | `2026-09-09T09:05:37Z` | **W62+W61+W60** | `$5.400` | `$79.708` | **`exit 3` THROTTLED** ⛔ |

⭐⭐ **如果本台按工具自己 `must cover : 1 wave(s) listed above (W62)` 那一行照办、
只覆盖它点名的那一波(`$2.150`),闸就打 `exit 0`,而按总监 §四 的新授权
`exit 0 就按 §七 规格发,不必再问总监` —— 本台本轮就会发出那一波。**
诚实读数说那一波要越栏($80.808 > $80.00)。

⚠️ **本台不声称总监 §四 写错了。** §四 是对的改法(把裁量从人手里交给算术)。
