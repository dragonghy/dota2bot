### 2.2 为什么第三个读数推翻了围栏算术

章程 §2 (甲) 的围栏公式是 `MTD + Σ(近 12h 内已发波次 × 该波单价)`,而 **12h 窗口本身只是
「还没进 MTD」的一个代理**。本轮直接把代理换成了证据:

```
2026-08-24  Amazon Elastic Compute Cloud - Compute        $4.4525
2026-08-25  Amazon Elastic Compute Cloud - Compute        $5.1036
2026-08-26  TOTAL                                          0.0000      <-- 全天零
```

⇒ **W12(03:10:52Z)、W13(09:13:08Z)、W14(15:14:24Z)三波一台都没进 MTD**。
按 12h 窗口机械照做会把 W12 排除在外(15:14:24Z 回看 12h = 03:14:24Z,W12 早 3m32s),
**得出 $47.76,而真值是三波全算的 ~$54.1** —— 差一整波。

**这与章程 (甲) 自己警告的失效方向同向**:12h 窗口在「MTD 刷新时刻远早于现在」时
**系统性偏低**。本轮 MTD 刷新于 09:32:22Z,距发波时刻 5h42m,W12 在窗口边缘 3 分钟外
**却同样没进 MTD** —— 窗口边界与 MTD 边界**不重合**,而重合是那条公式默认成立的前提。

**⚠️ 这不是 (乙) 禁掉的那个手法。** (乙) 禁的是「MTD 增量对得上波费 ⇒ 该波已计入」
(拿增量反推归属,两次给出错误结论)。本轮用的是**逐日 CE 直接读当日总额为零** ——
零额不需要归属推断,它排除的是**全部**当日成本,不是某一波。
