## 4. 交付二:**「保留语料」在成本上已经不是一个问题了 —— 现在是量出来的**

**(a) 整个 S3 桶的存储费 = $0.31/月。** `.dem` 占 8.79 GB / 13.7 GB 计费量 = 64%

量级参照:**$0.20/月 = 闲置日总开销的 4.6%,= AMI 快照那一行的 1/20**。

**(b) 活跃日上,S3 的请求费比存储费还高。** 08-20(收割日)按 `USAGE_TYPE` 拆:

| 行 | 数量 | $ |
|---|---|---|
| `USW2-Requests-Tier1`(PUT/LIST,实例上传 + 我们 ls) | 4,691 | $0.02346 |
| `USW2-Requests-Tier2`(GET,`recover_verdict.py` 全量下载) | 38,159 | $0.01526 |
| `USW2-TimedStorage-ByteHrs` | 0.53 GB-Mo | $0.01212 |
| | | **请求合计 $0.0387 = 当天 S3 账单的 76%** |

⇒ **一次全量收割的请求费($0.015)约等于整个 `.dem` 语料 2-3 天的存储费。**
换句话说:**我们读语料比存语料贵**。这把 §Z.4 的结论钉死成一句可引用的话 ——
**退役 `.dem` 不是成本决策**;若真有人想省 S3 的钱,该看的是重复全量下载,不是保留期。
