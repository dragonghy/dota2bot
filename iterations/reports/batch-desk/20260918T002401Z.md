### 3.4 ⭐⭐⭐ 机制:裁判的自动投降 + `natural_end` 的判据被它满足

`tools/batch_test/soak/referee.py` 的合同,**它自己的 docstring 逐字**:

> "the game is locked to 30 game-minutes; the **ECONOMIC leader at the cap is the winner**."
> "Which team the engine credits is **irrelevant**: `analyze_log.py` **overrides** the winner
>  for capped games with the economic leader computed from the signout scoreboard."

它的结束手法(`referee.py:173-180`)**不是**推遗迹:

```

rc.cmd("dota_auto_surrender_all_disconnected_timeout 1")
```

—— 一次**自动投降**,而 engine 把它写成 `goodguys_fort destroyed` + `Winning team = 1`。

而 `tools/batch_test/soak/analyze_log.py:94-104` 的分支**第一个问的就是 fort**:

```python
fort = next((t for t in base.get("towers", []) if str(t.get("building","")).endswith("_fort")), None)
natural_end = fort is not None
winner_by = "engine"
if natural_end:
    winner_by = "engine_natural"                      # ← 裁判的投降落在这里
elif ... and dur_min >= cap_min - 0.5:
    base["winner"] = econ_winner                      # ← 裁判合同依赖的那次覆盖:永不执行
```

⇒ ⭐⭐⭐ **裁判的合同从 cap 改成 25 的那天起一次都没有被执行过。**

⚠️ **这不是没人想过** —— 同一处的注释逐字写着两个 case「在 cap=10 上是同一个集合、在 25 上会分开」
(`At SOAK_CAP_MIN=10 this was nearly a constant false ... At 25 they come apart`),

reasoning is allowed to overwrite one`」。

而裁判造的正是一个遗迹。⇒ 这条与 `pullcad`「promote 一个 id 会静默冻死引用它的 gate」同族:
**门在,判据被结构性地绕开,而且绕它的正是本该被它挡住的那个东西。**
